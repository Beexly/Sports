# Assets

| File | Use |
|---|---|
| `logo-mark.svg` | Reticle mark only. `currentColor` — set via CSS color. Use at 32–96px. |
| `logo-lockup.svg` | Horizontal lockup: mark + "Galaxy Sports Edge" wordmark. Use in nav, marketing. |

Both are vector and inherit `currentColor`, so they can be tinted bone, signal, or ink as needed.

## Clear-space rule

Treat the mark's outer ring as `1x`. Clearspace around the lockup is `0.5x` on every side.

## Don't

- Don't recolor the wordmark to a different family.
- Don't add gradients, glows, shadows, or rotation to the mark.
- Don't place the mark on busy imagery without a 100% scrim.
- Don't separate the mark from its wordmark closer than the clearspace rule.
