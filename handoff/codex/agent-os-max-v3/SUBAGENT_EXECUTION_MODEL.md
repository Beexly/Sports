# Subagent Execution Model

Subagents remain governed design constructs in this slice.

- JARVIS and PRISM are the only agents marked as able to spawn subagents in the typed registry.
- No subagent may publish, deploy, spend, send externally, scrape protected sources, enable public gates, or change model weights.
- ASCEND is represented as the standing subagent seat but remains NOT_WIRED.
- Any future subagent execution must route through task gates and owner/Claude review where required.
