# Cockpit Operating Map

Implemented `apps/web/lib/cockpit/cockpit-operating-map.ts` mapping 24 cockpit surfaces to owner agents, supporting agents, workflows, gates, risk, audience, and next executable build.

Public-adjacent surfaces carry review gates. Spend-gated surfaces require owner approval. Data surfaces involve TAL/source governance. Calibration/result surfaces involve AUDIT or LEDGER. Memory belongs to ARCHIVE. Market Twin belongs to DELTA.
