# Failure Memory

## Product and architecture failures not to repeat

- Cosmetic progress is not product progress. Real data on screen with receipts outranks animation, boot sequences, and galaxy effects.
- Do not merge stale feature branches wholesale. Reproduce the invariant on current main, test it, and close the stale branch with a receipt.
- Do not create a second router, ledger, evidence truth, or event store beside an existing canonical path.
- Do not let raw confidence impersonate win probability or calibration input.
- Do not let PUBLIC serialization contain raw confidence, paid picks, line movement, factor trails, draft autopsies, raw model output, or source payloads.
- Do not dress DB outages as empty slates, collecting calibration, missing games, or zero records.
- Do not let illustrative fantasy/news/persona objects inhabit live public framing.
- Do not infer a close from an old quote, a team side from prefix matching, or a decision threshold from a nearby score.
- Do not replay outcome knowledge into the pregame evidence record.
- Do not describe observed transitions as causes.

## Operational failures not to repeat

- Preserve unknown workspace artifacts; never use `git add -A` in this mixed worktree.
- `gh` authentication disappeared after restart even though git push and the GitHub connector worked. Use the connector for PR metadata/mutations; do not claim a CLI-authenticated state.
- The OMO Git Bash wrapper repeatedly returned `Transport closed`; native PowerShell and raw git were the reliable fallback.
- Bun was absent. The plugin no-excuse checker also could not resolve TypeScript from its own path. A temporary patch-created CommonJS wrapper executed the exact checker with repository TypeScript, then was deleted.
- Next dev logs a missing auth secret unless a local non-secret placeholder is set. Browser-console results and server logs are distinct evidence.
- A renderer fixture proves UI behavior only. Delete it before commit and label screenshots as renderer-only.
- Build with an unreachable non-secret DB is a fail-closed compile test, not a live DB test.
