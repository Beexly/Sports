## What this pack is

The execution record for the Frontier program: truth reconciliation, R&D Radar
(Resource Intelligence 2.0), Agent Foundry, AI Setup Assurance, and the shadow
Model Portfolio Router. Every workstream ships additive modules behind flags
that default off, produces evidence before completion claims, and leaves
irreversible actions to the owner.

## Standing rules honored throughout

- No researched external repository is installed, cloned, vendored, or executed.
- No production migration, deploy, external publication, or merge of frontier PRs — owner-gated.
- No secrets in any artifact. No method exposure (factors, weights, thresholds, gate logic stay sealed).
- Shadow-mode work never alters production behavior.
- Statuses are never promoted on code existence alone.
