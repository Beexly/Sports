## 2. The One Truth that makes this real

> **Galaxy Dynasty's first real incarnation is a persistent, web-based
> sports-intelligence world — not a 3D open-world game. The 3D open world is the
> *funded endgame*, not the *starting build*.**

- A true 3D open-world MMORPG is a hundreds-of-people, multi-year, eight-or-nine
  figure category. It cannot be built autonomously in one pass.
- **The web-based persistent world captures ~90% of the magic at ~1% of the
  cost** — identity, skill progression, cards, crews, factions, prediction
  battles, PvM bosses, the economy, the loop. Fully and autonomously buildable.
- The move is **build the trunk** — the playable web world — and grow every
  later system (and eventually a 3D layer) out of it. The slice is not a smaller
  dream; it is the first executable increment of the same full dream.

## 4. What v2 contributes (the value-add)

### 4.1 The Calibration Engine — making "Sports IQ" mechanically real

**Sports IQ skills level through real, graded outcomes scored for calibration —
through the existing GSN/GSE engine (Brier scoring, closing-line value, the pick
lifecycle state machine).** Every reading is a prediction plus a stated
confidence; the engine grades it; your skill XP reflects not just *being right*
but *knowing how right you were*. A "Level 87 Football Scout" is therefore
**earned proof of demonstrated skill** — unbuyable, unfakeable.

- Connects every game action to GSE (website = brain, game = body).
- Makes leveling *useful grind*, not fake grind.
- Anti-pay-to-win guarantee: buy cosmetics and tools, never skill.
- The **Signal Check** is its atomic unit — a quick, skill-based, engine-graded
  decision moment, reused everywhere.

### 4.2 The Credit Constitution (the un-casino, in ink)

A bright line, enforced **architecturally**, never crossed:
1. No Galaxy currency (Credits, Nova, Vault Balance, Prestige) ever converts to cash.
2. No currency is ever the *stake* in a real-money wager.
3. The line is enforced in code, not just policy — crossing it must be hard.
4. Real-money monetization is **cosmetics, subscription, marketplace fees,
   achievement-gated merch, and lawyer-gated skill-tournament entry only.**
5. The sportsbook bridge is **routing, not funding** — credits never become
   betting money.

**Why this is law:** the sweepstakes "redeemable value" model is being dismantled
state-by-state. We do not build on a collapsing foundation. The closed loop is
also a **security feature**: when credits have no cash value, there is almost
nothing worth cheating for.

### 4.3 Integrity, trust & wellbeing tenets (binding)

- **Transparent, auditable grading with a real appeals path from day one.**
- **Skill-tiered ladders.** Casuals climb against casuals.
- **Anti-ghost-town seeding.** The solo spine is complete with zero other
  humans; the early world is seeded with **AI opponents / Ghost profiles**.
- **Wellbeing as a feature:** streak insurance, session-health awareness, no
  manipulative dark patterns, no fake scarcity, no "lock"/certainty language.

### 4.4 The honest build boundary

| Buildable autonomously now (web) | Needs a human / partner / funding / counsel |
|---|---|
| Profile, avatar shell, archetypes, factions | True 3D open-world city + netcode |
| Sports IQ skills + calibration engine integration | Physical card custody/grading/shipping |
| Core loop, Signal Checks, confidence-scored predictions | Real-money / wagering / cash redemption |
| Async PvP duels, PvM bad-logic bosses | KYC / AML / age-verification at scale |
| Card *collection* surface + digital companion data | Sportsbook partner integrations |
| Galaxy Credits ledger (closed-loop) | Live creator payouts / cash settlement |
| Crew/faction shells, clubhouses (web) | Enterprise B2B data contracts |
| Cosmetics (Nova, test mode), merch + subscription hooks | Mobile-native app builds |
| Higgsfield asset pipeline, admin dashboard, Galaxy Engine v0 | |

The build serves the whole left column autonomously and *stubs + roadmaps* the
right column. It never fakes the right column.

### 4.5 The autonomy protocol

Work fully autonomously; decide, log to `DECISIONS.md`, proceed. **Hard-stop only**
for the four irreversible-harm conditions:
1. **Real money / payment go-live** (Stripe stays in test mode).
2. **Destructive or irreversible data operations.**
3. **Legal / compliance / IP commitments.**
4. **Runaway third-party spend** (API/compute beyond a set ceiling).

> engine) → XP / Credits / skill level → Card / Reward → Crew / Faction progress

## 8. Build order (mapped to the real stack)

Stack: **Next.js / TypeScript, Prisma / PostgreSQL, Stripe (test mode), The Odds
API, the existing GSN/GSE grading engine, Higgsfield MCP** for assets.

- **Stage 1 — Rookie Season (the slice):** prove the core loop. *(This build.)*
- **Stage 2 — Signal Cup:** weekly retention, ranked PvP, Crew Clash, 5 PvM
  bosses, Season Program, marketplace prototype, GSE Pro prompts.
- **Stage 3 — Vault Season:** real card marketplace *(custody = partner-gated)*.
- **Stage 4 — Dynasty War:** faction territory, raids *(real money/KYC = counsel-gated)*.
- **Stage 5 — Galaxy Live:** AI-operated world, live-ops, Higgsfield queue.
- **Stage 6 — The endgame:** mobile, deeper world, partnerships, *and — if and
  when funded — the 3D open-world layer.*

Build the loop first. Then everything plugs in.

## 9. North Star & guardrails

- **North Star: Daily Sports Identity Growth** — every day a user leaves with at
  least one of {Sports IQ, character level, collection, crew status, faction
  standing, prediction record, creator reputation, merch access, GSE usage,
  reward wallet, public profile} improved.
- **The honest underlying metric: calibration improvement over time per active
  user.** People get better, stay because they're getting better, and the
  product is honestly good for them.
- **Guardrails:** session-health distribution, grading-dispute rate, social-layer
  fill rate before each wave, credit-redemption liability.
