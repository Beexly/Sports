# INGESTION LEDGER — 2026-10-15

Garrett's doctrine, operationalized: **all signals get ingested.** The engine is a reasoning engine; the equation gates (CRPS / frozen filter) are the bare minimum floor, never the intake filter. Gates rule **emission and promotion only — never knowledge.** A refused signal keeps its refusal as a status *inside* the engine, available to the reasoning layer; refusal is never exile. Order of operations: ingest first (a stamped home for every census row), diagnostics second, promotion last.

Every census row gets four independent determinations:

1. **INGESTION HOME** — where the signal lives for the reasoning layer: a situational-graph edge family, a named shadow ledger, a stamped reasoning template, the calibration substrate, the negative registry (refusal preserved as in-engine status), or NO HOME YET.
2. **STAMP DISCIPLINE** — the timestamp / PIT fields ingestion requires, and whether current sources supply them (YES / PARTIAL / NO + the gap).
3. **REASONING AVAILABILITY** — whether Layer 2 can invoke it today: **YES** (live edge/surface), **QUALITATIVE** (invocable in authored reads / readable shadow data), **FENCE** (operative as a gate — it can veto, never assert), **REFUSAL-ONLY** (Layer 2 may cite the refusal as knowledge, never invoke the construct as a signal), **NO** (dark until a named build lands).
4. **EMISSION STATUS** — recorded strictly separately. It never blocks columns 1–3. Fleet-wide state: **ZERO_OBJECT** (emission hard-coded zero; RVC NOT_CLEARED).

Machine-readable twin: `intelligence/ingestion/ingestion-ledger-2026-10-15.jsonl` on branch `motif/ingestion-ledger-2026-10-15` (Beexly/Sports), one object per row: census_id, name, home, stamp_required, stamp_available, reasoning_available, emission_status, source_doc.
