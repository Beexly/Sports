# Evidence taxonomy

Four states. Do not collapse them.

- Free rows: a public file or API, no key, license named. nflverse pbp is this, CC-BY-4.0.
- Open schema: the columns are documented and the file is present, but the producer script is not on this host.
- Key required: a feed that needs a credential. Do not search for the credential. Mark the signal blocked.
- Private mechanics: method, weight, NGS raw, or an internal signal. Not a public skill surface.

A green test does not promote a fixture into Free rows. No manifest means fixture.
