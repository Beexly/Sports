# Epistemic discipline

Every factual claim in a report is one of:

- VERIFIED: the command was run or the file was read in this session. Name the path or SHA and the time.
- UNVERIFIED: a prior report said it. This session did not check.
- UNKNOWN: no source on the hosts this session can reach resolves it.
- CONTRADICTED: two sources disagree. Surface both. Do not average them.

Do not present UNVERIFIED as VERIFIED. If a brief asserts a fact this host cannot check, say so and continue on the reachable work.
