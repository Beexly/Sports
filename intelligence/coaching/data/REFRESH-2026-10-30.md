## Method
- pbp + injuries fetched from the exact URLs recorded in parquet-pins.json /
  injuries_2026.manifest.json (nflverse-data releases). Two independent
  downloads produced identical sha256 for both files.
- Schema check: pbp column set identical before/after (372 columns, zero
  dropped, zero added); injuries columns identical. Safe for existing consumers.
- schedule.csv: the nflverse games.csv release URL returns 404, so the 2026
  slice was derived from the refreshed pbp itself — distinct REG games,
  team-perspective row pairs (season, week, team, opponent), matching the
  file's existing convention (played weeks only; the old slice carried weeks
  1–3, not the full future schedule). 2022–2025 rows untouched (verified equal).
