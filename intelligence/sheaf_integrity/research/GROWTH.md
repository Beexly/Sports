## B. Math / theory routes (research, not API surface)

### B1. Discrete Ambrose–Singer for SO(2) graphs
**Claim:** On finite graphs with SO(2) maps, holonomy group is generated by face/cycle curvatures; no extra global invariant.
**Test:** Prove for planar embeddings; counterexample search on non-planar K₅ minors with random angles.
**Why it matters:** Justifies “cycle basis is enough” for structural class.

### B2. Relative CRC as a cone, not a sheaf
**Claim:** Ledger grounding is a *pointed* comparison (cone), not another sheaf cohomology group.
**Test:** Formalize in CRC_S note; show value-diff alone cannot distinguish coordinated vs noisy mismatch (already in fraud_synthetic).
**Paper angle:** “Relative consistency for multi-source identity.”

### B3. Surgery ≠ feedback edge set (abelian monodromy)
**Claim:** Already documented in SURGERY_VS_FES.md — keep formal counterexample in tests.
**Test:** Unit test that FES size ≠ surgery edit count on a fixed fixture.
**Status:** Research note exists; promote to test.

### B4. Persistence of relative fraud under edge noise
**Claim:** Adding weak non-critical edges should not flip structural→consistent or erase relative fraud.
**Test:** Start from Alice VIP plant; add random “associated” edges; relative status stable.
**Kill:** If weak edges systematically destroy signal (then relation policy is mandatory).

### B5. Sheaf Laplacian vs connection Laplacian
**Claim:** For identity maps, energy Laplacian = graph Laplacian ⊗ I_d; for SO(2), it is the connection Laplacian.
**Test:** Numerical equality on identity case; deviation when θ≠0.
**Engineering:** One code path for both.
