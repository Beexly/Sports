# What the branch list does not show

Checked 2026-09-21 against GitHub, not against a remembered count.

Beexly/Sports has 442 branches (API Link header, last page 442) and 843
pull requests (last page 843). This clone tracks 443 remote refs and 56
local branches. A claim of 980 branches was not what GitHub returned.
843 pull requests plus 442 branches is a larger history than 980, and
almost all of it is opaque `claude/` slugs (187 of the remote names).
Branch names are a bad index. The work is in the PR titles and in
packages that never became a ledger row.

I did not open 187 claude branches one by one. I did not open the 96
Sports-* clones Mimo measured on disk. Those clones can hold commits
that never reached origin. That is a real gap. A clone diff is a later
pass. It is not an excuse to ignore what is already on origin.

## The miss is not another EPA variant

The engine conversation has been about NFL team sides. The repo is a
platform. These are already built and under-called.

Props. Thirty-three pull requests mention props. `props-hb.ts`,
air-versus-YAC, aDOT and separation, and a rest/weather context bind
are in `edge-lab/`. Fit them on prior seasons. Play-by-play 2019-2026
is already gzipped in the lab. Player yards and touchdowns are in those
releases. Our thin published NFL slate is the honesty surface, not the
training set. The missing half for a closing-line test is historical
prop prices, not historical outcomes. Fetch the prices from a source
whose terms allow it. Do not say we cannot price this Sunday because
the brand is new.

Market microstructure we measured and then scored backwards. Book depth
is rewarded with confidence points and, on MLB spreads, points the wrong
way. `consensusPct` is pinned on run lines, so the copy credits agreement
that is structural. In-play rows hit about 20 points higher because the
price already contains the outcome. Kalshi-versus-books, Kaunitz
outliers, and close-distillation are files. They are a second price and
a label, not a reason to freeze the ledger. They are catalog rows now.
Closing-line value remains a column. It is not the lock.

Fantasy is a second composite, not a side quest. Eight fantasy pull
requests against thirty-three prop pull requests. GSE score, ownership,
and salary value are the player-facing engine. If trade, draft, and
waivers do not read the same vector, we are not one product. They are
catalog rows. Sample data still has to leave the nav. That is honesty,
not a cut.

Same-game dependence. One parlay pull request, and `correlationAdjuster.ts`
already evaluates a score grid. A world-class card that treats legs as
independent is a known lie. The dependence model is the row. It does not
wait for a new paper.

Baseball is most of the published record and was missing from the first
catalog. Statcast loaders exist (`findBatter`, `findPitcher`). They are
rows now. Park, umpire, and platoon are the next baseball observables
once a cleared column is named. They are not invented tonight.

The lab already computed a second NFL and never handed it to the ledger.
Special teams and hidden yards. Kicker make rate by distance. Drive
outcomes. Early-down versus late-down. aDOT and CPOE. Pressure created,
not sacks. Those CSVs are in the research workspace. They are catalog
rows now, values still unfilled until the populator reads the files.

## Product lanes that are not pick factors

Forcing these into a win probability would fake the composite. They are
how a frontier shop is seen and trusted. They are under-valued if the
plan only talks about signals.

- Glass ledger and `recompute` — the record anyone can check. A schema
  change for the hash chain was flagged as founder-owned. Do not sneak it.
- Quote plane, stats API, partner stack, B2B v1 — a second business.
  Three pull requests already touched entitlement leaks. The product is
  the settled vector, not a dashboard.
- `gse-ml-service` — a Docker model service on disk, not in the catalog,
  not in the shadow cron. It is a serving lane for the fitter, not a
  fifty-first hand-weighted feature.
- Formal heartbeat and formal regression on the salvage branch — proof
  machinery. Use it to certify Book B. Do not market it as a pick.
- Feature store — an as-of store was the handoff's first requirement,
  and a registry file is sitting untracked in this worktree. That is
  the populator's home. It is not a new idea.
- MCP / public proof — the capstone's distribution bet. The measurement
  is the moat only if the page shows n, exclusions, and both books.

## What I will not pretend

I did not review 980 branches. GitHub does not have 980 branches.
I did not score the 96 local clones. I did not add a nutrition row.
There is still no calorie column, and a guessed one would be a fraud.
NBA rest is still an acquisition, not a number. Broadcast tracking stays
out until the license is real.

A signal we cannot compute stays named here, not stubbed as 0.5.
