#### Two bugs I found and fixed in `intelligence/reasoning_engine/emit_slate_board.py`
1. **Week-stamp bug.** `slate_games()` returned only games, and `reason_game()` defaults to
   `week: int = 4`. So Layer 1 odds came from the ESPN slate while Layer 2 team state was computed
   at **week 4** — every emitted `game_id` ended `-w4` even on a week-6 run. The emitter now reads
   `week`/`season` from the ESPN payload and stamps them through. **This is the kind of defect that
   silently degrades every card without failing any test** — Section 5 counts cards, not correctness.
2. **`?dates=` fetch bug.** Passing `--date` fetched a single day and the payload carries no
   `season` key, so the board stamped `season=0`. The CLI now supports `--week N`, which fetches
   `?week=N&seasontype=2` — the **full week slate plus `teamsOnBye`** — and falls back to season 2026
   with an explicit note in the board's `gaps` rather than silently reasoning season 0.

Also added `home`/`away`/`matchup` keys to each per-game doc (they previously carried only `game_id`,
so the board wasn't self-describing) and surfaced `byes` + `gaps` on the board.
