To switch to live: set DATABASE_URL, FORCE_REAL_PRISMA=true, unset DEMO_PICKS_ENABLED, run ingestion, wait for canonical settled picks.

To launch for real (in order):

1. Stand up real Postgres → set DATABASE_URL + DIRECT_URL, run npm run db:push to create the schema, npm run db:generate for the client.

2. Set FORCE_REAL_PRISMA=true and unset DEMO_PICKS_ENABLED in apps/web/.env.local.

3. Add THE_ODDS_API_KEY, STRIPE_SECRET_KEY + STRIPE_WEBHOOK_SECRET, GOOGLE_CLIENT_ID + GOOGLE_CLIENT_SECRET, ANTHROPIC_API_KEY.

4. Run the ingestion worker. Wait for the canonical settled pick count to reach 100. Jarvis will switch from NOT_READY_VALIDATION to LAUNCH_READY_PENDING_EXTERNAL_CONFIG to LAUNCH_READY.

5. Flip PERFORMANCE_STATS_ENABLED=true. Then git add -A && git commit -m "feat: launch-night observability" && git push.

6. Delete _overnight_quarantine/ from the workspace folder.

Live dev server: npm install && npm run dev from this folder with apps/web/.env.local containing DEV_FAKE_ADMIN=true, DATABASE_URL=stub, DEMO_PICKS_ENABLED=true, PUBLIC_PICKS_ENABLED=true. Then open http://localhost:3000/cockpit.
