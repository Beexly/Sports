# Definition Of World Class Done

Status: ACTIVE
Date: 2026-05-28

A surface is done only when it passes all gates below. A passing test suite is not enough.

| Gate | Required proof |
|---|---|
| Purpose | User understands why the surface exists within 10 seconds. |
| Next action | The page offers a safe, clear next step or explicit stop. |
| Trust | Freshness, source, actionability, uncertainty, and status are visible. |
| Evidence | Claims link to readable evidence without leaking protected methods. |
| Failure lens | The page says what could be wrong or why no action may be best. |
| Mobile | 390px and 430px experiences are usable. |
| Accessibility | Keyboard, semantics, contrast, focus, labels, and reduced motion are acceptable. |
| Performance | The surface meets preview Core Web Vitals expectations. |
| Design identity | It feels Galaxy-specific, not casino, generic SaaS, crypto, or AI sparkle. |
| Compliance | No certainty, tout, loss-chasing, fake live, or misleading monetization language. |
| Degraded state | Empty, loading, error, disabled, stale, and fallback states are intentional. |
| Runtime proof | Route, data, flags, kill switches, and rollback/probe path are documented. |
