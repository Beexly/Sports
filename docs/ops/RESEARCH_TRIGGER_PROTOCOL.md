# Research Trigger Protocol

Status: ACTIVE
Date: 2026-05-28

Agents must research current authoritative sources before acting when work depends on:

- Next.js route metadata, robots, sitemap, or App Router behavior.
- Lighthouse, Core Web Vitals, axe, WCAG, or browser support thresholds.
- Stripe webhook, checkout, billing, or refund behavior.
- Auth/session/security implementation.
- Vercel preview, env var, branch protection, deployment, or observability behavior.
- OWASP, NIST, AI RMF, LLM safety, privacy, or model-risk guidance.
- Data rights, legal/compliance, responsible gaming, or user-data handling.

Rules:
- Prefer official docs and primary sources.
- Cite source URLs in reports when research influences a gate.
- Do not use stale memory for unstable standards.
- Do not research as a substitute for repo verification when the answer is local.
