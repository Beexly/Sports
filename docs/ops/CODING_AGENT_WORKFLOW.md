# Coding agent workflow — research → PR

1. Read `AGENTS.md` laws + this file.
2. Pick one category from the P0 order in `CODING_AGENT_RESEARCH_WORKFLOW.md`.
3. Open only `docs/ops/research-by-category/<id>.md` — that is your paper list.
4. Implement inside `code_focus` paths until **Done when**.
5. PR title: `[cat:<id>] short description`.
6. Do not search arXiv; do not expand scope to other categories in the same PR.
7. Founder-only: Stripe catalogue, `PRICING_PHASE`, `MODEL_VERSION`, gate flips.
