# Platform Playbook

Updated: 2026-07-04

This playbook defines manual-review platform strategy. It does not approve auto-posting, auto-uploading, scraping, platform API integration, or paid tooling.

## Cadence Targets

- YouTube Long-Form: 2 videos/week target when production capacity supports it.
- YouTube Shorts: 1-2/day target when review capacity supports it.
- TikTok: 1-3/day if possible, used for discovery and hook testing.
- Instagram: Reels, carousels, stories, polls, and partner credibility.
- X/Threads: real-time commentary, founder voice, sports data thoughts, build logs.
- LinkedIn: B2B, partner, API, founder credibility, sports data business, AI governance.
- Newsletter: 1-2/week, owned-audience conversion spine.
- Podcast: future board meeting authority platform.
