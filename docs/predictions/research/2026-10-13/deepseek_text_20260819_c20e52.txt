Run the Real-Data Minimal Viable Experiment exactly once.

MVE Specification:
- Use the 241 clean-close MLB totals games.
- Market probability `m_t` = Shin-de-vigged no-vig over probability from the cross-book median at entry snapshot, at entry windows 24–12h, 12–6h, 6–3h, 3–1h before start.
- Build a hierarchical outcome model for total runs using only data available before each game date:
    * Team offensive/defensive rolling metrics from MLB Stats API.
    * Starting pitcher FIP/xFIP and recent form.
    * Bullpen recent usage (prior 3 days pitch counts).
    * Park factor.
    * Weather forecast from Open-Meteo.
    * Umpire plate zone history.
    * Rest days, travel, home/away.
- Model over probability `q_t` from the predictive distribution.
- Compute fractional e-process with λ = 0.3:
    E_t = 1 + 0.3 * (Y_t * q_t / m_t + (1 - Y_t) * (1 - q_t) / (1 - m_t) - 1)
- Group by game for any CV metrics. Report chronological capital path.
- Output final capital, max drawdown, crossing of thresholds 2, 5, 10, 20.
- If capital does not exceed 2 after all games, publish the kill and close the edge program.
- If capital exceeds 20, design a prospective pre-registered track with frozen rules, checkpoint cadence, certification threshold, and kill threshold.

Do not run more than one MVE cycle. It is the final experiment.
