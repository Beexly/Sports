# GSE NFL Optimizer Pattern Analysis

## Common Formats

| Pattern | Observed In | GSE Response |
| --- | --- | --- |
| Single-lineup quick optimize | FantasyPros, Footballguys, RotoWire, Fantasy Bullet | Offer a free quick-build mode with source badges and conservative assumptions |
| Mass multi-entry | RotoGrinders, FTN, Occupy, The Solver, FantasyPros, SlateDFS | Support controlled portfolio building only after legal import/export flow is approved |
| Simulation-first | SaberSim, Run The Sims, SportsLine, Stokastic, EdgeStack, Variance | Make world-state simulation a GSE core, but expose confidence and assumptions |
| Ownership/leverage | RotoGrinders, FTN, RotoQL, Stokastic, PropsOptimizer | Treat ownership as an uncertain market signal with source/freshness, not truth |
| Late swap | The Solver, Occupy, RotoQL | Prioritize side-by-side delta and source-triggered alerts |
| Stack/correlation controls | RotoGrinders, FTN, 4for4, Occupy, FantasySP | Build correlation as first-class world-state relationship, not only lineup rule |
| Custom projections | FantasyCruncher, FantasyPros, RotoGrinders, SlateDFS, Scry Pro | Allow uploads but store projection provenance and version labels |
| Free wedge | RotoWire, Daily Fantasy Fuel, DFS War Room, Fantasy Bullet, SlateDFS | Free tools should collect trust and habit, not give away founder formulas |
| Gamification | Fantasy Bullet, Rebet, social casino models | Use streaks, badges, quests and watchlists only if brand-safe and not exploitative |

## Where Competitors Are Weak

- Many optimizers hide source provenance.
- Many sell an optimal lineup without explaining the football story.
- Many rely on projections and ownership without showing freshness, uncertainty or source risk.
- Many are DFS-first and ignore season-long, best-ball, pick'em, social and content loops.
- Free tools can feel useful but lack trust, saved workflow, scenario depth and retention design.

## GSE Moat Path

1. Source-provenanced data layer.
2. Football world-state simulation.
3. Optimizer as one output, not the whole product.
4. Scenario lab and watchlists to retain users outside lineup-lock windows.
5. Founder-only alpha controls and public-safe explanation projection.
