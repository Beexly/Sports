# GSE Video-Game Analog Signal Map

## Guardrail

These are original GSE-derived estimates inspired by the usefulness of game-style ratings, not copied EA/Madden/NFL ratings, assets, marks, names, formulas, or official attributes.

## Strategy

- Use public performance data to create explainable archetypes and sliders.
- Show uncertainty bands instead of fake precision.
- Keep weights, transforms, and hidden features founder-only.
- Use game-like surfaces for comprehension, not as proof that the signal is official.
- Separate R&D proxies from production-grade features.
