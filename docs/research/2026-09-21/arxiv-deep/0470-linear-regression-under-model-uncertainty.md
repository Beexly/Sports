# [0470] Linear regression under model uncertainty (arXiv:2108.02140v1)

**Citation:** Shuzhen Yang and Jianfeng Yao (2021). *Linear regression under model uncertainty*. arXiv:2108.02140v1. URL: https://arxiv.org/abs/2108.02140v1
**Ledger completed:** 2026-09-21. **Read:** full text (PDF text extract, 8817 lines; main text + Appendices A–B proofs + references read sequentially).
**Verdict:** ADAPT — the moving-block min/max-MSE "Robust-LSE" estimator is a genuinely useful regime-robust regression diagnostic for NFL data; adopt the estimator mechanics, not the sublinear-expectation theory.

## 1. Research question
Can the classical linear regression coefficient β be consistently estimated when the model is subject to two simultaneous uncertainties: (i) some mean-relevant covariates are missing or inaccessible (unknown mean shift η), and (ii) the error variance is undetermined and changing by an unknown mechanism (unknown σ)? The paper uses sublinear-expectation theory (G-normal distribution) to characterize population-optimal parameters under min-max and min-min strategies, then builds a moving-block estimator with proven strong consistency.

## 2. Dataset / schema
No proprietary dataset. Three uses of data: (a) Monte Carlo simulation, data generation process (3.7): T = n0·K observations in K groups of size n0, y_i = βx_i + η_j + ε_i, η_j ∈ [0,5] uniform, σ_j ∈ [0.1,1] uniform, ε_i ∼ N(0,σ_j²), β=1, (n0,n,n1) = (200,150,20), T ∈ {400,800,1600,3200}, 500 replications; (b) contaminated Gaussian robust-regression benchmark (Y = X + ε, x_i = 1 + 0.01·i, 6 contamination scenarios ε ∼ N(0,1) for a_m·T samples and N(0,100) for the rest, a_m ∈ {0.95,0.90,0.80,0.85,0.70,0.60,0.50}, T=200, 500 replications, plus T ∈ {200,...,1000} consistency check); (c) heteroscedastic simulation K=10 groups with fixed σ list {0.6995,0.5851,0.3481,0.1304,0.7165,0.3344,0.4721,0.5211,0.1955,0.4851}, T ∈ {500,1000,1500,2000}; (d) real data: S&P 500 daily closing prices, Jan 3 2000 – July 17 2020, fit as AR(1).

## 3. Method / model
Model: Y = βᵀX + η + ε (1.1), where η is a nonlinear random variable capturing mean uncertainty (values in [μ̱,μ̄]) and ε follows the G-normal distribution N_G(0,[σ̱²,σ̄²]) capturing variance uncertainty; together they encompass an infinite family of classical distributions via the representation E[φ(ε)] = max_{θ∈Θ} E_θ[φ(ε)] (Θ = L² processes into [σ̱,σ̄]). Two population optima under convex loss φ: upper β̄*(φ) = argmin_β E[φ(Y − βᵀX − η)] (1.2, min-max) and lower β̱*(φ) = argmin_β −E[−φ(Y − βᵀX − η)] (1.3, min-min). Lemma 2.1: min-max = max-min and min-min = min-min (eqs. 2.3–2.4). Theorem 2.1 (main result): for convex φ, β̄*(φ) equals the classical optimum under N(μ_{θ̄_φ}, σ̄²) and β̱*(φ) under N(μ_{θ̱_φ}, σ̱²) — i.e., infinite-family uncertainty collapses to two classical normals. For square loss: U-LSE β̄* is the OLS optimum on data Y = βᵀX + μ_{σ̄} + ε′, ε′ ∼ N(0,σ̄²) (3.2); L-LSE β̱* on Y = βᵀX + μ_{σ̱} + ε′′, ε′′ ∼ N(0,σ̱²) (3.3); variances σ̄² = E_{σ̄}[(Y − β̄*X − μ_{σ̄})²], σ̱² = E_{σ̱}[(Y − β̱*X − μ_{σ̱})²] (3.4). Corollary 3.1: β̄* = β̱* = β under square loss. **Estimation (moving blocks):** scan T samples with m = T−n+1 overlapping blocks B_l of length n; per block OLS → (β̂_l, μ̂_l), block MSE σ̂_l² = (n−1)⁻¹Σz_i²; select k̂ = argmin_l σ̂_l²; β̂ = β̂_{k̂} (3.9), σ̱̂² = σ̂_{k̂}² (3.10); residuals w_i = y_i − β̂_{k̂}x_i, block means μ̃_l = n⁻¹Σw_i, μ̱̂ = min_l μ̃_l, μ̂̄ = max_l μ̃_l (3.8). Step 2 (upper variance): centralize w_i within small windows n1 (recommended 10/20/40), compute block MSEs σ̃̂_l² on centralized data, σ̂̄² = max_l σ̃̂_l² (3.11). Theorem 3.2: under the block-DGP (3.7) with (min η_j, max η_j, min σ_j², max σ_j²) → (μ̱,μ̄,σ̱²,σ̄²) as K→∞ and n0 ≤ n, as K∧n→∞ all estimators are strongly consistent.

## 4. Equations & assumptions
Model: Y = βᵀX + η + ε (1.1). β̄*(φ) = argmin_β E[φ(Y − βᵀX − η)] (1.2). β̱*(φ) = argmin_β −E[−φ(Y − βᵀX − η)] (1.3). Loss choices: φ(z) = z² (square), φ(z) = [α − I(z<0)]z (quantile), φ(z) = I(z ≤ 0) (VaR). Exchange: min_β max_θ E_θ[φ(Y − βᵀX − μ_θ)] = max_θ min_β E_θ[φ(Y − βᵀX − μ_θ)] (2.3); same for min-min (2.4). U-LSE: β̄* = argmin_β E[(Y − βᵀX − η)²] (3.1), attainable via N(μ_{σ̄},σ̄²) (3.2); L-LSE analog (3.3). σ̄² = E_{σ̄}[(Y − β̄*X − μ_{σ̄})²] = min_β E[(Y − βᵀX − η)²] (3.5); σ̱² = E_{σ̱}[(Y − β̱*X − μ_{σ̱})²] = min_β −E[−(Y − βᵀX − η)²] (3.6). Corollary 3.1: β̄* = β̱* = β. DGP: y_i = βx_i + η_j + ε_i, 1+n0(j−1) ≤ i ≤ n0j, η_j ∈ [μ̱,μ̄], ε_i ∼ N(0,σ_j²), σ_j² ∈ [σ̱²,σ̄²] (3.7). Estimators: k̂ = argmin_l σ̂_l²; μ̱̂ = min_l μ̃_l, μ̂̄ = max_l μ̃_l (3.8); β̂ = β̂_{k̂} (3.9); σ̱̂² = σ̂_{k̂}² (3.10); σ̂̄² = max_j σ̃̂_j² (3.11). Sublinear expectation axioms (App. A): E[X] ≤ E[Y] if X ≤ Y; E[c] = c; E[X+Y] ≤ E[X] + E[Y]; E[λX] = λE[X], λ ≥ 0; representation Theorem A.1: E[X] = max_{θ∈Θ} E_θ[X]. Assumptions: φ convex and locally Lipschitz (C_{l.Lip}); DGP block structure (3.7) with n0 ≤ n; group extremes converge to uncertainty bounds as K→∞; ε Gaussian within groups. Appendix A machinery: nonlinear CLT (Thm. A.2, Peng) — normalized sums under sublinear expectation converge to a G-normal N_G(0,[σ̲²,σ̄²]); the G-normal is constructed via the nonlinear PDE ∂_t u − G(∂²_{xx}u) = 0 with G(a) = ½(σ̄²a⁺ − σ̲²a⁻) (A.3)–(A.4), whose unique viscosity solution gives E[φ(Z_t+x)] = u(t,x). Proof of Lemma 2.1 (App. B.1): for convex φ the worst case is attained at the constant volatility process θ(s) = σ̄, yielding the min-max exchange min_β max_θ = max_θ min_β (B.1) and min-min exchange (B.3) — this is the exact justification for estimating β̄*/β̱* via single-distribution LSE at the extreme distributions. Proof of Thm. 3.2 (App. B.3): a block B_l overlapping two regime groups A_j has strictly larger MSE than a block inside one group (observation (ii) below (3.11)), so the min-MSE block k̂ identifies the min-variance regime: σ̂_{k̂}² → σ̲² a.s. as K∧n→∞, and (μ̱̂,μ̂̄) → (min_j η_j, max_j η_j) → (μ̱,μ̄).

## 5. Features / target
Inputs: q-dimensional deterministic covariate vector X (in the empirical applications: single regressor — lagged index level / scalar x). Target: univariate response Y (in applications: simulated y, contaminated regression response, S&P 500 level). Prediction framing is coefficient estimation, not forecasting per se; the AR(1) S&P application predicts X_{t+1} from X_t.

## 6. Validation design
No train/test split (theory + simulation paper). Simulation: 500 replications per configuration; compares Robust-LSE vs ordinary LSE (Tables 1–2) and vs MM robust estimator (Tables 3–4). Contamination study: 6 scenarios × T=200, 500 replications; MSE of β̂ vs MM and OLS. Heteroscedastic study: 500 replications, T ∈ {500,...,2000}. S&P 500: AR(1) fit on rolling 1-year windows (5 reported + all 20 years), compares R² and F-statistic of OLS vs Robust-LSE; no holdout — in-sample goodness of fit.

## 9. Leakage & limitations
Be adversarial: (a) the consistency theory (Thm 3.2) depends on the block DGP (3.7) with n0 ≤ n — if true regime lengths are shorter than the block length n, the min-MSE block straddles regimes and β̂ is biased; the paper recommends n < n0 but n0 is unknown in practice; (b) the (μ̱̂, μ̂̄) and (σ̱̂, σ̂̄) extremes converge only as K→∞ — with few regimes they estimate sample extremes, not the bounds, and max-MSE-based σ̂̄² is inherently noisy/upward-biased in small samples; (c) all simulations use Gaussian errors — the "infinite family" generality is theoretical; no heavy-tail stress test; (d) the S&P 500 application is in-sample R²/F only — no out-of-sample forecast comparison, and AR(1) on index levels is a nonstationary exercise where both estimators' R² comparisons are suspect; (e) the contamination benchmark's ε ∼ N(0,100) tail is symmetric noise, not leverage-point outliers — MM's breakdown in scenario 6 is partly a designed artifact; (f) NFL transfer risk: NFL game data has small T (17–18 games/season) — the method's block machinery needs hundreds of observations, so game-level use per team-season is underpowered; play-level or pooled use is required.

## 11. GSE implementation spec
1. **Regime-robust trend coefficients**: for pooled game-level regression (e.g., estimating offense/defense strength drift or weather-rest effects on margins), implement the moving-block Robust-LSE: rolling windows of n games (n ≈ 100–150 plays-games pooled across teams), OLS per window, take β̂ from the min-MSE window; report (μ̱̂, μ̂̄) and (σ̱̂, σ̂̄) as regime-uncertainty bounds. Data: nflverse 2020–2026 game-level table. Effort: ~1 day, ~100 lines of Python/pandas + numpy.
2. **Volatility-regime dashboard**: apply Step 2 (small-window centralization + max block MSE) to weekly engine residual streams (spread residuals) to estimate current high-volatility bound σ̂̄ — feed into bet-sizing as a regime-aware uncertainty input (pairs with the Kelly gap-list item #1).
3. **Serving**: diagnostics only; no inference change. Note: window hyperparameter n needs tuning against known regime boundaries (rule-change years, e.g., 2023 kickoff rule) rather than the paper's recommendation alone.

## 12. Reproducible test
Dataset: nflverse game-level 2020–2025, target = home-team margin; single-regressor pooled model: margin ~ closing spread (coefficient should be ≈1 in a well-calibrated market). Inject synthetic regime shifts (per paper's DGP): add group-varying mean shifts η_j ∼ U[0,5] scaled to points and group-varying residual variances σ_j ∈ [3,10] across K ∈ {4,8,16} regime blocks. Baseline: ordinary OLS on full sample. Metric: |β̂ − 1| and SE of β̂ over 200 replications. Rerun with the moving-block Robust-LSE (n=150, n1=20). Expectation per the paper: Robust-LSE smaller |β̂−1| and smaller SE for small K.

## 13. Acceptance / rejection gate
Adopt if: Robust-LSE reduces mean |β̂ − 1| by ≥ 20% relative to OLS at K=4 with T≈1000 injected games, AND the recovered (σ̱̂, σ̂̄) bracket the injected (3,10) bounds within ±1.5 points. Reject if: no material improvement (|β̂−1| within 5% of OLS) or block-length sensitivity is pathological (estimate flips sign across n ∈ {60,100,150,200}), indicating the DGP assumption (3.7) fails on NFL-style data.

## 14. Improvement experiment
Go beyond the paper: replace the paper's min-MSE single-block selection with a *regime-weighted* scheme — instead of discarding all blocks except k̂, weight each block's (β̂_l) by inverse block MSE (or softmax of −MSE) to form a variance-uncertainty-weighted pooled estimator, and compare its MSE to both OLS and the paper's hard-selection Robust-LSE on the same synthetic NFL DGP. Rationale: hard min-selection discards information and is jumpy; the sublinear-expectation theory only says the max/min extremes matter for the *bounds*, while a weighted average of blocks should better estimate β itself. If the weighted version wins, it also yields smooth regime-adaptive coefficients suitable for weekly engine updates.
