# [0439] A Fairness Audit of the Duckworth-Lewis-Stern Method: Format-Specific and Gender-Differential Bias, with an Interpretable Calibration Layer for Cricket Target Revision (arXiv:2609.04754v1)

**Citation:** Soumyadeep Roy (2026). *A Fairness Audit of the Duckworth-Lewis-Stern Method: Format-Specific and Gender-Differential Bias, with an Interpretable Calibration Layer for Cricket Target Revision*. arXiv:2609.04754v1. URL: https://arxiv.org/abs/2609.04754v1
**Ledger completed:** 2026-09-21. **Read:** full text (PDF text extract, ~810 lines).
**Verdict:** ADAPT — the cricket target-setting problem doesn't transfer, but the audit + interpretable calibration-layer methodology (state-conditioned residual correction on top of a deployed model, and the Win-Flip Rate thresholded error metric) ports directly to GSE win-probability/total calibration.

## 1. Research question
The paper asks: (i) is the Duckworth-Lewis-Stern (DLS) method's prediction error uniform across match states, (ii) does its bias differ between men's and women's cricket (one resource table governs both), and (iii) can a lightweight interpretable calibration layer placed on top of DLS reduce the structured bias? It is the first large-scale empirical audit of DLS as deployed (8,150 international matches), with a gender-differential fairness finding that the author states has not previously been documented.

## 2. Dataset / schema
- Cricsheet ball-by-ball data (public, https://cricsheet.org): 8,150 matches (3,095 ODIs, 5,055 T20Is; 5,708 men's, 2,442 women's), 2,781,465 ball records, date range 27 June 2002 to 5 March 2026.
- Synthetic interruption sampling: for every first innings of ≥30 overs (ODI) / ≥15 overs (T20I), 30 random interruption points sampled per innings (≥5 overs context + ≥5 overs remainder); supervision target = actual runs scored post-interruption. Yields 233,550 examples (train 140,160 / validation 24,300 / test 69,090). Temporal split: train ≤31 Dec 2022, validation 2023, test 2024 → Mar 2026.
- Dedicated held-out evaluation set: 417 real rain-affected (D/L-decided) matches from Cricsheet.
- All data and parsed YAMLs released by authors.

## 3. Method / model
Three DLS reconstructions: (D1) original published parameters (Z0ODI=245, Z0T20=145) via bilinear interpolation of the published resource table; (D2) recalibrated Z0 from training-period mean innings totals (246.1 ODI, 142.9 T20I); (D3) "canonical" reformulation blending current run rate with a format baseline (α=0.7 selected on validation). Five ML baselines: (M1) 2-layer Bi-LSTM, hidden 128, 6 ball features + 5 scalar context, 568K params; (M2) XGBoost, 10 hand-crafted features, 500 trees, max-depth 8; (M3) XGBoost-Plus, 16 features adding player career stats and run-rate×overs interactions; (M4) CAP-Net v2 (16-dim learned player embeddings frozen 2 epochs, Bi-LSTM ball encoder, fusion head, 491K params); (M5) stacking ensemble — ridge regression with non-negative weights over validation predictions of {DLS, LSTM, XGBoost, XGBoost-Plus, CAP-Net}. Proposed method: DLS-Cal, a 4-layer MLP (widths [18,128,128,64,1], GELU, dropout 0.25, 27,265 params, final layer zero-initialized) trained on Huber loss (δ=10) with AdamW (η=1e-3, weight decay 1e-4, batch 512, cosine annealing, ≤50 epochs, patience 8) to predict the DLS residual r − r̂DLS. Gender-aware variant: separate male/female DLS-Cal models, routed at inference. Hyperparameter search covered hidden widths {[64],[128,128,64],[256,128]}, dropout {0.1,0.25,0.4}, lr {3e-4,1e-3,3e-3}, Huber δ {5,10,20}, chosen by validation RMSE of the corrected prediction.

## 4. Equations & assumptions
- DLS resource model: cumulative resources Z(u,w) as a function of overs remaining u and wickets lost w; revised target proportional to resource fraction consumed. The paper reconstructs Z via bilinear interpolation of the published resource percentages (primary implementation) plus an independent parametric reconstruction as robustness check.
- DLS-Cal (eq. 1): r̂_{DLS-Cal} = r̂_{DLS} + Δ(x), where x ∈ R^18 = (DLS prediction, empirical training-set per-bucket bias prior, 16 enriched features).
- Win-Flip Rate (eq. 2): WFR_k(M) = (1/N) Σ_{i=1}^{N} 1[|r̂_{M,i} − r_i| > k], reported at k ∈ {3,5,10,15}.
- Key assumptions: (a) expected remaining runs proportional to resources consumed (DLS's governing assumption); the audit probes exactly where this fails; (b) synthetic-interruption sampling approximates the operational use of DLS (paper validates transfer on 417 real rain-affected matches in §5.4); (c) per-gender trained calibrators assume gender is a legitimate routing variable (policy considerations discussed §6.4).

## 5. Features / target
- DLS-Cal input x (18 features): the DLS prediction itself; the empirical training-set mean bias for the example's (overs, wickets) bucket (prior); 16 enriched features = the XGBoost-Plus set (player career stats: mean recent batter average and strike rate, recent bowler economy, average upcoming-batter quality; run-rate×overs interaction terms; current run rate, overs remaining, wickets lost, format, etc.).
- Target: residual r − r̂_DLS where r = actual remaining runs scored after interruption; equivalently r̂_DLS-Cal = r̂_DLS + Δ(x).

## 6. Validation design
Temporal splits (train ≤2022, val 2023, test 2024–Mar 2026) to prevent future leakage; all player-level stats computed from training period only. Baselines: three DLS variants + five ML methods. Metrics: RMSE, MAE, signed bias, format-stratified RMSE, WFR at k=5 stratified by format and interruption phase. Ablation ladder for the calibration layer (lookup vs linear vs MLP-without-prior vs full MLP). Inference robustness: match-level block bootstrap (B=2,000 whole-match resamples) for all audit intervals (accounts for ~30 correlated samples per innings); bucket-matched gender-gap estimate over 59 cells with ≥30 examples per gender; Full-Member-only team-strength stratification; rolled temporal windows (2021–2025 each held out). Second independent DLS reconstruction as robustness check.

## 7. Numerical results / baselines
- Test split (N=69,090), all lower-is-better (Table 3): DLS original RMSE 37.41 / MAE 30.54 / bias +17.40; DLS canonical RMSE 28.92 / MAE 22.61 / bias +7.57 (22.6% RMSE cut from original); Stacking RMSE 21.49 / MAE 16.19 / bias −0.20 (best RMSE/MAE); DLS-Cal gender-blind RMSE 23.72 / MAE 17.72 / bias −1.62. DLS-Cal achieves lowest ODI WFR5 of any method: 83.0% vs XGBoost 84.0%, Stacking 85.0%.
- Bias audit (training split): DLS mean error +4.79 runs (median +7.98); per-bucket mean bias spans −111 to +26 runs (ODI) and −19 to +25 (T20I) — a 137-run total span; ODI ANOVA F=527.16, Kruskal–Wallis H=9,797.69; T20I ANOVA F=1,540.14, H=9,609.67 (reported descriptively, non-independent samples).
- Gender gap (ODI, training split): men's mean bias +1.51 (N=60,660), women's +7.63 (N=10,350) → gap +6.13 runs; match-clustered 95% CI [+3.70,+10.07], bootstrap p(gap≤0)<0.001. Bucket-matched gap: +8.34 unweighted, +9.64 min-n weighted, 95% CI [+5.32,+12.29] unweighted / [+3.77,+10.26] weighted; sign test: women's bias exceeds men's in 55 of 59 cells. Full-Member-only gap +6.72 (CI [+3.38,+10.04]). T20I gap +0.51 runs, not significant under clustered inference (95% CI [−1.10,+2.12], p≈0.27). Second reconstruction gives ODI gap +7.80 runs.
- DLS-Cal bias reduction (test): mean |bias| ODI 33.74→23.29 runs (31.0% reduction); T20I 20.58→16.71 (18.8%). Gender-aware DLS-Cal on test (Table 5): women's residual bias +6.19→+0.65 runs (5.54-run cut); women's RMSE 22.92→22.11 vs gender-blind; men's calibration essentially unchanged.
- Real rain-affected matches (417): DLS under-predicts ODIs (mean bias −11.1 runs, RMSE 45.8), over-predicts T20Is (+8.7, RMSE 25.1) — corroborating the structural finding; perturbation grid (state ±5 runs, ±1 wicket) shows smooth monotonic bias drift.
- Temporal stability: ODI gender gap positive in 4 of 5 held-out-year windows (mean +6.20); 2023 window marginally negative (−0.39, CI [−9.45,+8.94]).

## 8. Code / data availability
Code, trained checkpoints, training logs, and the audit dataset released at https://github.com/sami42200/dls-cal/tree/main/repo; fixed seed 42; data from Cricsheet (public).

## 9. Leakage & limitations
- Synthetic interruptions are uniformly sampled over match states; real interruptions are weather/venue-shaped — distribution mismatch acknowledged; transfer validated on 417 real rain-affected matches but the gender gap itself cannot be resolved there (only ~1,290 women's ODI examples).
- The ICC's annually updated resource table is proprietary; the reconstruction may differ from official figures by a few runs (an order of magnitude below the gender gap, mitigated by the second independent reconstruction).
- Samples are non-independent (~30 correlated per innings); handled with match-level block bootstrap rather than naive tests (the paper's own original-submission Welch ANOVA result for T20I gap is explicitly superseded and retracted as an artifact).
- Gender finding is association, not causation; uncontrolled mechanisms (venue dimensions, ball type, era, data coverage) listed in §3.3; team-strength and era confounds controlled directly.
- Female DLS-Cal trained on 32,760 examples vs 107,400 male; learning curve plateaus (75%→100% of female data changes test RMSE by 0.03), so the female calibrator is data-limited.
- Weather, venue, dew, toss omitted as features. WFR is a proxy for outcome flips, not validated against actual flipped chases.
- External validity to NFL: DLS is a cricket-specific resource table; zero direct transfer of the cricket findings. The transferable parts are the audit methodology and the calibration-layer design.

## 10. GSE overlap
Per existing-research-map.md: GSE already has a calibration stack (CQR, grouping loss, temperature/Platt scaling, isotonic regression, Venn-Abers, LRD dashboards per 2207.13770, ECE-by-slice, conformal WP per 2208.08598, Mondrian/cross-conformal from the ML brief, and the "Auditing Conformal Prediction, Small-Sample Calibration, and Sports Market Probabilities for GSE" Deep Research report in Drive). DLS-specific findings (resource tables, cricket target revision) are a new domain with no overlap and no NFL transfer. What is NEW capability: (a) the "calibration layer on top of a deployed, opaque legacy model" framing — DLS-Cal corrects residuals of a fixed model rather than replacing it; GSE has not documented a post-hoc state-conditioned correction layer on the engine's own v5.2.7 outputs; (b) Win-Flip Rate — a thresholded-error fairness-style metric distinct from ECE/LRD, not in the repo inventory; (c) match-clustered block bootstrap inference on correlated samples — a rigorous inference tool not listed in the map. Verdict class: extension of the calibration lane with a new mechanism, not a duplicate.

## 11. GSE implementation spec
Build a "GSE-Cal" post-hoc calibration layer for the engine's spread/total/WP outputs: (1) assemble nflverse 2015–2025 pbp states at prediction time (score differential, time remaining, possession, down/distance, timeouts, timeouts, weather for totals); (2) compute per-bucket (score-bucket × time-bucket × weather-bucket × referee-crew, where data permits) empirical residual maps of engine predictions vs outcomes — the analogue of the DLS bias map; (3) train a small MLP/lightGBM residual corrector on ~18 features (engine prediction + bucket-bias prior + state features), zero-initialized final layer so it can only add value, Huber loss, temporal splits (train ≤2022, val 2023, test 2024–2025); (4) serve as an additive layer after the engine with versioned recalibration cadence; (5) parallel track: a "context-aware" variant routing by weather/venue/referee-crew analogue of the gender-aware variant. Data: nflverse + odds APIs (Odds API, de-vigged consensus); effort ~2–3 weeks for audit maps, ~2 weeks for the layer, ~1 week for WFR-metric integration into the weekly verification pipeline.

## 12. Reproducible test
Dataset: nflverse 2015–2025, engine (or a reference WP model) predictions vs outcomes. Baseline: the uncorrected model. Metric: RMSE/MAE of predicted vs actual total points + WFR at k∈{3,5,10} on point-total error. Time window: train ≤2022, validate 2023, test 2024–2025 seasons. Run the calibration layer vs no-layer comparison on the test window and report the bias reduction (percentage drop in mean |bias| per bucket, mirroring §5.3) and WFR deltas.

## 13. Acceptance / rejection gate
ADOPT the calibration-layer approach if, on the 2024–2025 test window: (a) the layer reduces mean |bias| per state-bucket by ≥15% on totals without increasing overall RMSE vs the uncorrected engine, and (b) WFR_5 improves by ≥2 percentage points vs baseline. REJECT if RMSE increases on the test window, or if the bucketed bias reduction is <10% (indicating residuals are already well-behaved), or if the residual map shows no statistically significant structure under block bootstrap by game (B≥1,000 resamples).

## 14. Improvement experiment
Beyond the paper: replace the static bucket-bias prior with a hierarchical Bayesian bucket model (partial pooling across sparse buckets, e.g., small-market stadium-weirdness cells) so the calibration layer is robust in low-n regimes — the paper's bucket lookup failed on tail examples (§5.2); partial pooling should beat both the raw lookup and the MLP in sparse cells. Also validate WFR against actual outcome flips (the paper leaves this future work): on NFL totals, test whether WFR_k with k matched to the pushed-margin distribution predicts real grading flips on real tickets.
