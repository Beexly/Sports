# [0365] Generalized Visual Relation Detection with Diffusion Models (arXiv:2504.12100)

**Citation:** Gao, K., Chen, S., Zhang, H., Xiao, J., Zhuang, Y., Sun, Q. (2025). *Generalized Visual Relation Detection with Diffusion Models*. arXiv:2504.12100. URL: https://arxiv.org/abs/2504.12100
**Ledger completed:** 2026-09-21. **Read:** full text (text extract, 5915 lines; body, experiments, references, appendix VLB derivations).
**Verdict:** ADAPT — the semantic-ambiguity framing and the generative (diffusion) approach to open-ended relation labeling are transferable design ideas for GSE's sports scene understanding (rich multi-label action/event vocabularies that escape fixed taxonomies); adopt it as a conceptual/secondary tool, not a production pipeline — 2,000 diffusion steps, 50 DDIM inference steps, and evaluation on HOI/SGG stills make it a research prototype, and the sports-transfer evidence is nil (person-ride-horse, not quarterback-releases-ball).

## 1. Research question
Can visual relation detection (VRD) be freed from pre-defined relation-category labels — overcoming the **semantic ambiguity** of relations (e.g., person–horse describable as "ride", "race", "sit on", "straddle" from different perspectives) — by modeling relations as continuous embeddings generated by a conditional diffusion model, then rounding them to discrete words from a large external vocabulary?

## 2. Dataset / schema
- **HICO-DET**: 37,633 train / 9,546 test images; 117 interaction categories, 80 object categories (HOI).
- **V-COCO**: 2,533 train / 2,867 val / 4,946 test images; 26 interaction categories (HOI).
- **Visual Genome (VG)**: 108,073 images; 150 object / 50 predicate categories under the standard split; 70/30 train/test (SGG).
- **Predicate vocabulary V**: 4,858 words/phrases built from image-caption verbs (POS tagger, frequency > 0.5, abstract verbs excluded) plus Stanford Scene Graph Parser predicate words; covers all annotated relation categories in the VRD datasets. CLIP-initialized text embeddings.
- Evaluation ground-truth labels remain within C_r (dataset categories) during training; testing uses V.

## 3. Method / model
**Diff-VRD** (two-stage): DETR detector → relation generation → bipartite matching.
1. **Conditional relation generation via diffusion**: extends DDPM with an embedding step q_φ(x_0|v) = N(x_0; Emb_φ(v), σ_0 I) mapping discrete relation words into R^d (d = CLIP dim, 512), and a trainable rounding step p_θ(v|x_0) = ∏ᵢ p_θ(v_i|x_0^(i)) (softmax over V). Denoiser f_θ is a 6-layer Transformer decoder (8 heads, hidden 512; 2-layer MLPs 2048) conditioned on CLIP visual features (subject/object/union boxes) + CLIP text features of object categories ("a photo of <object>") concatenated as y ∈ R^(N×d_y), injected via cross-attention: Q = φ_t(x_t)W_Q, K = τ_θ(y)W_K, V = τ_θ(y)W_V (Eq. 8). Sequence length L = 32 (CLIP pseudo-labels pad short GT sequences). T = 2,000 diffusion steps, 40,000 training steps, λ = 1.0, κ = 0.05, batch 128, lr 1e-4, 4×2080Ti. Inference: 50 DDIM steps.
2. **Matching**: similarity matrix S[i,j] = cos(Emb_φ(v_i), y_so^(j)) (Eq. 9); multi-round Hungarian bipartite matching assigns each of the L relations to subject-object pairs.
3. **Auxiliary matching supervision** (Eq. 12): L_match = E_t[BCE(Sigmoid(S_t/κ), M)] with GT IoU-assigned binary matching matrix M; overall L = L_simple + λL_match.

## 4. Equations / algorithms
- Forward: x_t ~ q(x_t|x_{t−1}) = N(x_t; √(1−β_t) x_{t−1}, β_t I) (1); closed-form x_t = √(ᾱ_t) x_0 + √(1−ᾱ_t) ε_t. Simplified objective: L_simple^ori(x_0) = E[‖ε_θ(x_t,t) − ε‖²₂] (4).
- Extended VLB with embedding/rounding steps (Eqs. 5–7): L_simple = E[Σ_{t=2}^T ‖x_0 − f_θ(x_t,t)‖² + ‖Emb_φ(v) − f_θ(x_1,1)‖² − log p_θ(v|x_0)] (7). Full derivation in appendix (Eqs. 13–22, final form Eq. 22) — quoted faithfully; no invention.
- Matching cost: σ̂ = argmin_σ Σ_j C(v_{σ(j)}, h_j), C = −1_{h_j≠∅} S[σ(j),j] (11), solved by Hungarian algorithm.
- Aux loss: L_match = E_{t~{0,…,T}}[BCE(Sigmoid(S_t/κ), M)] (12); L = L_simple + λL_match, λ = 1.0, κ = 0.05.

## 5. Key results
- **Conventional HOI recall on HICO-DET (Table I):** Diff-VRD (V/V) R@5 **17.28**, R@10 21.52, R@15 23.49 — far below closed-set UPT (52.30/64.35/69.71), as expected for open vocabulary; but crushes zero-shot HOI models equipped with V: GEN-VLKT 0.71/1.22/1.59, THID 1.99/3.32/4.36, CLIP baseline 1.21/2.72/3.08. Testing Diff-VRD with C_r instead of V jumps R@5 to 25.23; training on narrow C_r collapses it (4.92) — sparse anchor embeddings.
- **T2I retrieval on HICO-DET (Table II, CLIP retrieval):** Diff-VRD R@1 **11.13**, R@5 32.00, R@10 45.07 vs UPT 7.20/22.03/33.76 — the headline number: **+11.31 pp R@10 over UPT** (45.07 vs 33.76). Beats GEN-VLKT-with-V (8.96/28.13/41.32) and THID (7.91/23.79/35.69). X-VLM retrieval: 15.12/39.03/53.63.
- **Table III (same-detector, HICO-DET/V-COCO):** Diff-VRD R@1 11.13/10.07 vs UPT 7.20/7.36 and vs GT-annotations-as-query 7.97/8.60 — generating relations *beyond GT* retrieves better than the GT labels themselves.
- **SGG on VG (Table IV), Diff-VRD on IEtrans:** T2I retrieval R@1 17.72 / R@5 36.71 / R@10 **46.52** vs IEtrans 12.12/28.49/37.73 (**+8.79 pp R@10**) and CLIP 9.20/21.35/28.64 (Table V). Conventional SGG metrics dip slightly (mean recall 33.0/38.0 vs IEtrans 35.8/39.1 PredCls) because VG has one predicate per pair while Diff-VRD generates diverse multiples — motivating the proxy metrics.
- **SPICE PR curve (Fig. 3):** Diff-VRD clearly beats CLIP baseline on precision and recall; best recall among CLIP/UPT/Diff-VRD with slight precision sacrifice vs UPT; larger precision-recall trade-off space.
- **Diversity (Fig. 4):** Diff-VRD hits more GT relation categories than UPT, GEN-VLKT, CLIP; open-vocab competitors show high category counts but low precision (GEN-VLKT 37,594, CLIP 86,884 predicate-object categories, mostly wrong).
- **Ablations (Tables VI–VIII):** matching supervision M ✓ lifts HOI R@5 16.14→21.83 but *hurts* T2I R@1 11.37→8.67 (diversity suppression — GT labels cover only pre-defined categories); L=16/32/48 → R@5 21.38/21.83/22.60 (larger L better, more compute); increasing relations-per-pair K (1→8) hurts SGG recall but improves diversity.

## 6. Strengths
First generative (diffusion) formulation of VRD, with a principled embedding/rounding extension of DDPM (full VLB derivation in appendix). The **proxy-metric innovation** (T2I retrieval, SPICE PR curve) directly addresses the "reasonable but unannotated" evaluation problem — T2I retrieval beating GT annotations (Table III) is the most convincing validation. Honest ablation showing matching supervision *trades* detection recall for diversity. Works as a drop-in enhancement module (IEtrans + Diff-VRD). The semantic-ambiguity motivation is real for sports: one play segment is legitimately describable many ways.

## 7. Limitations / threats to validity
- No sports data: HICO-DET/V-COCO/Visual Genome stills; zero evidence on broadcast sports video or temporal relations.
- **Inference cost:** 50 DDIM denoising steps per image with a Transformer decoder — far from real-time; no latency reported.
- Matching supervision ablation shows the diversity claim is sensitive to training choices; GT synonyms extend HOI recall evaluation, softening the comparison.
- CLIP-baseline T2I result (57.67 R@10 with X-VLM) actually beat Diff-VRD (53.63) — the authors argue CLIP predicts by raw similarity regardless of sense (e.g., "barbeque" for outdoor cooking, Fig. 6a), but this cuts against the retrieval metric's discriminative power.
- "Person booze wine_glass" failure mode: predictions from pure visual info, not interaction (conditional features ignore context) — acknowledged in §V-A limitations.
- L=32 sequence length and CLIP pseudo-label padding are heuristics; larger L always better but pricier.

## 8. Implementation spec (how GSE would apply it)
1. Treat the paper as a **design pattern**, not a pipeline: for any GSE sports scene-understanding labeling task where the relation vocabulary is open-ended (e.g., QB–receiver interactions, blocker–defender engagements), generate candidate relation labels in embedding space and round to a large curated sports vocabulary, rather than forcing a fixed 17-class taxonomy. 2. Reuse the **proxy evaluation idea**: when GSE generates rich multi-label event descriptions that exceed annotator labels, evaluate via retrieval (do the generated triplets retrieve the right clip?) and SPICE-style semantic-tuple PR curves — this solves the "our model is richer than our labels" measurement problem that fixed taxonomies create. 3. If ever prototyping: Transformer decoder denoiser with CLIP-initialized embedding/rounding, Hungarian multi-round matching on cosine similarities, DDIM 50 steps; but only on stills first.

## 9. Experiments / tests to run

## 11. Improvement path
Add temporal conditioning (video VRD — relations unfold over time in sports); replace the CLIP-only conditional features with context-aware ones (fixing the "booze wine_glass" failure); reduce inference cost (distilled few-step diffusion or direct x_0 prediction); evaluate on sports-specific benchmarks (SoccerNet frames, NFL broadcast stills) to prove the transfer; and report latency/FLOPs so the engineering trade-off is explicit.

## 12. Verdict reasoning
**ADAPT.** The core transferable insights are two: (1) when the label space is semantically ambiguous — which sports action/event vocabularies are — *generative* open-vocab relation decoding with a large rounding vocabulary is a better paradigm than fixed-class discrimination; (2) the T2I-retrieval/SPICE proxy metrics solve the real evaluation problem of models richer than their annotations. But this is a stills-only research prototype (50 DDIM steps, no sports data, no latency numbers) — so the adaptation is conceptual and evaluative, not a pipeline to deploy. REJECT is wrong because the ambiguity framing and proxy metrics genuinely apply to GSE's scene-understanding work; MONITOR understates it since the design pattern is actionable now.

## 13. Risks / open questions
- Zero sports validation — person-ride-horse ≠ quarterback-releases-ball; broadcast occlusions and motion blur may break the union-box conditioning. - Inference cost unknown; 50 DDIM steps per image is likely prohibitive for video-frame processing without distillation. - The CLIP baseline beating Diff-VRD on one T2I variant raises questions about the proxy metric's robustness. - Training on narrow vocabularies collapses the model (R@5 4.92) — a sports deployment would need a large, well-built predicate vocabulary first. - The enhancement-module results show conventional metric *drops* — stakeholders expecting standard recall gains would misread the trade-off.
