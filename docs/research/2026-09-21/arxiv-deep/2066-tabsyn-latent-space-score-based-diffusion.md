**Verdict:** ADAPT — the strongest tabular-diffusion design in this lane so far: VAE Transformer latent space + linear-noise score diffusion, with a unified standardized benchmark (7 baselines × 6 datasets × 5+ metrics) showing 86% lower column-density error and 68% lower pair-correlation error than the best baseline, plus the cleanest categorical handling. Primary candidate for the NFL production backbone; adaptation needed for scale (M×d latent grows with feature count) and conditional sampling.

## 1. Research question
Prior tabular-diffusion methods either one-hot categoricals into continuous diffusion (STaSy — suboptimal per Lee et al. 2023) or run two separate diffusion processes for numeric/categorical features (TabDDPM, CoDi), which breaks cross-type co-occurrence modeling. Can a single diffusion model in a unified continuous latent space — learned by a VAE tailored to tabular structure — handle mixed-type columns jointly, generate higher-quality data, and sample faster than data-space diffusion? Secondary: what noise schedule minimizes reverse-process discretization error?

## 2. Dataset / schema
Six public tabular datasets (Table 6/Appendix E.1): Adult, Default, Shoppers, Magic, Beijing, News — mixed numeric/categorical, classification (Adult/Default/Shoppers/Magic) and regression (Beijing/News) targets. Detailed descriptives in Appendix E.1 (not extracted; all are standard UCI-style benchmarks).

## 3. Method / model
Two-stage: (1) **Tabular VAE** — column-wise tokenizer: numerics x_i·w_i+b_i (linear), categoricals x_i^{oh}·W_i+b_i (embedding lookup), each a d=4 vector; stack into E ∈ ℝ^{M×d}; two-layer Transformer encoder (self-attention, no multi-head; FFNN D=128) → μ, log σ; reparameterization; two-layer Transformer decoder; symmetric detokenizer (Eq. 3: linear for numerics, softmax for categoricals). β-VAE loss ℒ = ℓ_recon + β·ℓ_kl with **adaptive β schedule**: start βmax=0.01; when epoch-wise reconstruction loss stalls S epochs, β ← λβ (λ=0.7), floor βmin=1e−5. (2) **Latent score diffusion**: flatten encoder output z = Flatten(Encoder(x)) ∈ ℝ^{Md}; VE-SDE forward z_t = z_0 + σ(t)ε; reverse SDE Eq. 6; denoising MLP (5-layer, SiLU, TabDDPM-style, sinusoidal time embeddings); denoising score matching ℒ = E‖ε_θ(z_t,t)−ε‖². Noise schedule σ(t)=t (linear) with Proposition 1 + proof (Appendix C): linear schedule minimizes the Euler reverse-step approximation error (error exactly 0 for one step vs ≥0 for √t), enabling <20 NFEs for best quality vs STaSy 50–200 and TabDDPM ~1000. Bonus: the trained unconditional model does missing-value imputation without retraining (Appendix F.4). Code: https://github.com/amazon-science/tabsyn.

## 4. Equations & assumptions
Forward (Eq. 5): z_t = z_0 + σ(t)ε, ε∼N(0,I). Reverse (Eq. 6): dz_t = −2σ̇(t)σ(t)∇_{z_t}log p(z_t)dt + √(2σ̇(t)σ(t))dω_t. Score matching (Eq. 7): ℒ = E‖ε_θ(z_t,t)−ε‖²; score = −ε_θ(z_t,t)/σ(t). β-VAE (Eq. 4): ℒ = ℓ_recon(x,x̂) + βℓ_kl; adaptive rule β ← 0.7β on recon-loss plateau. Perturbation kernel (Eq. 10–12): p(z_t|z_0) = N(z_t; s(t)z_0, s²(t)σ²(t)I); VE: s(t)=1. Proposition 1 proof sketch (Appendix C): Euler one-step error ‖z_{t−Δt} − z^Euler_{t−Δt}‖ = ε·(σ(t)−σ(t−Δt)−σ̇(t)Δt) = 0 exactly when σ(t)=t (vs ≥0 for σ(t)=√t).
Assumptions: (1) the Transformer VAE latent is smooth enough that Gaussian diffusion is appropriate; (2) adaptive-β keeps reconstruction and KL balanced; (3) flattened M×d latent is compact (M = #columns, d=4 — fine for tens of columns, heavy for hundreds).

## 5. Features / target
Per-dataset standard columns; targets are classification labels (AUC) or regression targets (RMSE). NFL translation: same as ledger 2062 — game/team-level rows; columns = categoricals (team, opponent, venue, weather bins) + numerics (EPA, success rate, pace, spreads); target = cover/margin/outcome class for conditional extensions (paper is unconditional; conditional sampling would be the adaptation).

## 7. Numerical results / baselines
Table 1 (column density error %, lower better; bold = TabSyn everywhere): Adult 0.58±0.06 (next: SMOTE 1.60, TabDDPM 1.75); Default 0.85 (TabDDPM 1.57); Shoppers 1.43 (SMOTE 2.68); Magic 0.88 (TabDDPM 1.01); Beijing 1.12 (TabDDPM 1.30); News 1.64 (STaSy 6.89; TabDDPM 78.75 — total collapse). Average 1.08 vs 14.52 best-baseline avg → paper's claimed 86.0% error reduction. Per-dataset improvements 12.9%–76.2%.
Table 2 (pair correlation error %): TabSyn 1.06–2.24 per dataset, avg 1.73 vs best baseline TabDDPM 5.34 → 67.6% reduction (best generative baseline; SMOTE 4.36 avg is interpolation, not generative).
Table 3 (MLE; all best TabSyn): Adult AUC .915, Default .764, Shoppers .920, Magic .938, Beijing RMSE .582, News RMSE .861; avg gap to Real-trained 7.23% (next best: TabDDPM 19.14% incl. News collapse, SMOTE 9.39%).
Ablations (Table 5, Adult single/pair): TabSyn 0.58/1.54; TabSyn-DDPM (latent + DDPM) 1.02/2.15 — beats TabDDPM-in-data-space (1.75/3.01), isolating the latent-space benefit; TabSyn-OneHot 5.59/6.92 — worst, one-hot+continuous diffusion is inappropriate. Table 4 (Adult β): scheduled β 0.58/1.54 beats all constants except 1e−4 (0.69/2.01); tiny β=1e−5 explodes (41.96/69.17) — KL collapse without floor.
Speed: TabSyn reaches best quality at <20 NFEs; STaSy needs 50–200, TabDDPM 1000. Sampling wall-clock (Table 8, Adult): TabSyn 1.784s vs TabDDPM 28.92s (93% reduction) vs CTGAN 0.86s; training 1758s (VAE) + 664s (diffusion) — comparable to baselines overall. Table 7 property matrix: TabSyn is the only method with ✓ on all four (compatibility, robustness, quality, efficiency); STaSy lacks compatibility, CoDi/TabDDPM lack robustness+efficiency. Robustness detail (Appendix G.1): TabSyn uses the *same* hyperparameters on all six datasets (token d=4, 2-layer Transformer, βmax=0.01, diffusion MLP 1024-dim) with no per-dataset tuning — the anti-fragility claim is procedural, not just empirical. Missing-value imputation (Table 12): unconditional TabSyn as an inpainting imputer (Appendix F.4, Eq. 39) *beats XGBoost trained on real data* on 4/6 target-imputation tasks — Adult AUC 93.2 vs 92.7, Default 87.2 vs 77.0, Shoppers 96.6 vs 92.6, Beijing RMSE 0.258 vs 0.423 (loses Magic 88.8 vs 94.6, News 1.253 vs 0.842). Privacy (Table 13, DCR): TabSyn 51.20%/52.90% — synthetic samples are ~equally close to train and holdout (50% = ideal), i.e., no memorization. All numbers are the paper's claims from its own benchmark harness.

## 9. Leakage & limitations
Adversarial notes: (1) The TabDDPM News collapse (78.75%) and FinDiff-paper TabDDPM collapses (ledger 2065) both suggest baseline configs are fragile across papers — but TabSyn beats even SMOTE (a strong interpolation baseline) on most sets, so the win isn't purely baseline-bashing. (2) Unconditional generation only; NFL rare-regime oversampling needs conditional extension. (3) Latent dim = M×d with d=4 — scales linearly in feature count; a 100-column NFL table → 400-dim diffusion space, still tractable but VAE training cost grows (4000 epochs in ablations). (4) The adaptive-β trick is a heuristic plateau rule with 3 hyperparameters; Table 4 shows constant β=1e−4 nearly matches — the scheduling is nice-to-have, not decisive. (5) No time structure; DCR privacy is fine (51.2%/52.9%, near-ideal 50%) but the imputation result cuts both ways for privacy: a model that imputes a masked target better than XGBoost on real data (Default 87.2 vs 77.0) is also a model that can *reconstruct* held-out columns well. (6) MLE gaps vs Real are small for all methods (Table 3: "some columns may not significantly impact the tasks") — the low-order statistics (Tables 1–2) are the discriminative metrics, which is where the 86%/68% claims live. (7) New from this audit's tail read: the no-tuning property (Appendix G.1) means NFL deployment needs no per-season hyperparameter search — a real operational advantage over TabDDPM/STaSy/CoDi, whose tables the paper had to tune per dataset. External validity to NFL: high — mixed-type game tables are exactly this shape; the pair-correlation win (contingency similarity for categorical pairs) directly targets team–outcome interaction fidelity; and the imputation capability (Appendix F.4) is a second use case: filling missing charting/injury-designation fields without a separate model.

## 12. Reproducible test

Metrics: (a) GBDT spread-model log-loss on 2024; (b) paper's own Table 1/2 metrics — column density error (KS/TVD) and pair correlation error (Pearson/contingency) — reported per method; (c) sampling NFEs and wall-clock per synthetic season (the paper's speed claim). The test that matters: replicate the paper's 86%/68% error-reduction *ordering* on NFL-shaped data.

## 13. Acceptance / rejection gate
ADOPT TabSyn as the production synthetic-season backbone if: (a) its column-density error ≤ 50% of TabDDPM's on the NFL table (the paper shows ~3×; we require a conservative fraction), AND (b) real+synthetic GBDT log-loss beats real-only by ≥0.003 on held-out 2024, AND (c) sampling cost ≤ 30 NFEs per season batch (the paper's speed claim). REJECT (fall back to TabDDPM/FinDiff) if the VAE reconstruction of categorical columns degrades team-identity fidelity (any team's decoded self-consistency <95%) or if training cost exceeds 3× TabDDPM's without meeting gate (a). Gate set before running; 3 seeds.

## 14. Improvement experiment
Conditional latent diffusion with learned regime prompts: the paper's diffusion is unconditional, but the VAE latent already factorizes per-column (E ∈ ℝ^{M×d}). Add a learned "regime prompt" vector (team-tier × outcome-class × weather-band) added to the latent before diffusion — i.e., prompt-conditioned generation without retraining the VAE, analogous to prompt-tuning in LDMs. This gives rare-regime oversampling (blowouts, snow games) in one unconditional model. Test: prompt-conditioned rare-regime samples vs unconditional-filtered samples on fidelity (Table 2-style pair correlation on the rare slice) and on the §13 gate — if prompt conditioning preserves pair correlations on rare slices where plain filtering degrades them, it becomes the standard way to synthesize tail NFL regimes.
