# [0226] A State-Space Perspective on Modelling and Inference for Online Skill Rating (arXiv:2308.02414v3)

**Citation:** Samuel Duffield, Samuel Power, Lorenzo Rimella (2023). *A State-Space Perspective on Modelling and Inference for Online Skill Rating*. arXiv:2308.02414v3. URL: https://arxiv.org/abs/2308.02414
**Ledger completed:** 2026-09-21. **Read:** full text (local extraction, all 10,757 lines: Sections 1–6, references, Appendices A–D).
**Verdict:** ADAPT — import the factorial SSM framework with match-sparsity reduction, the discrete fHMM eigenmachinery (O(S²) updates via analytic eigendecomposition), the bivariate Poisson attack/defence SSM, and the EM parameter-estimation workflow into GSE's team-rating pipeline; do not re-derive Elo/Glicko/TrueSkill, which GSE already covers.

## 1. Research question
How should time-varying player/team skill be modelled and inferred from match results (and optionally margin-of-victory/scores) so that a single coherent framework supports online rating (filtering), retrospective evaluation (smoothing), and principled calibration of the model's static parameters (maximum-likelihood estimation)? The paper unifies Elo, Glicko, TrueSkill, sequential Monte Carlo, and finite-state hidden Markov models as different approximate-inference schemes inside one factorial state-space model, and asks which scheme practitioners should pick given their speed/robustness priorities — demonstrating the answer on women's tennis (WTA), English Premier League football, and classical-format chess.

## 3. Method / model
The paper proposes a factorial state-space model (fSSM) for N players and K matches at irregularly spaced times t_k (Section 2): player skills evolve independently a priori as Markovian continuous-time processes, and each match outcome depends only on the two participants' current skills. It then develops the inference toolkit:

- **Filtering** (online skill ratings), **smoothing** (retrospective evaluation), and **parameter estimation** (offline MLE via EM or Fisher-identity gradient ascent), presented as abstract Propagate/Assimilate/Bridge/Marginalise operators on probability measures (Sections 3.1–3.5).
- **Two standing approximations** applied to every method: the decoupling (factorial) approximation (Filter_k ≈ ∏_i Filter_k^i) and **match sparsity** — only tracking skills at matchtimes each player actually played, which rewrites the joint likelihood from O(N·K) terms to O(N+K) terms, making per-match assimilation cost independent of N and K (Sections 3.4.1–3.4.3).
- **Six concrete inference schemes** (Table 1): Elo-Davidson, Glicko, Extended Kalman, TrueSkill2 (moment-matching/ADF), SMC (bootstrap particle filter + backward simulation smoothing), and a discrete factorial HMM with continuous-time reflected-random-walk dynamics (Section 4, Appendix A).
- **Extensions** (Section 4.6): Ornstein-Uhlenbeck mean-reverting dynamics, bivariate Poisson attack/defence likelihood (Karlis and Ntzoufras 2003) for goals/points, and the Plackett-Luce multiplayer ranking likelihood.
- **Experiments** follow a realistic workflow: exploratory analysis with trial parameters → EM parameter estimation → filtering assessed by match-outcome negative log-likelihood on a held-out year → smoothing for historical evaluation → model refinement with the bivariate Poisson model (Sections 5.1–5.5). Open-source Python package `abile` at github.com/SamDuffield/abile; SMC run with J=1000 particles; fHMM with S=500 states (S=40 for the bivariate Poisson discrete case); fHMM scaling fixed at s_d = S/5 (Appendix D).

## 4. Equations & assumptions
Core model (Section 2, Eq. (1)):
P(x_{0:K}^{[N]}, y_{1:K}) = ∏_{i∈[N]} { m_0^i(x_0^i) ∏_{k=1}^{K} M_{k−1,k}^i(x_{k−1}^i, x_k^i) } × ∏_{k=1}^{K} G_k(y_k | x_k^{h(k)}, x_k^{a(k)}).
Match-sparse minimal form (Eq. (2)): P({x_{ℓ^i}^i : ℓ^i ∈ L^i, i ∈ [N]}, y_{1:K}) = ∏_{i∈[N]} { m_0(x_0^i) · ∏_{ℓ^i ∈ L^i} M_{ℓ^{i,−},ℓ^i}(x_{ℓ^{i,−}}^i, x_{ℓ^i}^i) } · ∏_{k=1}^{K} G_k(y_k | x_k^{h(k)}, x_k^{a(k)}), where L^i are the matchtime indices at which player i played — O(N+K) terms instead of O(N·K).
Decoupling approximation: Filter_k = P(x_k^{[N]} | y_{1:k}) ≈ ∏_{i∈[N]} P(x_k^i | y_{1:k}) = ∏_{i∈[N]} Filter_k^i (same for smoothing).
Filtering recursions: Predict_{k+1|k} = Propagate(Filter_k, M_{k,k+1}); Filter_{k+1} = Assimilate(Predict_{k+1|k}, G_{k+1}); with Predict_{k+1|k}(x_{k+1}) = ∫ Filter_k(x_k) · M_{k,k+1}(x_k, x_{k+1}) dx_k and Filter_{k+1}(x_{k+1}) ∝ Predict_{k+1|k}(x_{k+1}) · G_{k+1}(x_{k+1}).
Smoothing (backward) recursion: Smooth_{k,k+1|K}(x_k, x_{k+1}) = Filter_k(x_k) · M_{k,k+1}(x_k, x_{k+1}) · Smooth_{k+1|K}(x_{k+1}) / Predict_{k+1|k}(x_{k+1}); Smooth_{k|K}(x_k) = ∫ Smooth_{k,k+1|K}(x_k, x_{k+1}) dx_{k+1}.
Elo binary update: (x_k^h, x_k^a)^T = (x_{k−1}^h + γ·(𝕀[y_k=h] − sigmoid((x_{k−1}^h − x_{k−1}^a)/s)), x_{k−1}^a + γ·(𝕀[y_k=a] − sigmoid((x_{k−1}^a − x_{k−1}^h)/s)))^T, with logistic sigmoid; FIDE chess convention s = 400/log(10), γ ∈ {10, 20, 40}; authors set s=1 for identifiability.
Elo-Davidson: x_k^h = x_{k−1}^h + K·(𝕀[y_k=h] + ½𝕀[y_k=draw] − g((x_{k−1}^h−x_{k−1}^a)/s; κ)), with g(z;κ) = (10^z + κ/2)/(10^{−z} + 10^z + κ); predictions P(y_k=h) ∝ 10^{(x_{k−1}^h−x_{k−1}^a)/s}, P(y_k=a) ∝ 10^{(x_{k−1}^a−x_{k−1}^h)/s}, P(y_k=draw) ∝ κ.
Extended Kalman SSM (Eqs. (5)/(8)): m_0(x_0^i) = 𝒩(x_0^i | μ_0, σ_0²); M_{t,t'}(x_t^i, x_{t'}^i) = 𝒩(x_{t'}^i | x_t^i, τ²·(t'−t)); G_k ternary with draw band: P(draw) = sigmoid((x^h−x^a+ε)/s) − sigmoid((x^h−x^a−ε)/s), P(h) = sigmoid((x^h−x^a−ε)/s), P(a) = 1 − sigmoid((x^h−x^a+ε)/s). Static parameters θ = (σ_0, τ, ε); fixed μ_0=0, s=1 (translation/scale symmetry broken). τ=0 recovers static Bradley-Terry; ε=0 for sports without draws.
EK Assimilate: second-order Taylor expansion of log G_k about predictive means → approximate linear-Gaussian likelihood Ĝ_k; filter ≈ 𝒩((x_k^h, x_k^a) | (μ_k^h, μ_k^a), [[σ_k^{h2}, ρ_k^{h,a}],[ρ_k^{h,a}, σ_k^{a2}]]); marginalise by reading off μ_k^h, σ_k^h, μ_k^a, σ_k^a and discarding ρ_k^{h,a}.
Kalman smoother: D_k = σ_k²·(σ_k² + τ²(t_{k+1}−t_k))^{−1}; μ_{k|K} = μ_k + D_k·(μ_{k+1|K} − μ_k); σ_{k|K}² = σ_k² + D_k²·(σ_{k+1|K}² − σ_k² − τ²(t_{k+1}−t_k)); lag-one autocovariance μ_{k,k+1|K} := μ_{k|K}·μ_{k+1|K} + D_k·σ_{k+1|K}².
EM M-step (EK, closed form): σ̂_0² = (1/N)Σ_i (σ_{0|K}^{i2} + μ_{0|K}^{i2}); τ̂² = (1/(NK))Σ_iΣ_k (1/(t_k−t_{k−1}))[σ_{k−1|K}^{i2} + μ_{k−1|K}^{i2} − 2μ_{k−1,k|K}^i + σ_{k|K}^{i2} + μ_{k|K}^{i2}]; ε̂ by univariate numerical maximisation of a Gauss-Hermite-quadrature integral.
TrueSkill2 moment-matching identity (Eq. (12)): ∫ 𝒩(z | μ, σ²)·Φ(z) dz = Φ(μ/√(1+σ²)), with inverse-probit sigmoid Φ; exact normalised predictions P(y_k | y_{1:k−1}) = ∫ G_k·Predict_k^h·Predict_k^a (Eq. (13)).
SMC: Filter_k^i(x_k^i) ≈ Σ_{j∈[J]} w_k^{i j}·δ(x_k^i | x_k^{i j}); propagate x̂_k^{i j} ∼ M_{k−1,k}(x_{k−1}^{i j}, ·); reweight ŵ_k^j ∝ w_{k−1}^{h j}·w_{k−1}^{a j}·G_k(y_k | x̂_k^{h j}, x̂_k^{a j}); multinomial resampling each step (as in experiments); backward simulation Smooth via x_{k|K}^j ∼ Σ_{j'} w_k^{j'←j}·δ(x_k | x_k^{j'}), w_k^{j'←j} ∝ w_k^{j'}·M_{k,k+1}(x_k^{j'}, x_{k+1|K}^j), O(J²) reducible to O(J) via rejection sampling (Douc et al. 2011) or MCMC (Dau and Chopin 2023).
Discrete fHMM (Eq. (6)): m_0 = ν·M_{0,σ_d} (ν concentrated on median states, ≈ centred discrete Gaussian of sd σ_d), M_{t,t'} = exp(τ_d·(t'−t)·Q_S), Q_S = P_S − I_S the generator of the continuous-time reflected random walk on [S]; ternary emission with (s_d, ε_d). Analytic eigen-decomposition (Appendix B): Q_S = Ψ_S^T·Λ_S·Ψ_S, (Λ̃_S)_{i,i} = cos(2π(i−1)/S), (Ψ_S)_{i,j} = S^{−1/2} (i=1) or (S/2)^{−1/2}·cos(π(i−1)(2j−1)/S); propagation via π_0 = π, π_1 = π_0·Ψ_S^{−1}, π_2 = π_1·exp(−τ_d(t'−t)Λ_S), π_3 = π_2·Ψ_S — O(S²) per step after one-off O(S³) decomposition. Filtering: Filter_k^{h,a} ∝ ((Predict_{k|k−1}^h)^T·Predict_{k|k−1}^a) ⊙ G_k(y_k | ·, ·), marginalised by row/column sums. O(S²) smoothing via Smooth_{k|K} = Filter_k ⊙ [(Smooth_{k+1|K} ⊘ Predict_{k+1|k})·M_{k,k+1}^T]. τ_d updated by gradient ascent using ∂Q_2/∂τ_d with ∂_{τ_d}M_{k−1,k} = exp(τ_d(t_k−t_{k−1})Q_S)·(t_k−t_{k−1})·Q_S assembled in the eigenbasis.
Bivariate Poisson likelihood (Eq. (7)): G_k(y_k | x^h, x^a) = e^{−(λ_1+λ_2+λ_3)} (λ_1^{y_k^h}/y_k^h!)(λ_2^{y_k^a}/y_k^a!) Σ_{k=0}^{min(y_k^h,y_k^a)} C(y_k^h,k)C(y_k^a,k)k!(λ_3/(λ_1λ_2))^k, with λ_1 = exp(α^h + x^{att,h} − x^{def,a}), λ_2 = exp(α^a + x^{att,a} − x^{def,h}), λ_3 = exp(β), bivariate skills x^i = (x^{att,i}, x^{def,i}).
Plackett-Luce multiplayer likelihood: G_k(y_k^{1:M} | x^{[M]}) = ∏_{m=1}^{M} exp(x^{y_k^m})/(exp(x^{y_k^m}) + … + exp(x^{y_k^M})).
Ornstein-Uhlenbeck dynamics (extension): M_{t,t'} = 𝒩(x_{t'}^i | x_t^i·e^{−τ(t'−t)} + μ_0·(1−e^{−τ(t'−t)}), σ_0²·(1−e^{−2τ(t'−t)})).
EM surrogate: Q(θ | θ̂) := ∫ P(x_{0:K}^{[N]} | y_{1:K}, θ̂)·log P(x_{0:K}^{[N]}, y_{1:K} | θ) dx_{0:K}^{[N]}; Fisher identity: ∇_θ log P(y_{1:K} | θ) = ∫ P(x_{0:K}^{[N]} | y_{1:K}, θ)·∇_θ log P(x_{0:K}^{[N]}, y_{1:K} | θ) dx_{0:K}^{[N]}. (E-step approximated with the approximate smoother, compromising EM's monotonicity guarantee.)
Stated assumptions: players' skills evolve independently of one another a priori (each Markovian); each match outcome depends only on the two participating players' current skills; initial skills mutually independent; continuous-time evolution with irregularly spaced observations insisted upon; identical dynamics M^i = M across players and time-homogeneous observation model G_k (stated as presentational simplifications, straightforward to relax); all methods use the decoupling approximation Filter_k ≈ ∏_i Filter_k^i; computational budget linear in N and K (Table 1: all methods O(N) players, O(K) matches; per-match assimilation cost independent of N and K).

## 5. Features / target
Inputs: match outcomes (home win / away win / draw as applicable) with timestamps; for the football refinement, home and away goals (y_k = (y_k^h, y_k^a) ∈ ℕ²). Targets: match-outcome predictive distributions P(y_k | y_{1:k−1}) used both for online prediction accuracy (negative log-likelihood) and for parameter estimation (log P(y_{1:K} | θ)); the bivariate Poisson variant additionally predicts scorelines. Prediction horizon: next-match outcome for each match in the test year. No features beyond result/score/timestamp (no covariates); the paper explicitly notes richer models (player-specific τ^i, off-season vs in-season τ, format-specific s for 3-set vs 5-set tennis, home-advantage hypothesis α^h > α^a) are natural extensions, not fitted.

## 6. Validation design
Time-ordered splits: 3 years of training data → subsequent single year as test (tennis: train 2019–2021, test 2022; same 3-train/1-test design stated for football and chess). Static parameters chosen by grid search (Elo, Glicko) or EM (model-based methods) on the training window only. Metrics: average negative log-likelihood of match outcomes on train and test (Table 2; lower is better). For sports with draws, Glicko excluded from log-likelihood assessment (no normalised predictions). Bivariate Poisson variants assessed on the derived win/draw/win probabilities, not on scoreline likelihood. Baselines compared: Elo-Davidson, Glicko, Extended Kalman, TrueSkill2, SMC, discrete fHMM, plus bivariate-Poisson EK/SMC/discrete. Parameter-estimation convergence assessed via 1000 EM iterations from three initialisations on the tennis 2-D likelihood landscape (Fig. 3). Exploratory coherence checks (Fig. 2, Argentina World Cup) and smoothing-based historical evaluation (Fig. 4, Tottenham 2011–2023) are qualitative, not validated against ground truth.

Paper's stated claims: all models perform similarly on binary tennis (performance saturates) except TrueSkill2, which they attribute to EM optimisation bias; on football and chess the model-based approaches with uncertainty quantification "significantly outperform" Elo/Glicko and "are preferable"; the bivariate Poisson refinement "provides better predictions for the match winner than the sigmoidal SSM (8), despite not being directly optimised for the purpose". Parameter estimation (Fig. 3, WTA): TrueSkill2's Gaussian approximation contorts the landscape so EM "evades the global optimum"; SMC and discrete identify it ("no systematic bias beyond the factorial approximation"). SMC run with J=1000 particles; fHMM with S=500 states (S=40 for bivariate Poisson discrete due to exponential scaling in skill dimension); s_d = S/5. Smoothing finding (Fig. 4): Tottenham's skill ascended under Villas-Boas/early Pochettino and descended late Pochettino; the 2022 decline was driven by defence weakening while attack stayed proficient.

## 9. Leakage & limitations
- Adversarial points: (i) the model-free Elo-Davidson is a weak baseline by construction — the paper's "significant" outperformance on football/chess compares against a point-estimate system with no uncertainty; whether the margin survives against a well-tuned modern baseline (e.g. Glicko-2 with proper draw handling) is untested; (ii) the factorial (decoupling) approximation is applied everywhere and never quantified — correlated skills (e.g. all teams in a strong division, or offence/defence co-movement) are assumed away; (iii) NFL external validity: the bivariate Poisson is built for low-scoring football/soccer goals; NFL scoring (touchdowns/field goals, ~45 combined points) needs a different emission (Gaussian margin or a points-mixture), which the paper does not derive or test; (iv) tennis 2-D EM landscape is a toy — the paper admits higher-dimensional parameter sets make EM's behaviour "worthwhile to examine carefully" and online parameter estimation is untreated; (v) S=500/S=40 and J=1000 are fixed by fiat, not ablated; (vi) the fHMM's identifiability fix s_d = S/5 is ad hoc ("found to work well in practice"); (vii) chess draw rate 65% inflates NLL scale differences across sports — cross-sport comparisons of Table 2 magnitudes are meaningless; (viii) smoothing-based manager evaluation (Tottenham/Villas-Boas/Pochettino) is purely descriptive with no causal identification; (ix) no uncertainty is reported on the NLL differences (no standard errors or significance tests).

## 10. GSE overlap
The existing-research-map records that GSE already covers Elo/Glicko/TrueSkill, Poisson models, state-space models, NFL efficiency metrics, calibration, NGS tracking taxonomy, and market-relative work. This paper therefore does NOT add anything new in the Elo/Glicko/TrueSkill lane itself — those systems are explicitly re-derived here only as special cases. The new-to-GSE components are: (a) the **match-sparsity** reformulation (O(N·K) → O(N+K), per-match update independent of N and K) as a concrete design pattern for GSE's own time-varying models; (b) the **discrete fHMM with analytic eigendecomposition** and O(S²) vector-only filtering/smoothing recursions — no such discrete-state eigenmachinery exists in the corpus; (c) the **bivariate Poisson attack/defence SSM with time-varying strengths** integrated into the same inference engine (paper shows it beats the win/draw/win-only SSM on EPL: test 0.954 vs 0.973 for Elo-Davidson, 0.950 for the SMC variant); (d) the **EM parameter-estimation workflow with closed-form M-steps** for (σ_0, τ) and Gauss-Hermite M-step for the draw parameter, replacing empirical hand-tuning of rating-system hyperparameters; (e) smoothing for retrospective evaluation (e.g. quantifying coaching changes) — no explicit stakeless/dead-rubber or coaching-impact model exists in the corpus. Classification: extension/new capability, not duplicate.

## 11. GSE implementation spec
Concrete build plan for an NFL team-rating module ("abile-for-NFL"):
1. Data: nflverse play-by-play + games (2020–2025 seasons), final scores and timestamps; derive per-game (home_score, away_score).
2. Model: bivariate attack/defence SSM — per-team skill x^i = (x^{att,i}, x^{def,i}) with Brownian dynamics M_{t,t'}(x_t, x_{t'}) = 𝒩(x_{t'} | x_t, τ²(t'−t)); emission = bivariate Poisson (Eq. (7)) with λ_1 = exp(α^h + x^{att,h} − x^{def,a}), λ_2 = exp(α^a + x^{att,a} − x^{def,h}), λ_3 = exp(β); static parameters θ = (σ_0, τ, ε, α^h, α^a, β). Also fit a Gaussian margin-of-victory emission as an NFL-specific variant (paper does not derive one — the emission must be adapted since NFL scoring is not low-count Poisson).
3. Inference: two parallel engines per the paper's recommendation — (i) Extended Kalman (O(1) per game, speed default) for live ratings; (ii) discrete fHMM with S=200–500 states, one-off O(S³) eigen-decomposition of Q_S, O(S²) filtering/smoothing for robustness. Implement match sparsity: only propagate teams on weeks they play; parallelise smoothing across 32 teams.
4. Calibration: EM with closed-form σ_0, τ M-steps and Gauss-Hermite/1-D optimisation for ε (paper's Appendix A.3.3), run on 3 seasons, test on the 4th; compare average NLL of win/draw/win (draws ≈ 0 in NFL, set ε→0) against the current GSE spread model.
5. Serving: weekly filter update after each game (Predict/Assimilate), fixed-lag smoother (Duffield and Singh 2022) for season-long historical rating curves; expose attack and defence ratings separately (paper's Tottenham-2022 finding shows the decomposition is where the insight lives — e.g. a team's rating drop can be diagnosed as offensive vs defensive).
6. Effort estimate: Not stated in paper (methodological paper, no engineering estimate given). Roughly 2–3 weeks for a prototype in JAX/Python given the `abile` reference code.

## 12. Reproducible test
Dataset: nflverse games table, regular seasons 2020–2025 (final scores, home/away, dates). Protocol: 3-season train / 1-season test rolling (e.g. train 2020–2022 → test 2023; train 2021–2023 → test 2024; train 2022–2024 → test 2025). Static parameters via the paper's EM (Extended Kalman engine) on each train window. Metric: average negative log-likelihood of ternary outcomes (home win / away win / tie, ε fitted or fixed at 0) on the test season, exactly the paper's Table 2 protocol. Baseline to beat: Elo-Davidson analogue on the same window plus GSE's current team-rating/spread-implied baseline if available. Success = both SSM engines (EK and fHMM) beat Elo-Davidson on mean test NLL across the three rolling windows; report per-window numbers, not just averages.

## 13. Acceptance / rejection gate
ADOPT (build into GSE) if: on the rolling 3-train/1-test nflverse protocol, the bivariate attack/defence SSM achieves a mean test average-NLL improvement ≥ 0.01 over the Elo-Davidson baseline across all three test windows AND neither window shows a degradation vs baseline. REJECT (keep current stack) if: the SSM fails to beat Elo-Davidson on ≥2 of 3 test windows, or the attack/defence decomposition adds no interpretable signal beyond the single-skill SSM (smoothing curves of x^{att} vs x^{def} indistinguishable within ±1 posterior sd for ≥80% of teams).

## 14. Improvement experiment
Go beyond the paper with an NFL-specific emission and dynamics: (i) replace the bivariate Poisson with a **correlated Gaussian margin-of-victory emission** (score differential y_k = margin ∼ 𝒩(x^{att,h} − x^{def,a} − (x^{att,a} − x^{def,h}) + hfa, σ_margin²), tied to a win/tie/loss likelihood), which matches NFL scoring better than low-count Poisson; (ii) add the paper's suggested extensions the authors never fit: player/team-specific rate τ^i and separate τ_off-season vs τ_in-season (NFL teams change dramatically between seasons — a single Brownian τ cannot capture both within-season stability and off-season churn); (iii) test the OU mean-reverting dynamics against Brownian via marginal likelihood comparison (the paper derives OU but never runs it — the OU stationary variance would stop long-offseason skill estimates from diffusing to infinity, a real failure mode for NFL). This directly addresses the paper's own listed future work and its NFL validity gap.
