# [0497] Leveraging Minute-by-Minute Soccer Match Event Data to Adjust Team's Offensive Production for Game Context (arXiv:2508.04008v1)

**Citation:** Andrey Skripnikov, Ahmet Cemek, David Gillman (New College of Florida) (2026). *Leveraging Minute-by-Minute Soccer Match Event Data to Adjust Team's Offensive Production for Game Context*. arXiv:2508.04008v1. URL: https://arxiv.org/abs/2508.04008v1
**Ledger completed:** 2026-09-21. **Read:** full text (HTML text extract, 1,808 lines, including Appendix).
**Verdict:** ADAPT — port the context-adjustment methodology to NFL: fit a Negative Binomial GAM of drive/play offensive production on game script (score differential, time remaining, pre-game strength), then project team stats onto a neutral "tied, full-strength" baseline via the paper's multiplicative factor e^{−(η̂_s−η̂_0)}. Use as context-adjusted team-strength metrics in GSE matchup previews and content.

## 1. Research question
Can minute-by-minute offensive production (shots, corners) be modeled as a function of game context (score differential, red-card differential, home/away, pre-match strength, game minute) and projected onto a standardized "common denominator" — a tied home game at even strength — to produce fairer team comparisons than raw totals?

## 2. Dataset / schema
ESPN minute-by-minute event commentary, 2008–2023 (15 seasons), 5 leagues (EPL, La Liga, Bundesliga, Ligue 1, Serie A): ~4.97M minute-team observations (868,150 BL / 4,540 games; 1,080,842 Serie A / 5,593; 1,066,160 La Liga / 5,534; 1,042,564 Ligue 1 / 5,409; 918,658 EPL / 4,676). ~70 games excluded for corrupted commentary. Pre-match win probabilities from OddsPortal (Selenium scrape) as strength control. Response: per-minute shot attempts and corner kicks (>85% zeros). Data + code public: https://github.com/UsDAnDreS/JQAS_LeveragingMinuteByMinute_Soccer_Event_Data_Paper.

## 3. Method / model
Negative Binomial GAM (chosen over Poisson — failed DHARMa overdispersion/zero-inflation tests; over ZIP — BIC favored NegBin's lower complexity and ZIP miscalibrated on rates; over Gaussian — KS failures): log(Shots) ∼ s(Diff.S) + s(Diff.RC) + Home + s(Diff.WP) + s(GM|Half=1) + s(GM|Half=2) + s(Team) + s(season). Extreme bins: |score|>3→±3, |RC|>2→±2, minute 45+→45. GCV for spline df; team/season random-effect smooths; game-level random effects tested per season and rejected (75 tests, mostly n.s.). Significance: season-by-season fits with Holm correction across 75 tests; pairwise interactions tested as add-on terms. Adjustment: multiply output by e^{−(η̂_s−η̂_0)} for score differential s, e^{−(η̂_rc−η̂_0)} for red-card differential, e^{−γ̂} for away→home — with 95% CIs from the GAM Bayesian posterior covariance. No adjustment for win-probability differential (don't penalize strength) or minute (don't penalize timing).

## 4. Equations & assumptions
(1) log(Shots) ∼ s(Diff.S)+s(Diff.RC)+Home+s(Diff.WP)+s(GM|Half=1)+s(GM|Half=2)+s(Team)+s(season). Adjustment factor e^{−(η̂_s−η̂_0)}, η=log(response); away→home factor e^{−γ̂}. Assumptions: additive separability of context effects (interactions tested and mostly rejected, so the no-interaction model is empirically licensed); NegBin handles the count process; team/season random intercepts absorb dependence (game-level dependence tested and rejected); extreme-value binning fixes GCV spline instability; win-probability differential fully controls team strength; minute-by-minute independence conditional on smooths.

## 5. Features / target
Inputs: score differential, red-card differential, home indicator, pre-match win-probability differential, game minute × half, team, season. Targets: per-minute shot attempts and corner kicks; derived: context-adjusted season/game totals.

## 6. Validation design
Model selection via DHARMa diagnostics (KS, overdispersion, zero-inflation, outlier tests), AIC/BIC (Appendix Tables 7–8: e.g., EPL shots AIC Poisson 722,807.5 vs NegBin 720,360.4 vs ZIP 719,835.4; BIC favored NegBin everywhere), and leave-one-season-out CV calibration (0.01-width rate buckets vs observed; NegBin tracks x=y, ZIP miscalibrated). Predictive: LOSOCV per-game totals — shots MAE 3.24–3.53/game (27–28% of mean), R² 21–31%; corners MAE 1.9–2.1 (40% of mean), R² 17–22%. Decision-relevant validation: adjusted stats correlate more with points earned (shots 0.787 vs 0.718; corners 0.737 vs 0.603) and significantly beat raw stats in forecasting future score differentials (paired t-test, Holm p<0.01 all leagues).

## 7. Numerical results / baselines
Multiplicative coefficients: trailing shots ×0.70–0.90; leading ×1.10–1.75; up a man ×0.75 (down 1), ×0.40–0.70 (up 2+); down a man ×1.7–1.9 (down 1), ×2–3 (down 2+). Serie A steepest score-differential slope ("catenaccio"). Extreme examples: Bordeaux 31 shots → 13.8 [12.5, 15.1] (2-man advantage while trailing); Bayern 15 → 31.9 [30.1, 33.7] (red card in 12th minute, led throughout); Real Madrid 40 → 60.7; PSG 18 corners → 9.5; Getafe 22 shots/14 corners → 12.8/8.7. England–France 2022 WC: 16→14.35 vs 8→8.15 — adjustment narrows but doesn't erase the gap. Season: 8/10 strongest positive adjustments were league winners; 8/10 strongest negative were relegated teams. Forecasting gain: RMSE reduction 0.004–0.04 goals/game (1.5–15.2 goals over 380 games) — statistically significant everywhere but, as the authors admit, of marginal practical magnitude. Interaction score×minute significant in only a handful of 75 tests — additive model stands.

## 8. Code / data availability
Data + R code public: https://github.com/UsDAnDreS/JQAS_LeveragingMinuteByMinute_Soccer_Event_Data_Paper. Built on mgcv, DHARMa. Fully reproducible.

## 9. Leakage & limitations
- Forecasting evaluation uses first-50%/second-50% season splits with per-game averages from training data only — clean; but the forecasting model is a bare two-variable linear regression (absolute RMSE 1.3–1.9 goals/game), so the 0.004–0.04 RMSE gain is a weak decision test.
- Interaction testing: 75 season-by-season tests with Holm correction — the "few significant" score×minute interactions may be power-limited rather than truly absent; the additive adjustment inherits this assumption.
- 85%+ zero minutes; NegBin chosen for rate calibration over ZIP — reasonable for their adjustment purpose, but per-minute prediction R² 21–31% is modest and the authors concede the feature set is thin (no rosters, injuries, weather).
- Extreme binning is ad hoc (GCV instability fix); no sensitivity analysis on bin edges.
- NFL transfer caveat: soccer's continuous flow makes minute-level modeling natural; NFL is discrete plays/drives with heavy play-calling endogeneity (teams choose run/pass by script), so the "context → production" causal direction is muddier — trailing teams pass more by choice, which the GAM will attribute to the score differential itself.

## 10. GSE overlap
Directly adjacent to existing work, not duplicative. The corpus has garbage-time adjustments and EPA-based team ratings, plus Yurko et al. 2019 nflWAR (cited by this paper for LOSOCV). What this paper adds beyond the map: (a) the standardized-baseline projection methodology — multiplicative factor e^{−(η̂_s−η̂_0)} with posterior-based CIs, a cleaner mechanism than ad-hoc garbage-time filters; (b) minute/play-level NegBin GAM with separate smooths by half — a template for play-level NFL game-script adjustment (score differential × time remaining smooths); (c) the honest negative result that interaction effects (score×time) are mostly absent, which simplifies the NFL analogue. GSE's engine currently ingests raw or crudely-adjusted production; a principled context-adjusted production metric is a gap this fills.

## 11. GSE implementation spec
(1) Data: nflverse pbp 2015–2024, play-level: response = team EPA per play (or success indicator); predictors: score differential (binned ±21), time remaining (smooths by half), pre-game spread (strength control), home indicator, timeout/possession context, team + season random effects — NegBin GAM for counts (explosive plays, first downs) and Gaussian GAM for EPA/play. (2) Fit per the paper's protocol: DHARMa-style residual checks, AIC/BIC vs Poisson/OLS, LOSOCV calibration. (3) Adjustment: project each team's per-game EPA/success onto neutral script (tied, 30:00 remaining equivalent, home) via e^{−(η̂_s−η̂_0)} — producing "game-script-adjusted offensive efficiency" with 95% CIs. (4) Publish as a weekly GSE metric table (content-ready: "Team X's offense is #3 raw but #7 after adjusting for garbage time") and as an engine feature. Effort: ~1 week; mgcv-equivalent in Python (pyGAM) or R.

## 12. Reproducible test
Dataset: nflverse 2015–2024. Baselines: raw EPA/play and GSE's existing garbage-time filter. Metrics: (a) correlation of adjusted vs raw offensive efficiency with end-of-season point differential / wins (the paper's Table 5–6 analogue); (b) LOSOCV forecasting of future game margins using adjusted vs raw team stats (the paper's §3.4.3 analogue, paired t-test); (c) calibration of predicted play-level rates. Time-ordered: train ≤2022, test 2023–2024. Must beat raw stats on (a) and (b) with Holm-significant gains — if the gain is as marginal as the paper's 0.004–0.04 goals/game, adopt the metric for content (rankings narrative) but not as an engine feature.

## 13. Acceptance / rejection gate
ADOPT game-script-adjusted efficiency as a GSE metric if adjusted stats correlate ≥0.03 better with season point differential than raw stats AND beat raw stats in LOSOCV margin forecasting at p<0.05 (paper's bar: 0.787 vs 0.718 correlation, significant everywhere). Content adoption (adjusted rankings in matchup previews) needs only the correlation win; engine-feature adoption needs the forecasting win too, since the paper's own forecasting gains were practically marginal. REJECT if no correlation/forecasting gain — raw EPA with GSE's existing garbage-time handling suffices.

## 14. Improvement experiment
Model the causal direction the paper ignores: NFL play-calling is endogenous to game script (trailing teams choose to pass). Fit a two-stage model — (1) play-type choice (run/pass) as a function of script, (2) production conditional on play type and script — and compare the implied adjustments to the paper's single-stage GAM. Hypothesis: single-stage adjustment over-attributes production changes to the score differential itself and under-credits play-selection effects; the two-stage version will produce smaller, more honest adjustments (especially for pass-heavy trailing teams) and better LOSOCV forecasting — directly testing the paper's additivity assumption in a setting where it's most likely to fail.
