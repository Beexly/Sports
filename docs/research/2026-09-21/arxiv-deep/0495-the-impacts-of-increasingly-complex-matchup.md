# [0495] The Impacts of Increasingly Complex Matchup Models on Baseball Win Probability (arXiv:2511.17733v1)

**Citation:** Tristan Mott, Caleb Bradshaw, David Grimsman, Christopher Archibald (Brigham Young University) (2025). *The Impacts of Increasingly Complex Matchup Models on Baseball Win Probability*. arXiv:2511.17733v1. URL: https://arxiv.org/abs/2511.17733v1
**Ledger completed:** 2026-09-21. **Read:** full text (HTML text extract, 1,113 lines; master's thesis).
**Verdict:** ADAPT — port two things to NFL: (a) hierarchical Bayesian log5 matchup models with Marcel-style recency weighting for unit-vs-unit interactions (QB vs defense, OL vs DL), and (b) the paper's core finding that recency barely moves log-loss yet meaningfully moves simulated win probability — evaluate GSE matchup features by decision-simulation value, not predictive loss alone.

## 1. Research question
How do progressively more complex hierarchical Bayesian matchup models (pitcher-only → +batter → +recency → +base-running) change in-game strategy quality and win probability, and do the win-probability forecasts align with sportsbook consensus lines?

## 2. Dataset / schema
pybaseball/Statcast MLB plate appearances: train March 2015–June 2024, validation July–October 2024. Real 2024 playoff context from the MLB Stats API (actual batting orders, starting pitchers, rosters — bench/bullpen curated for realistic availability). 9 plate-appearance outcomes (K, BB, HBP, groundout, flyout, 1B, 2B, 3B, HR); 24 base-out game states; 216 outcome×state transitions. Simulation: each of the 43 2024 playoff games replayed 1.6 million times per model; odds from OddsPortal consensus lines.

## 3. Method / model
Matchup model = outcome distribution (depends on pitcher+batter only) × base-running state-transition distribution (depends on state, outcome, batter). Four hierarchical Bayesian log5 models: (P) pitcher-only — pitcher rates + batter-order aggregates, same/opposite-handed splits linked in hierarchy; (PB) + learned batter rates; (PBR) + recency weighting — 4 chains over 500-PA blocks, weights ~40%/30%/20%/10% (Marcel-inspired), max 2,000 PAs/player; (BR) + player-specific base-running transitions via posterior-predictive stolen-base rate, five SB-tendency strata (216 transitions estimated per stratum, weighted by posterior). NUTS sampling; posterior means for prediction. Each model embedded in the "pseudo-full game manager" from prior work [10] — a stochastic zero-sum perfect-information extensive-form game solved by approximate subgame-perfect Nash equilibrium (substitutions, intentional walks). Win-value measured via beta-posterior win-rate differences normalized to added wins per 162-game season.

## 4. Equations & assumptions
(1) state_{i+1} ∼ f(state_i, pitcher, batter). (2) Handedness offsets: a_i(n,h) = â_i(n)^{o_i(n)} if h=0 (opposite), â_i(n)^{1/o_i(n)} if h=1 (same); o_i ∼ Gamma prior, â_i ∼ Beta prior. (3) Log5 combination: S_i(n,m,h) = P_i·ln[a_i/(1−a_i)] + B_i·ln[b_i/(1−b_i)] − (P_i+B_i−1)·ln[c_i/(1−c_i)], with P_i, B_i ∼ Uniform(0.25, 1.75), 1 ≤ P_i+B_i ≤ 2 — the negative league weight −(P_i+B_i−1) creates the "extreme factor" amplifying extreme-on-extreme matchups. (4) x_i = 1/(1+e^{−S_i}). (5) X ∼ Categorical(x_i/Σ_j x_j). (6) Posterior-predictive SB rate = (α+x)/(α+β+n), α,β from beta prior fit on players with ≥200 steal opportunities. Assumptions: outcome distribution independent of game state; transition distribution independent of pitcher; 4-chain recency weighting approximates exponential decay; BR-as-ground-truth for GMP comparison; MLB managers behave optimally when comparing to betting lines; beta posteriors approximated as normal for difference estimation.

## 5. Features / target
Inputs: batter/pitcher identities, handedness, trailing PA histories (up to 2,000 PAs, recency-weighted), SB tendency (opportunities, successes), base-out state. Targets: 9-class PA outcome distribution, 24-state transition distribution, game-level win probability under each model's Nash-approximate management.

## 6. Validation design
Time-ordered validation (train ≤June 2024, validate July–Oct 2024) on cross-entropy log-loss + geometric mean probability GMP = e^{−log loss} for outcomes and transitions, plus GMP vs BR-as-ground-truth. Decision-value evaluation: 1.6M simulated replays per playoff game per model, beta-posterior win-rate differences vs self-play, normalized to added wins/season. Market comparison: $1,000 bets on all 43 games where model P(win) beat consensus-implied probability beyond overround + "cushion" threshold, with 90% Monte-Carlo ROI confidence intervals.

## 7. Numerical results / baselines
Outcome log-loss / GMP: P 1.788 / 16.73%; PB 1.772 / 17.00%; PBR 1.771 / 17.02%; BR 1.771 / 17.02%. Transition: P 1.171 / 31.00%; PB 1.168 / 31.09%; PBR 1.168 / 31.10%; BR 1.166 / 31.15%. Vs BR-as-ground-truth outcome GMP: P 16.48%, PB 16.79%, PBR 16.82%. Simulation: P loses ~1 win/season vs better models; PB significantly behind; PBR ≈ BR essentially tied (0.0 inside posterior difference). GMP gap PBR−P is only 0.15pp (16.82% vs 16.48%... 0.34pp vs BR-ground-truth; vs validation 0.29pp) yet buys ~1 added win/season — a top-50 position-player-level impact (~1 WPA). Betting: 15/43 games within overround (no bet); 28 bets at 0% cushion → −15.5% ROI; cushion 3% → +9.1% (16 bets); 4.5% → +13.5% (10 bets); 6% → +29.4% (5 bets); 7.5% → +52.0% (3 bets); 9% → +128.0% (2 bets); 9.5% → +125% (1 bet). Model never bet home team — no home-field advantage term (acknowledged flaw). Recency insight: adding recency barely changed log-loss but had a notable win-probability impact (PBR clearly beat PB in simulation); base running improved log-loss but had ~zero decision impact.

## 8. Code / data availability
Data: pybaseball (public Statcast), MLB Stats API (public), OddsPortal lines (public, cited). Code: not stated/released. Prior game-theoretic framework [10] is a Sloan 2025 paper. Fully specified equations (1)–(6) make reimplementation feasible; NUTS via PyMC.

## 9. Leakage & limitations
- Betting results rest on n=43 playoff games with as few as 1–3 bets at profitable cushions — +128% ROI on 2 bets is noise; even the 3% cushion (16 bets) has 90% CI [−21%, +48%] that includes negative. The "turns a profit at 3% cushion" claim is statistically unsupported.
- Using BR as ground truth for GMP-then-finding-BR-best is circular; authors admit BR slightly beat itself on validation, suggesting over-regularized priors (under-confident posteriors).
- Simulation assumes optimal opposing management and substitutes the authors' roster guesses where real availability was unknown (pitchers "believed rested and healthy").
- Recency chain-splitting (4 chains × 500-PA blocks, ~40/30/20/10) is ad hoc — no tuning or decay-parameter search.
- Model has no home-field advantage and never bets home teams — a basic miss.
- NFL transfer caveats: baseball is discrete, turn-based, with cleanly attributable batter–pitcher matchups; football plays are 22-agent simultaneous with heavy scheme confounding — the matchup-model decomposition is harder and the game-theoretic equilibrium computation explodes (NFL game tree >> baseball state space).

## 10. GSE overlap
Related but not duplicated. The map has 4th-down decision models, game-theoretic NFL work, and Bayesian team-strength models — but no hierarchical Bayesian log5-style unit-vs-unit matchup model with recency weighting, and no study coupling matchup-model fidelity to decision quality. The paper's central empirical finding (recency ≈ no log-loss gain but real win-probability gain; base-running = log-loss gain but no decision gain) is a direct methodological warning for GSE's feature selection: GSE currently evaluates features on predictive metrics (log-loss/Brier), which this paper shows can misrank features by decision value. That insight alone is worth porting even if the baseball specifics don't transfer.

## 11. GSE implementation spec
(1) Matchup model: hierarchical Bayesian log5 per the paper's equations (2)–(5) for NFL play outcomes — replace batter/pitcher with QB vs defensive unit (and OL vs DL for run plays): per-play success/turnover/explosive-play probabilities, same/opposite-style splits replaced by scheme-matchup offsets (e.g., man vs zone coverage splits, blitz-rate splits), trailing ~2,000-play windows with the paper's 40/30/20/10 recency weighting. (2) Fit with NUTS (PyMC), train 2015–2022, validate 2023–2024 on log-loss + GMP exactly as Table 1. (3) Decision layer: feed matchup probabilities into GSE's existing 4th-down/go-for-it decision model and measure the change in expected win probability added — replicating the paper's simulation protocol (self-play baseline vs augmented matchup model). (4) Evaluate features by decision-WPA, not just log-loss: adopt the paper's dual-metric reporting (predictive GMP + simulated added wins) as a standing gate for any GSE feature. Effort: 2–4 weeks; NUTS on ~2,000-play windows per unit is tractable.

## 12. Reproducible test
Dataset: nflverse 2015–2024. Baselines: GSE's current matchup/4th-down inputs vs hierarchical log5 with/without recency vs with/without unit-matchup offsets. Metrics: play-outcome log-loss + GMP (Table-1 analogue) AND Monte-Carlo added-wins from the decision model (the paper's Figure-3 analogue), on strictly time-ordered holdout 2023–2024. Must replicate the paper's key dissociation in NFL data: does recency weighting move decision-WPA even when it barely moves log-loss? Report both metrics for every candidate feature — any feature with log-loss gain but zero decision-WPA gain is deprioritized (the base-running lesson).

## 13. Acceptance / rejection gate
ADOPT hierarchical log5 matchup models if the PBR-style model (unit matchups + recency) shows ≥0.5% relative GMP improvement over GSE's current baseline AND the decision simulation shows ≥0.1 added wins/season attributable to the matchup upgrade (paper: ~1 win/season from 0.15–0.34pp GMP; scale expectations down for NFL's noisier plays). REJECT if no decision-WPA gain — the baseball result may be an artifact of baseball's clean attribution, and NFL's simultaneous 22-agent plays may wash out the matchup-model edge (in which case keep the dual-metric evaluation gate anyway, since that methodological lesson is free).

## 14. Improvement experiment
Make the recency decay rate a learned hyperparameter per matchup type instead of the paper's fixed 40/30/20/10 chain scheme: place a hierarchical prior over decay rates (pass-game matchups vs run-game matchups vs special teams) and fit via the same NUTS pipeline. Hypothesis: run-game matchups (OL/DL continuity) have longer effective memory than pass-game matchups (QB form, CB injuries turn over faster) — the paper's uniform 40/30/20/10 would be rejected in favor of type-specific decay, improving both GMP and decision-WPA while testing whether the recency effect is real or an artifact of the fixed scheme.
