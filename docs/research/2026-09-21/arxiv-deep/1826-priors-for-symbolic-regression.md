# [1826] Priors for Symbolic Regression (arXiv:2304.06333)

**Citation:** Deaglan J. Bartlett, Harry Desmond, Pedro G. Ferreira (2023, GECCO). *Priors for Symbolic Regression*. arXiv:2304.06333v2. URL: https://arxiv.org/abs/2304.06333
**Ledger completed:** 2026-09-22. **Read:** full text (ar5iv HTML).
**Verdict:** ADAPT

The n-gram language-model structural prior (operator arrangement matters, not just counts) plus the Fractional Bayes Factor treatment of parameter priors give GSE a principled model-selection layer on top of any SR engine; needs adaptation because the corpus must be rebuilt from sports analytics formulas, not physics equations.

## 1. Research question
When choosing between competing symbolic models, humans prefer "simpler" expressions and ones resembling equations seen before in the domain — a non-uniform prior on functions that SR frameworks ignore. Can we (a) build a structural prior via an n-gram language model over operator arrangements (capturing that sin(x0)+sin(x1) is a priori more plausible than sin(sin(x0+x1)) despite identical node/operator counts), (b) handle parameter priors fairly via the Fractional Bayes Factor (FBF), and (c) does Bayesian-with-priors beat MDL and heuristic Pareto methods at selecting the truth on noisy benchmarks and real cosmology data?

## 2. Dataset / schema
- Benchmarks: Nguyen-8 (x√x), Korns-1 (1.57+2.43x), Korns-4 (−2.13+0.13·sin x), Korns-6 (1.3+0.13√x), Korns-7 (213.81(1−e^{−0.547x})); 10⁵ x-values uniform per domain, Gaussian noise added (σ scaled to std of y), 5 independent datasets per function per sample size; functions up to complexity 8 over basis {x, a, √·, (·)², sin, …}.
- LM prior training corpus: 161 scientific equations (100 Feynman SR Database + 61 more), converted to function trees via `esr` (Bartlett et al. 2022).
- Real-world: Pantheon+ sample of 1590 Cepheid-calibrated Type Ia supernovae; target y(x≡1+z) = H²(z) (expansion history of the universe).

## 3. Method / model
Two upgrades to Guimerà et al. 2020's Bayesian SR selection:
- **Parameter prior via Fractional Bayes Factor**: P_b(θ_i|f_i) with initially uniform wide priors made acceptable/desirable under FBF; for uniform priors the MLE = posterior mode, so only a single likelihood optimization is needed. Evidence via Laplace approximation: log Z(D|f_i) ≃ log Ĥ + (p/2)log 2π − (1/2)log det Î^H (Eq. 3), Hessian via finite differences (numdifftools). Shows Guimerà's BIC-with-uniform-prior ranking can be altered arbitrarily just by changing uniform prior bounds — FBF fixes this.
- **Structural prior via n-gram language model**: parse each corpus equation into a tree; extract "phrases" = sets of sibling nodes + their direct ancestors; build an n-gram model over operator sequences (left/right split, separate back-off models). P(f_i) from the LM captures operator ARRANGEMENT correlations (nested sin vs sum of sins), not just marginal operator frequencies. Explicitly shows MDL's implicit function prior: replacing MDL's k·log n term with the LM prior is a drop-in change (MDL+LM variant).
- Six model-selection procedures compared: likelihood-only, 'score' (Pareto-front heuristic), MDL (Bartlett 2022), MDL+LM, MDL+FBF+LM, Bayes+FBF+LM. Procedures are search-agnostic (work with any function-generation algorithm, e.g. exhaustive scan).

## 4. Equations & assumptions
P(f_i|D) = P(f_i)/P(D) · Z(D|f_i); −log P(f_i|D) = −log P(f_i) − log Z(D|f_i) (Eqs. 1–2)
log Z(D|f_i) ≃ log Ĥ + (p/2)log 2π − (1/2)log det Î^H (Eq. 3, Laplace)
FBF substitution: P(θ_i|f_i) → P_b(θ_i|f_i); uniform priors acceptable
Assumptions: (1) uni-modal posterior (Laplace valid); (2) corpus equations representative of "reasonable" structure; (3) operator independence breaks only via n-gram correlations (higher-order structure beyond n-gram window ignored); (4) exhaustive scan up to complexity 8 covers the truth; (5) Gaussian noise model.

## 5. Features / target
Benchmarks: single input x, target = benchmark function value + Gaussian noise. Cosmology: input x≡1+z (redshift), target y = H²(z) expansion rate. GSE analog: inputs = team-game features, target = points/drive or wins.

## 6. Validation design
For each benchmark function × sample size: 5 independent noisy datasets; candidate functions generated by exhaustive scan (esr) up to complexity 8; six selection methods rank them; metric = whether/how strongly the truth (any mathematically equivalent form, via esr simplification + visual inspection) is ranked top. Fig. 2 plots (metric(top) − metric(truth)) vs number of data points. Cosmology: rank functions on real Pantheon+ data, inspect physical reasonableness (Table 2, top-4 per method).

## 7. Numerical results / baselines
- Likelihood-only selection NEVER puts the truth in the top two (overfitting always wins on noisy data — expected).
- 'Score' (Pareto heuristic): almost always selects truth for Nguyen-8 but the truth often doesn't appear in rankings elsewhere; worse, score need not prefer the truth even as N→∞ (likelihood scales ~linearly with N).
- MDL (no function prior): best on standard benchmarks — always selects truth for Nguyen-8; best for Korns-1/Korns-6 (needs more data); truth almost always selected for Korns-4. LM-prior variants slightly worse on pure benchmarks (e.g. truth often 3rd for Nguyen-8; MDL+LM the only other method to ever select Korns-1 truth, at ~10⁴ points).
- LM methods WIN on Korns-7: scientific-equation prior selects the truth with fewer data points than any other method.
- Cosmology (Pantheon+, Table 2): plain MDL's top functions include physically unreasonable x^x forms; replacing k·log n with the LM prior eliminates x^x from the top four — all become sums of x to integer powers with free scale parameters — and promotes the GR-motivated Eq. 18 to 4th. Paper's conclusion: MDL best on synthetic benchmarks but produces unphysical equations on real data; LM prior fixes this when domain prior information exists.

## 8. Code / data availability
`esr` package (Bartlett et al. 2022) used for tree conversion and exhaustive scan; numdifftools for Hessians; Pantheon+ data public. No single repo URL stated in extracted text for the prior code itself.

## 9. Leakage & limitations
- Corpus = physics equations; applying a physics prior to sports is exactly the kind of domain mismatch the authors warn about implicitly — the Korns-7 win was luck (truth happened to look scientific).
- Exhaustive scan limited to complexity 8 — trivially small; LM prior untested as a guide for open-ended search (they note the procedures are search-agnostic but never test with GP/RL).
- Laplace approximation assumes uni-modal posteriors; multi-modal sports likelihoods would break the evidence estimates.
- LM prior slightly HURTS on simple synthetic benchmarks (Nguyen-8) — a miscalibrated prior is worse than none; corpus quality is everything.
- FBF with uniform priors still needs defensible bounds in practice.
- Truth-equivalence judged partly by visual inspection — subjective.

## 10. GSE overlap
New capability: GSE has no principled model-selection layer for discovered equations — current practice would be Pareto-front eyeballing (the 'score' method this paper shows is asymptotically inconsistent!). The paper's demolition of likelihood-only and score-based selection is directly relevant to how GSE should pick among PySR's hall-of-fame. Complements 1822/1824/1825 (all need a selection rule).

## 11. GSE implementation spec
- Build a SPORTS corpus: collect ~100–200 published sports-analytics formulas (passer rating, QBR components, EPA models, DVOA-style expressions, Elo update rules, Pythagorean expectation variants, target-share formulas) → parse to operator trees → train the n-gram LM prior exactly per Sec. 2.4 (sibling+ancestor phrases, left/right back-off).
- Selection pipeline: take PySR Pareto front → compute for each candidate: Laplace-approximated log-evidence with FBF-style uniform parameter priors (Hessian via numdifftools or JAX) + LM log-prior → rank by −log P(f_i) − log Z. Compare against plain accuracy ranking.
- Data: nflverse; the prior is domain knowledge, data is the verifier. Effort: ~2 engineer-days (corpus curation is the long pole; code is straightforward).

## 12. Reproducible test
Dataset: nflverse team-season 2009–2023; generate PySR candidate equations (complexity ≤10) predicting points/drive. Selection methods: (a) best train-RMSE ('score'-like), (b) MDL, (c) Bayes+FBF+LM with sports corpus. Metric: rank-correlation between each method's ranking and held-out 2024–2025 RMSE ranking (does the selector pick equations that generalize?).

## 13. Acceptance / rejection gate
ADOPT the LM-prior selector if its top-3 picks achieve ≥10% lower held-out RMSE than the top-3 picks of plain best-fit selection on the 2024–2025 window AND it never ranks a degenerate (constant-only/single-input) equation in the top 5; REJECT if the sports corpus prior underperforms MDL or shows the Nguyen-8 pathology (truth-equivalent good equations systematically demoted).

## 14. Improvement experiment
"Corpus ablation by era": train two LM priors — one on pre-2015 formulas (passer rating era), one on post-2015 formulas (EPA/tracking era) — and test which selects better-generalizing equations for 2024–2025 data. This tests whether the prior should track the field's evolving notion of "reasonable structure," and directly measures the cost of a stale prior — a question the paper never asks but GSE needs answered before baking a prior into production.
