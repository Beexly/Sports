# [0111] Scoring Without the Engine: Validating a Deterministic, Manipulation-Resistant Content Score for Generative Engines, End to End (arXiv:2609.07559v1)

**Citation:** Elisha Bajemon, André-Louis Rochet (TW3 Partners / Citead), July 2026. *Scoring Without the Engine: Validating a Deterministic, Manipulation-Resistant Content Score for Generative Engines, End to End*. arXiv:2609.07559v1. URL: https://arxiv.org/abs/2609.07559v1
**Ledger completed:** 2026-09-21. **Read:** full text (PDF via arxiv.org, 42 pages, 4 figures; equations garbled in places by PDF extraction — reconstructions flagged as uncertain).
**Verdict:** ADAPT — the GEO/citation domain itself is not GSE's, but the validation protocol (adversarial falsification gates + per-weight identifiability + query-conditioned skyline bound) is a reusable, deterministic method GSE can port to quality-scoring sports content (post drafts, feed items, analyst copy) at zero inference cost.

## 1. Research question
How do you validate a cheap, deterministic proxy for an oracle that is expensive, rate-limited, and non-stationary? The paper builds a general validation protocol — define and select the proxy by adversarial falsification gates, bound what it can never resolve with a conditioned skyline, check it against external causal evidence, and re-measure that evidence on the current oracle — and demonstrates it end to end on Generative Engine Optimization (GEO), where the proxy is a deterministic content score (0–100) computed from page text alone, auditable line by line, with zero marginal recompute cost (~70 ms/page on commodity CPU). One step of the demonstration fails exactly as the protocol is designed to detect: the 2023 published causal anchors (GEO lever effect sizes) no longer move citation on any of ten modern engine families, so the anchors are an expired external check and what survives is the gate-enforced response surface.

## 2. Dataset / schema
- **GEO-Bench** (GEO-Optim, HuggingFace `GEO-Optim/geobench`, 2024; cited in paper §2/§5.2): 500 English page sources, fixed 250 train / 250 test split; 60 French sources for cross-lingual transfer. Each source: page text (markdown) plus deterministic edit variants (intervention realizations).
- **Intervention capture**: every source scored under 21 deterministic variants (paired edits at doses 1,2,3,8 plus content-neutral length-matched filler); full strategy-study capture ≈ 35,000 scorings.
- **Outcome records**: 821 (engine, query) records over 229 unique queries; 819 form complete five-source ranking groups; 777 have non-degenerate within-query variance for correlation analysis (§8). Seven engine arms: six open-weights (mistral-medium-3.5, gemma-4-31b, nexn2-pro, gpt-oss-120b, qwen3.5-122b, llama-3.3-70b, temperature 0, fixed seed, pinned model identifiers) plus one closed commercial (gemini-3.1-flash-lite). July-2026 replication: three proprietary gpt-5.x arms (gpt-5.5, gpt-5.4, gpt-5.4-mini), n=150 paired queries each (450 pooled), single-run by design (provider exposes neither temperature nor seed).
- **Gaming benchmark**: 500-source benchmark of volume-controlled adversarial edits (2,000 additional deterministic scorings for combined attacks).
- Access: public, released with the paper at https://github.com/TW3-Partners-OS/geoscorereproducibility (HuggingFace dataset cited; repo URL stated in §11).

## 3. Method / model
Pipeline (Fig. 2, §4): page text → 11 deterministic subcomponents f_i(x) ∈ [0,100] (regex, counting, scipy/numpy, wordfreq, sklearn TF-IDF; Appendix A gives exact formula, normalization, degenerate values, worked example per subcomponent, verified against the released implementation; no LLM/embeddings/network at scoring time) → concave anti-stuffing transform g(u)=100√(u/100) applied elementwise → weighted sum with w in the 11-simplex (Eq. 3) → 0.92·GEOcontent + 0.08·freshness blend F(x) (Eq. 4) → word-count caps (35 pts under 100 words, 50 under 200, 65 under 300; App. A.13). Domain ranking uses shrinkage: s̃ = (kp + n·s̄)/(k+n), prior p=50, strength k=5 (§4, Def. 2).
Calibration: each aggregation family fitted by regularized cosine alignment to the five causal anchors γ (Eq. 6, nested λ on inner split, ridge anchor to frozen prior observational weighting w0; unregularized fit rejected as overfit), then falsification gates eliminate infeasible families (Eq. 2). Candidates: raw-linear (production family), sqrt-saturated (selected), quantile-linear (ECDF); baselines: production weights, equal weights, best single feature, prior intervention-calibrated raw candidate.

## 4. Equations & assumptions
- **Problem 1 / 2 (§3):** s: X → [0,100] deterministic; visibility V_E(x_k|q,x_1:K) ∈ [0,1] (PAWC-like share) is the causal quantity. *(Notation V_E reconstructed from garbled PDF extraction — uncertain.)*
- **Eq. (1), Proposition 1 (query-blindness ceiling):** "For an unordered pair of sources {x,x′}, let p(x,x′) = Pr[V_E(x|q,·) > V_E(x′|q,·)] be the probability, over the queries in which the pair competes, that x is the more visible source. Any query-agnostic scorer s: X → R orders each pair identically for every query, so its expected pairwise concordance satisfies C(s) ≤ E[max{p(x,x′), 1−p(x,x′)}] =: C_max, max < 1 whenever visibility genuinely depends on the query, i.e. 0 < p(x,x′) < 1 on a set of pairs of positive measure. Only conditioning on q can close the gap 1−C_max." *(Formal E[max{...}] reconstructed from garbled extraction — uncertain in exact notation; the verbal statement is verbatim.)*
- **Eq. (2) (constrained selection):** w⋆ ∈ argmax_w align(Δ_m(s_w), γ) s.t. gate_j(w) passes, j=1…5; w ∈ Δ^{d−1}. *(Reconstructed — uncertain.)*
- **Eq. (3), Definition 1:** GEO_content(x) = Σ_{i=1}^{11} w_i g(f_i(x)), g(u) = 100√(u/100) elementwise, w in simplex. (Verbatim as stated §4.2; the summation rendering was garbled in extraction but the components are verbatim.)
- **Eq. (4):** GEO(x) = 0.92·GEO_content(x) + 0.08·F(x).
- **Eq. (5) (volume-controlled response):** Δ_m(s) = E_x[ s(x ⊕ e_m^δ) − s(x ⊕ e_0^δ) ] estimated over GEO-Bench sources. (Verbatim §5.2.)
- **Eq. (6) (fitting):** w⋆ = argmin_w [ −⟨Mw, γ⟩/(‖Mw‖‖γ‖) + λ‖w − w_0‖_2^2 ], w ≥ 0, w normalized to the simplex after; M ∈ R^{5×d} the matrix of volume-controlled subcomponent responses. *(Structure verbatim; exact rendering garbled — uncertain.)*
- **Lemma 1 (concave transforms bound single-lever amplification, §4.2):** "Suppose an edit at dose k moves a single subcomponent linearly, f_i → min(f_i + kδ, 100) with δ > 0, leaving the others unchanged. For any concave g with g(0) = 0, the transformed dose-k response satisfies Δ(k)/Δ(1) ≤ k, with equality only if g is linear on the traversed range; for g(u) = 100√(u/100) and a feature starting at its floor (f_i = 0), the ratio is exactly √k before the cap binds." (Verbatim.) Remark 1: dose-8 saturation gate demands ratio ≤ 3; √8 ≈ 2.83 passes structurally, identity attains worst case 8.
- **Definition 2 (domain ranking):** s̃ = (kp + n·s̄)/(k + n), p = 50, k = 5. (Verbatim.)
- Assumptions (verbatim §3): A1 Anchor validity — Aggarwal et al. (2024) PAWC effect sizes reflect the true relative causal ordering of the five deterministic interventions on their engines/corpus. A2 Anchor transport — the relative ordering carries over to GEO-Bench sources under the deterministic edit realizations (later shown NOT to hold on current engines — reported, not assumed away). A3 Volume control — a content-neutral filler block of the same added length isolates the content effect from the length effect (Eq. 5). A4 Determinism — under a pinned environment (fixed library versions and seeds), every subcomponent and statistic is a deterministic function of input text and released artifacts.

## 5. Features / target
Input: raw page markdown. 11 subcomponents (Table 9 / Fig. 3, released weights): shannon_entropy (0.246), information_density (0.244; dominant term 70% = shannon_entropy, Pearson 0.94 — one construct split across two artifact names), quotable_density (0.124), entity_density (0.094), semantic_coherence (0.084), self_containment (0.073), statistic_density (0.051), mmr_score (0.036), citation_f1 (0.019 — actually a weighted arithmetic mean, not an F1), ndcg_score (0.015 — DCG ratio used as stored metadata only), semantic_redundancy (0.015). Plus freshness F(x) (publication/update recency signals) at 8% blend. Target(s): (a) for calibration, volume-controlled response alignment with the five published causal anchors γ (Quotation +42.6%, Statistics +32.8%, Cite-Sources +27.7%, Technical Terms +18.5%, Keyword Stuffing −8.8% as negative control); (b) for outcome validation, within-query Spearman with engine PAWC citation share (Problem 2 only with query features — the score itself never sees the query).

## 6. Validation design
- Fitted on training split (nested λ on inner split); gates computed on both splits; family selection on train-split gates; test split = held-out confirmation only (Table 2 = heldout values; recompute on train gives identical outcome).
- Alignment reported as Pearson/Spearman between (Δ_m) and γ, bootstrap CI95 over sources, exact one-sided permutation p over the 5! = 120 anchor orderings (floor p = 1/120 ≈ 0.0083).
- Five falsification gates (§5.4): (1) negative control Δ_KS ≤ 0 at dose 1 and dose 8; (2) dose-response — volume-matched responses at doses 1,2,3 must not decline materially (worst consecutive step ≥ −0.5 points); (3) adversarial saturation — dose-8 response ≤ 3× dose-1 for each additive lever; (4) duplication — full-text duplication gains ≤ +2 points; (5) length bias — |corr(s(x), log‖x‖)| ≤ 0.35. Sixth (non-gate): French cross-lingual transfer, evaluated but excluded from gate count.
- Baselines: production weights, equal weights, best-single-feature (shannon-only), prior intervention-calibrated raw candidate; quantile family for comparison. Ranker study (Appendix E): LambdaMART (LightGBM), ridge, open-weights cross-encoder, regex-only ranker; cross-validation folds over UNIQUE queries (query-disjoint) — a (engine,query)-fold version that leaked was disclosed and corrected.
- Splits are page-split (sources), not time-ordered; N/A for the domain but the outcome arms are fixed-snapshot engines.

## 9. Leakage & limitations
Adversarial reading: (1) Anchor set is tiny — five interventions; exact permutation floor 1/120 means alignment claims sit at the boundary of testability; Pearson CI95 [0.932, 0.964] is real but the Spearman-1.0 ceiling is coarse. (2) Calibrating and gating on the same interventions risks teaching-to-the-test; the paper mitigates (nested selection, ridge anchor, held-out, adversarial variants never seen by fit, transfer corpus) and the strongest defense is that the headline property (Lemma 1) is not itself a test score. (3) Three harness bugs were found and disclosed (French quote-coverage hole, double-string-join negative-control bug — prior stuffing numbers were measured against letter noise, not keyword stuffing; (engine,query)-fold leakage); the paper's honest inference is residual undiscovered-bug risk. (4) Entropy saturates at 100 on 84% of base sources — absolute levels weakly supported vs edit responses; the entropy pair double-counts one construct (merge refit says immaterial, but it inflates the weight count). (5) Block-structural features degenerate on plaintext; tokenization ASCII-only; French transfer tests degraded features, not language fairness. (6) Outcome frame is a proxy: five curated sources, fixed prompt, PAWC share — not open-web competition with retrieval/deduplication (Puerto et al. 2025); gpt-5.x arms single-run, no temperature/seed; hosted snapshots may drift. (7) The score detects none of the OOD attacks tested; calling it a "manipulation detector" is unsupported by the benchmark — it is a manipulation-*resistant quality measure*, a different claim. (8) Domain gap to NFL: nothing in this paper concerns sports, odds, or prediction; the reusable asset is purely the validation methodology. Any GSE application must re-derive anchors/gates for the sports-content domain — the GEO weights and anchors do not transfer.

## 11. GSE implementation spec
ADAPT the protocol, not the score, to a "sports-copy quality filter" for GSE's publishing pipeline (X posts, Feed items, script briefs):
- Data: GSE's own published corpus — past @GalaxySportsHQ posts with their engagement, clip scripts, feed units (repo docs/research dated dirs). Deterministic features re-derived for sports copy: entropy family (unchanged), sports-specific carriers (stat-density = numerics/team names per 100 words; quote-density → analyst-attribution density; citation-F1 → link/source-attribution score; readability/structural features from the paper's family).
- Calibration: define falsification gates in sports-copy terms — negative control = keyword/em-dash stuffing or stat-stuffing edit must not raise score; dose-response at 1,2,3 insertions; saturation dose-8/dose-1 ≤ 3; duplication ≤ +2; length bias ≤ 0.35. Anchors: GSE's own causal levers where any exist (e.g., posts with/without stat tables); treat the paper's lesson as load-bearing — assume published "engagement levers" are expired until re-measured on the current X algo.
- Model: same sqrt-concave aggregation family (Lemma 1 transfers — it is transform-family math, not GEO math); Eq. 6 regularized cosine fit with ridge to a frozen prior; per-weight identifiability (Table-3-style profile refits) before claiming any weight is "calibrated".
- Serving: pure Python/scipy offline scorer (~70 ms/page); runs as a pre-publish check in the content pipeline, zero API cost; leaderboard shrinkage (Def. 2) for ranking analysts/drafts.
- Effort: ~1–2 days to port feature code + gates harness; ~1 day to collect the intervention capture on GSE copy; no ML training infra needed.

## 14. Improvement experiment
Apply the protocol's skyline idea to GSE's own validation problems: a *query-conditioned skyline* for pick confidence — train a cheap deterministic "pick quality" score on engine pick features (model agreement, market disagreement, CLV history) and bound it with a skyline model that sees the game context the score cannot (injury news, weather, line movement). The falsification-gate framing transfers directly: negative control = a pick record with shuffled outcomes must score ≤ baseline; dose-response = more agreeing signals must not decrease the score; bounded amplification = no single input feature may move the score by more than X via the sqrt transform. This would give GSE a manipulation-resistant confidence filter for the posted card — the exact property the paper proves for its domain, ported to the one number Garrett's public record lives or dies on.
