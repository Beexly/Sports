# [0489] Decoding Defensive Coverage Responsibilities in American Football Using Factorized Attention Based Transformer Models (arXiv:2603.25901v1)

**Citation:** Kevin Song, Evan Diewald, Ornob Siddiquee, Chris Boomhower, Keegan Abdoo, Mike Band, Amy Lee (2026). *Decoding Defensive Coverage Responsibilities in American Football Using Factorized Attention Based Transformer Models*. arXiv:2603.25901v1. URL: https://arxiv.org/abs/2603.25901v1
**Ledger completed:** 2026-09-21. **Read:** full text (PDF text extract, 1113 lines).
**Verdict:** ADAPT — port the "disguise rate" (pre-snap vs post-snap assignment divergence) and per-defender matchup-attribution concepts to GSE's matchup model using Big Data Bowl 2025 tracking; the proprietary NGS/PFF labels cannot be replicated.

## 1. Research question
Can factorized-attention transformers trained on NFL player-tracking trajectories predict individual defensive coverage assignments, receiver-defender matchups, and the targeted defender on every pass play — at any frame from pre-snap through pass arrival — and do these outputs enable new derivative metrics (disguise rate, double coverage rate) beyond post-hoc team-level coverage classification?

## 2. Dataset / schema
NFL Next Gen Stats (NGS) tracking data, seasons 2020–2024; 2020–2023 train, 2024 test. Five sources: (1) tracking — player and ball x,y at 10 Hz, plus player orientation and movement direction; (2) play events (snap, pass forward, pass arrival); (3) participation/roster data; (4) Pro Football Focus ground-truth labels (individual coverage assignment, defender-receiver matchups, target defender); (5) play data (play direction, field position). Filtered to passing plays with valid snap + pass-forward events and PFF annotations for each task. Sequences: -30 pre-snap frames at 10 Hz to pass forward, frame 0 = snap, directional normalization (all plays run left-to-right), angular transform on orientation/direction vectors. Proprietary NGS + PFF labels — not publicly replicable; Big Data Bowl (BDB) releases are the only public tracking proxy. Sample: 21,567 eligible pass plays in the 2024 season (double-coverage analysis).

## 3. Method / model
Three task-specific classifiers sharing a common factorized-attention transformer backbone. Attention is factorized: temporal attention per agent and agent ("social") attention per timestep, as in Scene Transformer / HoopTransformer, instead of full spatio-temporal attention. Learnable embeddings for categorical metadata (player position, offense/defense indicator) fused with transformer output into per-player latent vectors → feed-forward classification head. Coverage-assignment task additionally consumes situational features (down, distance, yard line, time left) and the team coverage scheme label (ground truth at train time; at inference, a separate model [12] predicts the scheme first). All heads apply temporal pooling (average over time) to get play-level per-player representations. Output shapes: coverage assignment [num_defenders, 20] (20 classes incl. "no assignment" for rushers); target defender [num_defenders + targeted_receiver] logits, masked so the receiver logit = -1e9 pre-softmax; matchup [num_defenders, num_receivers + 1] via pairwise concatenation of eligible-receiver and defender features + "no matchup" class. Target-defender pipeline adds post-processing rules: assign "no target defender" when confidence < 50% in prevent alignment or receptions behind the line; otherwise default to the matchup model's assignment. Training augmentation: random trajectory truncation — 11 fixed strategies (start ∈ {-30,-20,-10,0}, end ∈ {snap, pass forward, pass arrival}) at 60% plus fully random truncation at 40%. Hyperparameters (Table 4): batch 16; epochs 100 (target defender), 200 (matchup), 150 (coverage); AdamW (wd 1e-4, betas 0.9/0.999); target/matchup use OneCycleLR max_lr 2e-4 (pct_start 0.1, div_factor 10, final_div_factor 100); coverage uses CosineAnnealingWarmRestarts init_lr 2e-5, T0=15, Tmult=1, eta_min 2e-7; heads 4/4/8; layers 3/3/6; dropout 0.1/0.2/0.1.

## 4. Equations & assumptions
Cross-entropy losses, per task. Matchup loss (eq. 1): L_matchup = -(1/D) Σ_{d=1}^{D} Σ_{r=0}^{R} z*_{d,r} log( exp(Z_{d,r}) / Σ_{r'=0}^{R} exp(Z_{d,r'}) ), where Z_{d,r} is the logit for defender d covering receiver r, R the number of eligible receivers, z*_{d,r} the ground-truth assignment (r=0 = "no matchup"). Coverage loss (eq. 2): L_coverage = -(1/D) Σ_d Σ_{c=1}^{C} 1[c=c*] log( exp(z_{d,c}) / Σ_{c'=1}^{C} exp(z_{d,c'}) ), C=20 assignment classes, c* the ground-truth class. Target-defender loss (eq. 3): L_target = -log( exp(z_d) / Σ_{j=1}^{N} exp(z_j) ), single-label categorical over N players (receiver logit masked). Assumptions: one ground-truth label per play per task (play-level annotation, typically end-of-play state); exactly one true target defender per play; 20-class coverage-assignment taxonomy is exhaustive; the upstream predicted team coverage scheme at inference is interchangeable with ground truth; plays without valid snap/pass-forward events or PFF labels are droppable without bias.

## 5. Features / target
Inputs: per-frame (x, y) coordinates, orientation angle, movement-direction vector for all 22 players + ball; categorical embeddings (position, offense/defense); situational features (down, distance, yard line, time left); team coverage scheme. Targets: (a) per-defender coverage assignment (20 classes: 19 responsibilities e.g. hook curl left, deep right + "no assignment"); (b) per-defender receiver matchup (num_receivers + 1, incl. "no matchup"); (c) single target defender per play. Prediction horizon: any truncation window from -30 pre-snap frames through snap / pass forward / pass arrival; frame-by-frame inference possible.

## 6. Validation design
Time-ordered split: train 2020–2023, test 2024 (holdout season). Each model evaluated across the 11 truncation strategies (start × end boundaries) for temporal robustness. Accuracy per-defender for matchup (match = correct receiver per defender) and coverage assignment; target defender as plays-correct / total plays. Baselines: prior team-level CNN-LSTM coverage classification (88.9% across 8 coverage types) — team-level, not directly comparable; rule-based nearest-defender-to-targeted-receiver heuristic for target defender (76.4%); pre-snap vs post-snap contrast as an implicit ablation. No stated cross-validation or confidence intervals.

## 7. Numerical results / baselines
- Receiver-defender matchup: up to 0.894 accuracy / 0.894 F1 on full context (-30 → pass arrival); post-snap windows 0.872–0.873; pre-snap-only windows ~0.750–0.752 accuracy, 0.745–0.746 F1 (Table 1).
- Coverage assignment: ~0.918–0.919 accuracy / 0.877–0.879 F1 with post-snap context; pre-snap-only ~0.882–0.883 / 0.825–0.827 (Table 2); ~70% of 2024 plays had all coverage defenders correct at pass arrival; ~20% had 1–3 errors ("judgment calls"); Top-2 accuracy 97% across the 20 assignment classes.
- Target defender: rules-based nearest defender 0.764; transformer 0.862; transformer + post-processing 0.882 — ~12 percentage-point lift (Table 3).
- Double coverage: 1,179 instances across 21,567 eligible 2024 pass plays (5.5% rate); top-5 model-ranked double-covered receivers: Ja'Marr Chase, Garrett Wilson, CeeDee Lamb, Justin Jefferson (plus one more, aligned with human labels); model flagged 9 double coverages on Tre Tucker vs 0 in human labels (paper suggests human "reputation bias"); Mike Evans had only 10 all season.
- Disguise proxy: Kansas City (Spagnuolo) showed the lowest pre-snap prediction accuracy (most deceptive); Tampa Bay and San Francisco most predictable (Figure 7).

## 9. Leakage & limitations
- Ground-truth labels are play-level (end-of-play snapshot) from human annotators while the model predicts frame-by-frame; "errors" on mid-play rotation plays are counted wrong even when the model is temporally correct — the reported accuracy likely understates true frame-level performance (paper's own claim; implies label-noise-driven metric distortion in both directions).
- Training consumes the team coverage scheme as an input feature; inference substitutes a predicted scheme from a separate model — error cascades (scheme-level disagreement propagates to per-defender errors; Figure 5 shows a Cover 4 vs Cover 2 disagreement producing 4 "wrong" assignments). The test-set accuracy mixes two models' errors without an ablation of scheme-input quality.
- Labels are PFF annotations with documented charting-guideline violations (Figure 4: quarters-inside-left label violates the guidelines; authors call it labeling error). Inter-annotator agreement is never reported.
- Model learns scheme symmetry bias (defaults to symmetric assignments) and concentrates errors on rare schemes (Prevent: 3% of plays with 6+ errors).
- Quick-game passes (<2s) leave no time for coverage to develop, inherently limiting assignability.
- Training augmentation (random truncation) is effectively test-time aligned with the 11 truncation evaluation — the evaluation protocol rewards exactly the augmentation distribution (not leakage per se, but the temporal-robustness numbers are on-distribution by construction).
- NFL relevance to GSE: direct. But GSE has no NGS tracking feed; only BDB sample releases are available, and PFF coverage labels are paywalled. Replicating at scale requires proprietary data.

## 11. GSE implementation spec
Data: NFL Big Data Bowl 2025 tracking release (public) as the training corpus; derive weak labels instead of PFF — use the coverage-assignment taxonomy as pseudo-classes generated by rules + the [12]-style team-coverage classifier approximated from formation/alignment (or use unsupervised clustering from ledger 0006's Dutta et al. approach as labels). Model: reimplement the factorized transformer (temporal attention × agent attention) in PyTorch with the three heads; random-truncation augmentation per Appendix 0.A.1. Features per paper §3.1; drop the situational-scheme input or replace with a locally trained team-coverage classifier to avoid the cascade problem. Serving: offline batch per season for disguise-rate tables (pre-snap vs post-snap accuracy gap per team) and weekly matchup reports (double-coverage rate per receiver) — feeds the props/DFS matchup lane. Effort estimate: ~3–4 weeks for a tracking-literate engineer (data pipeline is the hard part; architecture is specified down to hyperparameters in Table 4). Requires BDB 2025 data access; no NGS feed needed.

## 12. Reproducible test
Dataset: BDB 2025 tracking release (pass plays). Baseline: rule-based nearest-defender matchup heuristic (lineup-at-snap proximity), mirroring the paper's §5.1 distance-based predecessor and the 76.4% nearest-defender target-defender baseline. Metric: per-defender receiver-matchup accuracy on the truncated (-30 → snap) and full (-30 → pass arrival) windows, plus target-defender play-level accuracy. Window: train on BDB 2025 weeks 1–8, test on weeks 9–17 (time-ordered), using pseudo-labels from an unsupervised coverage clustering or team-coverage classifier trained on the same window. Runnable without NGS or PFF.

## 13. Acceptance / rejection gate
ADOPT the factorized-attention per-defender approach if on the BDB test window the model beats the nearest-defender baseline by ≥10 percentage points on target-defender accuracy (paper's margin: 88.2% vs 76.4%) AND achieves ≥85% matchup accuracy with post-snap context; REJECT if either lift is <5 points. ADOPT the disguise-rate metric for matchup reporting if team-level pre-vs-post-snap divergence is stable week-to-week (rank correlation ≥0.6 across season halves).

## 14. Improvement experiment
Replace the hard team-coverage-scheme input with a learned scheme embedding trained jointly end-to-end (multi-task: scheme + assignment), eliminating the train/inference cascade the paper admits. Hypothesis: joint training forces per-defender features to be scheme-consistent without a brittle upstream dependency, and the scheme head's uncertainty can gate low-confidence assignments (the paper's §5.2 Figure 5 cascade becomes a calibrated uncertainty output instead of silent error propagation).
