# [0317] Scalable Injury-Risk Screening in Baseball Pitching via Pose-Derived Biomechanical Features (arXiv:2603.04864v1)

**Citation:** Jerrin Bright, Justin Mende, John Zelek (2026). *Scalable Injury-Risk Screening in Baseball Pitching via Pose-Derived Biomechanical Features*. arXiv:2603.04864v1. URL: https://arxiv.org/abs/2603.04864v1
**Ledger completed:** 2026-09-21. **Read:** full text (PDF text extract, 566 lines, main paper + appendix).
**Verdict:** ADAPT — the pose-derived biomechanical screening pipeline (video → 18 joint metrics → variability-weighted injury classifier, AUC 0.811 for Tommy John) is the strongest injury-analytics template in this wave; port the methodology to NFL-relevant movements with strict non-clinical labeling and prospective validation before any production use.

## 1. Research question
The paper asks whether scalable, video-based 3D pose estimation can produce biomechanical features that predict arm-injury risk (Tommy John surgery and significant arm injury) in baseball pitchers — without lab-grade motion capture. It builds a full pipeline: monocular pose → metric 3D via a lifting module → 18 biomechanical metrics → per-pitcher aggregates → injury classifiers, validated against a lab reference and deployed over 119,561 professional pitch sequences.

## 2. Dataset / schema
Two data layers: (a) pose validation — 13 pitchers, 156 pitches, 8 RHP / 5 LHP, all 8 pitch types, 75–102 mph, compared against a lab-grade reference; (b) injury modeling — 7,348 pitchers with workload/demographic/medical features, deployed pose extraction over 119,561 professional pitch sequences. Feature schema: 18 biomechanical metrics (lead/trail knee flexion; lead/trail shin X/Y; throwing/glove elbow flexion; pelvis and torso rotation; hip-shoulder separation; forward/lateral trunk tilt; throwing/glove shoulder abduction; COG x/y/z) aggregated to 90 per-pitcher summary statistics, plus 24 workload/demographic/medical features — stated total 114, though Table 2's V5 reports 144 features (internal inconsistency, flagged in Section 9). Access: not stated as public — proprietary/deployment data; verify before use.

## 3. Method / model
Pose pipeline: DreamPose3D/PitcherNet base pose + a Pelvis-to-Global Lifting Module; overlapping temporal windows with commit of the first K=10 frames; bone-length enforcement from the first N=30 frames (3 passes); joint-limited inverse kinematics; Savitzky-Golay smoothing (window 15, polynomial order 3); bilateral symmetry constraints. Injury models: gradient boosting machine (GBM), balanced random forest, L1-penalized logistic regression; final score = averaged probabilities; stratified 5-fold cross-validation with SMOTE for class imbalance. Feature-importance analysis shows variability/range/coefficient-of-variation features contribute 33–39% of importance — movement *inconsistency*, not just mean mechanics, drives the signal.

## 4. Equations & assumptions
No formal equations stated (the paper is procedural: lifting, IK, smoothing, and aggregation steps are described textually). Stated assumptions: (a) bone lengths are constant within a pitcher (enforced from first 30 frames); (b) bilateral symmetry holds for the skeleton model; (c) Savitzky-Golay smoothing (w=15, p=3) preserves biomechanical signal while removing jitter; (d) the 13-pitcher lab validation generalizes to the 119,561-sequence deployment population; (e) injury labels (Tommy John, significant arm injury) are correctly ascertained from records. The paper explicitly states prospective validation is needed before clinical deployment.

## 5. Features / target
Input features: monocular pitch video → 18 per-frame biomechanical metrics → 90 per-pitcher aggregates (means, maxima, ranges, variability/CV across pitches) + 24 workload/demographic/medical features. Targets: binary Tommy John surgery occurrence; binary significant arm injury. The standout structural finding: variability/range features (not mean mechanics) carry 33–39% of model importance.

## 6. Validation design
Pose validation: 13 pitchers / 156 pitches vs. lab reference, with a predeclared gate — angular MAE < 1° or position < 0.1 ft and r > 0.95 (the paper's stated acceptance criterion). Injury validation: stratified 5-fold CV with SMOTE on 7,348 pitchers; feature-set progression V1→V5 reported as AUC. No temporal holdout stated for the injury model (CV folds are stratified, not time-ordered — a limitation for a deployment that scores future seasons). Baselines: the three classifiers individually vs. the averaged ensemble; V1 (workload/demographics only) vs. V5 (full biomechanics) shows the marginal value of pose features.

## 7. Numerical results / baselines
Paper's numbers: Pose validation (Table 1) — knee/shin/elbow metrics 0.2°–0.5° angular MAE; throwing shoulder abduction 6.2° MAE (r = 0.912); glove shoulder abduction 21.4° MAE (r = 0.743, below the paper's own r > 0.95 gate); COG x 0.02 ft, COG y 0.50 ft (above the 0.1 ft gate), COG z 0.03 ft. Tommy John AUC progression (Table 2): 0.503 → 0.633 → 0.734 → 0.776 → 0.811 (V1→V5). Final V5: AUC 0.811 (Tommy John), 0.825 (significant arm injury). Two internal discrepancies to flag: (a) feature count — 114 stated in text vs. 144 in Table 2's V5; (b) recent-2024+ TJ cases — 167 in text vs. 209 in Table 2. These are the paper's claims; the discrepancies are minor relative to the main result but should be resolved before citing precisely.

## 8. Code / data availability
None stated. No code repository, no data release. Deployment data is proprietary.

## 9. Leakage & limitations
(a) No temporal holdout for the injury classifier — stratified 5-fold CV on pitcher careers risks training on later-career information when predicting earlier injuries; a forward (by season) validation is needed. (b) SMOTE inside CV: if applied before fold-splitting rather than within folds, it leaks — the paper does not specify the order. (c) Two internal numeric discrepancies (114 vs. 144 features; 167 vs. 209 recent TJ cases) indicate loose quality control. (d) The pose gate is not fully met: glove shoulder abduction (r=0.743) and COG y (0.50 ft) miss the paper's own thresholds — the weakest metrics are in the shoulder complex, exactly where arm-injury signal lives. (e) The paper explicitly limits itself: prospective validation required before clinical deployment. (f) External validity to NFL: pitching is a single, highly repeatable movement; NFL injury mechanisms (contact, cutting) are far more heterogeneous — the pipeline transfers, the specific metrics do not.

## 11. GSE implementation spec
NFL-adapted injury-analytics lane (research only, non-clinical): (a) data — licensed practice/film clips of repeatable NFL movements (throwing for QBs, cutting for skill players) with injury/outcome labels from public injury reports; never label outputs as medical advice; (b) pose pipeline — adapt the paper's recipe (lifting module, bone-length enforcement, joint-limited IK, Savitzky-Golay smoothing) to football movements, validating against any available wearable/multi-camera reference; (c) metrics — NFL analogues of the 18 (joint angles, trunk tilt, hip-shoulder separation on throws, knee flexion on cuts, COG trajectory); (d) aggregates — per-player means AND variability/range/CV (the paper's 33–39% finding says inconsistency is the signal); (e) models — GBM + balanced RF + L1 logistic, averaged, with forward-by-season validation (fixing the paper's CV weakness) and SMOTE strictly inside folds; (f) serving — offline research features for props/injury-risk content, never real-time medical claims; (g) estimated effort: 8–12 weeks including validation data. Legal/ethical: public-facing outputs must be framed as performance/injury-risk analytics, not diagnosis; consult counsel before any player-specific injury prediction is published.

## 12. Reproducible test
Dataset: one NFL season of QB throwing clips (or skill-player cutting clips) with public injury-report outcomes the following season. Metric: AUC for season-ending injury (or games-missed > 4) on a forward validation (train 2024 season movements → predict 2025 outcomes). Baseline to beat: workload/demographics-only model (snaps, age, prior injury — the paper's V1 analogue, AUC 0.503 in baseball). The test must use strictly forward splits and SMOTE-inside-folds.

## 13. Acceptance / rejection gate
Advance the NFL injury lane beyond research only if: (a) pose validation on football movements meets angular MAE < 2° on the primary joints (paper's 1° bar, loosened for contact-sport occlusion); AND (b) the full biomechanics model beats the workload-only baseline by ≥0.10 AUC on a forward-season validation; AND (c) variability features replicate the paper's importance pattern (top-quartile importance). If (b) fails, the lane stays a content/research product (film-room biomechanics stories), not a model input. Never publish player-specific injury probabilities without prospective validation and legal review.

## 14. Improvement experiment
Beyond the paper: fix its two validation weaknesses at once — run nested forward validation (outer loop by season, inner loop for hyperparameters, SMOTE strictly inside inner folds) and test whether the V1→V5 AUC progression (0.503→0.811) survives without information leakage from stratified CV. Rationale: the paper's headline 0.811 rests on a CV design that can leak future-career information; a forward design is the honest estimate, and if the gain survives it, the variability-as-signal finding is genuinely actionable for NFL work. This is the experiment the paper's own "prospective validation needed" limitation demands.
