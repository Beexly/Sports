- `[WEAK†]` / `[ELITE†]` = derived flag: the usage profile implies the percentile band, but no published rank exists. Treat as directional, not verified.
- **Second-party-verified salaries only** (DK Network, The Huddle). Salaries are never endpoint-verified and never invented. Rows without a sourced salary omit it.
- **Name resolution:** the request list spelled "Jayden Noel"; every published source lists Houston rookie WR **Jaylin Noel**. This file uses Jaylin Noel.
