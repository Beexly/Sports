# donlnz/nonconformist

- Stars: 479 (MIT)
- Repo: https://github.com/donlnz/nonconformist

## 1. Vision

One of the earliest Python implementations of the full conformal prediction framework (Vovk/Gammerman/Shafer), designed as a scikit-learn extension: inductive conformal predictors, cross-conformal variants, Venn predictors on the roadmap.

## 2. The Ask

sklearn estimator + numpy/scipy + a calibration split. pip-installable.

## 3. Constraints

- License: MIT, but **stale — last push 2021-03**, API docs "severely deprecated" per its own README, tested under Python 3.5-era stack.
- The TODO list (Venn predictors, Venn-ABERS, exchangeability testing) was never finished — and those unfinished items are exactly what crepes and MAPIE now do.

## 4. GSE lens

Historically important, functionally superseded. Its unfinished roadmap is a useful checklist for what the t10-conformal track must cover: exchangeability testing (→ crepes martingales / MAPIE tests), Venn-ABERS predictors (multiprobabilistic outputs — a future refusal-threshold input). Nothing to wire here; treat it as the "don't be this" example of a conformal implementation without drift detection.

## 5. Verdict

**IGNORE** — superseded by crepes and MAPIE on every axis that matters. (MIT.)
