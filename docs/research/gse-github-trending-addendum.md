## Executive Read

The current GitHub trend surface is dominated by agent infrastructure, skills, memory, context compression, code/research knowledge graphs, document ingestion, and agentic UI. That is directly relevant to GSE because the best 2026 sports product is not just a picks page; it is a research-to-decision operating system with source governance, memory, and fast handoffs.

## Add Now

- Code/research knowledge graph: inspired by codegraph and Understand-Anything. GSE needs agents to find source contracts, docs, feature flags, routes, and research decisions instantly.
- Context compression: inspired by headroom. Long R&D and Claude handoffs need source-preserving compression so work does not reset every session.
- Source-safe research skill: inspired by last30days-skill and Agent-Reach, but implemented with compliance controls and a source ledger.
- Document ingestion: inspired by markitdown/open-notebook. Needed for PDFs, coaching-staff guides, projections, data dictionaries, and source packets.
- Agent memory: inspired by supermemory, agentmemory, MemPalace, and personal AI infra repos. Must include strict secret and rights controls.
- Security gate: inspired by Trivy. Add dependency, secret, SBOM, and config scanning before GSE treats generated code as release-ready.

## Watch, But Do Not Blindly Adopt

- CopilotKit: useful for agentic UI patterns once the core GSE scenario and optimizer flows are stable.
- Vector-index repos: useful for retrieval, but not a substitute for source provenance.
- Video-generation repos: useful only for high-quality content operations; avoid low-trust spam automation.
- Stealth-browser and anti-detection scraping repos: reject for GSE. The legal/brand risk is bigger than the short-term data gain.
