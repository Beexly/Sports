# Kill ledger — why, and how to reopen

A kill is a decision, not a deletion. Reopen only if the condition prints.

| Item | Why killed | Reopen when |
|---|---|---|
| Sequential Glicko as the published update | Order changes the path. Sigma does not go to 2. Week-as-period is sequential only because a team plays once. | A month-as-period study on real games beats the close. Not before. |
| Newton as the volatility solver | Paper specifies Illinois. Canonical root sits on a, so a 2-iteration Newton success proves nothing. | A safeguarded Newton matches Illinois on a case where delta^2 >> phi^2+v, and the failure mode is written down. |
| HFA [1.54, 1.59] and sigma [13.34, 13.37] | ci() divides by sqrt(n). That is a CI of the mean. | Draws percentiles replace it. ci_fix.py. |
| +1.74 as the average miss | It is the prediction at 0 mph. File mean is +0.55 (n=3368) or +0.67 (n=3471), join-labeled. | A wind column is re-fit and the intercept is reported at a real mph. |
| Teaser fair -155 | A 46.8% ticket is +114. The dossier priced the other side. | Seed 7, n=20000 reprints the ticket price, not the complement. |
| 21.58 as a model gap | Scoreline log-loss set beside 1X2 log-loss. | The showdown marginalizes the grid to home/draw/away. |
| Ledger ports 0329, 0668, 1168, 1750, 2044 as named | IDs were swapped in the brief. Do not wire those mappings. | The ledger file is opened and the citation matches the claim. |
| Wind -0.197 as an engine constant | games.jsonl has no wind column. Production wind is the curve that does nothing at or below 10 mph. | A re-fit on a file that has wind, with the join count printed. |
| Rest, travel, timezone vs the close | Slate 3 said the close already has them. Not re-run here. | An early-line study, not a close study. |
| Nutrition / cognitive coefficients | No public per-player series. | A series exists. Until then it is a mechanism. |
| Paid odds API, PFF, DVOA, 10 Hz tracking | Cost or a key. Keyless feeds are the default. | CLV ledger has 500 settled bets with a positive t-stat, or a key already in hand. |
| Recon handlers | Not the sports tree. | Never in this repo. |
| 100% engine | No-market backtest was 55.8%. EPL model 1.047 vs Pinnacle 0.966. | Not a reopen. The bar is the close. |
