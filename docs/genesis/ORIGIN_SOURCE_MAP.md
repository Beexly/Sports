## Preservation rule

If a future agent believes an origin or accepted primitive should be removed, it must:

1. locate the corresponding Canon Manifest entry;
2. prove whether it is implemented, stranded, superseded, unsafe, or strategically invalid;
3. identify all dependent systems;
4. preserve historical lineage and rationale;
5. submit an explicit supersession decision;
6. never silently delete it from the canon.
