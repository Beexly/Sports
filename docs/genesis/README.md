# Galaxy Genesis v2 — The Metacortex Expansion

## Thesis

Galaxy Genesis is the internal civilization beneath Galaxy Sports Edge: a system that can observe sports reality, preserve competing truths, discover missing knowledge, acquire or invent capabilities, test them, prove what happened, and turn validated discoveries into durable product instruments.

The prior architecture remains intact. This expansion supplies the missing central spine.

# The Galaxy Metacortex

The Metacortex is a **semantic, policy-aware, cost-based meta-compiler**.

It converts a user goal, research question, product need or system failure into an executable Intelligence Contract and then selects an equivalent valid plan across:

- authorized data and evidence;
- statistical, causal, symbolic and neural models;
- historical replay;
- counterfactual and synthetic worlds;
- agents and tools;
- browser, device, server, cloud and confidential execution;
- human review;
- proof and provenance systems.

It optimizes only after hard constraints are satisfied.

```text
QUESTION / GOAL / FAILURE
          ↓
INTELLIGENCE CONTRACT
          ↓
SPORTSIR + CODEBASE TWIN + CAPABILITY GENOME
          ↓
ALTERNATIVE EXECUTION PLANS
          ↓
RIGHTS · PRIVACY · TRUST · TIME · AUTHORITY · SECURITY
          ↓
VALUE OF INFORMATION · ROBUSTNESS · COST · LATENCY · ENERGY
          ↓
SELECTED PLAN + REJECTED ALTERNATIVES
          ↓
DURABLE EXECUTION / SHADOW EXPERIMENT
          ↓
REALITY RECEIPT + LEARNING
```

## Why this genuinely improves the prior program

Without the Metacortex, the architecture risks becoming a set of impressive but parallel systems:

- one model router;
- one agent router;
- one evidence planner;
- one research planner;
- one media pipeline;
- one edge selector;
- one simulation system;
- one rights registry;
- one product compiler.

The Metacortex makes those systems interchangeable capabilities behind one typed planning language. It can reason about equivalence and select the best valid combination for the current question and world state.

## The eight planes

### 1. Intent Plane

Intelligence Contracts declare desired knowledge or maintained conditions. They specify outputs, deadlines, uncertainty tolerance, permitted evidence, privacy, budgets, proof requirements and triggers.

### 2. Semantic Plane

SportsIR, measurement ontology, provenance and source lineage define what every object means. This plane prevents two subsystems from using the same word for different concepts or different words for the same concept.

### 3. Planning Plane

The Metacortex generates, rewrites, compares and selects equivalent execution plans. Value of information determines what should be learned next. Robust decision logic determines whether the final action remains stable across admissible worlds.

### 4. Execution Plane

Durable workflows and incremental computation execute the selected plan across local, edge, server, cloud, federated or confidential environments. Capabilities have explicit authority and resource limits.

### 5. Scientific Plane

The Research Cortex, Red Queen Laboratory, Scientific Law Foundry, causal inference, symbolic discovery and process intelligence create and challenge new instruments.

### 6. Verification Plane

Policy-as-code, formal specifications, property tests, mutation tests, temporal leakage checks and proof receipts make protected behavior enforceable.

### 7. Evolution Plane

Failure Atlas, Negative Knowledge, model and agent ecology, data valuation, dynamic benchmarks and Product Twin feedback improve the system without erasing failed lineages.

### 8. Human Plane

Decision Twins, Athlete Twins, participatory design, local-first private state, Academy and accessible interfaces ensure the system improves human judgment rather than merely increasing machine output.

# The new category

The system is no longer defined by its largest model or most advanced page.

Its defining capability is **recursive instrument creation**:

```text
Galaxy encounters a question it cannot answer
  → identifies the exact missing knowledge or capability
  → searches across disciplines and ecosystems
  → compiles candidates into one semantic contract
  → designs the most informative affordable experiment
  → challenges the result across time, branches and adversarial worlds
  → promotes a surviving discovery into a measured, versioned instrument
  → compiles that instrument into APIs, interfaces, Academy and simulations
  → monitors whether the instrument continues to deserve its place
```

That loop is the moat.

# Implementation principle

Do not build the civilization all at once.

Build the common kernel first, prove it with one end-to-end contract, and make every later capability enter through that kernel.

The first build is defined in `FIRST_BUILD_CONTRACT.md`.
