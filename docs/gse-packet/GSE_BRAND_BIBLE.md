# Galaxy Sports Edge — Brand Bible
### Brand Identity & Visual System — v1.0 · canonical reference
**Galaxy Sports Edge (GSE)** is a next-generation sports-intelligence platform that uses proprietary AI to detect market inefficiencies and deliver high-confidence plays before the market moves. Parent: **Galaxy Sports Network, LLC (GSN)**.

> **Find the signal before the market moves.**

---

## 1. The Logo
A chrome abstract monogram that encodes **GSN** (the founding network) inside the identity of the product, **GSE**.
- **G** — the large broken chrome orbital ring. The market is never perfect; the opening is where insight enters.
- **S** — the central curved internal signal form. We detect what others miss.
- **N** — the right-side angular chrome structure, integrated into the diagonal vector.
- **The comet / signal vector** — a high-speed shooting star cutting lower-left → upper-right: a high-confidence signal moving before anyone else sees it. Glowing origin node at the tail, sharp star point at the head.
- **Wordmark** — GALAXY SPORTS EDGE, premium metallic chrome futuristic uppercase, carrying a cyan→magenta→violet energy fade across the full phrase, over a thin signal underline.

## 2. Color Palette
*Color is signal, not decoration. Use the exact hex — never substitute named colors.*

| Token | Hex | Role |
|---|---|---|
| Orbital Cyan | `#00E5FF` | Primary energy / leading edge |
| Ion Magenta | `#FF38C7` | Secondary energy / accent |
| Ultraviolet | `#7B61FF` | Tertiary glow / transitions |
| Electric Blue | `#2A6BFF` | Supporting cool |
| Nebula Purple | `#A855F7` | Nebula atmosphere |
| Cosmic Gray | `#0D1117` | Surface / UI panels |
| Obsidian Black | `#05070B` | Primary background |
| Starlight White | `#F5F7FF` | Chrome highlights / text |

**The signal fade** — the brand's signature gradient runs **Orbital Cyan → Ion Magenta → Ultraviolet**. Use it on the wordmark underside, active states, and energy elements.

## 3. Typography
| Use | Typeface | Notes |
|---|---|---|
| Display / headlines | **Exo 2** | Geometric, futuristic, uppercase for impact |
| Body / UI | **Inter** | Clean, legible, neutral workhorse |

Headlines: tight, confident, often uppercase. Body: generous line height, never crowded.

## 4. Brand Voice
**Calibrated. Precise. Always acquiring.** Intelligence isn't loud — it's on frequency. *We detect. You decide. You win.*
Pillars: **Intelligence** (data with purpose) · **Precision** (measured, not guessed) · **Advantage** (see it first, use it better) · **Discipline** (process over emotion) · **Results** (consistent long-term edge).

## 5. Logo Usage
- **Master:** full-color chrome mark on obsidian/galaxy field. Primary use everywhere there's room.
- **App icon / favicon:** symbol only (no wordmark), centered, tight margin (never below 32px).
- **Horizontal lockup:** symbol left, GALAXY SPORTS / EDGE stacked right — headers and banners.
- **Mono white / mono black:** single-color for stamps, partner walls, documents, print.
- **Animated reveal:** orbit forms → comet streaks → signal ignites → wordmark resolves.
- **Clear space:** ≥ the height of the comet's signal node around the mark.
- **Do not:** recolor outside the palette, stretch, add effects, place on busy photography without a dark scrim, or rebuild the wordmark in another font.
