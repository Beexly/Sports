# GSE Intelligence Packet — historical design records

This directory holds the **Galaxy Sports Edge intelligence packet** as uploaded by the owner:
strategy, architecture, and methodology documents, plus the cockpit prototype. They are preserved
here verbatim as **historical design records** — the design intent the codebase was built toward.

They are **not** the current source of record. Where any document disagrees with the code, with
reality, or with another document, the disagreement is reconciled in:

- **`../audit/gse-reconciliation/GSE_UNIFIED_FIELD.md`** — the master reconciliation: the One Law,
  the Four Projections, the packet manifest, docs-to-code traceability, and the contradiction ledger.
- **`../audit/gse-reconciliation/AUTHORITY_TENSOR_PROOF.md`** — the machine-checked theorem.
- **`../audit/gse-reconciliation/ADVERSARIAL_EXECUTION.md`** — what was actually run, and its result.
- **`../audit/gse-reconciliation/OWNER_DECISION_BRIEF.md`** — the verdict and the owner's gates.
