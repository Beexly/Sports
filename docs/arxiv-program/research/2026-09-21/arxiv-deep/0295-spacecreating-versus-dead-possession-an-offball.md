# [0295] Space-Creating versus Dead Possession: An Off-Ball Possession-Quality Index for Broadcast Football (arXiv:2608.09887v1)

**Citation:** Choi, S. (2026). *Space-Creating versus Dead Possession: An Off-Ball Possession-Quality Index for Broadcast Football*. Independent researcher (ORCID 0009-0001-3193-7424). arXiv:2608.09887v1. URL: https://arxiv.org/abs/2608.09887v1
**Ledger completed:** 2026-09-21. **Read:** full text (1674-line text extract).
**Verdict:** ADAPT — the two-layer design (event-side junk-possession flag + broadcast-video space-creation adjudication) is the direct template for an NFL "sterile offense" metric: flag low-threat drives from play-by-play, then adjudicate via NGS tracking or broadcast video whether the offense moved the defense.

## 1. Research question
Possession percentage in soccer is "the most-cited and most-misleading number in football": it conflates where the ball is held, whether it threatens goal, and game state. Event-based value frameworks (xT, VAEP, on-ball value) price on-ball actions but are blind to the off-ball question sterile possession poses: did holding the ball create space, or was the circulation genuinely dead? The paper contributes a two-layer off-ball possession-quality framework: (1) an event-side junk-possession index that flags low-threat sequences in tied-or-losing game states, with validation that it is not reducible to on-ball possession value; (2) a broadcast-video Space-Creation Index (SCI) that adjudicates flagged windows as spatially dead or space-creating via pitch-control change.

## 2. Dataset / schema
Event layer: 2026 FIFA World Cup, 103 of 104 matches (one absent from feed) → 206 team-match rows; WhoScored public event feeds; knockout penalty ties scored by advancement; xG from own gradient-boosted model (distance/angle, body part/phase approximated) because the feed's shot-xG is a constant placeholder; xT grid Karun-Singh-style; live scoreline reconstructed from goal events. Spatial layer: 9 purposively selected World Cup matches (high sterile index, adequate kit contrast, late-round narrative), 35 event-flagged junk windows → 31 survived CPU-only broadcast GSR pipeline (PnLCalib calibration, BoT-SORT tracking, Lab-chroma team assignment, training-free off-screen ghosting). Windows 10–60 s of continuous wide-angle play; extra time excluded.

## 3. Method / model
Event layer: possession segmented into maximal consecutive-event sequences s; sequence value value(s) = max(0, xT_max(s) − xT_start(s)) [peak threat gain, credited without shot] + 0.7·xG(s) [max shot xG in s] + 0.10·𝟙[box touch] (Eq. 1); normalized by corpus-wide 90th percentile, clipped to q(s) ∈ [0,1]; q < 0.15 = junk sequence. Headline metric junk-open = 100·Σ_{s: state≤0, q_s<0.15} n_s / Σ_{s: state≤0} n_s (Eq. in §3: junk event share among tied-or-losing possessions). Team metrics: raw%, effective% (threat-weighted), efficiency eff = Σ n_s q_s / Σ n_s, junk-open, field tilt (own final-third event share, x≥80), sterile index = (Raw−50)×(1−eff). Spatial layer: SCI = Δ_own + Δ_opp where Δ_own = C̄^{last}_{P,A} − C̄^{first}_{P,A} (possessing team P's attacking-third control share change) and Δ_opp = C̄^{first}_{O,Z} − C̄^{last}_{O,Z} (opponent O's presence in its own attacking third receding; Eq. 2), using Spearman et al. pitch-control model; prespecified bins: space-creating (SCI ≥ +12), weak progression (+4 ≤ SCI < +12), non-space-creating (SCI < +4). Redemption rule: junk sequence redeemed if same team regains ball within 25 s and reaches threat (peak-xT gain ≥ 0.04 or box touch).

## 4. Equations & assumptions
Eq. 1: value(s) = max(0, xT_max(s) − xT_start(s)) + 0.7·xG(s) + 0.10·𝟙[box touch]. junk-open = 100 Σ_{s∈T: state(s)≤0, q_s<0.15} n_s / Σ_{s∈T: state(s)≤0} n_s. eff = Σ n_s q_s / Σ n_s ∈ [0,1]. Sterile index = (Raw−50)×(1−eff). Eq. 2: SCI = Δ_own + Δ_opp; Δ_own = C̄^{last}_{P,A} − C̄^{first}_{P,A}; Δ_opp = C̄^{first}_{O,Z} − C̄^{last}_{O,Z} (pp units). Assumptions: "possession" = share of on-ball events (event-data proxy); lead-protecting circulation is sound tactics, excluded via score-state gating; peak threat location reached is worth crediting even without shot; box-touch weight 0.10 is data-informed (logistic coefficient +0.60 vs +0.39 for peak-threat gain, AUC 0.907) but not grid-searched; corpus-wide constants (90th pct, q<0.15, SCI +12/+4) apply to all splits (cross-fitted only up to these); SCI adjudication assumes imputed off-screen players' pitch control is meaningful (not sensitivity-filtered — flagged limitation).

## 5. Features / target
Features: WhoScored events (touch locations, goals, shots, box touches), live score state; broadcast video frames → pitch coordinates → pitch-control shares per zone/third. Targets: junk-open / efficiency at team-match level; SCI per flagged window. Outcomes for validation: team xG, goals, points, xG difference (206 team-matches); second-half xG (first→second-half split); this-match points/xG diff (leave-one-match-out team trait). Horizon: full match (event layer), 10–60 s windows (spatial layer).

## 6. Validation design
(a) Pearson correlations of all possession metrics vs outcomes (Table 2). (b) Joint OLS regressions: points ~ raw + tilt + junk-open (junk-open β=−0.020, p=0.017 iid; p=0.014 under match-clustered CR1); xG diff ~ tilt/junk-open (tilt p<1e-4, junk-open p=0.77) — quality vs territory axes. (c) VAEP non-reducibility: own event-fed VAEP implementation on same schema; points ~ VAEP + tilt + junk-open → VAEP p=0.34, junk-open p<1e-4 (Table 3; match-clustered re-estimation unchanged); xG diff ~ VAEP + tilt + efficiency → VAEP p=0.46, efficiency p<1e-4. (d) Out-of-sample: first-half efficiency → second-half xG (r=+0.32), first-half junk-open → lower second-half xG (r=−0.24); leave-one-match-out team mean efficiency → this-match points (r=+0.31), mean junk-open → lower points (r=−0.30) and xG diff (−0.32). (e) Redemption rule null test. (f) Spatial: 31 windows classified; case studies (Germany–Paraguay R32: Germany 73% possession, SCI −24.4/−14.2, eliminated; Paraguay window SCI +18.0 space-creating but unconverted; Norway–Brazil junk-but-won case).

## 7. Numerical results / baselines
Table 2 correlations (206 team-matches): junk-open vs xG −0.38, goals −0.38, points −0.37, xG diff −0.51 (partly mechanically coupled via shot-xG term); efficiency vs xG +0.59; field tilt vs xG +0.58 but points +0.18. 71 team-matches >55% possession split by corpus-wide median efficiency: 8 "junk dominators" avg 1.07 xG, 0.62 goals, 1.00 points vs 63 efficient dominators 2.05 xG, 2.24 goals, 2.24 points (descriptive, n=8). VAEP surface correlations: r=−0.49 with junk-open, +0.58 with efficiency. Shot-prediction logistic: 5-fold AUC 0.907 ± 0.004 (folds not match-grouped — upper bound). Redemption: only 9% of tied-or-losing junk redeemed; dead-only variant points r: −0.37→−0.41 in-sample, identical out-of-sample (honest null). Spatial: 74% non-space-creating, 19% weak progression, 6% space-creating (31 windows); proportions stable from 6-match (71/24/5) to 9-match sample. Event contrast: South Africa 0–1 Canada (57% poss, eff 0.27, junk-open 57%) = textbook junk; South Korea 1–0 Mexico (57% poss, eff 0.41) = less sterile, index does not locate cause.

## 8. Code / data availability
Event-side code: https://github.com/nowayfootball/junk-possession (index, validation battery, VAEP regression, gradient-boosted xG spec). Event corpus from public WhoScored feeds (re-collectable). Spatial pipeline described but footage/per-clip artifacts not redistributed. CPU-only, no GPU spend.

## 9. Leakage & limitations
(a) Author is transparently adversarial with himself: in-sample outcome associations are descriptive (junk-open built from contemporaneous score state; goal information enters weakly through the in-sample-fit xG model); the predictive weight rests on the cross-fitted splits. (b) xG-term mechanical coupling inflates xG associations — goals/points are the clean endpoints. (c) Corpus-wide constants (90th pct, q<0.15, box weight 0.10, SCI +12/+4) are round, not optimized; out-of-sample splits are cross-fitted only up to these. (d) Segmentation by possession change only (no stoppages/restarts special-cased). (e) Spatial sample is purposive, not random — proportions do not generalize tournament-wide. (f) Team assignment degrades on low-contrast kits (3 windows excluded); off-screen ghosting imputation not sensitivity-filtered. (g) Soccer-specific: continuous possession; NFL drives are discrete series — the adaptation must re-derive "sequence" for drive/series granularity. (h) 2026 World Cup data — verify competition naming/timing against the real world before citing.

## 11. GSE implementation spec
(1) Event layer on NFL: segment games into drives (or series); drive value = peak EPA gain (max EPA reached minus drive start, credited without score) + 0.7·(points scored share) + box/red-zone entry credit — the analog of Eq. 1; normalize corpus-wide; junk threshold tuned. Compute drive-level junk-open for tied-or-losing game states (win probability ≤ ~0.5 instead of score state, cleaner than the paper's scoreline). Team-level: efficiency, junk-open, and a "sterile index" = (time-of-possession share − 50) × (1 − efficiency). (2) Spatial layer on NGS tracking: for flagged low-threat drives, compute SCI analog — defensive "block" = box/shell depth: measure whether the offense pushed safeties back (avg safety depth change) and seized the intermediate/deep zones (pitch-control analog via NGS positions). Classify drives as space-creating vs sterile. (3) Run the VAEP-style non-reducibility regression: points ~ EPA + junk-open to test whether the flag adds information beyond on-ball EPA. Effort: ~1.5 engineer-weeks for the event layer on nflverse; spatial layer reuses NGS ingestion.

## 12. Reproducible test
Dataset: 2023–2024 NFL seasons, nflverse play-by-play (drives). Metric: correlation of team junk-open/efficiency with points and point differential; joint regression junk-open | EPA vs EPA | junk-open (mirroring Table 3); out-of-sample: first-half junk-open → second-half points (r target ≈ −0.20 or stronger). Baselines: raw time-of-possession share, EPA/play. Window: full seasons 2023–2024.

## 13. Acceptance / rejection gate
ADOPT the NFL junk-offense index for GSE matchup content if: leave-one-week-out team mean junk-open predicts next-game point differential with |r| ≥ 0.15 AND the joint regression shows junk-open significant (p < 0.05) controlling for EPA/play; REJECT if the index adds nothing beyond EPA (p > 0.10 in the controlled regression) or out-of-sample |r| < 0.10.

## 14. Improvement experiment
Go beyond the paper by making the spatial layer *predictive* rather than adjudicative: train the SCI-analog (safety-depth displacement, zone-control change) on NGS tracking from drives 1–3 to predict second-half scoring — testing whether early-game off-ball space creation (that the paper only classifies post-hoc) forecasts points before they materialize. The paper's spatial layer is purely retrospective; a forward-looking SCI would be a genuine GSE edge and directly testable against the betting market on second-half lines.
