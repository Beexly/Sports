# [0494] Large-Scale In-Game Outcome Forecasting for Match, Team and Players in Football using an Axial Transformer Neural Network (arXiv:2511.18730v1)

**Citation:** Michael Horton, Patrick Lucey (Stats Perform Inc., Chicago, IL) (2026). *Large-Scale In-Game Outcome Forecasting for Match, Team and Players in Football using an Axial Transformer Neural Network*. arXiv:2511.18730v1. URL: https://arxiv.org/abs/2511.18730v1
**Ledger completed:** 2026-09-21. **Read:** full text (HTML text extract, 3,726 lines, including Appendices A–B).
**Verdict:** ADAPT — port the agent×time axial transformer as GSE's first live in-game forecasting architecture: jointly predict game outcome, team totals, and per-player action totals (receptions, yards, TDs) at drive-level timesteps from NGS/pbp data, with the paper's Poisson-NLL multi-target heads and sub-second CPU inference.

## 1. Research question
Can one transformer model jointly and recurrently forecast the end-of-match totals of 12 individual actions for every player, both teams, and the game outcome — updated ~150 times per match as events occur — while staying internally consistent (e.g., shots-on-target ≤ shots; predicted totals ≥ running totals, converging to actuals at full time)?

## 2. Dataset / schema
62,610 soccer matches from 28 competitions (Opta event data via Stats Perform — proprietary, not public). Train: 8 seasons 2016–17 → 2023–24 (58,501 games). Test: partial 2024–25 season through 15 December 2024 (4,109 games). Each example = one match with T^(n) event timesteps, P^(n) match-day-squad players (~40 incl. substitutes), 2 teams. Inputs per timestep: live player features (position/team indicators + running totals of 12 actions); pre-game player-strength features (mean passes last 5 games, max fouls last 10 games, time since previous match, travel distances); live team features (team indicators + running action totals); team-strength aggregates; live game-state features (event type, game clock, event location); game-context features (competition, kickoff hour). Features are modalized (player/team/game × pre-game/live) with no duplication — the attention learns cross-modal relevance.

## 3. Method / model
Three-stage network: (a) embedding layers f_player, f_player-strength, f_team, f_team-strength, f_game, f_game-context map each input tensor to common dim D=128, concatenated into grid E_0 ∈ ℝ^(H×W×D) with H=P^(n)+2+1 agents, W=T^(n)+1 timesteps. (b) L=4 axial transformer layers (each: row/temporal attention with strict upper-triangular causal mask — attend only to previous timesteps — plus column/agent attention over all agents at current timestep, then feed-forward/layer-norm/skip as in Vaswani et al. 2017). (c) target layers: shared-over-agents-and-timesteps linear heads mapping final embeddings to per-target distribution parameters (Bernoulli, Poisson, log-Gaussian, "model-free" discrete). Target: remaining action counts in (t, T^(n)] (not cumulative totals), so Poisson is natural. ~505 predictions per timestep × ~150 timesteps ≈ 75,000 live predictions per game. Training: summed per-target NLL, Adam, LR 0.0003, cosine annealing without warm restarts, batch 30, ~150k steps, ~15 h on a single NVIDIA A10; 10% of train held for validation; model selected by total validation loss.

## 4. Equations & assumptions
(1) Attention(K,Q,V,M) := softmax(A)V; (2) A = (M + KQᵀ)/√d; (3)–(4) row-wise softmax via exp(A)/(n·1ᵀ), n = exp(A)·1. AxialAttention (Algorithm 1): per-row and per-column attention on grid G, then re-normalized additive combination R = [N^row/(N^row+N^col)]⊙R^row + [N^col/(N^row+N^col)]⊙R^col (Algorithm 1 line 17); the self-cell is masked in either row or column op to avoid double-counting. Equivalence theorem (5)–(7): axial attention ≡ sequential masked attention on the unraveled row-major sequence with mask M := M^row + P(M^col)Pᵀ, where P reorders column-major to row-major; sketch proof in Appendix A using softmax permutation-equivariance (Observation A.1). Complexity O((H+W)HW) vs O(H²W²) for the sequential equivalent — sub-quadratic in grid size. Assumptions: joint distribution approximated via marginals (true joint over 2^(|𝒜|×|𝒫|×|𝒯|) intractable; model "approximates the joint" through shared embeddings); remaining-count targets are Poisson-appropriate; consistency emerges from shared representation, not hard constraints; one-vs-one calibration plots treat per-value probabilities as binary classifiers.

## 5. Features / target
Inputs: modalized player/team/game × live/pre-game tensors (running action counts, strength aggregates over last 5–10 games, travel, rest, competition context). Targets: remaining totals of 12 actions (goals, assists, shots, shots on target, corners, attempted passes, accurate passes, tackles, fouls, yellow cards, red cards, own goals) per player (~40) and per team, plus game outcome. Horizon: in-game, updated at ~150 event-triggered timesteps per match; sub-second CPU inference.

## 6. Validation design
Test = future-season holdout (2024–25 partial, 4,109 games) — time-ordered, the right choice. Metrics: mean log-probability of ground truth under predicted distributions; binary calibration error of the modal value vs ground truth (one-vs-one calibration curves, 20 bins, all targets). No external baselines ("unaware of any existing work" for this task) — evaluation is calibration + ablation. Ablations: no-agent-attention (temporal-only), no-temporal-attention (agent-only), no pre-game context, stacked axial (Ho et al. 2019 sequential row-then-column). Appendix B: full qualitative trace of Fulham 1–3 Aston Villa (19 Oct 2024; Fulham pre-game win prob 0.47; red card → expected totals shift; substitutions → future-action forecasts zero out except cards).

## 7. Numerical results / baselines
Ours beat all four ablations on mean log-probability for every one of the 12 targets; calibration best on a plurality of targets. Ours (log-prob / calibration error): goals −0.111 / 0.002; assists −0.088 / 0.001; shots −0.515 / 0.021; shots on target −0.260 / 0.016; corners −0.289 / 0.019; attempted passes −3.039 / 0.074; accurate passes −2.765 / 0.075; tackles −0.608 / 0.027; fouls −0.517 / 0.018; yellow cards −0.202 / 0.019; red cards −0.018 / <0.001; own goals −0.006 / <0.001. Calibration curves generally well-calibrated (weak for sparse targets: red cards, own goals — zero-category mass ≥0.84 and ≥0.97 respectively; passes — wide range, small per-value mass). Ablation gaps (ours vs no-temporal on log-prob): goals −0.111 vs −0.124; assists −0.088 vs −0.098; accurate passes −2.765 vs −3.199; shots −0.515 vs −0.575 — temporal dynamics contribute most, pre-game context second, agent interaction third. Yellow cards: temporal-ablation looked best on calibration only because it predicted the majority class. 15 h training on 1×A10; inference sub-second on commodity CPU.

## 9. Leakage & limitations
- No external baselines; results are self-referential (calibration + ablations only) — "well-calibrated" is a weaker claim than "better than alternatives," and there is no accuracy/AUC comparison against even simple in-game models (e.g., Dixon–Robinson birth-process baselines from their own related-work section).
- Consistency desiderata (shots-on-target ≤ shots; team assists ≤ team goals) are achieved only softly through shared embeddings — no hard-constraint mechanism and no measurement of how often violations occur.
- Rare-event heads (red cards, own goals) are essentially degenerate zero-mass predictors; passes heads are diffuse — the 12-target "joint" model contains several near-useless heads that inflate the headline 505-prediction count.
- One-vs-one calibration on multi-valued count targets is a nonstandard metric; no scoring-rule (CRPS) or reliability-vs-resolution decomposition.
- No sensitivity to the timestep definition (35 key-event triggers; ~150 timesteps/match is data-specific); NFL games have ~130–160 plays — analogous, but the grid shape (agents×time) scales attention as O((H+W)HW), which for 53-man rosters × 150 timesteps needs checking.
- Results on one sport, one vendor's event feed; the "equivalent to sequential attention" theorem is a reformulation, not a new capability — the stacked-axial comparison wins are modest (log-prob gaps ~1–3%).

## 10. GSE overlap
Gap in Garrett's corpus. The map has extensive pre-game outcome models (state-space, Elo, Poisson score models, Dixon–Coles, in-game NBA win prob) and NGS tracking metrics — but no live in-game forecasting architecture, no multi-target agent-level model, and no joint player+team+game head. The paper's architecture fills a real capability hole: GSE publishes pre-game picks; live in-game probability updates and per-player live prop forecasts (which the NGS data can drive) do not exist in the repo. The axial decomposition is also directly relevant to NFL's natural grid (players × plays/drives) and to the props lane (receptions/yards/TDs/attempts heads from one shared state), which the existing briefs don't architecturally specify.

## 11. GSE implementation spec
(1) Data: nflverse pbp 2020–2024 → player×timestep grid: players = skill-position + kicker active roster (15–20 agents, keep H small), timesteps = per-drive summaries (~22–26 drives/game, W≈25) rather than per-play (keeps O((H+W)HW) cheap); live features = running receptions, targets, rushing yards, EPA, team totals; pre-game strength = trailing-4-game averages from gse-lab metric tables; game context = spread/total from consensus lines, rest days, weather. (2) Model: D=128, 4 axial layers per paper, heads for receptions, receiving yards, rushing yards, TDs, targets, turnovers (Poisson/log-Gaussian), team totals, and home-win (Bernoulli); train ≤2022, validate 2023, test 2024; Adam, summed NLL. (3) Serve: pre-game context features precomputed; per-drive event trigger updates → inference in <1s CPU. (4) Evaluate with log-prob + calibration exactly as the paper does, but ADD baselines the paper skipped: drive-independent Poisson projections and GSE's pre-game probabilities carried forward. Effort: 2–3 weeks (data windowing + model); inference trivial on one CPU.

## 12. Reproducible test
Dataset: nflverse 2020–2024. Baselines: (a) per-player Poisson projection from pre-game lines (no in-game updating); (b) GSE pre-game probabilities held static in-game; (c) ablations no-agent/no-temporal/no-pregame per the paper. Metrics: log-probability of realized receptions/yards/TDs, calibration curves, and a consistency audit (e.g., player receiving yards ≤ team passing yards violations — the paper's unmeasured soft-constraint claim). Time-ordered test: 2024 season. Must show full model beats (a) and (b) on log-prob for ≥4 of 6 prop heads AND ≤1% consistency violations.

## 13. Acceptance / rejection gate
ADOPT in-game axial architecture if it beats static pre-game baselines on log-probability for the majority of prop heads on the 2024 holdout with ≤1% consistency violations — this becomes GSE's live-in-game engine (a capability nothing in the corpus covers). REJECT if in-game updating adds nothing over pre-game lines (the soccer result is driven by 150 event updates; NFL drives are coarser and the paper's own ablation showed temporal > agent attention — if no-temporal beats full here, the axial machinery is overhead, not signal). REJECT also if H×W scaling forces roster truncation that loses the players the props lane needs.

## 14. Improvement experiment
Add hard consistency constraints the paper only approximates: project each head's predictive distribution through a differentiable feasibility layer (e.g., player totals sum ≤ team total + opponent-negated residual; shots-on-target ≤ shots) via isotonic/monotone coupling or a final convex-pooling step. Hypothesis: hard constraints will strictly reduce consistency violations to zero and improve log-probability on low-count heads (the paper's degenerate red-card/own-goal heads), because the unconstrained model wastes probability mass on impossible configurations — directly testing the paper's "shared embeddings suffice" claim.
