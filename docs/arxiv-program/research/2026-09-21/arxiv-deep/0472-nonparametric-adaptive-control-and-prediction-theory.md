## 1. Research question
Can the classical linear-in-parameters assumption of nonlinear adaptive control be relaxed to nonparametric learning over an RKHS, with (a) an implementable adaptive input despite infinite dimensionality, and (b) a tractable randomized implementation (random Fourier features) with explicit finite-sample bounds whose cost scales only polynomially in dimension? Demonstrated on a 60-dimensional 10-body Newtonian gravitation prediction problem.

## 2. Dataset / schema
No real dataset. Synthetic: (i) 5-D stable LTI system ẋ = A(x − 3/2·1) + u − h(x), h(x)=sin(x)·erf(x) elementwise; (ii) 60-dimensional Hamiltonian system (m=10 point masses, d=3, equal masses, 1/r² potential), non-dimensionalized; (iii) unstable 5-D variant with time-varying desired trajectory x_d(t)=sin(2πt+cos(√2πt)) and h_i(x)=¼x_i⁴ for the neural-network experiment. Euler integration Δt=0.001. No data URLs.

## 3. Method / model
Matched-uncertainty adaptive control ẋ = f(x,t) + g(x,t)(u − Yα_p − h(x)) with unknown physical parameters α_p and unknown dynamics h ∈ operator-valued RKHS ℋ (function class ℱ₂(B_h), kernel K decomposable as E_ν[Φ(x,θ)Φ(y,θ)ᵀ], e.g. Gaussian kernel Φ(x,θ)=B(w)cos(wᵀx+b)). Adaptive laws: (4.1)/(4.2) α̇(t) = −γΦ(x)ᵀg_e(x,t)ᵀ∇Q(e,t) with Lyapunov function Q on error e. **Kernel trick (Observation 4.1):** with α̂(0)=0 this equals the nonparametric input û(x,t)=∫₀ᵗK(x,x(τ))c(τ)dτ (4.3) — a kernel integral operator over the trajectory history (the trajectory plays the role of the "dataset"). Randomized version: draw K random features θ_i ∼ ν, use finite feature map Ψ(x;{θ_i}) and standard parametric update, which Theorem 6.4/6.7 proves drives tracking/prediction error into a ball of radius set by the uniform approximation error B_approx. Duality between adaptive control and adaptive state estimation (LQR/Kalman-like). Extension: reinterpretation as gradient flow α̂̇ = −γ∇_α̂Q̇(e,α̂,t) (7.3), extended to deep nets via the Jacobian (7.4): α̂̇ = −γ(∇_α̂φ(x,t,α̂))ᵀg_e(x,t)ᵀ∇Q(e,t) — empirically more expressive but closed-loop stability guarantees lost. Appendix A adds the discrete-sampling extension: Prop. A.1 gives the contraction bound E(x̂_{i+1},x_{i+1}) ≤ β e^{λ̄_iΔt_i} E(x̂_i,x_i) for a hybrid flow + measurement-update system with contracting update rate β and max expansion λ̄_i between samples.

**§7.3 neural-network experiment protocol (paper's exact setup):** unstable 5-D variant (7.5) ẋ = A(x−x_d(t)) + ẋ_d(t) + u(x,t) − h(x) with x_d(t)=sin(2πt+cos(√2πt)), h_i(x)=¼x_i⁴, Q=(x−x_d)ᵀP(x−x_d)/2 with AᵀP+PA=−I. Single-hidden-layer nets of width 32 or 64 with swish activation, adaptive law (7.4); γ=20 for the random-feature adaptation law, γ=10 for the neural network. Compared against the same random Fourier feature approximation of the Gaussian kernel used in §7.1 and the unadapted system.

**§8 future direction (paper's own):** study the Banach space ℱ₁ of single-layer nets h(·)=∫_ΘΦ(·,θ)μ(dθ) for signed Radon measure μ (Bach 2017; Bengio et al. 2006) via Wasserstein gradient flows and particle methods (Mei et al. 2018; Rotskoff & Vanden-Eijnden 2019), generalized to adaptive control through the gradient-flow law (7.4). No convergence results for ℱ₁ are given in this paper.

## 4. Equations & assumptions
α̇(t) = −γΦ(x)ᵀg_e(x,t)ᵀ∇Q(e,t) (4.2). Nonparametric input: û(x,t)=∫₀ᵗK(x,x(τ))c(τ)dτ (4.3). Random Fourier feature map: Φ(x,θ)=B(w)cos(wᵀx+b) (4.6). Uniform approximation bound (Theorem 6.4 context): sup_{‖x‖≤Bx}‖h(x)−Ψ(x;{θ_i})α_m‖₂ ≤ C(h,δ)(B_x√n+√d₁)/√K with probability ≥1−δ (polynomial in state dimension n — the key scaling result vs exponential gridding). Convergence (Theorem 4.5): u(x,t)=−γ∫₀ᵗK(x,x(τ))g_e(x(τ),τ)ᵀ∇Q(e(τ),τ)dτ ⇒ x(t),e(t) bounded and lim_{t→∞}‖x(t)−x_d(t)‖₂=0. NN gradient flow: α̂̇(t)=−γ∇_α̂Q̇(e(t),α̂(t),t) (7.3); with u(x,t)=φ(x,t,α̂(t)): α̂̇=−γ(∇_α̂φ(x,t,α̂))ᵀg_e(x,t)ᵀ∇Q(e,t) (7.4). Hamiltonian symplectic kernel: K(x,y)=−J∇²k(x−y)Jᵀ (7.2) for the RKHS of dynamics J∇_x̂Ĥ(x̂), Ĥ∈ℋ_k; with Gaussian k, K(x,y)=−JE[wwᵀcos(wᵀx+b)cos(wᵀx+b)]Jᵀ, w∼N(0,σ_w²I), b∼Unif(0,2π). Hamiltonian estimator dynamics: q̂̇_i=∂Ĥ/∂p̂_i + k(q_i−q̂_i), p̂̇_i=−∂Ĥ/∂q̂_i + k(p_i−p̂_i), with Ĥ(x̂,t)=Ψ(x̂)ᵀα̂(t), Ψ_i(x̂)=cos(w_iᵀx̂+b_i), and α̂̇(t)=−γ([∇_{p̂}Ψ(x̂)]ᵀq̃(t) − [∇_{q̂}Ψ(x̂)]ᵀp̃(t)). Discrete sampling (Prop. A.1): E(x̂_{i+1},x_{i+1}) ≤ β e^{λ̄_iΔt_i} E(x̂_i,x_i). Generalized Barbalat (Prop. B.4): limsup_{t→∞}|f(t)−α|≤ε with f′ L-Lipschitz ⇒ limsup_{t→∞}|f′(t)| ≤ 2√(εL); sharp, witnessed by f(t)=ε sin(√(ω/ε)·t) with limsup|f′|=√(εω). Deadzone law (Thm 6.4): with Δ-admissible deadzone σ_Δ and Δ ≥ μ₂(ρ⁻¹(2B_{g_e}B_{∇Q}B_approx)), limsup_{t→∞}‖e(t)‖₂ ≤ μ₁⁻¹(Δ); interpolation bound (Thm 6.6): limsup‖ė(t)‖₂ ≤ C₁√(μ₁⁻¹(Δ)(1+L)). Prediction (Thm 6.7): limsup‖x̂(t)−x(t)‖₂ ≤ √(Δ/μ) under contraction of the nominal predictor. Assumptions: matched uncertainty (uncertainty in span of control matrix), nominal error dynamics stable with Lyapunov function Q satisfying comparison-function bounds (Assumption 3.7), h ∈ ℱ₂(B_h) with known kernel (Assumption 4.3), feature maps locally Lipschitz with operator-norm integrability (Assumption 4.4), deadzone-based update for the approximate case (Theorems 6.4/6.7). NN law (7.4) additionally assumes a target parameter set exists that renders Q̇ negative definite and is findable by gradient descent — stated by the authors as plausible but unproved.

## 5. Features / target
Features: continuous-time state measurements x(t) (position/momentum). Target: tracking error e(t)=x(t)−x_d(t) → 0 (control) or prediction error e(t)=x̂(t)−x(t) → 0 (prediction). No discrete supervised-learning target; the "supervision" is the error signal through the known error dynamics — explicitly avoids needing time derivatives of the error (contrast with GP-MRAC, Chowdhary et al.).

## 6. Validation design
Simulation studies, not statistical validation: (i) adaptive control on the 5-D synthetic system — tracking error, input magnitude, interpolation error vs K (20 trials/draw of θ_i, 20%/80% quantile bands, medians); (ii) adaptive prediction on the 60-D 10-body system with K=2500 random features unless stated otherwise (10 trials; Figure 2 uses 20%/80% quantiles) — error-at-t=100 vs K with nonlinear-least-squares power-law fits for prediction-error exponent ξ and interpolation-error exponent ζ; (iii) unstable 5-D time-varying system, single-hidden-layer neural net (width 32 or 64, swish) adapted via the Jacobian law (7.4) vs random-feature adaptation (γ=20) vs no adaptation. No baselines vs other control methods; no real-world data.

## 7. Numerical results / baselines
Control experiment (§7.1): kernel input beats every finite-K approximation transiently and asymptotically by "several orders of magnitude" in tracking error; tracking error at fixed t decreases monotonically in K; kernel input also uses the lowest input magnitude ‖u‖₂. Prediction (60-D, K=2500): prediction and dynamics-interpolation errors smoothly driven to a small ball around zero; early transient oscillation (t≲5) then smooth accurate tracking; unadapted system fails to track. Power laws: asymptotic prediction error ∼ K^{−ξ}, ξ≈1.28±0.03; interpolation error ∼ K^{−ζ}, ζ≈0.77±0.03 (95% CIs, nonlinear least-squares fits at t=100) — empirically faster than the paper's analytical predictions ξ=1/2, ζ=1/4 (ζ=ξ/2 via Theorem 6.6) for this setting (quadratic V, exponentially stable nominal dynamics with rate k; Example 6.5). The paper notes the observed rates exceed the theory's O(1/√K) Monte-Carlo tail and conjectures the tail appears only near K≈20,000, where the fitted curve flattens. Deep-net experiment (§7.3): the system without adaptation is driven unstable; both the NN and random-feature adaptive systems regulate the trajectory to a ball around x_d (Figure 3A), with the NN obtaining slightly improved tracking over random features at both widths (32, 64) despite similar or fewer parameters — attributed to hidden-layer weight changes, i.e. operating outside the kernel regime (Figure 3C/D). But the NN law is significantly more brittle: the random-feature approximation is provably stable for any learning rate, while the NN law empirically renders the system unstable for many learning-rate choices, with the stable range architecture-dependent; increasing depth without careful tuning often leads to instability. During an initial transient the NN input norm exceeds the random-feature input norm by one to two orders of magnitude even on stable trajectories (Figure 3B). The paper's conclusion: for closed-loop adaptive systems where stability is necessary, kernel methods are the more desirable choice; no stability proof for (7.4) is offered. All numbers are the paper's claims.

## 9. Leakage & limitations
Adversarial notes: (a) no real data anywhere — all claims rest on three synthetic simulators; (b) the matched-uncertainty assumption (uncertainty enters through the control channel) rules out most real systems; (c) guarantees are asymptotic (error → ball of radius B_approx), with no finite-time rates for the closed loop; (d) the deep-network extension has no stability guarantees — the paper's headline "extra expressivity" result is precisely where the theory ends, and the authors themselves conclude that for closed-loop systems where stability is necessary, kernel methods are the more desirable choice than deeper architectures; (e) the NN law (7.4) is empirically brittle — unstable for many learning rates, architecture-dependent stable range, depth increases instability risk, and input norms exceed random-feature baselines by 1–2 orders of magnitude during transients; (f) the observed super-Monte-Carlo power laws (ξ≈1.28) are unexplained; (g) GSE relevance: nil — GSE is discrete-event probabilistic forecasting with no continuous-time error dynamics, no control input, no Lyapunov function; the only conceptual bridge (online kernel learning) duplicates what isotonic regression/PAV already does for GSE calibration at far lower complexity.

## 11. GSE implementation spec
The honest spec: none for the core method. The closest conceivable analog — a streaming online recalibration of GSE probabilities against incoming market odds using a kernel smoother with Lyapunov-guaranteed boundedness — is inapplicable because GSE's calibration problem is a batch, finite-sample proper-scoring problem, not a continuous-time control loop with known error dynamics. If ever pursued (it should not be), the steps would be: (1) define a forecast-probability "state" with market odds as the desired trajectory; (2) pick a Gaussian kernel + RFF map (K≈2500) on the probability simplex; (3) run the deadzone adaptive law of Theorem 6.7 on the streaming Brier gradient. This is recorded only to document that it was considered and rejected.

## 12. Reproducible test
Falsification test (runnable; designed to confirm non-applicability). Dataset: GSE engine pregame NFL win probabilities, 2024–2025 regular seasons (nflverse-aligned game list, engine DB pulls), treated as a probability stream with market closing odds (converted via The Odds API) as the "desired trajectory." Metric: out-of-sample Brier score of the probability stream after online recalibration. Test arm: the paper's deadzone adaptive law (Theorem 6.7 form) with a Gaussian-kernel random-Fourier-feature map (K=2500) applied to the streaming Brier gradient. Baseline: isotonic regression (PAV) recalibration refit weekly on the same stream. Time window: fit recalibrators on 2024, score on 2025 weeks 1–18. Expect isotonic to win; the deadzone kernel law has no proper-scoring rationale on batch probabilistic data.

## 13. Acceptance / rejection gate
Numeric gate: the paper's method is rejected for GSE unless the deadzone-kernel online recalibration beats isotonic regression by ≥0.002 Brier points on the 2025 holdout window — a material calibration gain. Otherwise REJECT stands: the method stays out until a genuine continuous-time controlled system appears in the GSE pipeline (a measurable error signal, a known error-dynamics model, and an actuation input). As of 2026-09-21 no such subsystem exists.

## 14. Improvement experiment
Academic-direction note only: if the lab ever needs online nonstationary calibration (e.g., mid-season drift in GSE probabilities), the correct improvement over this paper is not its control machinery but the standard online-learning formulation — kernelized online logistic regression with RFF and a regret bound (à la Boffi & Slotine 2021 "Implicit regularization and momentum"), which keeps the kernel expressivity and polynomial scaling while dropping the control-loop machinery. That belongs to a different paper; nothing to build here.
