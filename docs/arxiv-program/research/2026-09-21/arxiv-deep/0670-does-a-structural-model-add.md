# [0670] Does a Structural Model Add Anything to the Closing Price? (arXiv:2608.11505)

**Citation:** Yannik Pitcan (2026). *Does a Structural Model Add Anything to the Closing Price? Calibrated forecasting, incremental information, and match leverage in the Italian Serie A*. arXiv:2608.11505. URL: https://arxiv.org/abs/2608.11505
**Ledger completed:** 2026-09-21. **Read:** full text (arxiv.org HTML, all sections 1–11, tables 1–5, equations 1–10).
**Verdict:** ADAPT — adopt the logarithmic-pooling-weight diagnostic as GSE's primary market-benchmark protocol, validate Shin de-vig as the house margin-removal method, and adapt match leverage to NFL season-objective analysis.

## 1. Research question
Whether a structural (Dixon–Coles) football forecasting model carries any information that a margin-free closing price has not already absorbed; and, given the negative answer, what a calibrated-but-less-sharp model is still good for — operationalised as "match leverage", the change in a club's season-objective probability between winning and losing a given fixture.

## 2. Dataset / schema
Nineteen complete Serie A seasons (2007–08 through 2025–26), 7,220 matches, from football-data.co.uk. Each record: date, two clubs, full-time score and outcome, shots and shots on target and corners for both sides, bookmaker prices. Bet365 opening prices available all seasons; Pinnacle opening and closing from 2012–13 onward. Pinnacle closing preferred where available as "the closing price of a low-margin, high-limit book is the sharpest widely published forecast". Access: public (football-data.co.uk). Replicable for NFL only via odds APIs, not identical schema.

## 3. Method / model
Dixon–Coles bivariate-Poisson model with attack/defence ratings, home advantage γ, low-score dependence correction ρ, exponential age-weighting w(Δt)=exp(−ξΔt), fitted by weighted maximum likelihood walk-forward (refit each fortnight, forecast next fortnight). Identifiability via Σα_j=0; unseen clubs get exposure-weighted league mean. Decay ξ selected by grid search on validation: ξ=0.002/day (half-life 347 days). A process-based variant refits the identical machinery to shots on target and converts shot rates to goal rates with a single league-wide finishing factor κ estimated on the same window. De-vigged market via Shin (1993) inversion with root found by bisection. Incremental information measured as the fitted weight ŵ in a logarithmic opinion pool of market and model forecasts, minimising out-of-sample log loss on validation. Match leverage L_m = P(Ω|win m) − P(Ω|lose m) estimated by post-hoc conditioning on a single season simulation, justified by fixture-score independence (verified by exhaustive enumeration of a reduced four-club league and by forced-result simulation at 10^6 replications).

## 4. Equations & assumptions
- Shin margin removal (Eq. 1): p_i(z) = (sqrt(z² + 4(1−z)·π_i²/Π) − z) / (2(1−z)), Σ p_i(z) = 1, with π_i = 1/o_i, Π = Σπ_j; root located by bisection since ∂p_i/∂z < 0. Assumes bookmaker prices arise facing proportion z of insider trade (Shin 1992/1993).
- Goal rates (Eq. 2): log λ = γ + α_h − δ_a, log μ = α_a − δ_h.
- Joint mass (Eq. 3–4): P(X=x,Y=y) = τ_ρ(x,y;λ,μ)·Pois(x;λ)·Pois(y;μ), τ_ρ the Dixon–Coles low-score correction on cells (0,0),(0,1),(1,0),(1,1) — the unique assignment conserving total probability.
- Weighted log-likelihood (Eq. 5): ℓ = Σ_m w(Δt_m)[log τ_ρ + log Pois(x_m) + log Pois(y_m)].
- Shot-to-goal conversion (Eq. 6): λ̂ = κ_H·λ^S, μ̂ = κ_A·μ^S, κ_H = Σw_m x_m / Σw_m s^H_m (κ_H=0.309, κ_A=0.317).
- RPS (Eq. 7): RPS = 1/(r−1)·Σ_{i=1}^{r−1}(Σ_{j=1}^{i}(p_j − a_j))², r=3, ordered home/draw/away.
- Logarithmic opinion pool (Eq. 8): p^{(w)}_i ∝ (p^M_i)^{1−w}(p^S_i)^w, w ∈ [0,1].
- Match leverage (Eq. 9): L_m = P(Ω|club wins m) − P(Ω|club loses m).
- Post-hoc conditioning identity (Eq. 10) holds under S ⊥ R (fixture score independent of other results).
- Assumptions: fixture scores independent across matches; attack ratings sum to zero; promoted clubs default to exposure-weighted league mean; Serie A tie-break approximated by points → goal difference → goals scored (exact ties affect <0.01% of simulations); benchmark closing price embeds late information (team news) the model never sees.

## 5. Features / target
Features: date, club identities (ratings fitted, not input features per se), full-time scores, shots, shots on target, corners, bookmaker decimal odds (Pinnacle closing preferred; Bet365 opening as pre-2012 fallback). Target: ordered match outcome {home win, draw, away win}; primary horizon is next-fortnight walk-forward forecasts; season objective Ω (e.g. survival = final position ≥17th) for the leverage application.

## 6. Validation design
Walk-forward: parameters fitted strictly before each origin, forecasts for the following fortnight, refit each origin. Hyperparameters, pooling weights, calibration temperature fixed on validation 2013–14 to 2018–19 (n=2,280); test 2019–20 to 2025–26 (n=2,660) scored once. Percentile bootstrap intervals on means; paired bootstrap over matches for model comparisons. Baselines: de-vigged market, walk-forward base-rate forecaster (40.6% accuracy), uniform (33.3%), shots-on-target variant, market+model pools. Metrics: RPS (primary), log loss, Brier, accuracy (for comparability only).

## 7. Numerical results / baselines
Test period n=2,660 (Table 1): Market (Shin de-vigged) RPS 0.1905 [0.1856, 0.1957], log-loss 0.9620, Brier 0.5717, accuracy 54.8%. Market+model pool: identical to market on all metrics (pooling weight 0.000). Dixon–Coles (calibrated) RPS 0.1972 [0.1921, 0.2024], log-loss 0.9858, Brier 0.5862, accuracy 53.4%. Shots-on-target variant: RPS 0.2001 [0.1959, 0.2042], log-loss 0.9959, accuracy 52.9%. Paired RPS difference market-minus-model: +0.0067, 95% CI [0.0046, 0.0088]. Market wins RPS in all 7 test seasons; season gaps 0.0044 to 0.0101 (Table 2). Pooling weight ŵ = 0.000 on validation; log loss monotone increasing in w on [0,1] on validation AND test — genuine boundary solution. Unconstrained extension to w∈[−1,1]: validation minimum interior at ŵ=−0.225; carried to test it improves log loss by 0.00062 [−0.00105, 0.00231] and RPS by 0.00021 [−0.00029, 0.00071] — intervals contain zero. Three-way pool weights (Table 3): market 1.00, goals 0.00, shots 0.00; goals+shots alone: 0.65/0.35. Calibration (Table 4): DC home-win slope 0.995 vs market 1.103; ECE(H) 0.0208 vs 0.0285; recalibration temperature 0.99. Match leverage (Table 5, Fiorentina from 1 Mar 2026, 16th on 24 pts, 12 fixtures): Lecce away L=0.073 vs Inter home L=0.033 — away fixture carries 2.25× the leverage (gap ≈8 MC standard errors; MC SE <0.005). Simulation coherence check: projected 41.4 expected points vs actual 42; survival probability 96.4%, finished 15th. Shin fitted z over 17,479 complete books: median 0.017, max 0.061.

## 9. Leakage & limitations
Paper's own admissions: no player-level info (injuries, suspensions, transfers) — "the largest gap relative to a club's internal information set and the most plausible location of remaining edge"; no xG (shots on target weights tap-ins and long shots equally); benchmark embeds late information (team news) the model never sees, so part of the 0.0067 RPS gap is information asymmetry, not modelling deficiency; one league, one period (Serie A, efficiency need not transfer to thinner markets); home-advantage erosion (home win rate 47.5% in 2007–13 → 40.2% in 2023–26) means non-stationary DGP; leverage is single-objective. Platform sensitivity: results reproduce exactly on the generating machine but differ across machines in the fifth decimal (BLAS reduction order), flipping 1 of 2,660 matches; tables survive at printed precision. Author is single, non-peer-reviewed. My adversarial notes: NFL is a two-outcome-margin market, not 1X2 — the "weight 0.000" result may not transfer because GSE's signal set (tracking, EPA, injuries) is private relative to the closing price, exactly the author's stated remaining-edge location; the shots-on-target variant underperforming goals (RPS 0.2001 vs 0.1972) weakens the "process-based is better" framing, though the pooling-weight argument (0.35 vs goals-only) rescues it; the unconstrained negative-weight analysis borders on over-analysis of noise (author reads sign, not magnitude — honest).

## 10. GSE overlap
Existing-research-map market-microstructure lane already inventories CLV as training label, de-vigged consensus, beat-the-close, line movement/steam, and market-implied ratings (benbbaldwin tiers). The Shin de-vig equation and the "closing line is the ceiling" evidence are confirmation/extension of existing practice, not new. What is NEW: (a) the logarithmic-pooling-weight diagnostic as the primary headline measure of whether any GSE model adds information beyond the de-vigged closing price — a sharper protocol than comparing accuracy/scoring-rule figures side by side; (b) match leverage as a season-aggregation quantity — no equivalent in the map; (c) the calibration-vs-discrimination decomposition applied to market vs model (market wins on sharpness, not calibration) — extension of the CQR/calibration lane; (d) the errata discipline (Section 3) as a template for GSE's own negative-result reporting. Complements 0277 (the EMH odds-only/GLM paper) rather than duplicating it.

## 11. GSE implementation spec
Three builds, ascending effort: (1) Pooling-weight diagnostic (small): for any GSE win-probability model, fit w in the log-opinion pool of de-vigged Pinnacle/Odds-API closing price vs model on a walk-forward validation window, minimising log loss; report ŵ and the full loss profile on [0,1]. Data: Odds API closing prices + GSE engine outputs. Effort: ~1–2 days. (2) House de-vig audit (tiny): implement Shin bisection exactly per Eq. 1, compare implied probabilities vs current proportional normalisation on a season of NFL moneylines; check fitted-z distribution sanity (paper: median 0.017). Effort: hours. (3) NFL game leverage (medium): season simulator over remaining schedule with fitted team-strength model; for each remaining fixture compute L_m = P(playoffs|win) − P(playoffs|loss) by post-hoc conditioning on one 20k-replication run (justified under fixture independence, same as paper's Eq. 10); publish weekly "highest-leverage games" as a content + decision-support product (rest/load-management angle). Data: nflverse schedules + GSE ratings. Effort: ~1 week including validation against forced-result simulation.

## 12. Reproducible test
Dataset: NFL 2023–2025 moneyline closing prices (Odds API or Pinnacle) + GSE v5.2.7 engine win probabilities, weekly walk-forward. Metric: fitted log-opinion-pool weight ŵ of engine vs Shin de-vigged closing on a validation window, plus paired Brier/log-loss difference with bootstrap CI on a held-out test window. Baseline to beat: ŵ = 0 indistinguishable — i.e., the test "passes" (is informative) if ŵ is materially positive; if ŵ ≈ 0, the engine adds no information beyond the close and the protocol correctly diagnoses it. Runnable on existing engine outputs — no new data collection.

## 13. Acceptance / rejection gate
Adopt the pooling-weight protocol if on 2023–2024 validation the fitted ŵ for GSE engine vs close is stable across two independent 20-week folds and the loss-profile minimum is interior (not a boundary artefact); otherwise report the diagnostic as unstable. Adopt NFL game leverage if post-hoc conditioning agrees with forced-result simulation within MC error on a 10-fixture pilot (same verification the paper ran, max |z| < 1.5); reject the single-run estimator otherwise. Adopt Shin de-vig as house method if fitted z on NFL books is stable and implied probabilities pass a 10-bin calibration check (ECE ≤ 0.02) on 2023–2025; keep proportional normalisation otherwise.

## 14. Improvement experiment
Repeat the paper's pooling design but with a private-information model (injury-adjusted ratings + tracking-derived matchup features) instead of Dixon–Coles: the paper's own limitation section predicts remaining edge lives exactly there, so the fitted weight should be materially positive against the closing price — if it is still zero, that is a stronger statement than the paper's (it would say even GSE's private data is priced in, and value must come from the leverage/aggregation layer alone). Second experiment: extend match leverage to multi-objective (playoff seeding × bye) with a utility function over position bands instead of a single binary objective.
