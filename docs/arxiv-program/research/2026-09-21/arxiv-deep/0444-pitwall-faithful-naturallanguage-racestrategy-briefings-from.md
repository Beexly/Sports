# [0444] Pitwall: Faithful Natural-Language Race-Strategy Briefings from a Calibrated Real-Time Monte Carlo Engine (arXiv:2607.06495v1)

**Citation:** Juan S. Santillana (2026). *Pitwall: Faithful Natural-Language Race-Strategy Briefings from a Calibrated Real-Time Monte Carlo Engine*. arXiv:2607.06495v1. URL: https://arxiv.org/abs/2607.06495v1
**Ledger completed:** 2026-09-21. **Read:** full text (all §§1–9 plus references; 3,232 text lines).
**Verdict:** ADAPT — the strongest operational-forecasting paper in this wave for GSE: (1) a bounded-parameter, per-path-gated Monte Carlo calibration protocol whose discipline (held-out wins only, parity gating, published negative results) is a template for GSE engine calibration; (2) common-random-numbers counterfactuals for decision contrasts with percentile-bootstrap CIs; (3) verifier-gated natural-language generation — typed factual claims extracted and checked against the engine state before publication — directly applicable to GSE's X content pipeline where confidently-wrong claims about real athletes are the same severity-class defect.

## 1. Research question
Build the first publicly documented end-to-end system that (i) ingests the official F1 live-timing stream, (ii) maintains a canonical probabilistic race state, (iii) evaluates strategic counterfactuals by vectorized Monte Carlo at interactive latency, (iv) reports calibrated win/podium/points/undercut probabilities validated on seven scored seasons (2018–2025, excl. 2022) plus early 2026, and (v) verbalises state and recommendations as natural-language briefings in English/Spanish/Portuguese with every published sentence claim-verified against the engine state. The methodological argument: realism, task-level accuracy, decision quality, and generation richness are separate objectives that must be gated separately.

## 2. Dataset / schema
- Structured race store: 157 races 2018–2026 (2022 absent — its timing data does not load reliably), extracted via FastF1 into canonical JSON: per-race stints (compound, start/end lap, tyre life), lap times, pit stops, SC/VSC periods, final classification. Degradation models fitted per race+compound on green laps only (SC/VSC, in-laps, out-laps excluded).
- Overtake kernel: every adjacent-car battle in the store (consecutive cars within interaction window on green laps, pit-cycle changes excluded): 131,000 battles, 4,142 clean passes (3.2% base rate); fitted ≤2023 (89k), tested ≥2024 (41k).
- Calibration: 126 training races (2018–2024); held-out test 2025–2026 (29 races at gating, 31 in the final run).
- Fine-tuning corpus: 3,045 trilingual briefing targets from 145 training races × 7 lap fractions × 3 languages (2025–2026 held out); GPT-4o candidates admitted only if ≥1 checkable claim and 0 contradicted claims; 2,494 (81.9%) admitted, 551 (18.1%) template fallback.
- Undercut model: 2,134 undercut events from pit_battles (1,306 train ≤2023; 828 held-out test 2024–2025).
- Live: SignalR timing at 1s cadence via proxied edge agent; live deployments at 2026 Austrian and British Grands Prix; Silverstone trace = 14 polls over laps 39–52, 120s cadence.

## 3. Method / model
- Vectorized MC engine: N=2,000 replications advanced in lockstep as N×C arrays (C≤20 cars); per-car cumulative time, stint index, tyre age, pit schedule; one lap = one pass of array ops with no per-car branching; validated vs a scalar reference by distributional parity (max per-driver mean-finish discrepancy <0.6 positions); 10–50× faster, full-field lap-rate re-simulation on a single CPU node.
- Lap-time model (H5): compound base + linear wear slope + mined tyre cliff (37 circuit–compound cliffs passing an evidence gate: ≥25% SSE reduction over linear fit, n≥300 laps; 8,278 stints / 191k laps); fuel-burn correction with tyre-only wear clamped to [0, 0.22] s/lap; max-stint feasibility cap (95th percentile of circuit history pre-race; demonstrated max post-race).
- Logistic overtake kernel (H7) with additive-shrinkage per-circuit difficulty offsets.
- Compound-base normalization (H9): projection onto canonical soft≤medium≤hard ordering.
- SC/VSC regime models (H13) with calibrated rate/pace/pit-loss multipliers (VSC new vs prior academic simulators); pace-optimal open-loop rival policy (H1); SC-reactive pull-forward (H17), pit-stop physics with exponential slow-stop tail (H15), live Kalman pace filter (H18) — H15/H17/H18 parity-gated (bit-identical at defaults, golden-hash regression) pending held-out wins.
- Undercut window (H14): box-now vs +1 vs +2 laps vs stay, each under the identical random seed (CRN), with 90% percentile-bootstrap CIs (B=500 resamples along the replication axis, zero extra simulation cost).
- Calibration: bound-constrained differential evolution maximizing J(θ)=ρSpearman − 2·BS − 1·ECE over a 12-parameter vector inside physically interpretable bounds; discrete switches pinned per run with each configuration independently recalibrated; identifiability logging via CMA-ES stds; season-blocked cross-validation.
- Language layer: 10 typed claim types (leader, position, gap-to-leader, battle, pace, tyre, safety-car, lap-number, overtake, position-change); LLM extractor (8–15 claims/text vs 0–2 for pattern extractor — coverage is a validity precondition); verifier-gated fine-tuning (Qwen2.5-3B LoRA v1 on templates vs v2 on gated corpus); sparse-context audit over four base models (1B–7B): Phi-4-mini chosen for production (degrades to generic non-checkable phrasing on sparse contexts where the others invent drivers), served greedy, 8-bit quantization OK, 4-bit/LoRA-on-quantized reintroduces hallucination; downstream claim verification on every published briefing.

## 4. Equations & assumptions
(1) ℓ(t,a) = f₀⁽ᵗ⁾ + δ⁽ᵗ⁾a + 𝟙[a>k⁽ᵗ⁾] s⁽ᵗ⁾(a−k⁽ᵗ⁾) + ε, ε∼𝒩(0,σ²lap); (2) P(pass)=σ(AGP + kpΔpace + ktΔage), kp=+0.87, kt=+0.46; (3) b̂c = bc − b̄ + c̄, c̄ = argmin ‖c−b‖² s.t. gmin≤ct+1−ct≤gmax, gmin∈[0,0.2], gmax∈[0.3,1.2] s/lap; (4) P̂h(ahead)=N⁻¹Σ𝟙[Fh⁽ⁱ⁾<R⁽ⁱ⁾], Δ̂h=P̂h(ahead)−P̂stay(ahead), with CRN variance term −2·Cov(Fh,Fstay) negative for positively coupled options; (5) Ŵd=N⁻¹Σ𝟙[rank(d,i)∈E], CI90=[q5%(Ŵd*),q95%(Ŵd*)]; (6) BS=n⁻¹Σ(pi−yi)² = REL−RES+UNC (Murphy decomposition); (7) J(θ)=ρSpearman−wB·BS−wE·ECE, wB=2, wE=1.
Assumptions: rivals play pace-optimal open-loop plans (non-reactive to focal stops — known limitation, §8(v)); SC/VSC regime hazards; retirement as calibrated per-car hazard; no telemetry (mechanical failures invisible); rain out of scope; simulator predicts on-road order (post-race stewarding is a noise channel charged against the engine in backtests); CIs quantify MC sampling error only, model error is handled by calibration.

## 5. Features / target
Features: per-race fitted compound base paces/slopes/cliff knots, tyre ages, gaps, track-status history, circuit SC/VSC frequency priors, grid slots. Targets: per-driver win/podium/points probabilities; undercut success probability vs a named rival; binary event outcomes (calibration); pass probability per battle (H7); position-swap success in undercut events.

## 6. Validation design
Honest by construction: (i) full backtest = pre-race oracle over 155 scoreable races, 400 sims/race; (ii) gating ablations: each configuration independently recalibrated on 2018–2024 and evaluated on held-out 2025–2026 (3 seeds), never evaluated with another configuration's parameters; (iii) decision-path gating on 42 dry races 2024–2025 with H5 artifacts mined ≤2023 only; (iv) undercut logistic on 828 held-out events; (v) live deployment as adversarial test of state estimation (Austria incident → H18; Silverstone prior incident → analog-spread guardrail); (vi) language audit on deployment-shaped dense/sparse probe contexts, replicated across four base models; explicit declaration of what fourteen live polls cannot claim ("an anecdote, not calibration evidence").

## 7. Numerical results / baselines
- Backtest (Table 3): modal winner hit 64.5%; winner in top-3 90.3%; podium recall 72.3%; mean Spearman ρ=0.749 overall, 0.766 held-out 2025–2026; no drift across the 2022 regulation change; grid-order baseline substantially worse.
- Calibration (Table 4): production config held-out combined Brier 0.0745, ECE 0.0297; per-event: win 0.0254 (reliability 0.0014), podium 0.0652, points 0.1381; +H7 kernel 0.0757/0.0344 (neutral-to-negative despite kernel's own pass-task Brier 0.0275 vs 0.0298 climatological, passes/race MAE 8.9 on mean 23.5); +H9 normalization 0.0784/0.0308 (−4–6%); +H5 engine-path cliff 0.0786. Optimizer saturates pace_clip/pace_scale/grid_spread bounds → pace-spread magnitude, not the pass model, binds order fidelity.
- Decision fidelity (Table 5): feasibility caps cut infeasible recommendations 90.5%→0.0%; stop-count agreement 59.5%→69.0% (baseline degenerate — always one stop); on modal-2-stop races 1/18→9/18; stop-count MAE 0.40→0.31; strategy-cost median gaps collapse (Monza +73–102s→16s, Suzuka→7s, Monaco→19s, field median 11s).
- Undercut window: CRN option-delta signs stable to <±0.3pp at N=2,000; H14 logistic: Brier 0.168 vs climatological 0.188, BSS 0.107 (base rate 25%, N=828); gap_before_s coefficient ŵ=−1.21, tyre-age delta ŵ=+0.01.
- H9 pathology: 2025 Spanish GP lap-46 box-now call 72.9% under raw bases vs 23.4% after projection, flipping stay-out.
- Language: v1 (templates) faithful, 28–52 tokens; v2 (gated) vivid on dense contexts but hallucinates on sparse ("closing in at 1.8s on fresher mediums" with no such car); replicates on 1B and 7B bases, not on Phi-4-mini; temperature-0.7 sampling hallucinates where greedy doesn't; 4-bit quantization introduces compound errors.
- Live: Silverstone trace locked onto the eventual winner at lap 42 (97.7–99.5%), ten laps before the flag; one transient under the closing SC (lap 50, 55.4%); on-road ordering matched official classification through P8 (sole divergence: a post-race 5s penalty). Austria deployment caught out-lap contamination (P8 at 55.8% win, lap 17) → H18 Kalman filter; Silverstone caught wet-regime prior contamination (P21 at 89.1% win → 0.0% after dry-analog reseed, with a pre-race spread gate ≥3–4 s/lap rejecting the analog).

## 9. Leakage & limitations
- Backtest oracle conditions on the grid: measures race-simulation quality, not qualifying prediction (§8(vi)).
- Rivals are open-loop: no covering game vs the focal undercut; H17 covers only SC/VSC pull-forward. Residual error in undercut moments is likely rival-reactivity, not compound pace (§8(v)).
- No telemetry, approximate fuel, age-based thermals, rain out of scope; H15 constants await calibration; eras with sparse timing data (2022) contribute less.
- Simulator predicts on-road order; post-flag stewarding reorders official results and is silently charged against the engine (§8(vii); planned classification-noise term).
- The 2026 live traces are anecdotes (14 polls, one race), not calibration evidence — the author says so explicitly.
- Brier-optimal is not decision-optimal and vividness is not faithfulness: components that encode domain knowledge (H7 kernel, H9 canonical ordering, rich targets) are exactly the ones gated off the calibrated/production paths — the paper's core lesson, and the reason its claims are credible.
- Reuse caveat for GSE: the domain (F1 lap/tyre/SC dynamics) has no direct NFL analog; what transfers is the calibration protocol, CRN counterfactual machinery, and the claim-verification layer — not the simulator's physics.

## 11. GSE implementation spec
Phase A — engine calibration discipline (Mimo lane): (1) define a bound-constrained parameter set for the GSE NFL engine with physically interpretable bounds (spread/shock params, home-edge, market-blend weights), each with documented meaning; (2) adopt the gating rule: any component (new feature, market-blend change, distribution choice) gets its own full recalibration on the training window and is evaluated only on the held-out window with its own parameters — never scored under incumbent parameters; (3) calibration objective J=ρSpearman−2·Brier−ECE over game-outcome events, where events = win/cover/total-hit for ML/SPREAD/TOTAL; (4) parity gating: every engine change ships behind a flag whose default is bit-identical (golden-hash regression on a fixed fixture of games); (5) keep per-path configurations: the probability board uses the calibration-optimal config; any recommendation/rank/bet-selection path uses the decision-fidelity config (gated on pick-level profit or rank calibration, not Brier). Phase B — CRN counterfactuals for in-play/hedge decisions: simulate hedge/cash-out/let-ride options under a shared random seed so option deltas reflect the decision, not noise; attach percentile-bootstrap CIs to reported win/cover probabilities. Phase C — claim verifier for published content: define typed claim types over the pick domain (record claims, line/odds claims, engine-probability claims, matchup-stat claims); extract claims from drafted X posts/threads with an LLM extractor; verify each against the engine state snapshot before posting; reject drafts with any contradicted claim; log extractor coverage per post (a low-coverage extractor makes scores degenerate — audit coverage as the paper does).

## 12. Reproducible test
Calibration-gate test: (1) take a candidate GSE engine change; (2) recalibrate both configs on the training window (e.g., 2020–2023) via bound-constrained DE on J=ρ−2·Brier−ECE; (3) score on the held-out window (2024–2025) with per-config parameters; accept only on a held-out win on the relevant path metric. Expectation set by the paper: some realism-improving components will lose on calibration and must be routed to the decision path or shelved — a negative result counts as success of the protocol. Claim-verifier test: backfill 50 recent GSE X posts, extract claims, verify against contemporaneous engine states; measure contradicted-claim rate — target 0 contradicted claims before any post goes live.

## 13. Acceptance / rejection gate
Accept into the calibration lane if: (1) the bound-constrained parameter set is defined and documented; (2) at least one engine change is gated with the full recalibrate-both-configs protocol and the decision recorded (adopt / route-to-decision-path / shelve); (3) the X-post claim verifier covers ≥90% of extractable claims per post with 0 contradicted claims published. Reject if any component is adopted on vibes or realism alone without a held-out win on its path's metric.

## 14. Improvement experiment
Extend the undercut-window idea to GSE in-play decisions: model the "hedge now vs +1 quarter vs let ride" option set under common random numbers on the live NFL MC engine, with bootstrap CIs on each option's expected bankroll delta; gate the option set against historical in-play price data the way H14's logistic is grounded on 828 held-out undercut events. Second: close the H8(v) analog in GSE — the open-loop rival is GSE's market model; measure how much of GSE's residual line error is market-reactivity (lines moving after GSE-relevant news) vs price-model error, and only then invest in a reactive-market extension.
