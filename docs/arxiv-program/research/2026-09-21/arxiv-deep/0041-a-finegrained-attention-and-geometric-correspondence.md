# [0041] A fine-grained attention and geometric correspondence model for musculoskeletal risk classification in athletes using multimodal visual and skeletal features (arXiv:2509.05913)

**Citation:** Rahman, M. A., Raiaan, M. A. K., Shermin, T., Islam, M. R., Hussain, M., Azam, S. (2025). *A fine-grained attention and geometric correspondence model for musculoskeletal risk classification in athletes using multimodal visual and skeletal features*. arXiv:2509.05913. URL: https://arxiv.org/abs/2509.05913
**Ledger completed:** 2026-09-21. **Read:** full text (arXiv PDF, v1; assignment lists v3 — see version note in §1).
**Verdict:** REJECT — the 8-class REBA labels are a deterministic rule-based function of the same skeletal inputs the model is given, so the 93.89% test accuracy is inflated by label circularity and the method transfers nothing to real NFL injury prediction.

## 1. Research question
The paper asks whether a multimodal deep-learning model (ViSK-GAT, "Visual-Skeletal Geometric Attention Transformer") can classify musculoskeletal-disorder risk from a single still image of an athlete's posture, by fusing image pixels with MediaPipe 2D skeletal coordinates through a fine-grained intra-modal attention module (FGAM) and a cross-modal geometric correspondence module (MGCM). It also introduces a custom dataset (MusDis-Sports, 8,989 samples) labeled into 8 risk classes by a rule-based REBA (Rapid Entire Body Assessment) scoring algorithm.

**Version note (my own observation, not a paper claim):** I read the v1 full text; the assignment lists v3. The v3 abstract describes FGAM as refining *intra-modal* features via self-attention before fusion, which matches the v1 body text (Section 3.2.2: "let each image patch attend to others within the same modality"). The reported metrics are identical across v1/v3 abstracts (test acc 93.89%, RMSE 0.1205, MAE 0.0156), so version differences appear cosmetic.

## 2. Dataset / schema
- **MusDis-Sports** (custom, constructed by the authors): 8,989 annotated samples. Each sample = one image of a human subject in a sports-related posture + corresponding 2D skeletal keypoints + an ergonomically informed class label (8 REBA-based risk categories).
- Source images compiled from publicly available sports datasets: Sports1M, "Sports Classification," "Sports Image Classification," and Cricket Shot datasets; filtered to full-body visible configurations.
- Keypoints: MediaPipe extracts 33 anatomical landmarks per subject; landmarks with visibility confidence < 0.5 discarded; coordinates rescaled to original image size.
- Class distribution (Table 1): Class 1: 1,083; Class 2: 1,213; Class 3: 1,181; Class 4: 1,332; Class 5: 1,144; Class 6: 1,117; Class 7: 888; Class 8: 1,031. Total = 8,989. Classes 4+ are riskier postures.
- **Critical construction detail (§3.1.2):** "the REBA scores are generated by applying a deterministic, rule-based algorithm to the coordinates. The model's task is therefore to learn the mapping from visual and coordinate data to" the rule-based label. I.e., labels are a deterministic function of the input skeleton features (joint angles via cosine law + trunk/leg/arm lookup tables → Group A/B → REBA matrix Group C).
- Access: GitHub https://github.com/mak-raiaan/MusDis-Sports_Dataset — "upon valid request for research purposes only" (§Declarations).

## 3. Method / model
ViSK-GAT pipeline:
1. **Image branch:** frames resized to 224×224; passed through ResNet-inspired residual blocks → feature map F_img ∈ R^{H×W×C}, flattened to 256×128 image tokens.
2. **Coordinate branch:** 33 keypoints flattened to joint-token sequence P ∈ R^{N×2} (N=33), linearly projected to E_pose = PW_e + b_e (Eq. 4, d=128) → lightweight Transformer block (multi-head self-attention + FFN) → F_pose ∈ R^{33×128}.
3. **FGAM (Fine-Grained Attention Module):** multi-head self-attention with 8 heads on image tokens (each patch attends within the same modality), residual + LayerNorm → intermediate F1 ∈ R^{256×128}; then two stacked Lightweight Transformer blocks (self-attention, dropout, FFN expansion 128→512→128) → F2 → F3; then F̂_img = LayerNorm(F3 + FFN(F3)) (Eq. 5).
4. **MGCM (Multimodal Geometric Correspondence Module):** both modalities projected to a common space with d=256 (image via linear + LayerNorm + GELU; pose via two-layer projection network with intermediate compression/re-expansion). Cross-attention: image tokens as queries Q, pose tokens as keys/values K,V → F_attn = MultiHeadAttn(Q=F'_img, K=F'_pose, V=F'_pose) (Eq. 6). Concatenate [F'_img ∥ F_attn] → F_fused ∈ R^{1×2d}; 2 stacked Transformer layers (4-head self-attention, FFN expanded to 4d, residual norm) → fusion head (linear + LayerNorm + GELU) → F_corr ∈ R^{512} for classification.
5. **Training:** 100 epochs, batch size 16, AdamW with weight decay 1×10⁻⁵, OneCycleLR scheduler (peak LR 3×10⁻⁴, warmup over 10% of epochs, div factor 1000), categorical cross-entropy loss (selected config used label smoothing 0.1, gradient clip 1.0), images resized 224×224. Hardware: NVIDIA RTX 3060 12GB, CUDA 12.6, PyTorch 2.6.0+cu126, Python 3.12.9. Final epoch: training loss 0.0007, training accuracy 99.97%.
- REBA labeling pipeline (Algorithm 2): joint angles → region scores (trunk, neck, legs → Group A; upper/lower arm, wrist → Group B; group-based formulation from Hignett & McAtamney [10]) → REBA matrix lookup → final score → 8 classes. Load and activity modifiers fixed to zero (single-frame images, no dynamic tasks).

## 4. Equations & assumptions
- Eq. (1): K = {(x_i, y_i, v_i)}_{i=1}^{33}, (x_i, y_i) ∈ [0,1]², v_i ∈ [0,1]. (Skeleton keypoint set; visibility v_i.)
- Eq. (2): θ_ABC = cos⁻¹((BA⃗·BC⃗)/(‖BA⃗‖·‖BC⃗‖)), where BA⃗ = A − B, BC⃗ = C − B. (Joint angle via cosine law.)
- Eq. (3): θ_trunk = tan⁻¹(|x_shoulder − x_hip| / (|y_shoulder − y_hip| + ε)), ε a small constant to prevent division by zero. (Vertical inclination angle of trunk.)
- Eq. (4): E_pose = P W_e + b_e, with W_e ∈ R^{2×d}, b_e ∈ R^d, d = 128. (Pose token embedding.)
- Eq. (5): F̂_img = LayerNorm(F3 + FFN(F3)). (FGAM output refinement.)
- Eq. (6): F_attn = MultiHeadAttn(Q = F'_img, K = F'_pose, V = F'_pose), with F'_img ∈ R^{256×d}, F'_pose ∈ R^{33×d}, d = 256. (MGCM cross-attention.)
- Eq. (7): F_corr = FusionTransformer[F'_img ∥ F_attn], F_corr ∈ R^{512}. (Fused representation for classification.)
- Eqs. (8)–(11): Accuracy = (TP+TN)/(TP+TN+FP+FN); Precision = TP/(TP+FP); Recall = TP/(TP+FN); F1 = 2·(Precision·Recall)/(Precision+Recall).
- Eq. (12): MCC = (TP·TN − FP·FN) / √((TP+FP)(TP+FN)(TN+FP)(TN+FN)).
- Eq. (13): κ = (p_o − p_e)/(1 − p_e).
- Eq. (14): RMSE = √(Σ_i ‖p̂_i − y_i‖² / n); Eq. (15): MAE = Σ_i ‖p̂_i − y_i‖₁ / n, where p̂_i is the predicted probability vector (softmax) and y_i the one-hot ground truth.
- Assumptions (stated): MediaPipe's pretrained model provides scalable, reproducible 2D keypoints adequate for dataset creation; keypoints with visibility < 0.5 are unreliable (dropped); load and activity REBA modifiers fixed to zero (single-frame, no dynamics); 8 REBA classes defined from final Group C value with classes 4+ indicating riskier postures.

## 5. Features / target
- **Inputs:** (a) RGB image frame resized to 224×224; (b) 33 MediaPipe 2D keypoints (x, y normalized, visibility-filtered) plus derived joint angles (cosine-law triplets, vertical inclination angles).
- **Target:** 8-class REBA posture-risk category (discrete class label 1–8), derived deterministically from the same keypoints via the rule-based REBA algorithm.
- **Prediction horizon:** single-frame classification (no temporal horizon).

## 6. Validation design
- Random (not time-ordered — single-frame images) 70% train / 10% validation / 20% test split.
- Baselines: nine ImageNet-style CNN backbones (VGG16, VGG19, ResNet50, ResNet101, InceptionV3, Xception, EfficientNet-B0, MobileNetV2, DenseNet121) each paired with an MLP coordinate encoder + simple concatenation fusion and a shared classification head (fair pipeline control).
- Metrics: accuracy, precision, recall, F1, specificity, NPV, FPR, FDR, FNR, Cohen's κ, MCC, multiclass ROC AUC, RMSE/MAE of predicted probability distribution vs one-hot label.
- Ablations: (a) module ablation — baseline simple-concat → +Residual blocks → +FGAM → +MGCM; (b) 12-experiment hyperparameter ablation (LR, batch, weight decay, optimizer, grad clip, label smoothing, loss function).
- Comparison with prior ergonomic studies (Li et al. 93% RULA; Seo et al. 89% OWAS; Doong et al. 76.1% REBA; Xiahou/Zhao/Qi multimodal sensor-based studies).

## 9. Leakage & limitations
- **Label circularity (fatal for the reported accuracy):** the target labels are computed by a deterministic rule-based function (joint-angle thresholds + REBA lookup tables) applied to the same MediaPipe coordinates the model receives. The classification task is therefore largely "re-learn a known deterministic mapping from its own inputs," which inflates accuracy relative to any genuine risk-prediction task. The authors state this explicitly ("the REBA scores are generated by applying a deterministic, rule-based algorithm to the coordinates").
- Train accuracy 99.97% vs test 93.89% suggests heavy memorization; the deterministic label structure makes train/test leakage of the *rule* trivial.
- Single-frame images, no temporal dynamics — cannot assess repetitive loading or cumulative fatigue, which the paper itself acknowledges as impossible to estimate from visual data alone.
- Load and activity REBA modifiers fixed to zero — real-world ergonomic risk components are excluded by construction.
- Random 70/10/20 split, not time-ordered or athlete-disjoint (athlete identity overlap between splits is not discussed); images drawn from public sports datasets with unknown duplication/near-duplication across splits.
- REBA is an occupational-ergonomics tool (designed for industrial posture); its mapping to actual athletic injury probability is asserted, not validated against injury outcomes.
- No external validity to NFL: the task is posture classification, not injury prediction; no football data, no temporal load, no contact.

This paper does NOT fill that gap: it classifies posture risk via a deterministic rule, it does not predict injuries or estimate causal effects.
- Overlap assessment: **extension-adjacent, not duplicate.** GSE has no posture-classification work, but the method (fusing tracking-derived keypoints with video frames via cross-attention) is methodologically related to multimodal fusion in the ML brief's area 13 (multimodal fusion). However, the deterministic-label circularity means the paper's *numbers* carry no transferable signal — only the FGAM/MGCM architectural pattern is reusable, and even that is marginal value vs. well-known cross-attention fusion.
