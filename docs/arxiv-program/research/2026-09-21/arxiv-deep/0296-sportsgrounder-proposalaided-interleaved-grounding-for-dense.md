# [0296] SportsGrounder: Proposal-Aided Interleaved Grounding for Dense Sports Video Reasoning (arXiv:2608.07932v2)

**Citation:** Li, Y., Jiang, J., Wang, G., Wu, Y., & Wang, G. (2026). *SportsGrounder: Proposal-Aided Interleaved Grounding for Dense Sports Video Reasoning*. Proc. 34th ACM Multimedia (MM '26), Rio de Janeiro. DOI: 10.1145/3767308.3836263. arXiv:2608.07932v2. URL: https://arxiv.org/abs/2608.07932v2
**Ledger completed:** 2026-09-21. **Read:** full text (2510-line text extract).
**Verdict:** ADAPT — the Interleaved Grounding Fusion (IGF) architecture is the blueprint for a football-video Q&A engine (auto-tagging plays, answering "who blew the coverage" from All-22). Do not adopt the LMM weights; adapt the proposal-aided interleaved fusion design to NFL footage.

## 1. Research question
Dense sports video reasoning requires fine-grained understanding of small, highly interactive, visually homogeneous entities across long temporal contexts. LMMs fail three ways: (1) patch-based ViTs discard fine spatial detail; (2) models over-rely on language priors, guessing answers from text bias (e.g., hallucinating "shot" instead of "pass"); (3) naive grounding (appending hundreds of object tokens or text bboxes) destroys temporal structure and quadratically explodes sequence length. SportsGrounder proposes proposal-aided interleaved grounding: an open-vocabulary visual expert (OV-DINO) with domain-guided top-K selection, an Interleaved Grounding Fusion (IGF) mechanism that weaves explicit bbox coordinates + implicit visual semantics into global grid features frame-by-frame, and an Action-Aware Supervision (AAS) module regularizing hidden states against language bias, trained with Mixed Preference Optimization (MPO).

## 2. Dataset / schema
Newly curated dense sports VQA datasets (programmatically generated 4-option multiple-choice): SoccerNet (soccer, 17 action categories; 26k QA, 25k train / 1k test; subtasks: Action, Team comparison, Jersey number, Spatial reasoning) and FineSports (basketball, 24 action labels; 24k QA, 23k train / 1k test; subtasks: Action, Actor grounding, Dense disambiguation, Spatial). Soccer clips: short segments around annotated timestamps, sparse keyframes; FineSports: pre-extracted complete sequences (≤8 frames/clip). Questions use varied referring expressions (jersey number, relative position, jersey color); explicit (x,y) coordinates strictly excluded from evaluation questions to prevent trivial spatial matching. Metrics: top-1 accuracy (%) per subtask.

## 3. Method / model
(1) Proposal-aided representation: global ViT branch (Eq. 1: Z_t^vit = Φ_vit(I_t) ∈ ℝ^{N×d_vit}); object branch: OV-DINO with Language-Aware Selective Fusion decoding M=900 queries; domain-guided top-K selection via cross-modality similarity S = ℱ_c(Q_sf) ⊗ E_t^⊤ (Eq. 2) against a sport-specific vocabulary; retain K=15 queries → Z_t^sem ∈ ℝ^{K×d_dino}; explicit normalized bboxes b_t ∈ ℝ^{K×4}. (2) IGF: two MLP projectors; hybrid entity token per object = text-embedding of bbox coordinate string E_{t,k}^{box} (via Φ_emb) concatenated with projected semantic vector 𝒫_dino(Z_{t,k}^{sem}); all K entities concatenated (Eq. 4); interleaved frame-by-frame: H_vis = [Z̃_1^vit ⊕ Z̃_1^obj ⊕ … ⊕ Z̃_T^vit ⊕ Z̃_T^obj] ∈ ℝ^{T(N+K(L_box+1))×d_llm} (Eq. 5) — avoids naive-fusion O((T(N+K·L_box))²). (3) AAS: final hidden state h_EOS → softmax action head (Eq. 6: p_act^(i) = Softmax(W_act h_EOS^(i) + b_act)); masked CE loss (Eq. 7: ℒ_act) with task-conditional indicator 𝕀_act^(i) (1 iff query is action-related) and balanced task sampling. (4) Three-stage curriculum: Stage 1 alignment (freeze encoders/LLM/𝒫_vit, train 𝒫_dino 1 epoch, Eq. 8); Stage 2 LoRA SFT 3 epochs (Eq. 9–10: ℒ_SFT = ℒ_vqa + λℒ_act, λ=0.1; learnable = {θ_LoRA, 𝒫_vit, 𝒫_dino}); Stage 3 MPO 1 epoch (Eq. 11–12: ℒ_MPO = ℒ_p + αℒ_q + βℒ_g; DPO-style preference loss with margin τ, β=0.1). Backbone: InternVL3.5-2B; AdamW, cosine decay.

## 4. Equations & assumptions
Eq. 1: Z_t^vit = Φ_vit(I_t) ∈ ℝ^{N×d_vit}. Eq. 2: S = ℱ_c(Q_sf) ⊗ E_t^⊤ ∈ ℝ^{M×C} (M=900). Eq. 3: Z̃_t^vit = 𝒫_vit(Z_t^vit) ∈ ℝ^{N×d_llm}. Eq. 4: Z̃_t^obj = ⊕_{k=1}^K (E_{t,k}^{box} ⊕ 𝒫_dino(Z_{t,k}^{sem})) ∈ ℝ^{K(L_box+1)×d_llm}. Eq. 5: H_vis = [Z̃_1^vit ⊕ Z̃_1^obj ⊕ … ⊕ Z̃_T^vit ⊕ Z̃_T^obj] ∈ ℝ^{T(N+K(L_box+1))×d_llm}. Eq. 6: p_act^(i) = Softmax(W_act h_EOS^(i) + b_act) ∈ ℝ^C. Eq. 7: ℒ_act = −(1/(Σ𝕀_act+ε)) Σ 𝕀_act^(i) Σ_c y_{act,c}^(i) log p_{act,c}^(i). Eq. 8: min ℒ_align = −Σ log P(y_j | H_vis(θ_dino), y_{<j}). Eq. 9: ℒ_vqa = −Σ log P(y_t | X, y_{<t}). Eq. 10: ℒ_SFT = ℒ_vqa + λℒ_act (λ=0.1). Eq. 11: ℒ_MPO = ℒ_p + αℒ_q + βℒ_g. Eq. 12: ℒ_p = −log σ(τ log(π_θ(y_c|X)/π_ref(y_c|X)) − τ log(π_θ(y_r|X)/π_ref(y_r|X))). Assumptions: uniform frame sampling sufficient; top-K=15 captures active entities; causal-attention EOS state can be forced to aggregate motion dynamics via direct gradient; hard-negative preference pairs calibrate decision boundaries; bbox-as-text embeddings are geometrically meaningful.

## 5. Features / target
Features: video frames (SoccerNet clips, FineSports ≤8-frame sequences), OV-DINO proposals (top-15), domain vocabulary (soccer/basketball entities), action label taxonomies (17 soccer, 24 basketball classes). Targets: 4-option multiple-choice answers across subtasks (Action, Team comparison, Jersey number, Spatial reasoning / Actor grounding, Dense disambiguation). Metric: top-1 accuracy (%). Horizon: clip-level (seconds).

## 6. Validation design
Two comparison settings: (1) Parameter-Efficient SFT — baselines (Qwen3-VL-2B-Instruct, VideoLLaMA3-2B, InternVL3.5-2B, MiniCPM-V 4.0) LoRA-fine-tuned on the same datasets with default global visual inputs; (2) Prompt Injection — stronger baseline feeding OV-DINO bbox coordinates as text into baselines' context. Ablations (Table 2, SoccerNet): IGF-only baseline (no AAS, no MPO) → +AAS → +MPO → full. QA construction excludes coordinates from questions; models for the two datasets trained independently.

## 7. Numerical results / baselines
Table 1 (accuracy %): SoccerNet Overall — SportsGrounder 51.8 vs MiniCPM-V 4.0 47.5, InternVL3.5-2B 43.7, Qwen3-VL-2B 42.3, VideoLLaMA3-2B 38.6; with bbox prompt injection MiniCPM-V 49.1, InternVL3.5+BBox 45.2. FineSports Overall — SportsGrounder 53.6 vs MiniCPM-V 48.2, InternVL3.5 44.8. Subtasks (SoccerNet): Action 42.5 vs 41.2 (MiniCPM-V); Team 71.2 vs 64.1; Jersey 33.4 vs 37.8 (MiniCPM-V wins — OCR scales with params); Spatial 54.2 vs 46.8. FineSports subtasks: Action 43.2, Grounding 59.2 vs 53.4, Disambiguation 53.1 vs 48.7, Spatial 54.2 vs 51.5. Ablation (Table 2): IGF-only baseline 47.2 Overall / 38.4 Action; +AAS → 48.9 / 40.8 (+2.4 Action); +MPO → 49.6 / 39.1, Spatial 53.0 (+4.4 vs baseline); full 51.8 / 42.5 / Team 71.2 / Jersey 33.4 / Spatial 54.2. Prompt injection consistently degrades Action accuracy across baselines (temporal-attention distraction) while SportsGrounder's visual-level fusion avoids this. Note: absolute accuracies (38–54%) show how hard dense sports VQA is — even SOTA is barely above chance on a 4-option test in some subtasks (Jersey 33.4% vs 25% chance).

## 9. Leakage & limitations
(a) Absolute accuracy is low: 51.8% overall on 4-choice QA — the paper's SOTA is still wrong nearly half the time; production use requires human-in-the-loop. (b) Jersey-number OCR (33.4%) lags a bigger model — fine-grained identity from video remains unsolved. (c) QA pairs are programmatically generated from metadata (template risk; "linguistic diversity" claims not quantified). (d) Soccer + basketball only; no American football; NFL's line-of-scrimmage bunching is denser than anything in SoccerNet/FineSports. (e) MPO recipe is InternVL3.5's native protocol, not novel — reproducibility depends on that base model. (f) λ=0.1, K=15, τ/β=0.1 are empirical, not swept. (g) Conference is MM '26 (Nov 2026, Rio) — the paper is dated after today; treat as a preprint, peer-review status pending. (h) No code link in text; no released weights confirmed.

## 11. GSE implementation spec
(1) Pilot: replicate the IGF architecture with an open LMM backbone on NFL All-22 clips, domain vocabulary = {quarterback, receiver, defender, referee, football, pylon, ...}, K tuned for 22-player frames (start K=22, not 15). (2) Curate an NFL-VQA set from charting data: questions like "which receiver ran the dig route?" / "was the coverage man or zone?" with charted answers — programmatically generated like the paper's QA, but grounded in FTN/PFF-style charting labels. (3) Train the AAS head on action classes (route types, coverage shells, penalty types) to fight language bias. (4) Human-in-the-loop deployment: model proposes play tags + narration; analyst confirms before publish (required given ~50% accuracy). Effort: ~3–4 engineer-weeks for pilot given open LMM + OV-DINO availability; NFL-VQA curation is the long pole.

## 12. Reproducible test
Dataset: 200 NFL All-22 plays with charted labels (coverage type, route concepts, penalty flags). Metric: top-1 accuracy on 4-option questions (coverage ID, route ID, responsible defender) vs a prompt-injection baseline (bboxes as text) and a global-ViT-only LMM baseline. Window: 2024 season plays.

## 13. Acceptance / rejection gate
ADAPT further (toward production pilot) if IGF-style fusion beats prompt injection by ≥5 pp on coverage-ID and route-ID accuracy AND action accuracy ≥ 55%; PARK if overall accuracy < 45% or if the fusion model cannot beat prompt injection — the architecture advantage must survive on NFL data to justify the training cost.

## 14. Improvement experiment
Go beyond the paper by adding *audio/commentary as a second interleaved stream*: NFL broadcasts carry rich commentary that resolves action ambiguity (the paper's core failure mode: shot vs pass); interleaving ASR tokens per segment alongside the visual IGF stream would let the model disambiguate visually identical motions (e.g., play-action vs run) using the announcer's call — a modality the paper never considers and one uniquely abundant in NFL broadcast footage.
