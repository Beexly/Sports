# [1835] Neural-Guided Equation Discovery (arXiv:2503.16953)

**Citation:** Jannis Brugger, Mattia Cerrato, David Richter, Cedric Derstroff, Daniel Maninger, Mira Mezini, Stefan Kramer (2025). *Neural-Guided Equation Discovery*. arXiv:2503.16953v1. URL: https://arxiv.org/abs/2503.16953
**Ledger completed:** 2026-09-22. **Read:** full text (ar5iv HTML).
**Verdict:** ADAPT

The most useful negative results in the lane: supervised training beats RL for neural-guided SR in nearly all module combinations, grammar-rule action spaces beat token action spaces, and risk-seeking MCTS (max-backprop) improves search; needs adaptation since GSE's discovery loop is LLM- and evolution-based, but the design rules (supervision over RL, grammar actions, max-backprop) transfer directly.

## 1. Research question
For neural-guided equation discovery, which design choices actually matter? The authors build MGMT (Multi-Task Grammar-Guided Monte-Carlo Tree Search for Equation Discovery) — a modular system with interchangeable dataset encoders, syntax-tree embeddings, training modes (supervised vs RL), and MCTS variants — and ablate: encoder architecture, supervised vs RL, grammar-rules vs tokens as actions, and two MCTS adaptations (AmEx-MCTS, risk-seeking MCTS).

## 2. Dataset / schema
Synthetic equation-discovery tasks generated per grammar (Sec. 5); Nguyen benchmark (500 test equations); tabular datasets embedded via contrastive learning auxiliary task (100 rows/dataset). Encoders compared: MLP (144,717 params), LSTM (82,381), Bi-LSTM (44,400), CNN (113,189), NPT (12,037,627), Text Transformer (41,546,701) — Table 2.

## 3. Method / model
- **MGMT**: neural-guided MCTS over expressions generated by a context-free grammar; modules: dataset encoder (tabular → embedding), syntax-tree embedding, policy/value heads; trainable supervised (imitate good derivations) or by RL.
- **Grammar rules as actions** (not tokens): each MCTS action applies a grammar production — declarative bias baked into the search, reviving Todorovski & Džeroski (1997).
- **Risk-seeking MCTS**: replace mean with MAX in backprop Q-updates (one good equation in a branch shouldn't be diluted by bad siblings — same philosophy as 1824's risk-seeking PG); PUCT c=10 to preserve exploration since max-backprop inflates root Q-values.
- **AmEx-MCTS**: second MCTS adaptation (details in Table 3 configs); improves over classic MCTS.
- **Contrastive learning for tabular data**: auxiliary task to learn dataset embeddings (which datasets are "similar" in equation structure).

## 4. Equations & assumptions
PUCT with c=10; Q(s,a) ← max over children (risk-seeking) instead of mean; contrastive loss λ=0.1.
Assumptions: (1) dataset embeddings capture equation-relevant structure; (2) supervised derivations exist/are representative; (3) grammar covers the truth; (4) max-backprop doesn't collapse exploration (mitigated by high PUCT c).

## 5. Features / target
Tabular datasets → equations. GSE analog: nflverse tables → metric equations.

## 6. Validation design
Module ablation across 7 encoders × training modes × grammar/token actions × MCTS variants; Nguyen benchmark (500 equations); contrastive auxiliary task; seed/iteration configs in Table 3.

## 7. Numerical results / baselines
- **Supervised learning outperforms RL in nearly all module combinations** — the paper's headline negative result for the RL-SR fashion.
- **Grammar rules as action space > tokens** — "an easy but effective way to introduce domain knowledge."
- **NPT** (permutation-resistant transformer) best on the contrastive tabular-embedding auxiliary task, but **simpler LSTMs better end-to-end in MGMT** — auxiliary-task wins don't transfer; the 12M-param NPT loses to 82K-param LSTM in the real loop.
- Risk-seeking MCTS and AmEx-MCTS both improve over classic MCTS.
- Seven desirable properties of ED systems summarized (Sec. 2), with dataset embedding flagged as the critical one.

## 8. Code / data availability
MGMT system described; no public repo URL extracted. Funded by HMWK/hessian.AI.

## 9. Leakage & limitations
- Synthetic training tasks from the same grammars used for testing — in-distribution by construction; Nguyen benchmark is the only external check.
- No comparison against PySR/DSR/LLM-SR — the ablations are internal to MGMT.
- "Supervised beats RL" may reflect RL tuning effort rather than a fundamental gap; RL hyperparameters barely discussed.
- Contrastive auxiliary task uses 100-row datasets; sports tables are smaller.
- AmEx-MCTS mechanism not fully extracted (table-only in the scrape).

## 10. GSE overlap
Three directly portable rules: (1) prefer supervised/imitation-style guidance over RL for GSE's search components (relevant if GSE ever trains a neural proposer — don't default to RL); (2) grammar-constrained generation beats free-token generation — supports constraining GSE-SR's LLM proposals with a grammar/operator whitelist; (3) risk-seeking (max) aggregation beats mean aggregation — applies to how GSE-SR's island model scores program families (keep the best, don't average). Complements 1824 (risk-seeking PG) with the MCTS version.

## 11. GSE implementation spec
- Add grammar-constrained decoding to GSE-SR proposals: operator whitelist + max depth + max constants (mirroring Table 3's caps: depth 10, nodes 25, constants 5).
- Change island-model scoring from mean-fitness to best-fitness (risk-seeking aggregation).
- If GSE trains a neural proposer: supervised on (dataset, equation) pairs first; RL only as fine-tuning for noisy data (the paper's own suggested future work).
- Effort: ~1–2 days.

## 12. Reproducible test
Dataset: Nguyen benchmark (500 equations, public). Baselines: MGMT-classic vs MGMT risk-seeking (max-backprop) reimplementation, or simply PySR with mean- vs best-aggregation selection. Metric: recovery rate at fixed compute budget.

## 13. Acceptance / rejection gate
ADOPT grammar-constrained proposals + best-aggregation if GSE-SR valid-program rate rises ≥10pp with no OOD-NMSE regression on the 2024–2025 holdout; REJECT if constraints reduce the diversity of discovered forms (count distinct skeletons — must not drop >20%).

## 14. Improvement experiment
"Learned dataset embeddings for warm-starts": train a small encoder (Bi-LSTM per the paper's winner) contrastively on (nflverse table slice → discovered equation skeleton) pairs, then use embedding similarity to warm-start new discovery tasks with equations from similar tables. If metric discovery for a new stat (e.g. punt-return value) warm-starts from a similar old task (kick-return value) and converges faster, GSE gets transfer learning across its metric portfolio — the meta-learning question (III) the paper poses.
