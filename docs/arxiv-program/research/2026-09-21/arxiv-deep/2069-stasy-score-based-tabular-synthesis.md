# [2069] STaSy: Score-based Tabular data Synthesis (arXiv:2210.04018)

**Citation:** Jayoung Kim, Chaejeong Lee, Noseong Park (2022; rev. May 2023). *STaSy: Score-based Tabular data Synthesis*. arXiv:2210.04018. URL: https://arxiv.org/abs/2210.04018. Code on GitHub (stated in abstract; URL not captured verbatim in this read). CC-BY 4.0.
**Ledger completed:** 2026-09-22. **Read:** full text (ar5iv HTML, 2210.04018 v4, sections 1–7; Appendices A–J; all equations, Tables 1–27 verified).
**Verdict:** ADAPT — the self-paced curriculum training (quantile-weighted soft record selection, Eq. 15) and the probability-flow-ODE log-probability fine-tuning are the most NFL-transferable training tricks in the tabular lane: they directly stabilize generation on small, heterogeneous, imbalanced tables (Credit 99.7/0.3 imbalance; smallest Crowdsource class 79 records; Obesity 1.6K train rows). Needs adaptation: replace its one-hot/min-max numerics with FinDiff-style embeddings + quantile preprocessing (ledgers 2065, 2068), which the paper itself does not do.

## 1. Research question
Can score-based generative models (SGMs) — which resolved quality/diversity issues in image generation — synthesize tabular data well enough to win the "generative learning trilemma" (quality, diversity, time)? The technical questions: does a continuous SDE score model beat 7 tabular baselines on task-dependent TSTR evaluation and coverage; does a self-paced learning (SPL) curriculum with a closed-form soft record-weighting rule stabilize denoising score matching on heterogeneous tabular rows; and can exact log-probability via the probability-flow ODE identify poorly-modeled records for targeted fine-tuning?

## 2. Dataset / schema
15 real-world tabular datasets (Table 25, Appendix H.2), selected for citation/download popularity, each with >5 columns and >1,000 rows; 80/20 train-test splits:
- Binary classification (7): Credit (264.8K train, 29 cont/1 cat — European cardholder fraud), Default (24K, 13/11), HTRU (14.3K, 8/1), Magic (15.2K, 10/1), Phishing (8.8K, 0/31), Shoppers (9.8K, 10/8), Spambase (3.7K, 57/1).
- Multi-class (6): Bean (10.8K, 16/1, 7 classes), Contraceptive (1.2K, 0/10, 3 classes), Crowdsource (8.6K, 28/1, 6 classes), Obesity (1.6K, 7/10, 7 classes), Robot (4.4K, 24/1, 4 classes), Shuttle (46.4K, 9/1, 7 classes).
- Regression (2): Beijing (15.2K, 8/6 — PM2.5), News (31.6K, 45/14 — shares).
The paper emphasizes the small/imbalanced end: smallest class in Crowdsource is 79 records; Credit is 99.7%/0.3% imbalanced (my inference: these are the NFL-analogous cases — few hundred rows per regime, rare outcome classes).

## 3. Method / model
STaSy pipeline: (1) preprocessing — min-max scaler for continuous, one-hot encoding for categorical; reverse mapping by softmax with temperature τ followed by rounding; (2) score-based SDE training (Song et al. 2021) with VE, VP, or sub-VP SDE (Appendix A) and only T=50 diffusion steps (vs T=1000 for images), which they argue suffices for low-dimensional tabular data; (3) self-paced learning: soft record weights v_i ∈ [0,1] from the closed-form rule (Eq. 15) using loss quantiles Q(α), Q(β), with α, β increasing logarithmically to 1 over S=10,000 steps (Appendix D), β0 ≥ 0.8 so ≥80% of records train from the start; (4) fine-tuning (Algorithm 1): compute each record's exact log-probability under the probability-flow ODE with Hutchinson trace estimation, and retrain (with denoising score matching loss, not the Hutchinson objective — Appendix F shows DSM is better) on records with log p(x_i) < τ_i; (5) sampling via reverse SDE solvers — probability flow (PF) mostly best (Table 8: Magic F1 0.781±0.054 PF vs 0.779 EM), predictor-corrector with ancestral/reverse-diffusion/Euler–Maruyama predictors also tested. Score network (Appendix C): h_0 = x(t); h_i = ω(H_i(h_{i−1},t) ⊕ h_{i−1}); S_θ = FC(h_{d_N}); layer types Squash/Concat/Concatsquash; β0 search {0.80,0.90,0.95}, α0 {0.20,0.25,0.30}, SDE type and layer type per-dataset (Table 27). Baselines: MedGAN, VEEGAN, CTGAN, TVAE, TableGAN, OCT-GAN, RNODE (Appendix H.1).

## 4. Equations & assumptions
Forward SDE (Eq. 1): dx = f(x,t)dt + g(t)dw. Denoising score matching objective (Eq. 6): the weighted per-record loss l_i trains S_θ(x(t),t). Reverse SDE (Eq. 2) and probability-flow ODE (Eq. 10): dx = [f(x,t) − ½g(t)²∇_x log p_t(x)]dt, whose trajectories give exact log-probabilities via the instantaneous change-of-variables with Hutchinson trace estimation of ∇·f̃_θ. SPL objective (Eq. 13): min_{θ,v} Σ_i v_i l_i − ((Q(α)−Q(β))/2)Σ_i v_i² − Q(β)Σ_i v_i, with optimal weights (Eq. 15): v_i* = 1 if l_i ≤ Q(α); 0 if l_i ≥ Q(β); (l_i − Q(β))/(Q(α) − Q(β)) otherwise (Theorem 1 proof, Appendix E). Threshold schedule (Appendix D): α = α0 + log(1 + c((e−1)/S)(1−α0)), same for β; S=10,000. Assumptions: (1) min-max + one-hot is an adequate continuous embedding of mixed tabular data (the weak point — ledgers 2064–2066 argue otherwise); (2) denoising loss quantiles measure "training difficulty" faithfully; (3) below-median-log-prob records are the ones worth fine-tuning; (4) T=50 steps suffice for tabular data.

## 5. Features / target
Per dataset (§2); TSTR targets are the dataset labels (fraud/default/spam flags, bean types, land-cover classes, PM2.5, news shares). NFL translation (my inference): rows = team-game observations; features = EPA/success/pace/spread numerics + team/opponent/venue/weather/rest categoricals; the "small class" role = rare regimes (playoff games, extreme weather, backup-QB starts) where NFL tables are thinnest — exactly where STaSy's imbalance results (Credit, Crowdsource) are most encouraging.

## 6. Validation design
TSTR (train-synthetic/test-real) protocol (Appendix H.3): 80/20 splits; generate synthetic sets the same size as the training set; train DecisionTree/AdaBoost/LogisticRegression/MLP/RandomForest/XGBoost (classification) or MLP/RF/XGBoost/LinearRegression (regression) with per-model hyperparameter grid search (Table 26); evaluate F1 (binary), macro F1 (multi-class), weighted F1 (inverse-class-size weighted, designed to penalize mode collapse of small classes), AUROC, R², RMSE — 5 repeats, mean ± std. Plus: median test-record log-probability vs RNODE (Table 3/18); coverage (k-NN diversity, k=5, k=7 for Phishing; Tables 19–21); wall-clock sampling time (Table 5/22–24); ablations (Table 6: Naïve-STaSy / w/o fine-tuning / w/o SPL / full STaSy); sensitivity on SDE type, α0, β0 (Table 7); solver comparison (Table 8); oversampling conversion vs SOS (Appendix B, Table 9); fine-tuning-objective comparison (Appendix F, Table 10). Splits random, not time-ordered; no temporal design.

## 7. Numerical results / baselines
Trilemma (Table 1, averaged over all datasets): STaSy quality 0.733 / diversity 0.658 / runtime 10.663s; Naïve-STaSy 0.717 / 0.637 / 8.855s; CTGAN 0.569 / 0.352 / 0.704s; TVAE 0.521 / 0.564 / 0.100s; TableGAN 0.429 / 0.449 / 0.046s; OCT-GAN 0.534 / 0.400 / 26.926s; RNODE 0.383 / 0.332 / 13.392s.
TSTR (Table 2, all the paper's claims, 5 repeats):
- Binary F1: Credit — STaSy 0.794±0.035 (Naïve 0.782±0.042, CTGAN 0.757±0.064, Identity/real-data 0.775±0.071 — synthetic beats real-data training); Default — 0.523±0.007 (Naïve 0.509, CTGAN 0.497); HTRU — 0.885±0.007 (Naïve 0.885); Magic — 0.781±0.054; Phishing — 0.932±0.013 (Naïve 0.925); Shoppers — 0.642±0.015; Spambase — 0.893±0.025.
- Multi-class macro F1: Bean 0.935±0.009; Contraceptive 0.451±0.017 (Naïve 0.418); Crowdsource 0.743±0.104 (Naïve 0.710); Obesity 0.910±0.025; Robot 0.944±0.032; Shuttle 0.865±0.072 (Naïve 0.791 — the biggest SPL+fine-tuning gain, +0.074).
- Regression R²: Beijing 0.672±0.166 (Naïve 0.625±0.141, Identity 0.728±0.196); News 0.029±0.008 (Naïve 0.023±0.011).
Aggregate TSTR (§4.2.1): F1 0.792, AUROC 0.925, weighted F1 0.801, R² 0.350, RMSE 4071.643 (STaSy best on all five).
Log-probability (Table 3, median of test records): STaSy 131.734, STaSy w/o fine-tuning 129.293, RNODE 59.327 — fine-tuning consistently raises held-out likelihood (Table 18 full breakdown).
Coverage (Table 4): STaSy 0.658, Naïve-STaSy 0.637, TVAE 0.494, TableGAN 0.449, OCT-GAN 0.400, CTGAN 0.352 — best in 12/15 datasets per §G.2 (but note: Credit coverage only 0.014 and Default 0.101 even for STaSy, Table 19 — diversity still collapses on the hardest imbalanced sets).
Ablation (Table 6): full STaSy beats all three ablations on all 7 reported datasets (e.g., Shuttle 0.865 vs Naïve 0.791; Crowdsource 0.743 vs 0.710), so both SPL and fine-tuning contribute.
Sensitivity (Table 7): best SDE type is dataset-dependent (sub-VP on Spambase 0.893±0.025; VE on Crowdsource 0.743±0.104 and Beijing 0.672±0.166); recommended α0 ∈ {0.2, 0.25}, β0 ∈ {0.9, 0.95}.
Oversampling (Appendix B, Table 9): STaSy w/o fine-tuning converted to a per-minor-class oversampler beats SOS (Kim et al. 2022) on weighted F1 — HTRU 0.8803±0.0027 vs 0.8767±0.0017; Magic 0.7960±0.0015 vs 0.7949±0.0011; Robot 0.9270±0.0029 vs 0.9197±0.0040.

## 9. Leakage & limitations
Adversarial notes: (1) One-hot + min-max is the weakest preprocessing in this lane — 32 NFL teams one-hot to 32 dims per team field is manageable, but venue/weather/lineup categoricals compound; TabRep (2067) and FinDiff (2065) embeddings are strictly better and the paper gives no comparison. (2) Min-max scaling is outlier-fragile (blowout margins, single-game EPA spikes will compress the bulk of NFL numerics) — quantile preprocessing (ledger 2065, Table 3) should precede it. (3) Coverage still collapses on the hardest sets (Credit 0.014, Default 0.101) — the exact imbalanced regime the paper sells; diversity on rare NFL classes is not solved, only improved. (4) SDE type, layer type, α0, β0, activation, and LR are all tuned per dataset (Table 27) — expect per-table tuning cost on NFL data too. (5) No temporal structure, no missing-data handling, no conditional generation on arbitrary regimes (SOS is the conditional follow-up, not this paper). (6) Runtime 10.663s avg is fine, but training cost (10,000-step SPL schedule + fine-tuning epochs) is heavier than reported sampling time suggests. (7) Ethics section flags the dual use: high-quality fake tabular data can also be used to retrieve private original records. External validity to NFL: the method's demonstrated strength — small tables (1.2–1.6K rows), severe imbalance (99.7/0.3), heterogeneous row difficulty — matches the NFL regime table almost exactly; the preprocessing is the part to replace, not the training strategy.

## 11. GSE implementation spec
Build plan (effort: ~4 engineer-days; the training-strategy wrapper, not a standalone backbone):
1. Data: nflverse team-game rows 2015–2024 (~2,700 rows — the "small heterogeneous table" regime STaSy was built for).
2. Representation: replace the paper's one-hot/min-max with TabRep roots-of-unity encodings (2067) for team/opponent/venue/weather/rest categoricals and quantile transform (2065) for EPA/margin/pace numerics.
3. Model: continuous score-based SDE (start with VP; search VE/sub-VP per Table 7's dataset-dependence), T=50 steps, concatsquash/squash score net per Appendix C.
4. Training: SPL with α0=0.2, β0=0.9, S=10,000 (paper's recommended); then probability-flow-ODE log-probability scoring of training rows; fine-tune with DSM loss on rows with log p(x_i) < τ_i (median threshold to start, per Algorithm 1).
5. Sampler: probability flow (Table 8's winner) for exact log-probability scoring of generated seasons.
6. Select on CatBoost ML-efficiency on a held-out season, plus coverage on rare regimes (playoff, extreme weather) as the diversity check.

## 12. Reproducible test
Dataset: nflverse team-game rows 2018–2023 train, 2024 held-out. Baseline: plain VP-SDE tabular diffusion without SPL/fine-tuning (the paper's "Naïve-STaSy" analog) generating 3 synthetic seasons. Challenger: full STaSy training (SPL + log-prob fine-tuning) on the TabRep/quantile representation. Same downstream GBDT spread model (real+synthetic train, real 2024 test). Metrics: (a) 2024 log-loss; (b) per-regime coverage on playoff + extreme-weather + backup-QB rows (the rare-class analog of weighted F1); (c) median held-out log-probability of 2024 rows under each generator (the paper's Table 3 metric, directly implementable via the PF ODE).

## 13. Acceptance / rejection gate
ADOPT the SPL + fine-tuning wrapper if: (a) real+synthetic log-loss beats the Naïve baseline by ≥0.003 on held-out 2024 (the lane's standing bar), AND (b) rare-regime coverage improves by ≥10% relative with no column-fidelity regression (Ω_col within 0.02 of baseline, per ledger 2065's Eq. 5), AND (c) median 2024 log-probability under the STaSy model exceeds the Naïve model (the paper's fine-tuning signature: 131.734 vs 129.293). REJECT the wrapper (keep the plain diffusion) if the log-loss gate fails or if SPL collapses to near-uniform weights (all v_i ≈ 1 by step S — check the weight histogram; if the curriculum does nothing on NFL rows, the complexity is unjustified). Gate set before running; 3 seeds; SDE type fixed to the validation winner before the gate run.

## 14. Improvement experiment
Difficulty-aware SPL with a football prior: the paper's SPL derives difficulty purely from denoising loss quantiles, which on tiny NFL tables may just track noise. Initialize the record weights with a domain difficulty prior instead of uniform — v_i^(0) from a heuristic (e.g., down-weight preseason-coaching-change and extreme-weather games known to be high-variance), then let the quantile rule take over after 2,000 steps. Test: does prior-initialized SPL beat loss-only SPL on the §13 gate, especially on rare-regime coverage? If yes, the curriculum is doing real work on NFL structure rather than fitting noise; if no, fall back to the paper's pure loss-quantile version.
