# [0601] Prediction and Evaluation in College Hockey using the Bradley-Terry-Zermelo Model (arXiv:2001.04226v2)

**Citation:** Whelan, J. T., Wodon, A. (2020). *Prediction and Evaluation in College Hockey using the Bradley-Terry-Zermelo Model*. arXiv:2001.04226v2. URL: https://arxiv.org/abs/2001.04226v2
**Ledger completed:** 2026-09-21. **Read:** full text (PDF text extract, 4564 lines).
**Verdict:** ADAPT — port the Hessian-based posterior-uncertainty machinery and the Bayes-factor-vs-tossup model-evaluation protocol into GSE's ratings and engine-verification stack; do not import the hockey-specific Pairwise Probability Matrix.

## 1. Research question
How can the Bradley-Terry model be used not just for ranking NCAA Division I men's ice hockey teams (the existing KRACH ratings), but for principled probabilistic prediction and model comparison? The paper builds a Bayesian Bradley-Terry construction (MAP + Hessian-based Gaussian posterior approximation + importance sampling) to produce posterior predictive probabilities for future games, defines a Bayes-factor protocol to evaluate any probability-generating model against actual NCAA tournament outcomes, and applies it to compare MLE/KRACH, a regularized logistic-prior BT, and a naïve win-ratio model over 17 tournaments. It also describes a Monte Carlo "Pairwise Probability Matrix" tool that estimates each team's chance of making the tournament, with a proposed upgrade that draws ratings from the posterior instead of using point estimates.

## 2. Dataset / schema
- **NCAA Division I men's ice hockey game results:** collected from https://www.collegehockeynews.com/schedules/composite.php. At the time: 60 teams, each playing ~30–40 games per season. Seasons used: tournaments 2003 (first year of the current 16-team format) through 2019; the 2018–2019 season pre-selection results as training data D for the predictive demos.
- **Evaluation data:** actual NCAA tournament games (15 games per tournament, single elimination; 17 tournaments × 15 games = 255 games for the cumulative Bayes-factor study).
- Schema: team pairs (i, j), games played n_ij = n_ji, wins w_ij (team i over team j); total wins v_i = Σ_j w_ij. Ties (possible in college hockey regular season) are split 0.5/0.5 to wins and losses — acknowledged as a conceptual inconsistency with the no-ties derivation, but ties are rare enough to cause no pathology.

## 3. Method / model
- **Bayesian Bradley-Terry:** log-strengths λ_i ∈ (−∞,∞); win probability θ_ij = e^{λ_i}/(e^{λ_i}+e^{λ_j}) = logistic(λ_i − λ_j) (eq. 1.1). Likelihood: P(D|{λ_i}) = ∏_{i}∏_{j=i+1}^{t} θ_ij^{w_ij}(1−θ_ij)^{n_ij−w_ij} (eqs. 1.2–1.3); log-likelihood = Σ_i v_i λ_i − ½Σ_{i,j} n_ij ln(e^{λ_i}+e^{λ_j}) (eq. 1.4); MLE moment condition v_i = Σ_j n_ij θ̂_ij (eq. 1.5), solved by Ford's iteration (eq. 1.6). MLE is defined only up to an additive constant.
- **Priors (eqs. 1.9–1.11):** Haldane prior f({λ_i}|I₀) = constant (improper; limit of Beta(α,β)→0, of generalized logistic as η→0, of Gaussian as σ→∞); generalized logistic prior f({λ_i}|I_η) = ∏_i Γ(2η)/[Γ(η)]² · 1/[(1+e^{λ_i})^η(1+e^{−λ_i})^η] (eq. 1.10); Gaussian prior N(0,σ²) (eq. 1.11). MAP equations: η + v_i = 2η θ̃_{i0} + Σ_j n_ij θ̃_ij for logistic prior (eq. 1.14) — equivalent to MLE with 2η fictitious half-win/half-loss games against a zero-strength team; v_i = λ̃_i/σ² + Σ_j n_ij θ̃_ij for Gaussian (eq. 1.15).
- **Posterior predictive probabilities:** marginalize P(O|D,I) = ∫ P(O|{λ_i}) f({λ_i}|D,I) d^t λ (eq. 2.1) via three approximations: (1) MAP evaluation — delta function at MAP, P(O|{λ̃_i}) (§2.1); (2) Gaussian approximation — Taylor-expand log-posterior at MAP; Hessian H_ij = −n_ij θ̃_ij θ̃_ji + δ_ij Σ_k θ̃_ik θ̃_ki − (prior term) (eq. 2.3); logistic-prior term δ_ij θ̃_{i0}(1−θ̃_{i0}) (eq. 2.4); Gaussian-prior term δ_ij/σ² (eq. 2.5); covariance Σ = H^{−1}, or the Moore-Penrose pseudo-inverse for the Haldane prior because of the one degenerate direction ℓ^{(1)} = (1/√t,…,1/√t), zero eigenvalue h₁=0 (eqs. 2.6–2.8); Monte Carlo estimate (eqs. 2.9–2.10) with N samples from N_t({λ̃_i},{Σ_ij}); (3) importance sampling — reweight by w_s ∝ f/g (eqs. 2.11–2.12), noted to be unstable when the posterior tail exceeds the Gaussian's (Figs. 1–3; the 59-dof χ distribution of normalized distance sits 5–10σ out, so heavy-tailed Student-t proposals make things worse, §2.3; skew-normal suggested as future work).
- **Evaluation via Bayes factor (§3.1):** B_12 = P(O|M₁,D,I)/P(O|M₂,D,I) (eq. 3.1); compares models on the exact sequence of results that occurred, benchmarked against a tossup model M₀ with P(O|M₀,D,I) = 2^{−n_O} (eq. 3.3); B_mle,0 = ∏_{g=1}^{n_O} 2θ̂_{w_g l_g} — each correctly-called game multiplies the factor by up to 2, each miss divides.
- **Pairwise Probability Matrix (§3.2):** N = 20,000 Monte Carlo trials simulating remaining season games with BT probabilities (θ_ij = logistic(λ_i − λ_j)), handling bracket-dependent scheduling and conference-tournament auto-qualifiers, then applying NCAA selection criteria; probability of outcome O = fraction of trials (eq. 3.5). Proposed modification: per trial, draw {λ_i^{(s)}} from the Gaussian posterior and use θ^{(s)}_ij (eqs. 3.8–3.9) — demonstrated on Cornell–Quinnipiac.

## 4. Equations & assumptions
Listed in §3 (eqs. 1.1–1.16, 2.1–2.15, 3.1–3.10). Key additional equations: Hessian decomposition H_ij = Σ_k h_k ℓ^{(k)}_i ℓ^{(k)}_j with orthonormal eigenvectors (eq. 2.6); pseudo-inverse covariance Σ_ij = Σ_{k=2}^{t} ℓ^{(k)}_i ℓ^{(k)}_j/h_k (eq. 2.7); importance weights w_s ∝ f({λ_i^{(s)}}|D,I)/g({λ_i^{(s)}}|D,I) (eq. 2.11); win-ratio comparator model θ^{wr}_ij/θ^{wr}_ji = √[(v_i/(n_i−v_i))·((n_j−v_j)/v_j)] (eq. 3.4); posterior predictive for a game ∫₀¹ θ_CrQn f(θ_CrQn|D,I) dθ (eq. 3.6) and best-of-three ∫₀¹ [θ²+2(1−θ)θ²] f(θ|D,I) dθ (eq. 3.7).
Assumptions: BT win-probability law holds (no margin, no home advantage — the paper's θ has no home term); games independent given λ; ties split 0.5/0.5 despite no tie parameter; Gaussian approximation adequate near the MAP; for Haldane prior the additive-constant degeneracy must be pinned (Σ λ_i = 0).

## 5. Features / target
Inputs: game-result counts {n_ij, w_ij} (pre-tournament season results as training D). Target 1: posterior distribution over log-strengths {λ_i} (KRACH ratings = 100·e^{λ̂_i}). Target 2: posterior predictive probabilities for future outcomes O (single games, best-of-three series, tournament-selection outcomes). Derived product: Bayes factors comparing predictive models on realized tournament sequences.

## 6. Validation design
- No train/test split in the ML sense; the Bayes factor uses pre-tournament games as training and tournament games as evaluation (temporally clean: 17 tournaments 2003–2019, 15 games each = 255 games).
- Compared: MLE/KRACH BT, generalized-logistic-prior BT (η=1, Gaussian approx + 20,000 MC draws; four replications overlaid to show MC convergence), naïve win-ratio model (eq. 3.4), tossup baseline. Note: Gaussian importance sampling was deemed too unstable (four replications give "vastly different" estimates) to evaluate the small probability of one specific result sequence — an honest negative result.
- The RPI couldn't be compared because it doesn't generate predictive probabilities — a methodological point the paper flags.

## 7. Numerical results / baselines
- **2019 NCAA tournament (KRACH/MLE):** cumulative Bayes factor vs tossup ends slightly below 1 (Fig. 4) — the American International College upset of St. Cloud State was such a surprise to the model that it wiped out the gains from correct calls.
- **Cumulative 2003–2019 (Fig. 5):** BT/KRACH is clearly preferred over the win-ratio model, which is in turn better than tossup. 255 games are enough to separate BT from win-ratio, but NOT enough to distinguish the Haldane prior from the generalized logistic (η=1) prior, though their predictions were not always identical.
- **Cornell (KRACH 415.3) vs Quinnipiac (93.30), 2019-03-09 (Table 1, four replications of 20,000 draws):** single-game Cornell win probability — KRACH point estimate 81.7%; Gaussian approximation 80.0% (analytic integration 80.0; MC 80.0/80.1/80.0/79.9); importance sampling 81.5–81.8% (MC 81.8/81.7/81.4/81.5). Best-of-three series — KRACH 91.1%; Gaussian 88.2% (MC 88.2/88.3/88.1/88.0); importance sampling 89.5–89.9%. The paper's key lesson: for the series, the uncertainty correction is NOT a coincidence-level cancellation — 91.1% (point) vs 88.2% (uncertainty-aware) vs ~89.7% (IS) differ meaningfully, because uncertainty induces correlation across games (a loss revises λ_Cr − λ_Qn downward, raising the chance of another loss).
- Largest IS weights in the four replications: 0.00399, 0.00686, 0.00488, 0.00509 vs average weight 0.00005 (outliers exist but estimates stayed consistent, "slightly below 82%").

## 9. Leakage & limitations
- **External validity to NFL:** college hockey (60 teams, ~35 games each, heavy schedule imbalance, ties) differs from the NFL (32 teams, 17 games, balanced-ish schedules, no ties). The paper's own Hessian analysis relies on "late in a season with as many games as college hockey" for MLE existence and finite λ̂ — with 17 NFL games and early-season sparseness, point estimates are wobblier and the Gaussian approximation needs stronger priors.
- No home-field term — the paper acknowledges BT ignores "broader circumstances"; GSE's NFL needs home advantage explicitly.
- Importance sampling instability is a real negative: on a 59-parameter posterior, Gaussian-IS weight outliers make it unreliable for the small-probability sequences you actually want (e.g., specific playoff-bracket outcomes). The Gaussian approximation alone was the stable workhorse.
- The Bayes-factor comparison is thin: 255 tournament games separate BT from a strawman win-ratio model but can't distinguish priors — in NFL, distinguishing *your* engine from the market needs many more games or richer evaluation data (all regular-season games, not just playoffs).
- Ties handled by 0.5/0.5 fudge rather than a tie model (Davidson [5], Rao-Kupper [13] cited but not used).
- KRACH is MLE-only in production (the paper's Gaussian/IS upgrades were "not yet integrated" into the Pairwise Probability Matrix as of v2) — the demonstrated gains are for one example, not a production system.

## 10. GSE overlap
**Extension of covered territory.** The existing-research map shows Bradley-Terry, Elo/Glicko/TrueSkill, nfelounits, and the Sept-17 gse-lab ratings work are all in-repo, and Bayesian hierarchical work (Lopez/Baumer state-space 1701.05976) has been read. But nothing in the corpus: (a) gives closed-form posterior uncertainty for BT ratings (Hessian → covariance, pseudo-inverse handling of the additive-constant degeneracy); (b) runs a Bayes-factor-vs-tossup evaluation protocol over realized game sequences to compare probability models; (c) demonstrates the playoff-probability-simulation upgrade of drawing ratings from the posterior per Monte Carlo trial (GSE's playoff-picture content, if built, would otherwise use point-estimate draws and inherit the 91.1%-vs-88.2% style overconfidence). The engine-benchmark lane (benbbaldwin objective ratings etc.) compares point forecasts; this paper's protocol compares *distributions* over sequences — new capability. Not a duplicate.

## 11. GSE implementation spec
- **(A) Uncertainty-quantified team ratings.** Fit BT (or the engine's logistic team-strength head) on nflverse game results with a generalized-logistic or Gaussian prior (η=1 or σ tuned); compute MAP via Ford-type iteration; build the Hessian H_ij = −n_ij θ̃_ij θ̃_ji + δ_ij Σ_k θ̃_ik θ̃_ki + prior term; invert (pseudo-inverse, 32×32 — trivial) → covariance Σ. Serve per-game win probabilities as posterior-predictive (MC over the Gaussian, N=20,000 like the paper) instead of point estimates, and publish uncertainty bands on ratings. Home-field: add a λ_H home parameter (the paper's formulation has none — this is the required NFL adaptation). Effort: ~3 days, pure numpy/scipy.
- **(B) Bayes-factor model-evaluation protocol.** For every NFL season, take pre-playoff game results as training, playoff games as evaluation; compute B_engine,0 = ∏ 2θ_{winner,loser} for GSE's published probabilities and B_market,0 from de-vigged closing lines; track cumulative log-Bayes-factor across seasons. This gives a single number answering "is the engine's distribution better than the market's?" that the current log-loss/accuracy dashboards don't express as cleanly. Also usable weekly: train on weeks 1..k, evaluate on week k+1. Effort: ~2 days; slots into the existing verification workflow.
- **(C) Playoff-picture Monte Carlo upgrade.** When the season-simulation content lane is built (playoff odds per team), draw the team-strength vector from the Gaussian posterior each trial (paper §3.2.2 workflow) rather than simulating from one rating snapshot — avoids the documented overconfidence on correlated multi-game outcomes (e.g., "team wins division AND two playoff games").

## 12. Reproducible test
Dataset: nflverse regular-season + postseason game results, 2015–2025 seasons (ties: none in NFL — cleaner than hockey). Task: fit Bayesian BT with Gaussian prior (σ = 1.0) + home-field parameter on regular-season games; compute posterior-predictive win probabilities for postseason games via Gaussian-approximation MC (N=20,000). Metric: mean log-likelihood per postseason game. Baseline: point-estimate BT (MLE + home field, no uncertainty). Pass criterion (gate): posterior-predictive mean log-likelihood ≥ baseline + 0.02 nats/game on the 2015–2025 postseason pool (~130 games), i.e., uncertainty-awareness demonstrably improves calibration, not just vibes. Report per-season as well to check for the paper's "cancellation" phenomenon.

## 13. Acceptance / rejection gate
ADOPT (A) and (B) into the ratings/verification stack if the §12 test passes: posterior-predictive beats point-estimate BT by ≥0.02 nats/game on 2015–2025 NFL postseasons. ADOPT (C) for playoff simulation content if (A) passes, regardless — the correlation-across-games argument is theoretical and the cost is one extra sampling step per trial. REJECT all three if the test shows no gain or a loss; then this ledger stands as an evaluated-and-parked method with the Bayes-factor protocol still available for engine-vs-market reporting.

## 14. Improvement experiment
Replace the paper's static-season Bayesian BT with a dynamic version for NFL: λ_i(t) evolving week-to-week as a Gaussian random walk (state-space BT), estimated by extended Kalman filter/smoother, with the Hessian replaced by the smoother's posterior covariance at each week — combining the paper's uncertainty machinery with the time dynamics of Lopez/Baumer (1701.05976, already read). Test whether the dynamic posterior-predictive beats both the static posterior-predictive and a dynamic point-estimate on weekly NFL prediction (2015–2025, mean log-likelihood per game). Hypothesis: in-season team-strength drift (injuries, QB changes) makes the static posterior stale by December, and the random-walk variance term naturally widens uncertainty late in the season — the exact failure mode the paper's fixed-season model can't express.
