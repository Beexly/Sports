# [1474] Beep: Balancing Effectiveness and Efficiency when Finding Multivariate Patterns in Racket Sports (arXiv:2307.11780v2)

**Citation:** Jiang Wu, Dongyu Liu, Ziyang Guo, Yingcai Wu (2023). *Beep: Balancing Effectiveness and Efficiency when Finding Multivariate Patterns in Racket Sports*. arXiv:2307.11780v2. URL: https://arxiv.org/abs/2307.11780 (KDD 2023).
**Ledger completed:** 2026-09-21. **Read:** full text (PDF via arxiv.org/pdf, 6 pages + appendices A–D, all sections and tables read in full).
**Verdict:** ADAPT
**Verdict rationale:** MDL-based multivariate pattern mining with noise-tolerant encoding and LSH acceleration; adapt from table-tennis rally mining to unsupervised NFL opponent-tendency/tactic discovery on play-by-play sequences.

## 1. Research question
How can an analyst discover meaningful multivariate patterns (player/team tactics) in racket-sport event sequences — where each hit carries multiple correlated attributes (technique, ball placement, spin, position) — such that the mined patterns (a) preserve cross-attribute correlations, (b) tolerate single-value noise (one attribute changing to a similar value while the tactic is preserved), (c) are few enough for a human to inspect, and (d) are returned in minutes rather than hours? Prior univariate transforms destroy correlations; SPM methods return an unmanageable pattern explosion; MDL summarizers (Ditto) are slow and not noise-tolerant.

## 2. Dataset / schema
- **Table-tennis case-study dataset:** 716 sequences (rallies) collected from 10 matches played in 2019 by Mima Ito against Chinese players; average sequence length 5.91 events. Each hit = multivariate event with 4 categorical attributes: Tech (16 values: Pendulum serving, Reverse serving, Tomahawk serving, Topspin, Smash, Attack, Flick, Twist, Push, Slide, Touch short, Block, Lob, Chopping, Pimpled techniques, Other techniques); Ball (12 table-area values); Spin (7 values: Strong topspin, Normal topspin, Strong downspin, Normal downspin, No spin, Sink, Without touching); Player (6 position values). Proprietary labeling (analyst-annotated); schema documented in Appendix B, not publicly hosted.
- **Synthetic datasets (5):** multi-scale grids varying |S| ∈ {50, 70} sequences, |s_i| ∈ {20, 30} length, |A| ∈ {5, 7} attributes, |V_k| ∈ {100, 200} values/attribute. Each planted with 5 patterns (5 non-empty values each, random length, covering 10% of events); 10 single-value missing values planted total (2 occurrences × 1 value per pattern). Generated by authors, not public.

## 3. Method / model
MDL (minimum description length) pattern-set optimization, following Ditto's [2] framework with two novel components.
**Objective (Eq. 1):** minimize L(S|P) = L(P) + Σ_{s∈S} L(s|P), where L(P) is the description length of the pattern set and L(s|P) the description length of sequence s encoded with the pattern set (as a code table CT / code stream CS).
**Encoding features:** (1) empty values in a pattern match any value; (2) *missing values* (new) — a pattern event may skip a value in the sequence, interpreted as single-value noise; (3) gap events — pattern events may be non-consecutive in the sequence; (4) interleaving patterns may overlap in time. Per-pattern caps: empty values ≤ |p|; missing values ≤ ||p||/10 (at most 1 per event); gaps ≤ |p|−1.
**Search heuristic:** initialize P with all singleton patterns; each iteration, generate candidates by combining every pair of patterns in P at every alignment (conflicts resolved by treating the conflicted value as missing — Fig. 2); add candidates that reduce L(S|P); prune patterns whose removal reduces L(S|P); stop when P stabilizes.
**Acceleration:** pairs of patterns with low co-occurrence rarely form good candidates, so filter them with weighted LSH: for each pattern, record the set of sequence positions (segments of ≤ l=20 events) where it occurs; two patterns are combined only if their position sets have weighted Jaccard similarity above threshold th (Ioffe [6] weighted minhash).
**Covering algorithm (Appendix A):** greedy Krimp-style — traverse CT patterns in Cover Order (↓||p||, ↓support(p|S), ↑lexicographic), KMP search per pattern; unmatched values covered by singletons. Time complexity O(|P|·||s|| + ||P|| + ||s||) per sequence; total description-length computation O(|P|·||S|| + ||P||·|S| + ||S||). Implemented in C++; authors note covering is embarrassingly parallelizable / GPU-amenable.
**Code lengths (Appendix D, Shannon-entropy based):** pattern code L(code_p(p)) = −log2(usage(p)/Σ usage(p_i)); gap/fill/miss codes as their relative share of gaps+fills+misses, with miss codes carrying +L_N(|A|) extra bits for the missing-attribute index. Code table length L(P) = L(ST) + L(CT*) with universal-integer coding L_N(k) for integers.

## 4. Equations & assumptions
- Objective: minimize_P L(S|P), L(S|P) = L(P) + Σ_{s∈S} L(s|P). (Eq. 1)
- Code lengths: L(code_p(p)) = −log2( usage(p) / Σ_{p_i∈CT} usage(p_i) ); L(code_g(p)) = −log2(gaps(p)/(gaps(p)+fills(p)+misses(p))); L(code_f(p)) and L(code_m(p)) analogously; L(code_m(p)) adds L_N(|A|).
- L(ST) = Σ_k [ L_N(|V_k|) + log( C(|S_k|,|V_k|) ) ] (per-attribute singleton encoding); L(CT*) = L_N(|P*|) + L_N(usage(P*)) + log(|usage(P*)| multinomial over |P*|) + Σ_{p_i∈P*} L(p_i); L(p_i) = L_N(|p_i|) + L_N(||p_i||) + L_N(gaps(p_i)+1) + L_N(misses(p_i)+1) + Σ_{v∈p_i} L(code_p(v|ST)).
- Assumptions: categorical attributes only; sequence order matters, gaps/misses treated as noise to be encoded rather than evidence against a pattern; MDL two-part coding is a valid proxy for "meaningfulness" (validated only via the analyst case study); weighted Jaccard ≥ th approximates true co-occurrence; greedy covering order yields near-optimal covers.

## 5. Features / target
Unsupervised: input = multivariate event sequences (each event a vector of categorical attribute values). No target label. Output = pattern set P minimizing description length — each pattern a multivariate subsequence with empty values, missing values, and gap allowances. In the case study the patterns were presented to analysts as tactic summaries.

## 6. Validation design
- **Case study (effectiveness):** 2 table-tennis analysts (3+ years experience each) evaluated patterns mined by Beep vs Ditto on the 716-rally Ito dataset. Metrics: |P| (pattern count), avg. frequency per pattern, # missing values, runtime.
- **Quantitative (5 synthetic datasets):** metrics |P|, ΔL% (description-length reduction vs singleton-only model), miss count, runtime t(s). Comparators: Ditto, Beep, Beep-miss (miss codes only, no LSH), Beep-LSH (LSH only, no miss codes), Beep-none (neither). Ground truth: 5 planted patterns + 10 planted missing values per dataset — all algorithms recovered all 5 planted patterns (manual check); Beep-miss/Beep recovered all planted missing values.
- No predictive task, no train/test splits — this is unsupervised pattern mining; "validation" is analyst judgment + compression on synthetic ground truth.

## 7. Numerical results / baselines
- **Table 1 (table-tennis case study):** Ditto — |P|=161, avg.freq=4.36, t=1747 s. Beep — |P|=62, avg.freq=12.94, miss=280, t=425 s. (Beep ~4.1× faster, 2.6× fewer patterns, ~3× higher per-pattern frequency.) Abstract claims "about five times faster than the SOTA" (supported on synthetic; case study ratio is 1747/425 ≈ 4.11×).
- **Table 2 (synthetic), e.g. dataset row 1 (|S|=50, |s|=20, |A|=5, |V_k|=100):** Ditto |P|=19, ΔL%=24.5, t=399 s; Beep |P|=9, ΔL%=27.2, miss=33, t=79 s (~5.1× faster). Row 2 (|S|=70): Ditto t=987 s, ΔL%=19.0 vs Beep t=215 s, ΔL%=21.3 (~4.6×). Row 5 (|V_k|=200): Ditto t=175 s vs Beep t=18 s (~9.7×). Across rows Beep consistently gives higher ΔL% with lower t than Ditto; Beep-LSH vs Beep-none comparisons show LSH alone cuts runtime ~10× (e.g. 1276→120 s row 3) at small ΔL% cost; miss codes reduce |P| and raise ΔL%.
- Analyst anecdote (Fig. 4): Beep pattern p covered two sequences despite single-value deviations; analysts confirmed one deviation was a data-recording error — i.e., miss codes surfaced a labeling error.

## 9. Leakage & limitations
Adversarial notes: (1) Unsupervised mining — no lookahead issue, but patterns are only as good as the encoding; analyst case study is n=2 analysts, subjective, no blinded A/B protocol. (2) Synthetic evaluation is favorable-by-construction: planted patterns exactly match the model's generative assumptions; ΔL% comparisons vs Ditto are fair but the ablation (not independent replication) comes from the authors. (3) Sequences are short (avg 5.91 events); complexity O(|P|·||S|| + ...) may blow up on long football drives/seasons — LSH helps but no scaling experiment beyond |S|=70. (4) MDL minimization can merge distinct tactics that happen to co-occur (the miss/empty machinery biases toward fewer, broader patterns — avg freq 12.94 vs Ditto 4.36 may hide genuinely distinct sub-tactics). (5) No predictive validation: patterns are never tested for predicting future outcomes. External validity to NFL: events are hits-in-rally; NFL plays are richer (continuous features like yardage, clock) and require discretization, which the paper doesn't address — categorical-only assumption is a real adaptation cost.

Metrics: (a) ΔL% (compression) on the held-out season's drives vs a singleton-only code table; (b) pattern-set size |P|; (c) runtime per team-season. ## 13. Acceptance / rejection gate
ADAPT-accept iff on the 2025 held-out drives Beep achieves ΔL% ≥ 15% vs singleton baseline AND |P| ≤ 60 patterns per team-season (analyst-manageable) with runtime ≤ 30 min per team-season on GSE hardware; otherwise reject the adaptation (pattern sets that are huge or uncompressed add analyst burden without value).

## 14. Improvement experiment
Supervised-MDL variant: score candidate patterns not only by description-length reduction but by outcome association — add a penalty/bonus term λ·|E[EPA | pattern present] − E[EPA]| to candidate acceptance, so mined "tactics" are discriminative of play success, not just frequent. This would turn unsupervised tendency mining into a weakly-supervised edge detector directly usable in matchup modeling; test whether the supervised set predicts held-out drive EPA better than the pure-MDL set at equal |P|.
