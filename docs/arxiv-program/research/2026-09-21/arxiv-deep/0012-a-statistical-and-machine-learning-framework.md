# [0012] A Statistical and Machine Learning Framework for Quantifying Offensive Impact in Professional Box Lacrosse (arXiv:2609.06610)

**Citation:** Robert Jimerson Jr (2026). *A Statistical and Machine Learning Framework for Quantifying Offensive Impact in Professional Box Lacrosse*. arXiv:2609.06610. URL: https://arxiv.org/abs/2609.06610
**Ledger completed:** 2026-09-21. **Read:** full text (arXiv HTML v1), all 11 sections + Data/Code Availability statements + Appendices A (feature dictionary), B (experiment settings, software environment), C (complete 25-player attribution roster).
**Verdict:** REJECT — methodologically transparent and admirably honest about its own null results, but a single-team 13-game case study whose best xG model beats a constant base-rate predictor by only ~1%, with proprietary data/code that cannot be replicated and no transfer path to any GSE lane.

## 1. Research question
Three RQs (§1.3): (RQ1) which of nine statistical/ML specifications produces the lowest held-out probability error for NLL games excluded from training; (RQ2) whether two-man-action role and qualifying pick-type fields improve held-out probability quality beyond a contextual baseline; (RQ3) how shot-level xG estimates can be extended to attribute recorded offensive value to shooters, final passers, and qualifying pickers for player/game analysis.

## 2. Dataset / schema
Custom frozen dataset from manual video annotation of 13 consecutive Rochester Knighthawks regular-season games (Jan 3 – Apr 4, 2026; excludes first two games Dec 14/20 2025 and final three Apr 11/18/19 2026), via the Shot-Plotter application on NLL+ broadcast replays. 1,006 shot attempts: 151 goals, 587 saved, 203 missed, 65 blocked; observed goal rate 15.01%. Final passer recorded for 881 attempts; 225 qualifying directly shot-producing picks (210 on-ball, 15 off-ball). Schema: 10 numeric + 7 categorical baseline fields per attempt (Appendix A lists every stored field), plus two nested extension fields (two-man-action role, qualifying pick type). Mean shot distance 21.18 ft, max 78.81 ft. Access: proprietary — "not publicly available... retained for potential proprietary research"; only the schema (Appendix A) is published. Single team, single season: a case study, not a league sample.

## 3. Method / model
xG_i = Pr(y_i = 1 | x_i) via three fixed classifiers × three nested feature sets: (a) logistic regression (C=1.0, 3,000-iteration limit, no class weighting), (b) random forest (500 trees, min leaf size 5, max_features=sqrt, no class weighting), (c) extremely randomized trees (same settings); seed 20251214 throughout. Feature sets: contextual baseline (10 numeric + 7 categorical: quarter, time remaining, shot-clock seconds, shot-clock-disabled indicator, passer-present indicator, normalized X/Y, distance, angle, behind-goal indicator; strength state, offense type, swing state, shot type, off-pass state, score differential, pulled-goalie state); baseline + two-man-action role; baseline + two-man-action role + qualifying pick type. Preprocessing within each training fold: median-impute + standardize numerics, most-frequent-impute + one-hot-encode categoricals (unseen held-out levels ignored). Attribution: OI_p = xG_p + xA_p (core), exploratory OI^expl_p = OI_p + xPV_p; FAE_p = G_p − xG_p kept separate. xPV_i = p̂_i^obs − p̂_i^{no-pick} (counterfactual with pick fields set to no-pick values, location held fixed).

## 4. Equations & assumptions
Distance (Eq. 1): d_i = √((85 − x_i)² + y_i²); angle (Eq. 2): θ_i = atan2(|y_i|, 85 − x_i)·180/π, goal at (85,0) after normalization. Target (Eq. 3): y_i = 1 if goal, 0 if saved/missed/blocked. xG (Eq. 4): xG_i = Pr(y_i=1|x_i). LOGO split (Eq. 5): D_train^(i) = ∪_{j≠i} D_{g_j}, D_test^(i) = D_{g_i}, 13 folds. LogLoss (Eq. 6): −(1/N)Σ[y_i log p_i + (1−y_i) log(1−p_i)]. Brier (Eq. 7): (1/N)Σ(p_i − y_i)². ECE (Eq. 8): Σ_b (n_b/N)|ȳ_b − p̄_b|, 10 equal-width bins. xG_p = Σ_{i∈S_p} xG_i (Eq. 9); xḠ_p = xG_p/N_p (Eq. 10); xGShare_p = xG_p/Σ_q xG_q (Eq. 11); FAE_p = G_p − xG_p (Eq. 12); FAEPerShot_p = (G_p − xG_p)/N_p (Eq. 13); FI_p = G_p/xG_p (Eq. 14); FAE_team = G_team − xG_team (Eq. 15); xA_p = Σ_{i∈A_p} xG_i (Eq. 16); xĀ_p = xA_p/N_p^SA (Eq. 17); xA_{p→q} = Σ_{i∈A_{p→q}} xG_i (Eq. 18); ShootingPercentage_p = G_p/N_p (Eq. 19); FAEPerShot_p = ShootingPercentage_p − xḠ_p (Eq. 20); OI_p = xG_p + xA_p (Eq. 21); OI^expl_p = OI_p + xPV_p (Eq. 22); xPV_i = p̂_i^obs − p̂_i^{no-pick} (Eq. 23); xPV_p^on = Σ xPV_i, xPV_p^off = Σ xPV_i, xPV_p = sum (Eqs. 24–26); OI_{p,g} = Σ_{S_{p,g}} xG_i + Σ_{A_{p,g}} xG_i (Eq. 27); N_g decomposition and OnTargetRate_g, xG_g, FAE_g (Eq. 28). Assumptions (mostly implicit): shots conditionally independent given features within game-fold structure; LOGO folds isolate game-level dependence; missingness handled by fold-level imputation (author flags visibility-related missingness "may not be random" as a limitation); xPV explicitly "not a causal treatment effect."

## 5. Features / target
Inputs (Table 3): 10 numeric baseline (quarter, time remaining, shot-clock seconds, shot-clock-disabled indicator, passer-present indicator, normalized X, Y, distance, angle, behind-goal indicator) + 7 categorical (strength state, offense type, swing state, shot type, off-pass state, score differential, pulled-goalie state); extensions add two-man-action role (ball carrier/picker/not two-man) and qualifying pick type (on-ball/off-ball/no qualifying pick). Shooter/passer/picker identities excluded from all model inputs. Target: binary goal indicator y_i (Eq. 3); prediction horizon is per-shot probability (no forward horizon).

## 6. Validation design
Leave-One-Game-Out CV (13 folds; §5.4): each game held out once, all imputation/encoding/fitting restricted to the other 12 games; out-of-fold probabilities concatenated for all 1,006 shots. Primary metric: pooled log loss; tie-breakers Brier and 10-bin ECE; supporting ROC AUC and average precision. Base-rate benchmark: constant predictor assigning each held-out shot its training-fold goal rate (same LOGO partition; pooled log loss 0.4241, Brier 0.1279). Critical caveat (author's own, §5.4/§6.2): the same CV predictions were used for both comparison and model selection — descriptive, not an independent post-selection assessment.

## 7. Numerical results / baselines
Table 4 (out-of-fold, pooled): baseline RF — log loss 0.4189 (ΔLL +1.22%), Brier 0.1260, ROC AUC 0.604, AP 0.214, ECE 0.026; +two-man RF — 0.4195 (+1.07%), 0.1261, 0.603, 0.215, 0.019; +pick-type RF — 0.4197 (+1.03%), 0.1260, 0.604, 0.216, 0.019; baseline ExtraTrees — 0.4219 (+0.51%), 0.1268, 0.569, 0.207, 0.030; +two-man ExtraTrees — 0.4256 (−0.37%), 0.1277, 0.557, 0.195, 0.027; +pick-type ExtraTrees — 0.4269 (−0.66%), 0.1276, 0.553, 0.204, 0.035; baseline LR — 0.4311 (−1.65%), 0.1299, 0.582, 0.205, 0.050; +pick-type LR — 0.4315 (−1.76%), 0.1299, 0.584, 0.211, 0.049; +two-man LR — 0.4328 (−2.07%), 0.1303, 0.579, 0.203, 0.050; base-rate benchmark — 0.4241, 0.1279. Four of nine specs beat the benchmark; five did not. Game-level baseline-RF log loss ranged 0.295–0.597 across the 13 held-out games (unweighted mean 0.421055, SD 0.086494; §B.2) — variation dwarfs the aggregate spec differences. Individual xG values spanned 0.028–0.470 (median 0.139); player xG/shot compressed to 0.130–0.166. xPV diagnostics (Table 5, §6.4): mean |xPV| observed 0.0222 vs null mean 0.0236, null 95% interval [0.0181, 0.0306], 74/200 replicates below observed; fraction positive observed 0.822 vs null 0.551 [0.391, 0.707], 0/200 at or above observed (max replicate 76.9%); placebo on 781 no-pick shots: mean absolute contrast 0.0176 (vs 0.0222 genuine), 76.6% positive. Player xPV totals correlated with raw pick count at Spearman ρ = 0.98. Coordinate perturbation: ±1 ft noise → mean |ΔxG| 0.0116; ±3 ft → 0.0227 (xG SD 0.0717). Attribution leaders (Table 6): Lanchbury (No. 7) OI^expl 64.32 (xA 45.27); Fields (No. 10) 60.30 (xG 32.56, 233 shots); Smith (No. 43) 44.34; McConvey (No. 12) 38.64 (xPV 1.16, largest but "should not be interpreted as evidence" of better picks).

## 8. Code / data availability
Both explicitly withheld: "The manually annotated event data are not publicly available... retained for potential proprietary research"; "The analysis code is not publicly released... retained for potential proprietary use." Schema and settings documented (Appendices A–B); software environment Python 3.12.13, scikit-learn 1.7.2, seed 20251214. Author states the paper contributes "a documented methodology rather than an open dataset or a directly replicable numerical analysis."

## 9. Leakage & limitations
Model selection on the same CV used for comparison (author-flagged; descriptive not confirmatory). Single-team, 13-game sample: LOGO measures generalization to unseen games of the same team, not to other teams/seasons. Manual broadcast-video annotation: no inter-rater reliability assessed; coordinate error of a few feet moves xG appreciably (0.0116–0.0227 mean |Δ|). Missingness imputation assumes ignorability the author doubts. xPV magnitude indistinguishable from noise; direction diagnostic has only 200 replicates and breaks game composition (author's own caveats). Picker identity never a feature, so xPV is context-determined (ρ=0.98 with pick count). No defensive pressure, goalie positioning, shot velocity, tracking data. No uncertainty intervals on player metrics (author notes 13 clusters too few). External validity to NFL: none — different sport, no transfer attempted.

## 10. GSE overlap
No overlap and no duplication. Lacrosse is outside every GSE lane; the existing-research map's non-NFL list (gap 11) names golf/MMA/NHL/MLB — box lacrosse has no GSE product surface. The honest negative result (rich contextual annotation ≈ +1% over base rate at n=1,006) is a cautionary analogue for any future NFL charting/annotation effort, but GSE's xG-adjacent work (EPA, CPOE, xFP) is computed from nflverse-scale data, not manual annotation. Nothing to dedup.

## 11. GSE implementation spec
No build recommended (REJECT). If the methodology were ever borrowed: the transferable piece is the LOGO-CV + base-rate-benchmark + permutation-diagnostic discipline for evaluating manually charted features (e.g., FTN charting fields) — i.e., require any new charted feature to beat a constant benchmark on game-held-out log loss before entering the engine, and run placebo/permutation diagnostics on counterfactual attributions. Effort if pursued: 1 day to add a base-rate benchmark and LOGO evaluation to the existing charting-feature pipeline.

## 12. Reproducible test
Not runnable: data and code are proprietary. The closest GSE analogue test: take any candidate set of manually charted NFL features (e.g., FTN charting), fit the engine's probability model under Leave-One-Game-Out CV, and require ≥2% pooled log-loss improvement over a base-rate benchmark before the features ship — the paper's own gate, applied to football.

## 13. Acceptance / rejection gate
REJECT already decided: the paper's best model clears only +1.22% log loss / +1.50% Brier over a constant predictor, five of nine specs fail to beat the constant at all, and neither data nor code is available for verification. No GSE build proceeds from this paper.

## 14. Improvement experiment
The experiment the author didn't run but should have: a nested LOGO design (inner loop for the RF-vs-ExtraTrees-vs-LR selection, outer loop for the reported estimate) once the sample reaches ~40+ games, plus game-block-preserving permutations with ≥2,000 replicates for xPV — this would convert the descriptive comparison into an honest post-selection estimate. For GSE's purposes, the better follow-up is the analogue test in §12 on NFL charting data, which directly prices whether manual annotation is worth its cost.
