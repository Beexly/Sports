# Repo Oracle

Galaxy Dynasty uses external repositories as engineering mentors, not as asset or code sources.

## Loop

1. Classify the implementation problem.
2. Select the repo mentor.
3. Inspect docs, examples, or source.
4. Extract the pattern.
5. Implement a Galaxy-native version.
6. Add tests.
7. Record the trace in `docs/game/REPO_TO_FEATURE_TRACE.md`.

## Mentor Map

- Babylon.js: browser 3D engine lifecycle, scene shell, materials, lighting, and spatial instruments.
- Phaser: fast browser minigame loop for Blacktop.
- Colyseus: authoritative small-room presence and state sync.
- GDevelop and RPG-JS: event/quest DSL shape.
- Kaetram and Biomes: browser MMO presence, ghost population, and persistent account boundaries.
- tinyrenderer: camera/light fundamentals.
- 3d-game-shaders-for-beginners: glow, fog, depth, and visual polish vocabulary.
- Magnum: scene/asset/input modularity.
- GlPortal: room gates and portal continuity.

No external assets were copied. No external source was copied. The implementation uses package APIs and Galaxy-native code.
