# AWS re/Start Application Boundary

The re/Start career track is personal learning and application work first. The repo can reference it only through public-safe summaries after owner approval.

Allowed:
- course or track name.
- public program link.
- public-safe learning summary.
- repo impact statement.
- owner-approved badge or certificate proof.

Not allowed:
- application forms.
- private application status.
- personal essays submitted to a program.
- recruiter or staff contact details.
- personal email unless explicitly approved.
- payment, identity, eligibility, or demographic information.
- AWS account identifiers or credential material.

Repo-safe value:
- strengthens public narrative around cloud operations discipline.
- improves vocabulary for cost, IAM, monitoring, and operational runbooks.
- helps explain why GSE/FABLE uses no-cost mocks before live AWS actions.
- supports a portfolio story without exposing personal records.

Publication rule:
- Do not add re/Start proof to the repo until the owner approves the exact artifact.
- If a screenshot is used, redact all personal data before commit.
- Keep any unapproved proof outside the repo.
