# Partner Target List Template

Updated: 2026-07-04

Use this schema for a local spreadsheet, GitHub issue, or future internal tool. Do not store secrets here.

| Field | Description |
| --- | --- |
| partner_id | stable internal id |
| display_name | public-facing name |
| category | revenue partner category |
| website | public homepage |
| contact_channel | email, form, LinkedIn, or other |
| fit_reason | why the partner fits GSE |
| risk_notes | source, disclosure, regulated-offer, or brand risks |
| recommended_motion | affiliate, sponsor, content_collab, api_beta, local_sponsor, reject |
| outreach_status | research, qualified, outreach_ready, contacted, review, approved, rejected |
| owner_notes | manual notes |

No private credentials, API keys, or personal sensitive data should be stored in this template.
