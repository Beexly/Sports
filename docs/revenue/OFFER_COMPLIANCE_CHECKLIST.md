# Offer Compliance Checklist

Updated: 2026-07-04

Before any offer appears publicly:

- partner exists
- partner approval is approved
- partner approval is not expired
- offer approval is approved
- offer is not expired
- partner and offer both allow the target surface
- terms URL exists for high-risk offers
- disclosure exists
- responsible-gaming text exists for high-risk offers
- minimum age is 21 or higher for high-risk offers
- user state is known for high-risk offers
- user state is eligible
- user state is not restricted
- copy scan passes
- manual review is complete

Code surface:

- `apps/web/lib/revenue/offer-eligibility.ts`
- `apps/web/lib/revenue/banned-copy.ts`
