# 02 — Decision Log

One note per owner decision, named `YYYY-MM-DD-short-slug.md`, from `TEMPLATE.md`.

## Protocol

- A decision note is written BEFORE the action is taken (the action queue requires it for HIGH/CRITICAL risk).
- Once status is APPROVED or REJECTED, the note is immutable — append corrections as new notes that link back.
- Every decision records: context, options considered, the call, the reversal plan.
- Link from the daily note with `[[02-decisions/...]]`.
