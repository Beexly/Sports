# 00 — Inbox

Capture-first folder. Anything that does not yet have a home lands here:
raw observations, half-formed ideas, pasted context, TODO fragments.

## Protocol

1. Capture fast — a title and one summary line is enough.
2. Every note still gets frontmatter (`created`, `tags`, `source`).
3. Triage on the next daily pass: move to `01-daily` … `08-audit`, or delete.
4. Inbox notes older than 7 days without triage are flagged in the daily note.
5. No secrets, ever — even in quick captures.
