# 04 — Agent Notes Index

Per-agent working notes. The roster source of truth is
`apps/web/lib/jarvis/agent-council.ts` (15 council seats; 6 registered
cockpit agents, all DRAFT_ONLY/MANUAL/NOT_WIRED — never autonomous).

## Convention

- One file per seat: `JARVIS.md`, `SCOUT.md`, `TAL.md`, `SARAH.md`, `AVA.md`,
  `BOBBY.md`, plus designed seats (`LEDGER.md`, `AUDIT.md`, `METER.md`, ...).
- Each file holds: current charter pointer, open handoffs, recent scribe
  entries authored by that seat, and known limitations.
- Agents write through the Scribe protocol; notes here are the rendered output.
- No agent note may claim autonomy, external actions, or wiring that does not exist.
