# 01 — Daily Notes

One note per operating day, named `YYYY-MM-DD.md`, created from `TEMPLATE.md`.

## Protocol

- The daily note is the owner's cockpit on paper: state, decisions, blockers, next actions.
- Agents append HANDOFF and RESULT scribe entries under "Agent activity".
- Decisions made today get a one-line pointer here plus a full note in `02-decisions/`.
- End-of-day: unresolved items roll forward to tomorrow's note or `00-inbox/`.
