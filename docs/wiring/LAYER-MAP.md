# THE 26-LAYER CONTEXT & REASONING STACK MAP (`docs/wiring/LAYER-MAP.md`)

Every game context packet (`data/context_packets/<game_id>.json`) is assembled by executing all 26 layers in strict sequence (`L01`..`L26`), validated at runtime against `schemas/v1/layer_output.schema.json` and `schemas/v1/context_packet.schema.json`.

- **Python Executor:** `intelligence/reasoning/layers/layer_registry.py` (`execute_all_26_layers`, `build_context_packet`)
- **TypeScript Bridge:** `packages/prediction-engine/src/layers/layer-registry.ts` (`ALL_26_LAYER_IDS`, `loadContextPacketSync`)
- **Consumption & Perturbation Test:** `tests/wiring/test_wave_consumption_proofs.py` (`test_wave7_26_layer_stack_and_context_packet`)
