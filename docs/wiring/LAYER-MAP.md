## Mandatory Architectural Guardrails
1. **Pre-Game Temporal Leakage Guard:** Every context packet enforces `as_of_utc < kickoff_utc` at runtime. Any packet with `as_of_utc >= kickoff_utc` raises `SchemaValidationError`.
2. **Dependency Order (`OL -> scheme -> QB`):** Layer 05 / Layer 08 / Layer 09 (`offensive_line`) execute and feed into Layer 10 / Layer 11 / Layer 12 (`coaching_scheme`), which feed into Layer 07 / Layer 13 / Layer 14 (`qb_behavior`), before Layer 15 / Layer 16 (`scheme_matchup`) and Layer 01 / Layer 20 / Layer 21 (`trust_signals`).
3. **Market Enters LAST (Layer 23):** Domain and structural valuation layers (`01..22`) complete before `layer_23_market.py` applies Shin de-vigging, line-move velocity across key numbers `3` and `7`, and SGP copula hold checks.
4. **GSI Cross-Domain & Coaching Manual Integration:** Layers `10`, `11`, `14`, `15`, `16`, `19`, and `24` directly import and consume `intelligence/coaching/core_nfl_schemes_and_systems.py` (8 offensive schemes, 11 route concepts, `2-Jet`/`3-Jet` `"One You, Two Me"` pass protection, `Cover 1 Plug`/`Cover 2`/`Cover 3 Buzz`/`Cover 4 Quarters MOD/PUSH`, Gruden `S-Words` & `T-Words`, Sinkhorn machine-floor residual `1.387779e-16`, and GSI CTE 878-player / Dynamic Kickoff `-43.0%` concussion hazard priors).
