# TEST 24 full-file spot-check — caveat (Motif, 2026-11-07)

The evaluate_all test in tests/test_week9_forensic_autopsy_fixes.py spot-checks every 61st catalog entry (~202 samples) asserting v1 != v2 on two flat game states differing only in off_epa/def_epa/pressure_rate/proe_pct. Replicated by Motif: 177 distinct / 25 identical / 0 errors — the test as written passes on its samples. Run across ALL 12,304 entries: **1,776 (14.4%) return identical values** on those two states. Explanation, verified: those entries bind only to environment/market keys (wind/temp/precip 423, rest/OL-outs 423, spread/market/total 414, altitude/wind/total 381 = 1,641) plus 135 cases whose kernels are saturated or exactly linear in the differing inputs (per-operator identical counts: bellman_advantage 391, copula_tail 279, python_callable 279, rational_pade 279, bilinear_interaction 274, sheaf_laplacian 274; linear_logit, exponential_survival and conformal_quantile kernels show 0 identical) — none of the four flat inputs touches them, so identical outputs are mathematically necessary, not a defect. TEST 24 itself asserts on router aggregates (deltas and masks differ) and is unaffected. Recorded so no later reader cites the ~202-sample spot-check as catalog-wide proof of state sensitivity.
