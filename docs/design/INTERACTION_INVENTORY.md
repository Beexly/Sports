# Interaction Inventory

> Phase 0. The owner's #1 directive: **no read-only website**. For every primary surface, what is read-only today, what becomes interactive, the primary + next action, what data should move, and which decision it improves. This drives the Phase 10 no-read-only sweep — any surface that ends as cards + paragraphs only is a failure.

## Legend
- **Primary action** = the one thing the user is here to do.
- **Next action** = where we route them after.
- **Data moves** = what animates / updates to convey live intelligence.
