# Competitor Intelligence Matrix

Updated: 2026-07-04

This matrix is for positioning, not unsupported claims.

| Competitor type | Common weakness | GSE response | Proof required |
| --- | --- | --- | --- |
| Tout pick sellers | confidence theater | no-bet discipline and loss autopsy | published methodology and settled evidence |
| Generic sports blogs | shallow analysis | source reliability and model accountability | cited sources and clear caveats |

## Rule

Do not say GSE is better than a named competitor unless the repo contains measured evidence for that exact comparison.
