# 90 Day Commercialization Plan

Updated: 2026-07-04

Status: execution plan only. No live outreach automation, affiliate links, provider integrations, or sponsor claims are created here.

## Days 1-30

- Use `/media-kit` and `/partners` as the public-safe explanation layer.
- Build the manual partner target list.
- Send up to 10 human-reviewed outreach messages per day.
- Keep all offers in review-only state until terms, disclosure, and risk checks pass.
- Use `apps/web/lib/revenue/*` to evaluate partner and offer readiness.

Success means:

- partner list is structured
- no unsafe copy ships
- at least one low-risk local or tool sponsor conversation is logged

## Days 31-60

- Convert repeated outreach patterns into templates.
- Draft first sponsor placement examples with no live links.
- Build partner tracker UI only after the pure seam holds.
- Prepare a newsletter provider decision packet.

Success means:

- outreach has a weekly review rhythm
- sponsor package boundaries are understood
- high-risk offers remain gated

## Days 61-90

- Decide whether to build API v1 shadow seam or content production queue first.
- Add route/UI only where pure logic is tested.
- Prepare data-room and licensing readiness checklists.

Success means:

- commercial assets are reusable
- revenue claims remain evidence-bound
- no false readiness appears in public copy
