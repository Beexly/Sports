# GSE Business Model Map

Updated: 2026-07-04

| Model | Near-term role | Evidence required before public claim | Current implementation |
| --- | --- | --- | --- |
| Subscriptions | core product revenue | server-side entitlement and proof-gated performance policy | existing pricing/entitlement surfaces |
| Media sponsorship | credibility and cash-flow lane | sponsor package, disclosure, no audience inflation | media pages and revenue core |
| Affiliate/tool reviews | workflow monetization | disclosure, honest review, approved offer metadata | revenue core, no live links |
| Newsletter | owned audience | provider, consent, unsubscribe, privacy review | coming-soon page only |
| B2B Evidence API | medium-term revenue | auth, scopes, quota, payload rights, OpenAPI | future shadow seam |
| Data room/licensing | long-term moat | source-rights envelopes, metric validation, drift cards | metric and FABLE docs |

## Non-goals

- GSE is not selling raw odds.
- GSE is not selling raw NGS.
- GSE is not selling unreviewed gambling offers.
- GSE is not promising betting outcomes.
