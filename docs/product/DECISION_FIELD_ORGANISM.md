# Decision Field Organism

*The connective runtime that turns GSE's tested engine + mesh organs into one running, bounded,
self-auditing decision cycle. This doc is honest about what is real, what is fixture-only, and what is
blocked.*

## What it is

Four new workspace packages compose the organism. Each cycle runs:

```
TemporalFact[] → point-in-time filter → source race → field stress → change detection →
source conflict → data leverage → required-stat audit → permission gradient → prosecution →
claim-bounded card → proof drawer → propose-only autonomy plan → autopsy hook →
ghost/law/theory update → Intelligence Ledger → missed/over observation
```

| Package | Role | Status |
|---|---|---|
| `@sports/decision-field-runtime` | the heartbeat — runs the whole cycle on a fixture | **real, fixture-only** |
| `@sports/decision-factory` | compiler trace + Product Intelligence Loop (scar memory) + regime profile + Intelligence Ledger | **real, fixture-only** |
| `@sports/nfl-stat-universe` | the hunger system — stat ontology, source paths, legal policy | **real manifest, no ingestion** |
| `@sports/autonomy` | the nervous system — propose-only operating cycle | **real, propose-only** |

## What is real

- The full cycle runs end to end on the **Field 001** fixture (`runDecisionFieldFrame`) and produces a
  proven, claim-bounded **WATCH** card — not an ADD — with a Why-not, a source race, a proof drawer, a
  propose-only plan, and a Conscience snapshot.
- Every step calls a **tested** function in `@sports/engine` or `@sports/data-intelligence` (no forks):
  `knowableAt`/`pointInTimeFacts`, `classifyConflict`, `computeDataLeverage`, `classifyRegime`,
  `assessAgainstGhosts`, `assessTradability`, `roleVsProduction`, `checkOpportunityConservation`,
  `fantasyAutopsy`, `evolveTheory`, `benjaminiHochberg`, `studentTTwoSidedP`.
- The closed loop is proven: a settled trap becomes a ghost that **suppresses its twin** next cycle.
- The Conscience is proven to **not p-hack itself** (BH-FDR + per-cycle t-test on deltas).

## What is fixture-only (NOT live)

- All inputs are deterministic fixtures. **No network, no keys, no ingestion, no clock.** The packages
  import no live data and touch no live gate.
- The "cards" are illustrative — they are never published, priced, or shown as live. Surfacing them in
  the product (Phase 2) and feeding one real NFL week (Phase 3) are **not built** and are owner-gated.

## What is blocked / owner-gated

- Publish, spend, roster-write, gate-flip are **un-constructible as executed** inside `@sports/autonomy`
  (the discovery-engine literal-type pattern, generalized). They can only be *proposed*.
- The NFL stat universe is a **manifest + policy + planner** — it acquires nothing. Provider portfolios
  are plans; spending requires a `--plan` cost preview and owner approval.

## What the tests prove

`npx vitest run packages/decision-field-runtime packages/decision-factory packages/nfl-stat-universe packages/autonomy`
→ 45 tests: heartbeat (14), compiler+loop+regime (9), Conscience FDR (3), stat universe A–J (13),
autonomy K–P (6). Upstream engine/mesh/prediction-engine suites unaffected.

## What must NOT be claimed publicly

- That GSE ingests live NFL data (it does not yet).
- That any card is a real, settled pick (they are fixtures).
- Any certainty language. The copy guard bans "guaranteed", "lock", "sure thing", "risk-free".
