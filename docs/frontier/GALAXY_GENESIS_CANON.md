# Galaxy Genesis — Canonical Architecture

Status: accepted frontier R&D doctrine. Improve, do not remove.

## North star

Galaxy Sports Edge is the public doorway into a living sports-science civilization that can observe reality, preserve competing truths, discover missing knowledge, acquire or invent capabilities, simulate alternate worlds, prove what it did, and convert validated discoveries into permanent product instruments.

This is not a mandate to build everything at once. It is the architecture that prevents local work from creating dead ends.

## The organism

Galaxy Genesis unifies the following existing and planned systems:

- Software Genome: GitHub, packages, SDKs, APIs, cloud templates, code agents.
- Neural Genome: Hugging Face models, datasets, adapters, Spaces, evaluations, inference and experiment infrastructure.
- Research Cortex: papers, patents, standards, replications, disputes, negative results and cross-domain science.
- Reality Kernel: SportsIR, bitemporal evidence, source lineage, branching reality and replay.
- Red Queen Laboratory: competing hypotheses, experiments, adversarial evaluators, replications and evolving benchmarks.
- Model Ecology: model genomes, shadow evaluation, regime routing, model chemistry and failure ancestry.
- World Foundry: observed, epistemic, intervention, adversarial and synthetic worlds, including Dynasty Studio.
- Capability Genome: a universal representation for models, datasets, papers, algorithms, APIs, agents, simulations, tools, interfaces and hardware runtimes.
- Proof Fabric: reproducible receipts tying data, code, model, time cutoff, world branch, computation and output together.
- Agent Civilization: agents separated by role, capability and authority; no intelligence level implies permission.
- Edge Swarm: browser, mobile, desktop, server, confidential enclave and local-device execution selected by privacy, latency, cost and rights.
- Private Intelligence Federation: computation travels to protected data; raw data need not be centralized.
- Interface Compiler: Intelligence Contracts compile into approved, accessible, entitlement-aware Galaxy components.
- Science-to-Product Compiler: validated research becomes schemas, APIs, evaluations, receipts, UX states, Academy lessons and coding workstreams.
- Galaxy Commons: selected rights-clean benchmarks, schemas, papers, Spaces and evaluation tools are published while proprietary intelligence remains private.

## Model-derived knowledge classes

Do not collapse all AI output into one category.

- Source Observation: direct observation from an authorized source or sensor.
- Model-Derived Measurement: calibrated interpretation linked to an underlying observation.
- Model Transformation: embedding, translation, denoising, transcription, diarization or normalization.
- Model Forecast: prediction about unresolved future state.
- Synthetic Output: generated prose, media, scenario or simulation.

Models never become independent evidence sources merely because they are accurate.

## Causal Constitution

Machine-enforced invariants:

- No future information in historical decisions.
- No causal claim without a causal model, assumptions and refutation suite.
- No model output promoted to source truth.
- No duplicated evidence counted as independent.
- No hidden change to settlement, evaluation or public-performance populations.
- No benchmark chosen after seeing the answer.
- No model promoted on one favorable window.
- No rights classification silently weakened.
- No private data used beyond declared purpose.
- No public metric without a reproducible definition.
- No generated interface bypassing entitlement, accessibility or evidence projection.
- No agent may rewrite its evaluator and declare itself improved.

These rules compile into types, tests, database constraints, promotion gates, agent permissions and Reality Receipt requirements.

Research is a branching evolutionary tree. Winning, failed and abandoned hypotheses are preserved. Evaluators evolve from production failures, adversarial worlds, temporal leakage attempts, source conflicts and user misunderstandings.

A discovery is not accepted until it survives independent windows, baselines, refutation, temporal integrity checks, rights review and product-value analysis.

## Galaxy Multiverse and World Foundry

World classes:

- Observed World: what occurred and what Galaxy knew.
- Epistemic Worlds: coherent interpretations of unresolved facts.
- Intervention Worlds: controlled changes to one or more variables.
- Adversarial Worlds: scenarios designed to expose shortcuts.
- Human Decision Worlds: alternative information order and user behavior.
- Synthetic Worlds: Dynasty Studio or external simulations.

Every synthetic experiment records assumptions, seed, intervention, mechanism, closest real analogs, transfer performance and sim-to-real gap.

Promotion optimizes portfolio value, not isolated benchmark rank:

```text
utility = decision loss avoided
        + unique failure coverage
        + calibration gain
        + modality diversity
        + privacy and resilience value
        - inference cost
        - latency
        - operational burden
        - rights and security risk
```

Model chemistry measures shared ancestry, error correlation, useful disagreement and marginal ensemble contribution.

## Private Intelligence Federation

Protected data can remain with teams, athletes, schools, labs or users.

Approved computation travels to the data. Execution occurs locally or in attested confidential compute. Only permitted aggregates, updates or proofs return.

Each participant defines permitted computations, prohibited computations, retention, aggregation thresholds, privacy budgets, training rights, output visibility and revocation.

## Edge Swarm

Execution location is selected by privacy, latency, model size, device capability, network, battery, rights and task urgency.

```text

```

Partial results may be progressively escalated only when remaining uncertainty matters.
