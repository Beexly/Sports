# GSE Frontier Kernel

## Product identity

Galaxy Sports Edge is a living, temporal, evidence-governed sports reality and decision-intelligence system. It is not a collection of picks pages, a tout surface, or a generic model wrapper.

## Five compilers

1. **Reality Compiler** — authorized observations become a versioned sports-world model.
2. **Decision Compiler** — user intent becomes persistent Intelligence Contracts that monitor, branch, simulate, explain, and emit material changes.
3. **Capability Compiler** — repositories, APIs, models, datasets, documentation, and internal discoveries become tested capabilities.
4. **Discovery Compiler** — unanswered questions and unexplained residuals become hypotheses, experiments, metrics, and reusable instruments.
5. **Evolution Compiler** — product failures and comprehension gaps become bounded, tested product improvements.

## Implementation doctrine

- No big-bang rewrite.
- One canonical truth path.
- Recover proven work before recreating it.
- Build the invariant before the spectacle.
- Build the replayable object before adding consumers.
- Land thin vertical slices through domain logic, deterministic projection or persistence, server boundary, UX, proof, and tests.
- Real data and honest unavailable states beat elaborate fixtures.
- Public conclusions must be reproducible from bounded evidence, exact model/version context, and temporal cutoff.
