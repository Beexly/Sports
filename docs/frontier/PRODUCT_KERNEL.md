# Product Kernel — directional constraints

Galaxy Sports Edge is evolving from a sports analytics website into a spatial, temporal, evidence-governed sports decision-intelligence system. These are directional constraints for all future workstreams — NOT a mandate to implement everything now. Build only what the current workstream contract freezes.

- **SportsIR** — one canonical representation for entities, observations, events, claims, measurements, states, branches, interventions, outcomes, and proof.
- **Bitemporal reality** — distinguish when something occurred, was published, was observed by Galaxy, and became decision-effective.
- **Intelligence Contracts** — persistent user-defined conditions Galaxy monitors, evaluates, simulates, and explains.
- **Branching Reality** — preserve competing interpretations while facts are unresolved; no forced false consensus.
- **Reality Receipts** — every important output replayable from evidence, temporal cutoff, model version, computation, and decision state. (Nearest existing asset: `PickEvidenceEnvelope` in PR #112.)
- **Model Ecology** — multiple model species, regimes, adversaries, baselines, and disagreements; never one oracle. (Nearest asset: shadow Model Router in PR #124 — advisory-only, default off.)
- **Capability Foundry** — convert useful repos/APIs/datasets/models/docs into versioned, tested capabilities. (Nearest asset: Agent Foundry + Resource Radar in PR #124.)
- **Hypothesis-to-Instrument** — unanswered questions and residuals become formal research, then reusable metrics and product instruments.
- **Galaxy Twin** — spatially render evidence, uncertainty, time, branches, causal pressure, market behavior, model disagreement.
- **Product & Decision Twins** — learn where the product fails to explain decisions and where users miscalibrate.
- **Dynasty Studio convergence** — one world model for real intelligence, counterfactuals, Academy scenarios, playable worlds. (Nearest asset: PR #52 world graph — stale base.)

Standing invariants (never violated by any workstream): no fake data, no fabricated stats, server-side paywalls only, rights-gated scraping through the Clearance Engine, settlement/CLV/calibration are protected zones, write-once history stays write-once.
