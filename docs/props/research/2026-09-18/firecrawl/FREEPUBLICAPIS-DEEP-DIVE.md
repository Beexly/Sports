# FreePublicAPIs.com — Deep Dive
**Research date:** 2026-09-18 (CDT)
**Researcher:** Motif (deep public research; no logins, no paywall bypass, no credentials used)
**Access method:** public web search + public page fetches + live public JSON endpoints

## TL;DR for Garrett

**Correction to the premise:** freepublicapis.com is **not** an odds/statistics data provider. It is a **directory of free public APIs** across every category (weather, music, crypto, dev tools...). Its only sports value for GSE is as a **discovery index** — and as a keyless, GET-only meta-API you can query programmatically to find and health-check free-tier sports APIs.

- **Its own free API:** keyless, **1000 requests/day**, three GET routes. CONFIRMED live.
- **NFL-relevant entries found in its catalog:** TheSportsDB (Free Sports API, health 95 — multi-sport incl. NFL schedules/teams, free tier real), iSports API (soccer + basketball), 5DollarFootballAPI (**soccer only** — not NFL), Football Data API (soccer).
- **No NFL odds APIs listed** in the catalog scan (no balldontlie, no Odds-API.io, no odds aggregators found on 2026-09-18).
- **No historical odds data** is hosted here. No public leaks/archives of its data found; Wayback returned no snapshot for the root domain at access time.

## 2. FreePublicAPIs' own public API (meta-API)

Base URL: `https://www.freepublicapis.com/api` (CONFIRMED — the Go client hardcodes `Host: "www.freepublicapis.com", Path: "/api"`, `Scheme: "https"`).

**Free tier:** 1000 requests/day, keyless. CONFIRMED — stated in the official Go client README (https://github.com/go-api-libs/freepublicapis, fetched 2026-09-18): "It is limited to 1000 requests a day, if you need more, feel free to reach out."

### Endpoint inventory (CONFIRMED from generated client source)

Source: https://raw.githubusercontent.com/go-api-libs/freepublicapis/HEAD/pkg/freepublicapis/client.gen.go (fetched 2026-09-18). "Code generated by github.com/MarkRosemaker DO NOT EDIT" — i.e., generated from the official OpenAPI spec, so this is first-party contract, not hand-written guesswork.

| Method | Route | Returns | Notes |
|---|---|---|---|
| GET | `/api/random` | SimpleAPIInfo | Returns one random catalog entry; live-verified 2026-09-18 (returned Scryfall API, id 189) |
| GET | `/api/apis/{id}` | SimpleAPIInfo | E.g. id 275 per client README example |
| GET | `/api/apis` | APIInfos (list) | Query params: `limit` (int), `sort` (string, e.g. `sort=best`). Live-verified with `?limit=100` and `?limit=2000` on 2026-09-18 — returns a JSON array |

**Auth:** none. **Methods:** read-only GET. **CORS:** not measured in this pass (UNVERIFIED).

- `methods` field on entries ranges 1–6 (observed) — likely "number of endpoints the site tests per API" (UNVERIFIED).
- Per-API directory pages show: description, documentation link, API stats (health/reliability/error), **Endpoints (N)** with per-endpoint 30-day reliability, error rate, avg latency, CORS, "Endpoint Checked X hours ago", "Endpoint Added X time ago", showcase and comment counts, tag picker.
- A `/learn` page exists with beginner tutorials (CONFIRMED).

## 7. How this compares as a data source for Sports (GSE)

| Dimension | Verdict |
|---|---|
| Odds data (NFL) | **None.** Directory only; no NFL odds API listed |
| Historical NFL odds / line movement | None here |
| NFL statistics / advanced metrics | None here beyond TheSportsDB basics |
| TheSportsDB free tier | Schedules, teams, players, event scores across sports incl. NFL; livescores throttled/slow on free, $9/mo unlocks 2-min livescores + V2. Genuinely free-at-access — usable as a **schedule/roster enrichment fallback**, not as an odds or metrics feed |
| The meta-API itself (1000 req/day, keyless) | Usable as a **free-API discovery/health service** inside Sports: periodic sweep for newly listed sports/odds APIs, health-gated failover candidates. Near-zero integration cost |
| Data provenance / licensing | Each entry links upstream docs; licensing is per-upstream-API. TheSportsDB: free at access; 5DollarFootballAPI: commercial use allowed, no raw redistribution as competing feed, attribution required on $0 plans |
| Trust / freshness | Daily health testing is the site's differentiator — reliability/error/latency published per endpoint. Useful as a **pre-filter** before wiring a new free source |
