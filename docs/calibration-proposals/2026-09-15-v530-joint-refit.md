## 1. What the candidate actually is

D17 describes the candidate as "market-anchored probability, shrinkage
weight from A2, every factor that passed §4.2." As of this run
(`docs/factors/*.yaml`, 28 specs, C-409 complete), seven rows read
`CANDIDATE`: A6, A7, A14, A19, A22, A23, A25. **None of the seven join to a
PICKS-H1 row.** Every one is a team- or player-game feature (play-call
entropy, target share, red-zone share, snap-share slope, weather-on-yardage)
measured against nflverse outcomes on its own discover/validate split — not
against a settled moneyline/spread/total pick's market price. The join that
would attach a player-level feature to a specific priced pick is the props
board (Phase 3, C-383), which has not shipped. Building that join now would
mean inventing a feature transform with no code, no data model, and no
review anywhere in the repo — that is fabrication (law 8), not a joint
refit, so it is not done here.

`packages/verifier/src/candidates/v530.ts` exports
`V530_CANDIDATE_FACTOR_REVIEW`: one entry per CANDIDATE factor, its own
measured effect, and why it is excluded. A test
(`v530.test.ts`) asserts that list stays in sync with the live
`docs/factors/*.yaml` CANDIDATE set — it re-reads the directory rather than
hardcoding a snapshot, the same fix already applied to
`scripts/factors/index.test.mjs` after C-421.

## 2. Duel vs market (`buildV530DuelVsMarket`, §4.2 keep rule)

**Keep rule:** ΔBrier < 0 AND P(better) ≥ 0.75 vs `marketFairProb`.

**Source: committed C-362 fixture** (`packages/verifier/fixtures/picks-h1.json`,
n=33, synthetic). A real `verifier/picks-h1.json` export does not exist on
this branch, so the frozen-holdout confirmation is **NOT RUN** — same honest
gap as A2/C-366.

Run: `npx tsx` one-liner over `buildV530DuelVsMarket(rows, {resamples: 1000, seed: 20260915})`.

| arm | n | Brier | log-loss |
|---|---|---|---|
| v5.3.0 candidate | 33 | 0.23549 | 0.66302 |
| market (`marketFairProb`) | 33 | 0.23222 | 0.65634 |
| Δ (cand − mkt) | | **+0.00327** | +0.00668 |

- **P(better) = 0.036** (paired bootstrap, 1000 resamples, seed 20260915)
- Outcome Wilson 95%: 17/33 = 51.5% [35.2, 67.5]
- Football subset (NFL, n=18): ΔBrier **−0.00122**, P(better) 0.691 — non-negative but under the 0.75 floor.
- MLB subset (n=15): ΔBrier +0.00865, P(better) 0.

**`passesKeepRule: false`.** Identical result to A2/C-366 because it is the
identical formula on the identical fixture — expected, not a new finding.
