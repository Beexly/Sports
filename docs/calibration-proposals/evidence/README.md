# Calibration evidence — what each artifact supports

`docs/calibration-proposals/` is the authority for `MODEL_VERSION` bumps, and the
JSON in this directory is the measurement those bumps rest on. Nothing here is
regenerated by hand; each file is the output of a scored run.

| Artifact | Supports | Status it justifies |
|---|---|---|
| `2026-09-15-a2-shrinkage-scorecard.json` | [`../2026-09-15-shrinkage-display-probability-v5.2.8.md`](../2026-09-15-shrinkage-display-probability-v5.2.8.md) — display-probability shrinkage at `w = 0.1` on PICKS-H1 (n=33) | Shrinkage improves on the raw model (ΔBrier 0.0425 → 0.0033) while still trailing market, which is the L11 precondition for the harness being trustworthy |
| `2026-09-15-a8-boltzmann-vs-isotonic.json` | Factor **A8** (`docs/factors/A8.yaml`) — Boltzmann temperature recalibration versus isotonic on an ordered 13/20 split of PICKS-H1 | **BLOCKED.** The pre-registered kill line is "validate-era Brier ≥ isotonic Brier"; Boltzmann scored 0.2558 against isotonic's 0.2148, which is the FAIL side of that rule. The recorded `mde80` (0.0557) is the same number A8's spec pre-registered |

**Caveat on the A8 row.** The artifact sets `fromFixture: true` and its `source`
is `packages/verifier/fixtures/picks-h1.json` — the run used the **synthetic
committed fixture**, not a real holdout export, which does not exist on `main`.
The v530 proposal says so in the same terms. A8 stays BLOCKED on that basis; a
future re-run against a real export is what would change its status, not a
re-reading of this file.

**Known gap.** The A8 artifact was previously uncited from any proposal — it
predates the factor-spec convention and was carried in the same branch as the
v530 joint refit, which does not discuss Boltzmann or isotonic at all. The table
above is the fix: the artifact now names what it supports, and
`verify-evidence.test.mjs` fails if a future edit removes a row from it without
re-pointing the citation.

## Running the guard

```
node --test docs/calibration-proposals/evidence/verify-evidence.test.mjs
```

It re-derives each recorded delta from the two scores it claims to difference,
checks that every Wilson band is arithmetically possible, that every P(better)
is a whole number of the resamples it declares, that intervals are ordered and
MDEs are positive, that the train/validate split accounts for every holdout row,
and that `MODEL_VERSION` is still the frozen `v5.2.7` these numbers were
measured against.

It cannot tell you whether a measurement was *right* — only that the recorded
pieces still add up to the recorded conclusions, so nobody can quietly edit one
side.
