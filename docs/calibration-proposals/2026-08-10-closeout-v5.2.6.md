# CalibrationProposal — market-anchored live eligibility + evidence shrink (v5.2.2 → v5.2.6)

## Decision

`MODEL_VERSION` is **v5.2.6**, covering the v5.2.3 → v5.2.6 closeout run.

1. **v5.2.3** — independent estimators (free MLB StatsAPI standings, nflverse EPA)
   priced into the ranking path.
2. **v5.2.4** — Murphy RES unlock: independent p first; a synthetic
   `marketFairProb = 0.5` is never treated as a real book line.
3. **v5.2.5** — dual-objective selective publish (RES under a Brier cap); live
   eligibility blend 0.7 independent / 0.3 confidence; softer discrimination stretch.
4. **v5.2.6** — market-anchored live eligibility: a fixed evidence shrink toward 0.5
   and a 0.55 / 0.45 independent-to-market blend, plus pick-card
   priced-into-ranking honesty.

Heuristic confidence weights and the composite formula are otherwise unchanged.
Calibration maps, `AUTO_PUBLISH`, `PERFORMANCE_STATS`, and every floor are unchanged.

## Why this is IMPLEMENTED and not FROZEN

`docs/calibration-proposals/FROZEN.md` exists for the case where a version bump
changed **no** scoring weights. That option is not available here, and using it would
be a false statement in a repository whose entire product thesis is that it does not
make false statements about its own math.

The eligibility probability computation materially changed at v5.2.6. Verified in the
current tree:

- `apps/web/lib/calibration/live-calibration-p.ts:37` —
  `export const MARKET_ANCHOR_INDEP_WEIGHT = 0.55;`
- `apps/web/lib/calibration/live-calibration-p.ts:43` —
  `function shrinkIndependent(p: number, alpha = INDEPENDENT_EVIDENCE_SHRINK)`
- `apps/web/lib/calibration/live-calibration-p.ts:73-74` —
  `MARKET_ANCHOR_INDEP_WEIGHT * shrunk + (1 - MARKET_ANCHOR_INDEP_WEIGHT) * marketP`
- `packages/prediction-engine/src/constants.ts:23` — `MODEL_VERSION = "v5.2.6"`

That replaces v5.2.5's `0.7 independent / 0.3 confidence` blend. A different formula
now converts evidence into a published probability, so the version bump carries a real
calibration change and owes a real artifact.

## What this is — and what it is not

This is a calibration and eligibility **math** change. It is **not** a performance
claim and it is **not** a step on the revenue ladder.

Every PROVEN floor is unchanged and still required: Brier ≤ 0.22, ECE ≤ 0.05,
Murphy R ≤ 0.05, n ≥ 100 settled, and GREEN across K consecutive windows. Live
calibration eligibility is RED at the time of writing and this artifact does not
alter that. Nothing here licenses a public track-record claim.
