# DFS — Daily Fantasy Sports

Everything DraftKings/FanDuel: the optimizer, slates, GPP lineup construction, pick'em wiring, weekly research packets.

## Layout

- `optimizer/ — optimizer notes (the code lives in apps/web/lib/fantasy/)`
- `research/<YYYY-MM-DD>/ — dated research: weekly packets, pool notes, GPP studies, full-tables, chart-reads`

## The rule

New research goes in `research/<YYYY-MM-DD>/` — dated, always. Nothing lands at the bucket root. See `docs/INDEX.md` for the full map.
