SECTION 01

The Standard Process

0 / 10 operational gates clear this session

Weekly cadence for the Sun–Mon slate. Lock the source baseline, then clear all ten numbered gates. Every gate is a hard stop: it must pass before the process moves forward.

Wednesday

Data pull from the locked source set + full QB pool scan (every starting QB on the slate, priced and tiered — no QB is locked before the scan is complete).

Thursday

Position pools, stack candidates, Jeff Mans Core Four study.

Friday

Garrett's calls logged in the input zone; Dad's research added.

Saturday

Build lineups; run every gate and audit below.

Sunday AM

Weather + inactives verification; final lock.
