The standard process

Weekly cadence for the Sun–Mon slate. Every input has a time. Every decision passes the same gates.

Wednesday

Data pull from locked sources + full QB pool scan. Every starting QB is priced and tiered. No QB locks before the scan completes.

Position pools, stack candidates, Jeff Mans Core Four study.

Friday

Garrett's calls logged. Dad's research added.

Saturday

Build lineups. Run all gates.

Sunday AM

Weather + inactives verification. Final lock.

Ten-gate system

Gates 00–09 · final lock follows
  1. GATE 00Data lock

    Locked v1 sources: DraftKings salaries + ownership; FantasyGuru.com (Jeff Mans Core Four); Weather.com game-day readings (never narratives); official inactive reports; GSE engine signals. No swapping sources mid-week.

  2. GATE 01QB pool scan

    Every starter priced/tiered; cheap QBs with rushing floors flagged as value.

  3. GATE 02Game-pick firewall

    Team fades don't eliminate opposing players.

  4. GATE 03Stack rules

    QB + max 2 same-team pass-catchers; no TE at FLEX; full $50,000 spent.

  5. GATE 04Injury gate

    Any flag = player removed, no exceptions.

  6. GATE 05Weather gate

    Numbers verified within hours of lock; narratives rejected.

  7. GATE 06Garbage-time discount

    4th-quarter trailing volume discounted hard.

  8. GATE 07Thesis-to-roster audit

    Every written thesis has a rostered player.

  9. GATE 08Garrett's calls

    Logged pre-lock, scored post-slate, never ignored.

  10. GATE 09Simulations

    10,000+ correlated slates before lock; lineups need top-decile ceiling and positive sim ROI vs field.

Final: LockAll ten gates pass or the lineup doesn't ship.

03 / 07

Core Four study: Jeff Mans

Study the best, then build our own.

FOUNDATION / 01

What it is

One QB, one RB, one WR, one TE — the foundation a lineup is built around. Not the four highest-projected players: cost and value are co-equal inputs. One value piece frees up money for a stud elsewhere.

Published Fridays on FantasyGuru.com in Mans' DFS NFL Cash Game Breakdown. The Friday panel show is separate and hosted by Tyler Buecher.

METHOD / 02

His theory

Objective: “Beat the optimizers.” The field runs the same vanilla projections through optimizers, so he builds cash-game lineups as the kryptonite of that — then funds GPPs with cash winnings.

Cash preferences: dual-threat QBs with rushing floors (“dual-threat quarterbacks are our jam in cash games”); willing to pay up at TE when volume is elite, with no blanket never-pay-up rule; and ownership discipline. Chalky value is playable, but cap how many chalk pieces the build carries. A chalk fade is a legitimate differentiator.

He runs separate cash and GPP Core Fours.

PIPELINE / 03

His weekly pipeline

  1. 01Weather: wind and total effects per game.
  2. 02Vegas: team totals, spreads and over/unders; implied totals anchor game selection.
  3. 03Price tiers: positional tiers on each site; the four can differ because pricing differs.
  4. 04OL vs DL: the “Mans Model” grades each line from −100 to +100.
  5. 05Coverage: which corners shadow which WRs.
  6. 06Don't Forget About…: cheaper pivots with similar roles.
  7. 07Favorite GPP Play…: per position, same game environment, lower ownership.
  8. 08Sunday update: late news folded into the pool before lock.
