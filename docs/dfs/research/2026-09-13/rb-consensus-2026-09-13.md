# RB Consensus — FanDuel NFL Classic, Sunday-Monday Slate (Sept 13-14, 2026)

**Slate:** 14 games (all Sun games + Mon Broncos@Chiefs). FD scoring: 0.5 PPR, $60K cap.
**Method:** 4 parallel researchers + coordinator spot-checks across 12+ distinct free sources, all
date-verified to 2026 Week 1: FantasyPros (0.5-PPR consensus), numberFire (stat-line projections),
DK Network (projections + touch model), FantasyLabs (FD salaries/ownership/model ranks),
FanDuel Research, thehuddle/USA Today (full-slate FD salary table), fantasyalarm, RotoBaller,
PFF, Fox Sports, Packers Wire, thedeepshot. Numeric consensus = mean of available FD-scale
projections (DK full-PPR numbers adjusted −0.5/rec using numberFire reception figures).
**Salary cross-checks:** 2-3 sources on Gibbs/Henry/Hampton/Lloyd/Javonte/Achane/Bijan; single
full-slate-table source on the rest (thehuddle). Salaries are from full-slate tables; FD prices
run identically across slates sharing games (primetime-only slate differs — excluded).
**Ownership:** hard number only for Gibbs (~40%, FantasyLabs); rest estimated from "no other RB
over 18-20%" + chalk commentary.
