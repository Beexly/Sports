# Brand Marks to Clear — Galaxy Sports Edge

This is the candidate list of word marks, taglines, and product names that
should go through trademark clearance before public launch and, where
appropriate, federal trademark application.

**Status:** No marks filed yet. No clearance searches completed.
**Next step:** USPTO TESS search + state-level common-law search per mark,
then attorney consultation for filing strategy.

## Filing strategy notes

- **Class 41** (entertainment / education services) likely applies to
  educational content, the Academy, and reports.
- **Class 42** (technology services / SaaS) likely applies to the
  intelligence platform itself.
- **Class 9** may apply if there is a downloadable app.
- File **Intent-to-Use (ITU)** for marks not yet in commerce.
- Conduct a knockout search before any filing.
- Document first use in commerce per mark.
