## How to use this log

Each week:
1. Open the corresponding week's section.
2. Fill in the metrics + observations honestly.
3. Note any decisions taken or deferred.
4. Note any pattern-checks or signals worth carrying forward.

The log is private. Year-1 annual report references aggregate themes; specifics stay internal.

## Weekly retrospective integration

Each week's `Observations` + `Decisions taken` + `Carry forward` synthesizes into the weekly retrospective per `week-minus-1/09-weekly-retrospective-template.md`. The 90-day log captures the same data with longer arc; both feed the quarterly audit.

---

## When entries get sparse

If a weekly entry has only metrics without observations: investigate. Honest observations are the highest-signal part of the log. Sparse entries suggest:

- Garrett is too tired to reflect (mental health signal — per `founder-resilience-playbook.md`).
- Week was operationally uneventful (which is fine; honest "nothing to add this week" is fine).
- Garrett is avoiding a hard observation (the pre-mortem mitigation: catch yourself).

---

## When metrics are missing

If specific metrics (calibration, retention, cancellation reasons) are unfilled: trace why.

- Operational tooling broken? (Fix it; per `copy/vault-member-support-playbook.md`.)
- Data not yet available? (Note the constraint; carry forward.)
- Avoiding the number? (Pre-mortem flag: brand position depends on metrics, not vibes.)
