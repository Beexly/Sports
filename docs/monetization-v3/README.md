# Galaxy Sports Edge Monetization Expansion v3

Date: 2026-05-23
Status: Execution source of truth
Owner: Garrett

This folder converts the monetization-v3 plan into an operating system. The strategic commitment stays unchanged: execute only the active tracks that match runway, measure them mechanically, and keep all deferred tracks gated until the active tracks earn expansion.

## Operating Principle

Galaxy Sports Edge wins by compounding trust: transparent math, restraint discipline, public losses, Pass List, and founder-led editorial judgment. This operating system exists to protect that position under monetization pressure.

## Active Tracks

The full v3 portfolio has 13 tracks, but only 3 are active in the full 24-month plan:

1. Galaxy Vault
2. The Galaxy Almanac
3. Galaxy Live - Sketch partnership

Runway determines which subset is active:

| Runway | Operating posture | Active tracks |
|---|---|---|
| 6 months | Survival | Vault only |
| 12 months | Foundation | Vault + Almanac |
| 24+ months | Portfolio | Vault + Almanac + Live |

## Expansion Rule

No deferred track activates until:

- The current active tracks clear their KPI gates.
- The required capability or hire exists.
- Runway supports the additional burn.
- A decision-log entry records why the activation is allowed.

This rule is the plan's integrity layer.
