# Vega Character Brief

**Status:** Internal creative brief.
**Related decision:** DEC-NEXT-021
**Pairs with:** `audit/galaxy-character-media-strategy-2026-05-23.md`

---

## Role

Vega is Galaxy's short-form artifact guide.

Vega explains:

- why a loss matters,
- why a pass matters,
- what calibration means,
- what the methodology page documents,
- where the viewer can read the record.

Vega does not:

- make picks,
- promise outcomes,
- replace Garrett,
- become a customer-support identity,
- pretend to be real,
- appear as a photoreal human.

---

## Character concept

Vega is a stylized telescope/lens character with a constellation-map faceplate and calibration-dial accents.

The design should feel:

- precise,
- quiet,
- curious,
- a little strange,
- not cute-first,
- not casino-adjacent,
- not childish.

---

## Visual vocabulary

Allowed motifs:

- star map,
- telescope lens,
- calibration dial,
- grid lines,
- small orbit marks,
- understated glow,
- data tick marks.

Rejected motifs:

- money,
- chips,
- cards,
- fire,
- trophies,
- team-logo parody,
- loud sportsbook colors,
- humanoid glamour,
- childish plush styling.

---

## Palette

Use Galaxy's existing palette when available.

If palette is unavailable, use:

- near-black background,
- off-white linework,
- one restrained blue accent,
- one muted gold/star accent.

Avoid:

- neon casino palette,
- all-purple gradient,
- red/green betting palette,
- loud influencer colors.

---

## Shape

Silhouette:

- readable in a circular avatar,
- recognizable at 64px,
- simple enough for animation,
- distinctive enough for merch if the test works.

Recommended V1:

- compact telescope/lens body,
- circular face/lens with star-map expression,
- small calibration dial as side accent,
- minimal arms or pointer marks only if needed for expression.

---

## Expression set

V1 needs only five states:

1. Neutral.
2. Reading.
3. Questioning.
4. Flagging a pass.
5. Filing a record.

Do not create emotional extremes. No yelling, cheering, crying, or shocked reaction thumbnails.

---

## Motion style

V1 motion should be simple:

- blink or lens glint,
- small dial rotation,
- subtle star-map movement,
- caption blocks entering,
- artifact screenshot sliding in.

No dancing.
No reaction-face thumbnails.
No exaggerated gestures.

---

## Voice

Default:

- Garrett's real voice.

If a voice treatment is used:

- light,
- clearly branded,
- not a fake human persona,
- not a customer-support voice.

Vega's written voice:

- "Galaxy filed..."
- "The model published..."
- "The Pass List shows..."
- "Read the artifact..."

Vega never says:

- "I picked..."
- "Trust me..."
- "This will hit..."
- "My members..."
- "My model..."

## Designer handoff

Ask for:

- primary character,
- 5 expression states,
- transparent PNG exports,
- 9:16 title-card composition,
- simple color palette,
- vector source file,
- usage rights transferred to Galaxy.

Designer brief sentence:

> Build Vega, a stylized telescope/lens character for a restrained sports research brand. Vega is not cute-first, not a gambling mascot, and not a humanoid influencer. It should feel like a guide to a public record.

---

## Acceptance criteria

Vega is approved only if:

- visible synthetic identity is obvious,
- no one would mistake Vega for a real person,
- no one would mistake Vega for a sportsbook mascot,
- it reads at phone size,
- it can sit beside the Loss Room without making the Loss Room feel unserious,
- Garrett would be comfortable using it in five test clips.
