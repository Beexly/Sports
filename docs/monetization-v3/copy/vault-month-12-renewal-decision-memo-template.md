## Section 3 — Anti-rationalization audit (CRITICAL at Month-12)

Renewal decisions are the highest-stakes Galaxy decisions in Year-1. The temptation to rationalize a borderline renewal rate is highest here.

```
**Question 1:** Is the renewal rate computed honestly? Specifically:
- Did I count members who quietly let cards expire as "non-renewed"?
- Did I count refund-requested mid-year cancellations as non-renewed?
- Did I count "soft-pause" extensions correctly? (Pauses with re-engagement plan = uncertain; treat as non-renewed for the threshold check.)
- Did I exclude any genuine outliers (e.g., a member who explicitly stated they would return next year but canceled this year for non-Galaxy reasons)?

[Honest answer]

**Question 2:** Are there structural reasons the renewal rate would not represent typical year-1-to-year-2 behavior?

Examples that might justify special framing:
- Galaxy launched mid-year (Vault was operational <12 months for some members)
- A specific operational disruption affected a sub-population
- A known one-time event drove churn

[Honest answer. Be specific. If structural reason exists, it's still subject to the override protocol — first override per track only.]

**Question 3:** Am I considering override because the evidence supports it, or because I want Vault to continue?

[Honest answer]

**Question 4:** Did the personal kill criteria (per `01-runway-scenarios.md` + `founder-resilience-playbook.md`) fire during Year-1?

[Yes/No + details if yes]

**Question 5:** If a Vault founding-50 member asked me publicly today whether Year-2 Vault is justified, what would I honestly say?

[Single honest sentence]

**If any check surfaces dishonesty: the conservative plan applies. Don't override.**
```

## What Month-12 memo deliberately doesn't do

1. **No "wait for Q1 of Year-2" deferrals.** Month-12 is the decision point. Don't push it to January.

2. **No "explore other options" before kill threshold.** If renewal is below 50%, the playbook is sunset. Don't invent alternatives.

3. **No retroactive metric redefinition.** Renewal rate is what it is; don't argue about whether to count specific edge cases differently.

4. **No founder-personality justifications.** Galaxy's brand position is method-led; sunset decision should not invoke "but I love this work."

5. **No member-facing apology for the decision.** Whatever the decision, communicate honestly. Don't apologize for following the discipline.
