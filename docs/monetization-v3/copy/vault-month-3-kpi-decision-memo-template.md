```
**My felt response to the headline numbers:**

[1-2 sentences. Honest emotional read.]

**Does my felt response match the mechanical read?**

- Felt good + mechanically green: aligned. Continue confidently.
- Felt good + mechanically mixed/warning: investigate the gap. Am I in denial?
- Felt mixed + mechanically green: something invisible going wrong. Investigate.
```

## What this memo deliberately doesn't do

1. **No member-facing communication generated.** The memo is internal; member updates happen via the brand-voice channels Codex's launch runbook + ongoing operations cover.
2. **No long-term V2 planning.** That's the Year-2 strategic question framework.
3. **No comparison to other companies' Month-3 metrics.** Galaxy's metrics are Galaxy's.
4. **No emotional decisions disguised as data decisions.** The felt-response section is honest about emotional state.

---

## Use cycle

- Block the last Friday of month 3 (calendar entry): 09:00–11:00 for the KPI ritual + 13:00–14:00 for this memo.
- After the ritual: complete the memo template, archive, write the decision-log entry.
- Communicate the decision per the rules (Codex notification, possibly Vault Discord update).

The Month-3 memo template is reusable. Month-6 and Month-12 use slightly different versions of the same template (Month-6 includes a kill-criterion section; Month-12 includes a Year-2 strategic transition section).
