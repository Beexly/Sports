# Galaxy Twitter Launch Thread

**Audience:** Garrett. Internal.
**Use:** Single Twitter thread that announces Vault publicly after the founding-50 window closes (Day 14 of launch).

**Why this exists:** The Vault public launch is announced via a tweet thread on @GalaxySportsAI. The thread needs to be brand-aligned + restrained + paste-ready. This document is the thread.

---

## The thread (5 tweets, ~280 chars each)

### Tweet 1 — The lede

```
Vault is open to the public today.

A premium tier above Pro and Elite. $200/year. Capped at 1,000 founding members. For readers who want the rationale behind the publications, not more picks.

→ galaxysportsedge.com/vault
```

### Tweet 2 — What's inside

```
What you get:

— Weekly internal-rationale digest (Wednesdays)
— Monthly group office hours (second Tuesdays)
— Quarterly private data review
— Early access to the Model Journal draft
— Vault-only Discord channel

The discipline of the publication, deepened.
```

### Tweet 3 — What it's not

```
What Vault isn't:

— Not extra picks. Pro and Elite already cover the publication slate.
— Not private information. Nothing in Vault sees data the public methodology page doesn't already describe.
— Not a Discord trading room. We don't tail; we don't pool.

It's the room behind the publication.
```

### Tweet 4 — Founding cohort

```
The first 1,000 seats are the founding cohort. Founding rate ($200/year) locked for the life of continuous subscription.

When the cap fills, the next seat opens when an existing one frees up.

This isn't manufactured scarcity. It's a small room by design.
```

### Tweet 5 — The close

```
Vault is the part of Galaxy that's hardest to copy. The Loss Room, the Pass List, the methodology page already exist publicly. Vault adds the rationale around them.

If that's the room you want to be in:

→ galaxysportsedge.com/vault

— Garrett
```

## Sending instructions

### When

Send the thread on Day 14 of launch (the morning the founding-50 window closes + public Vault opens).

Suggested time: 09:00 Eastern, a Wednesday (timed with the Wednesday digest publishing).

### Sequencing

Post all 5 tweets as a thread, one immediately after another (within 5 minutes total). Don't space them across days.

### Engagement protocol

Per `copy/galaxy-twitter-content-discipline.md`:

- Don't engage with quote-tweets or replies for the first 24 hours. Let the thread land.
- Respond to direct questions ("can I join?", "what's the difference vs Pro?") with single-tweet answers + link.
- Don't engage with critics ("why $200?" "isn't this just marketing?") via tweet thread. If response needed: link to the appropriate Galaxy surface (`/methodology`, `/vault`, etc.).
- Don't retweet or quote-tweet member responses to the thread unless explicitly approved by the member.

### What the thread accomplishes

- Announces Vault publicly.
- Establishes the brand position one more time.
- Links to the conversion surface (`/vault`).
- Models Galaxy voice for the moment (restrained, specific, founder-led).

### What the thread doesn't do

- No images / graphics / cover art (Galaxy social is text-only).
- No price-comparison to competitors.
- No urgency language ("Founding rate ends soon!").
- No "join thousands of bettors" social proof.
- No "watch our launch video" CTA.

## What this thread doesn't do (final reminders)

1. **No "we'd love to have you" warm-and-fuzzy language.** Galaxy's voice doesn't go there.

2. **No "limited time only" pressure.** The founding-rate guarantee is real but not promoted as scarcity.

3. **No "click here" or "buy now" buttons.** The link itself is the call.

4. **No emoji other than possibly 🪐 once (sparingly).** Most likely no emoji at all.

5. **No founder-personality angle.** Galaxy is method-led; the founder's name appears in the close ("— Garrett") but not as a personal pitch.
