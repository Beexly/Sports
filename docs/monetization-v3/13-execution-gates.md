# Execution Gates

Status: Required before engineering

This file preserves the hard stop between planning and product implementation.

## Before Vault Engineering Starts

- [ ] Garrett has confirmed runway scenario.
- [ ] DEC-NEXT-001 is written in `templates/decision-log.md`.
- [ ] 30 Vault customer-development interviews are complete, unless Scenario A survival mode is explicitly selected.
- [ ] Day-7 decision memo exists.
- [ ] DEC-NEXT-002 is written.
- [ ] Vault decision is GO at $200 or GO after retest.
- [ ] Canonical landing page decision is recorded in DEC-NEXT-003.
- [ ] Brand-safety review is complete for landing page, outreach, welcome emails, digest template, retention emails, referral page, Discord launch copy, support scripts, press pack, and press kit.
- [ ] Founding-50 cohort framework is ready before the private launch window.
- [ ] Referral program policy is either locked in DEC-NEXT-009 or explicitly deferred.
- [ ] Retention and cancellation lifecycle emails are reviewed before payment launch.
- [ ] Engineering repo location is confirmed.
- [ ] App repo locator checklist is complete.

If any box is unchecked, Vault engineering does not start.

## Before Almanac Production Starts

- [ ] Runway scenario is B or C.
- [ ] Vault is not at a kill threshold.
- [ ] 25 Almanac customer-development interviews are complete.
- [ ] Almanac price decision is recorded in DEC-NEXT-006.
- [ ] Hardcover, digital, or digital-only format is confirmed.
- [ ] Cover-design budget is authorized if hardcover proceeds.
- [ ] 30-day hardcover refund mechanic is approved.

## Before Live Engineering Starts

- [ ] Runway scenario is C.
- [ ] Vault and Almanac are not at kill thresholds.
- [ ] Live activation is recorded in DEC-NEXT-007.
- [ ] Sketch outreach path is recorded in DEC-NEXT-008.
- [ ] 3+ founding partner commitments exist, or Garrett records a single-partner pilot override.
- [ ] Founding-partner agreement draft is ready.
- [ ] Lawyer-approved agreement exists before any agreement is sent to a partner or manager.
- [ ] Closed-beta launch gate includes zero stream crashes attributable to overlay.

## What Codex Can Do While Waiting

Allowed:

- Maintain docs.
- Prepare specs.
- Build templates.
- Review source assumptions.
- Draft copy for Garrett review.
- Prepare issue/backlog structure.

Not allowed:

- Product engineering that assumes Vault is validated.
- Stripe product creation.
- Discord role automation.
- Paid outreach commitments.
- Live OBS engineering.
- Deferred-track activation.
