# Galaxy End-of-Year-1 Checklist

**Audience:** Garrett. Internal.
**Use:** December 2026. Complete in order. ~3-4 days of focused work.
**Purpose:** The Year-1 close has many dependencies. The checklist below sequences them.

---

## Week 1 of December (Days 1-7)

### Day 1 — Personal preparation

- [ ] Re-read `founder-resilience-playbook.md` § "Year-end reflection"
- [ ] Re-read `01-runway-scenarios.md` § Personal kill criteria
- [ ] Block calendar for December 7-21 (Year-1 close work)
- [ ] Confirm any travel / family commitments around the close don't conflict

### Day 2-3 — KPI data preparation

- [ ] Pull Vault subscription data: founding-50 retention, founding-1000 retention, total active members at Day 365
- [ ] Pull renewal data from Stripe: renewed / canceled / refunded counts
- [ ] Pull calibration data (rolling 12-month, per sport, per confidence band)
- [ ] Pull Loss Room + Pass List metrics for the year
- [ ] Pull Vault feedback themes log + cancellation reason notes

### Day 4-5 — Monthly KPI ritual + Month-12 decision memo

- [ ] Run the standard monthly KPI ritual for December (last Friday of month, per `audit/kpi-operator-ritual.md`)
- [ ] Complete the Month-12 Renewal Decision Memo per `copy/vault-month-12-renewal-decision-memo-template.md`
- [ ] Write DEC-NEXT-VAULT-MONTH-12-001 decision-log entry
- [ ] Communicate decision to Codex
- [ ] If sunset triggered: notify designated emergency contact + lawyer

### Day 6-7 — Quarterly deep audit (Q4)

- [ ] Run the Q4 quarterly deep audit per `galaxy-quarterly-deep-audit-protocol.md` (4 hours)
- [ ] Document audit findings in the Q4 quarterly audit file under `reviews/`
- [ ] Note any drift from brand position that needs immediate action

---

## Week 2 of December (Days 8-14)

### Day 8-9 — Year-1 retrospective synthesis

- [ ] Complete personal retrospective per `copy/galaxy-12-month-personal-retrospective-template.md` (private file)
- [ ] Synthesize lessons across 4 quarterly audits
- [ ] Compile member feedback patterns from year's feedback log

### Day 10-11 — Year-2 strategic question framework

- [ ] Run through all 7 questions per `galaxy-year2-strategic-question-framework.md`
- [ ] Write 7 corresponding DEC-NEXT-Y2 decision-log entries:
  - DEC-NEXT-Y2-001 — Vault Year-2 trajectory
  - DEC-NEXT-Y2-002 — Almanac annual commitment
  - DEC-NEXT-Y2-003 — Live track status
  - DEC-NEXT-Y2-004 — Hiring plan
  - DEC-NEXT-Y2-005 — Capital structure
  - DEC-NEXT-Y2-006 — Sport coverage
  - DEC-NEXT-Y2-007 — Brand position
- [ ] If hiring decision is yes: identify specific role + start engagement search

### Day 12-13 — Year-end annual report draft

- [ ] Draft the year-end annual report per `copy/galaxy-year-end-annual-report-template.md`
- [ ] 2,500-3,500 words across 8 sections
- [ ] Garrett edits across 1-2 sessions
- [ ] Brand-safety scanner pass

### Day 14 — December Wednesday digest

- [ ] Write the December Vault digest with year-end reflection theme
- [ ] Send Wednesday December 31 (or last Wednesday if Dec 31 isn't a Wednesday)

### Day 15-16 — Almanac final production

- [ ] Confirm Almanac is ready for January 15 ship (per `copy/almanac-production-pack.md`)
- [ ] Final proof PDF check
- [ ] Amazon KDP upload confirmed
- [ ] Pre-order pipeline reviewed

- [ ] Send year-end member communication (final digest of the year)
- [ ] If continuing Year-2: announce V2 + thank founding cohort
- [ ] If sunset: send the Scenario C sunset email per `launch/vault-sunset-playbook.md`
- [ ] Update `/about`, `/vault`, `/pricing` pages with Year-2 status

### Day 19-20 — Decision-log + memory archive

- [ ] All Year-1 decision-log entries reviewed; ensure complete
- [ ] Memory file updated with Year-1 summary entry
- [ ] Year-1 retrospective archived under `reviews/` as the public version, distinct from personal-private

### Day 21 — Press cycle

- [ ] Year-end annual report publishes at galaxysportsedge.com/annual-report/2026
- [ ] Twitter thread announcing year-end report
- [ ] Email to all Galaxy subscribers
- [ ] Press outreach to Tier 1-2 outlets per `copy/vault-launch-press-pack.md`

## Week 4 of December (Days 22-31)

### Day 22-28 — Off mostly

- [ ] Saturday OFF discipline holds (Days 25, 27)
- [ ] Limited reactive work only
- [ ] Recovery from intensive Year-1 close

### Day 29-31 — Year-2 setup

- [ ] Verify Stripe is configured for any Year-2 changes (V2 cap-lift if applicable)
- [ ] Verify Codex is ready for any Year-2 engineering changes
- [ ] Verify communication systems (email templates, Discord channels) are ready for January
- [ ] Calendar blocked for January's peak blocks
- [ ] Year-1 retrospective writing complete (personal + public)

## Year-1 close output

By December 31, Galaxy has:

1. **DEC-NEXT-VAULT-MONTH-12-001** decision-log entry (Vault Year-2 trajectory).
2. **7 DEC-NEXT-Y2** decision-log entries (Year-2 strategic decisions).
3. **Year-end annual report** published at `/annual-report/2026`.
4. **Personal retrospective** archived privately.
5. **Q4 quarterly audit** documented.
6. **Year-1 retrospective** archived under `reviews/`.
7. **Memory file** updated with Year-1 summary.
8. **Member communication** sent.
9. **Almanac** ready to ship January 15.

---

## If sunset is triggered at Year-end

The checklist changes substantially if Month-12 renewal triggers Scenario C sunset:

- Days 5-10: Sunset operations (per `launch/vault-sunset-playbook.md`)
- Days 11-15: Member communication + refund processing
- Days 16-21: Year-end annual report becomes Year-1 retrospective with sunset framing
- Days 22-31: Year-2 reorganization around Almanac + Live (Scenario C runway) + new product designs influenced by Vault learnings

---

## What this checklist deliberately doesn't do

1. **No "Year-1 celebration."** Galaxy doesn't celebrate milestones publicly.
2. **No press blitz for Year-1.** The annual report is the substantive Year-1 communication.
3. **No founder-personal-brand content.** Galaxy is method-led.
4. **No "look how far we've come" framing.** Restraint applies to Year-1 close too.
5. **No comparison to other companies' Year-1.**
