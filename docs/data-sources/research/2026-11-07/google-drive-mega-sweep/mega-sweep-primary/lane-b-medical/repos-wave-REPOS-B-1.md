## B-R1-01 — HEADSport Filter Method
- **Repo:** GTBiomech/HEADSport-Filter-Method — 1★ · last push 2025-04-17 · MATLAB · license CC-BY-4.0
1. **WHAT IT IS** — Artefact-attenuation filtering method for instrumented-mouthguard (iMG) head-acceleration-event signals, built from power-spectral-density characteristics of 72 laboratory headform impacts (25-150 g) and 5,694 on-field rugby head acceleration events; published in BMJ Open Sport & Exercise Medicine 2024 (HEADSport study). (API description: none set on the repo)
2. **WHERE** — https://github.com/GTBiomech/HEADSport-Filter-Method
3. **HOW TO USE IT** — Clone and run the MATLAB filter on raw iMG tri-axial accelerometer/gyroscope waveforms before computing peak linear/angular kinematics; designed as the common pre-processing step that makes different iMG systems (Prevent, HitIQ, ORB) comparable.
4. **WHICH SYSTEM** — GSI head-impact telemetry line — the signal-cleaning gate for every mouthguard dataset GSI touches. GSE tie-in: cleaner per-impact kinematics = less noisy player head-impact-exposure features behind availability risk.
5. **SECOND-ORDER** — Pair with CNN-brain-strains (B-R1-02): filtered kinematics in, voxel-wise strain out — a complete open mouthguard-to-brain-strain chain. Also a benchmark filter: run HEADSport vs Butterworth-200Hz vs CFC180 on any new sensor dataset and report SNR deltas.
6. **§8 ENGINE-TRAINING VALUE** — TRAINING VALUE: Metric = PSD-derived filter cutoffs + per-event SNR for 5,694 labelled head acceleration events (lab impacts carry known 25-150 g ground truth). Data lives in the HEADSport study (field data on request; filter code + lab PSD characteristics in-repo). Labels: lab impacts have ground-truth kinematics; field events are video-verified HAE vs artefact classes in the parent study.
7. **PROVENANCE** — Original lab code from the HEADSport consortium (Georgia Tech GTBiomech org on GitHub; Tooby/Williams et al.). Not a fork (API fork=false).
8. **VERDICT** — TEST

## B-R1-02 — CNN Brain Strains (WHIM-trained instantaneous brain-strain model)
- **Repo:** Jilab-biomechanics/CNN-brain-strains — 2★ · last push 2020-11-11 · MATLAB · license GPL-3.0
1. **WHAT IT IS** — Pre-trained convolutional neural network that instantly estimates element-wise whole-brain peak maximum principal strain (MPS) from head-impact kinematics; trained on finite-element simulations from the anisotropic Worcester Head Injury Model (WHIM v1.0, ~55k brain elements, tractography-based white-matter anisotropy). Validated on Stanford mouthguard impacts (college football/boxing/MMA, N=110) and lab-reconstructed NFL impacts (N=53); reported R2=0.916, RMSE=0.014 for whole-brain MPS (Sci Rep 2019; J Neurotrauma individualized extension 2023). (API description: "Convolutional neural network for efficient estimation of  regional brain strains")
2. **WHERE** — https://github.com/Jilab-biomechanics/CNN-brain-strains
3. **HOW TO USE IT** — Download the pre-trained MATLAB CNN, feed a head-impact kinematic time history (or peak rotational velocity/acceleration within the validated envelope, ~900-5,100 rad/s2 PRA, 2-40 rad/s PRV), receive voxel/element-wise peak MPS maps and regional (cerebrum, corpus callosum, brainstem) strain summaries in seconds instead of hours of FE compute.
4. **WHICH SYSTEM** — GSI brain-strain metrics line — this is the MPS engine: turns any measured or reconstructed impact into the strain field that concussion-risk curves are built on. GSE tie-in: per-impact strain accumulation is the mechanistic core of a cumulative head-impact load feature for player-health research (internal only).
5. **SECOND-ORDER** — Chain after HEADSport filtering (B-R1-01) and impact_retriever kinematics (B-R1-03). Use its MPS outputs as labels to train a fast GSI surrogate in MONAI/PyTorch; regional strain (esp. corpus callosum) is the natural feature for DTI-outcome studies (B-R1-24..27).
6. **§8 ENGINE-TRAINING VALUE** — TRAINING VALUE: Metric = element-wise peak MPS strain fields (labels generated by WHIM FE simulation over 2,592 augmented training impacts). Data lives in-repo (pre-trained model + example impacts) and in the Stanford/NFL source datasets cited in the papers. Labels: FE-derived strain labels — simulation ground truth, not diagnosed-concussion labels; concussion labels must come from the clinical cohorts paired with the same kinematics.
7. **PROVENANCE** — Original research code from Songbai Ji's lab (Jilab-biomechanics, Worcester Polytechnic Institute lineage — WHIM was developed at WPI). Not a fork. Note: two papers cite a 'CNN-brainstrains' spelling; the live repo is the hyphenated CNN-brain-strains (verified).
8. **VERDICT** — ADOPT

## B-R1-03 — Impact Retriever (head-impact location/speed/force from kinematics)
- **Repo:** xzhan96-stf/impact_retriever — 2★ · last push 2024-05-31 · Python · license none stated
1. **WHAT IT IS** — LSTM network that identifies head-impact location, speed and force from tri-axial linear acceleration + angular velocity alone; trained on 16,000 simulated helmeted impacts from the Riddell helmet finite-element model and validated on 79 video-verified on-field instrumented-mouthguard impacts with identifiable location (arXiv:2409.08177, 2024). (API description: "AI-based identification of head impact locations, speeds, and force based on head kinematics in contact sports")
2. **WHERE** — https://github.com/xzhan96-stf/impact_retriever
3. **HOW TO USE IT** — Clone, load the trained LSTM, feed mouthguard/helmet kinematic windows; outputs impact location class, closing speed and force estimates — the inverse problem (what hit the head, where) solved from the same signals GSI sensors record.
4. **WHICH SYSTEM** — GSI head-impact telemetry line — reconstructs impact circumstances when video is missing. GSE tie-in: impact-location/speed distributions by play type feed situational exposure research (which schemes/plays generate the worst head impacts).
5. **SECOND-ORDER** — Inverse complement to CNN-brain-strains: retriever estimates the impact, CNN estimates the tissue response. Its 16k-simulation training recipe is a template for GSI sim-to-real transfer (same pattern as the DRCA MLHM work from the same lab).
6. **§8 ENGINE-TRAINING VALUE** — TRAINING VALUE: Dataset = 16,000 simulated helmeted impacts (in-repo per paper's code/data availability) with location/speed/force labels from the Riddell helmet FE model, plus 79 on-field mouthguard impacts with video-verified location labels. Labels exist for all three targets (location, speed, force) — simulation labels for training, human-video labels for validation.
7. **PROVENANCE** — Original code from Stanford's Camarillo Lab (authors Zhan/Liu, Dept. of Bioengineering, Stanford; Beihang co-authors). Not a fork.
8. **VERDICT** — TEST
