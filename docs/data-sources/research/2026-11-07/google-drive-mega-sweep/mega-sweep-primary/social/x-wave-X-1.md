Second angle: threshold discipline is the same shape as the engine's pass discipline on picks (act only when the margin clears the bar) — one doctrine, two surfaces.
6. RISKS/UNVERIFIED flags — Single-post argument, no dataset attached; the 0.6% figure is CITED from ESPN's model output as quoted by the author; threshold placement is itself a modeling choice.

CREATIVE/SECOND-ORDER ANGLES — The bias-correction method transfers: any voluntary-donation or voluntary-reporting dataset in sports medicine (injury registries, symptom surveys) has the same inflation structure, and this paper shows how to price it.
