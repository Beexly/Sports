## EXTRACTION PROTOCOL (Per Target)

For **every target**, you MUST perform ALL of the following. If you cannot find something, write `NOT CONFIRMED` and explain why.

### 1. Network Traffic Analysis
- Load the homepage in a **headless browser** (use Hermes browser tools).
- Capture **every network request** (XHR, fetch, WebSocket).
- Log all API endpoints: URL, method, headers, request/response bodies.
- Identify **WebSocket connections** and their message formats.
- Save the **full HAR file** or request log.

### 2. JavaScript Bundle Analysis
- Fetch **every `.js`, `.mjs`, `.js.map`** file from the page.
- Parse each file (use Hermes `web_extract` or custom script) to find:
  - **API base URLs** — `baseURL`, `apiRoot`, `endpoint`, `axios.create`
  - **Model definitions** — TypeScript interfaces, JSDoc, class properties
  - **Feature flags** — `user.tier`, `isPremium`, `hasAccess`, `featureEnabled`
  - **Entitlement logic** — what features are gated by which tier
  - **Scoring formulas** — look for `*`, `/`, `+`, `-` on player stats, weight constants (e.g., `0.35`), threshold arrays
  - **Simulation parameters** — `numSims`, `correlationMatrix`, `gameScripts`, `monteCarlo`
  - **Local storage keys** — what data is cached client‑side
  - **Error messages** — reveal internal state names and validation rules
- **Reconstruct each formula** in plain English. Quote the exact code snippet.

### 3. API Discovery
- Check these paths (use Hermes `web_extract` or browser):
  - `/openapi.json`, `/swagger.json`, `/swagger.yaml`
  - `/graphql` — test for introspection: `{__schema{types{name}}}`
  - `/api`, `/api/v1`, `/api/v2`, `/rest`, `/rpc`
  - `/docs`, `/api-docs`, `/help`, `/developer`
  - `/.well-known/`, `/robots.txt`, `/sitemap.xml`
- If OpenAPI/Swagger is found, **parse the entire spec**.
- If GraphQL introspection is enabled, **dump the full schema**.
- If public endpoints exist, make a sample request and save the response.

### 4. Infrastructure Fingerprinting
- Check **HTTP response headers** for:
  - `Server`, `X-Powered-By`, `X-AspNet-Version`, `X-GitHub-Request-Id`
  - `CF-RAY` (Cloudflare), `x-amz-*` (AWS), `X-Google-*` (GCP)
  - `Set-Cookie` — reveals session management
- Check **DNS records** for subdomains: `api.`, `app.`, `admin.`, `dev.`, `staging.`
- Check **SSL certificate** details (issuer, SANs) for hosting provider.
- Identify **CDN** (Cloudflare, Fastly, Akamai) from headers or asset URLs.

### 5. Mobile Backend Discovery
- If an iOS app exists:
  - Fetch the App Store page using `https://apps.apple.com/us/app/<app-name>/id<id>`
  - Extract **app ID**, **developer name**, **version history**, **IAP price tiers**
  - Extract the **top 10 one‑star reviews** (customer pain)
- If an Android app exists:
  - Fetch the Google Play page
  - Extract **package name**, **version**, **IAP tiers**, **reviews**
- Search for **mobile‑specific API endpoints** (e.g., `api-mobile.`, `mobile.`)

### 6. Social & Community Intelligence
- Search **Reddit** for the domain:
  - `r/dfsports`, `r/sportsbook`, `r/fantasyfootball`, `r/algobetting`
- Extract **10 sharpest complaints** with exact quotes and source links.
- Search **Discord** — look for public invite links on the website, join, observe public channels.
- Search **Twitter/X** for mentions and complaints.
- Search **GitHub** for:
  - `"domain.com"` — find leaked API keys, unofficial clients, reverse‑engineered code
  - `"domain.com/api"` — find public code samples

### 7. Data Supply Chain
- Look for attribution lines: "Data provided by...", "Powered by..."
- Search JavaScript for known vendor names:
  - `sportradar`, `statsperform`, `opta`, `geniussports`
  - `the-odds-api`, `odds-api`, `sportsdata.io`
  - `nflverse`, `nba_api`, `pybaseball`
- Check help center / FAQ for data source documentation.
- List every **external vendor** you can confirm.

### 8. Product Limits & Entitlements
- Look for upgrade boundaries on pricing pages:
  - "150 lineups per export", "50K simulations per slate", "10 sports"
- Check Terms of Service, FAQ, API docs for usage caps.
- Identify the **most restrictive** limit that triggers an upgrade.
- Map each feature to its required tier.

### 9. Job Postings (Tech Stack Inference)
- Check the company's **careers page**.
- Check **LinkedIn** job listings.
- Check **Greenhouse**, **Lever**, **Ashby** public boards.
- Extract: programming languages, frameworks, databases, cloud providers, model types.
- Infer their **future roadmap** from job titles (e.g., "Senior Quant — Monte Carlo Simulation").

### 10. GitHub Repository Analysis (If Found)
- If the target has a public GitHub org, **clone or fetch all repos**.
- Parse source code for:
  - Algorithm implementations (Monte Carlo, Bayesian, XGBoost)
  - Data pipelines and ETL logic
  - API clients and data fetchers
  - Configuration files (revealing dependencies)
- Identify the **primary algorithm** and **reusable logic**.
- Check the **license** for reuse potential.
