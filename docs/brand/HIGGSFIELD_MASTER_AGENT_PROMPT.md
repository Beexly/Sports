**Reference quality bar:** [unseen.co](https://unseen.co) — immersive, elegant, bold,
breathing room, easy navigation. Not crypto-noise, not sports-clipart, not 3D chrome.

**Mark system (geometry only):**
1. Open orbital ring (cyan stroke)
2. Single diagonal edge vector (ion white)
3. One plasma signal core (magenta) + soft UV halo
4. No mascot, no ball, no letterform inside the mark

**Wordmark:** GALAXY (ion white, tight track) + SPORTS EDGE (cyan, wider track). Exo 2 / geometric sans.

## Laws (hard)

1. Keep the **existing palette** — recolor only if founder asks.
2. Every asset must work on **dark UI** and pass contrast for nav (16px mark legible).
3. Generate for **every surface**: favicon, app icon, nav mark, wordmark, OG, PWA, social avatar, email header, loading splash.
4. Prefer **flat vector precision** over photoreal 3D for logos.
5. **Accountability:** ship variants + recommend 1 winner with reasons; export sizes checklist; do not stop after one pretty image.
6. No sports clichés. No lens flares. No busy backgrounds on logo plates.
7. GSE integrity: logo work never invents live board / PROVEN claims in marketing frames.

## Higgsfield execution protocol

1. `models_explore` for image; prefer high-res mark models (Nano Banana Pro / Seedream when text needed).
2. Generate **L1 mark first** (2–4 variants, same prompt family).
3. Pick winner by: edge clarity at 16px, palette fidelity, Unseen restraint, no accidental letterforms.
4. Derive L2–L9 from winner (img2img / edit / outpaint) — do not invent a second brand.
5. Optional: short logo reveal video from winner still.
6. Deliver: URLs + which file maps to which surface + SVG redraw recommendation if raster wins.
