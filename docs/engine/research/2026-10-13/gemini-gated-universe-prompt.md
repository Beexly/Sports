## Gate 2. MinHash false-merge. This gate is the point. Do not skip to formulas.

Open Broder 1997, On the resemblance and containment of documents, Sequence, pp. 21-29. PDF: https://www.cs.princeton.edu/courses/archive/spring13/cos598C/broder97resemblance.pdf DOI 10.1109/SEQUEN.1997.666900. If the PDF 404s, say so. Do not reconstruct Theorem 1 from a blog.

Print, as separate equation objects, only what that PDF prints:

- resemblance r_w(A, B) = |S(A, w) ∩ S(B, w)| / |S(A, w) ∪ S(B, w)|
- containment c_w(A, B) = |S(A, w) ∩ S(B, w)| / |S(A, w)|
- the min-s sketch. M(A) = MIN_s(π(S(A, w))). The unbiased estimate is |MIN_s(M(A) ∪ M(B)) ∩ M(A) ∩ M(B)| / |MIN_s(M(A) ∪ M(B))|.
- null case: empty shingle set. Denominator zero. Return null. Do not define resemblance as 1.

Then the false-merge, as a multi-step argument on those printed definitions. Do not add a theorem.

Step 1. Let P be a shared preamble, macro file, or copied related-work section. Let M1 and M2 be disjoint math spans. Document A = P ∪ M1. Document B = P ∪ M2.
Step 2. Substitute into the printed resemblance. r(A, B) = |P| / |P ∪ M1 ∪ M2|. Compute these two cases from that identity. Do not treat either number as a recommended threshold. Case A: |P| = 400, |M1| = |M2| = 50, so r = 400 / 500 = 0.8. An 0.8 rule merges two papers whose equation sets are disjoint. Case B: |P| = 2000, |M1| = |M2| = 500, so r = 2000 / 3000 = 0.67. A 0.5 rule merges them too. The estimator is unbiased for that number. It is not unbiased for "same paper."
Step 3. Name the false-merge: the sketch collides because the preamble dominates the shingle set. The math spans never enter the min-s sample if they sort above the preamble under π. Case C, containment: if A is the macro file and B is the paper, c(A, B) is near 1. Containment is the wrong merge key. It catches "v2 contains v1." It does not catch "same equations."
