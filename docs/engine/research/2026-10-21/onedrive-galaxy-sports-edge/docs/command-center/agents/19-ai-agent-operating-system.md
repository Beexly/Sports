# AI Agent Operating System

As of: 2026-06-09

Agents operate as read-first, evidence-first workers. They do not deploy, mutate production data, launch live affiliate links, expose methodology, or mark work complete without proof.

| Agent | Tools | Permissions | Cadence | Escalation |
| --- | --- | --- | --- | --- |
| Research Agent | source-led research, web when needed, docs synthesis | read-only | on demand | unknown or source conflict |
| Repo Auditor | repo truth, route inventory, git status | read-only | daily during launch | missing app clone |
| Data Accuracy Agent | roster/source canaries | read-only unless approved | daily/NFL change windows | conflicts/stale data |
| UX Agent | visual/IA/mobile review | route screenshots | weekly/prelaunch | mobile/accessibility fail |
| Copy Auditor | human/method-safe copy | docs/routes copy | prelaunch/release | fake certainty/method leakage |
| Growth Agent | funnels/lifecycle | analytics/copy only | weekly | billing/promotions approval |
| Promotions Compliance Agent | affiliate/promo safety | read-only until approval | before promo work | live link or legal uncertainty |
| Support Agent | support minimum | docs/templates | daily launch | harm/billing/legal issue |
| Content Agent | brief/articles/SEO | docs/content | weekly | unsupported claims |
| Analytics Agent | event contracts/dashboards | code/docs when approved | weekly | privacy concern |
| QA Agent | release gates | tests/screenshots | every release | test fail |
| DevOps Agent | CI/secrets/deploy/rollback | config only with approval | prelaunch | secret/deploy risk |
| Finance Agent | unit economics | docs/dashboards | weekly | unknown pricing/payout |
| Sales Agent | partners/enterprise | CRM docs only | weekly | legal promises |
| Legal/Compliance Agent | legal/promotions/responsible gambling | read-only/review | before risky launch | unapproved legal issue |
| Claude Handoff Agent | final verification/polish | real clone with approval | final pass | claim mismatch |
