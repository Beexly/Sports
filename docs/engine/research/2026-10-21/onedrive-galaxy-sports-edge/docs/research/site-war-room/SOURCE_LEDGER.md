# Source Ledger

As of: 2026-06-09

- web.dev Core Web Vitals: https://web.dev/articles/vitals - Performance must be judged by user-centric LCP/INP/CLS, not just aesthetic polish.
- web.dev INP: https://web.dev/inp/ - Responsiveness is a stable Core Web Vital and should target <=200ms at p75.
- W3C WCAG 2.2: https://www.w3.org/TR/WCAG22/ - Accessibility is a stable W3C standard; design must keep keyboard, focus, contrast, headings, and cognitive clarity.
- Apple Human Interface Guidelines - Motion: https://developer.apple.com/design/human-interface-guidelines/motion - Motion should convey status, feedback, instruction, and respect accessibility settings.
- Bloomberg UX: https://www.bloomberg.com/ux/ - Complex data products need interaction design, visualization, and prototyping discipline.
- Bloomberg Terminal UX story: https://www.bloomberg.com/company/stories/how-bloomberg-terminal-ux-designers-conceal-complexity/ - Advanced users need power, but complexity should be progressively exposed.
- ESPN navigation guide: https://www.espn.com/espn/news/story/_/id/5474529 - Sports users value fast personalization by sport/team/player.
- The Athletic App Store: https://apps.apple.com/us/app/the-athletic-all-sports-news/id1135216317 - Premium sports products sell follow-your-favorites and clean coverage.
- Webby 2025 winners: https://www.webbyawards.com/press/press-releases/29th-annual-webby-awards-announce-2025-winners/ - Award-winning web work rewards distinct voice, strong interaction, and memorable positioning.
- Awwwards: https://www.awwwards.com/ - Premium web design rewards craft, motion, typography, and distinct visual identity.
