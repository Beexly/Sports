# 10-Second Teachability System

As of: 2026-06-09

First 2 seconds: identify the surface.  
First 5 seconds: explain why it matters.  
First 10 seconds: give the next action and trust cue.

Every item gets:

- plain title
- one-sentence value
- what it means
- how to use it
- why it matters
- trust/source note
- best next action
- media slot
- glossary links
- mobile-safe summary
