## Buildable systems (component name, inputs→method→output, acceptance gate)

Prioritized for QB behavior, coaching/scheme, OL, trust signals, calibration, uncertainty, sizing.

**S1. Play-call equilibrium-deviation scanner** (0222 + 0282-Ötting pointer)
- Inputs: nflverse pbp (down, distance, field position, formation, play type run/pass/PA), per team-season.
- Method: fit low-cardinality (≤I-atom) equilibrium-structured latent mixture for play-type given game state; compare empirical (down, distance, FP) mix vs Nash mix with Bonferroni-corrected deviation tests per team.
- Output: per-team deviation statistics + predictability scores (run/pass given state), feeding the coaching-tendency program and defensive game-plan priors.
- Gate: ≥0.005 nats log-loss improvement over logistic baseline on 2025 holdout AND ≥3 teams with significant equilibrium deviations. Do not build the CAMS differential-game machinery.

**S2. Sparse matchup imputation engine (GLMF)** (0068)
- Inputs: sparse binomial matchup matrices (receiver×defense completions/targets; QB×defense; OL×DL pressure rates) + normal marginal aggregates (offense/defense team stats).
- Method: reimplement GLMF from Li & Gaynanova (2018) (not the garbled PDF equations) with ridge regularization; alternating IRLS, rank selected by CV.
- Output: imputed matchup probabilities for thin head-to-head histories (rookie QBs, new WR–QB pairs — the JOI unseen-pair problem class).
- Gate: beat GSE's current shrinkage prior on time-ordered holdout log-likelihood; rank-monotonicity must hold (performance improves with rank). INFERENCE: pairs naturally with S5 as a feature source.

**S3. Totals weather mediation decomposer** (0272)
- Inputs: nflverse pbp 2015–2025 + stadium weather (wind speed), with game-script controls.
- Method: medshift (open-source R) — decompose wind's effect on total points into direct (physics) vs indirect (mediated by deep-pass rate, pace) via exponential-tilt stochastic interventions at δ=5, 10 mph.
- Output: per-game (direct_effect, indirect_effect, se) feeding the totals-model weather adjustment: QB-behavior lane consumes the mediated path, totals model consumes both.
- Gate: PIIE at δ=10 mph significant at 5% with expected sign, sum matches naive total-effect sign, holdout (2023–2024) sign stability, A3 defensible after game-script controls. Expect a possible null — the null resolves the d34 wind DARK either way.

**S4. Nested score-state sampler** (0242)
- Inputs: favorite strength (Elo/spread), location, realized favorite score; nflverse game-level scoring data.
- Method: two-stage sampler — favorite's score distribution, then underdog's scoring mean conditional on realized favorite score (log μ_B|A with β₃·G_A term); single joint fit (replace the paper's ad hoc averaging).
- Output: underdog score distribution / exact-score probabilities for the simulation stack.
- Gate: β₃ ≠ 0 AND nested sampler beats independent-Poisson exact-score log-loss by ≥0.5% out-of-sample. Run jointly with the d22 kneel-out adjustment (favorite-side attempt deletion).

**S5. flexBART categorical tabular stack** (0232)
- Inputs: GSE tabular tasks with high-cardinality categoricals (team ID, QB ID, coach ID, referee crew ID, formation, coverage shell).
- Method: flexBART multi-level split prior (R package) as drop-in vs XGBoost; ≥4 chains, R-hat < 1.05; DGP2-style singleton-outlier diagnostic on every fit.
- Output: posterior predictive distributions + 80%/90% intervals (uncertainty contract for downstream sizing).
- Gate: ≥3% out-of-sample RMSE improvement on 2024 holdout AND interval coverage within ±3pp of nominal. Benchmark verdict, not a pre-adoption.

**S6. EV-threshold policy engine** (0176)

- Output: deployed static θ for the bet-selection layer + a measured NFL line-shopping uplift band (the EPL 42–296% is the hypothesis, not the hurdle).

## Integration notes

For a unified intelligence API tying qb-behavior + coaching + trust-signals + reasoning into one callable interface:

1. **Play-keyed join schema.** 0202's Remember tier keyed on play boundaries (down/distance/formation/outcome) + 0262's warehouse landings on (game_id, play_id) + 0332's (game_id, play_id, timestamp, confidence) emission shape → every module's output is keyed on **(game_id, play_id)** with evidence pointers (frame spans, box coords, source file:line). Video, tracking, and tabular lanes join there; nothing joins on wall-clock time alone.

2. **Ordered dependency OL → scheme → QB.** The chunk supports this ordering directly: OL/availability first (0098 conditioning/non-conditioning injury taxonomy → weekly availability features; 0068 OL-vs-DL pressure-rate matchup matrices; 0232 crew/coach categoricals) → scheme context (S1 play-call equilibrium priors; S4 nested score-state sampler) → QB behavior conditional on scheme (S2 QB×defense matchup imputation; EHCP-style decision grades from map #3). The API should evaluate in this order and expose intermediate states, so a scheme change (e.g., OL out → heavier blitz expectation) propagates to QB outputs deterministically.

3. **Uncertainty is the cross-module contract.** S5's posterior-interval gate (coverage within ±3pp), S3's Wald CIs, S4's full predictive distributions → modules return **distributions/draws, never point estimates**. Downstream sizing consumes the δ/σ gate (map #15) on the probability-estimation RMSE. Any module that can't state its uncertainty is shadow-only (per Garrett's honest calibration-state labeling).

4. **Mediation-aware adjustment layer.** S3 provides the causal-split contract: (game_id, variable_delta) → (direct_effect, indirect_effect, se). The adjustment layer stores both paths so the QB-behavior module consumes only the mediated path (how wind changes play-calling changes QB decisions) while the totals model consumes both. This generalizes beyond weather (crowd noise → false starts → scoring; injuries → play-calling → EPA) and is the one genuinely new capability in the chunk (map notes no mediation analysis in the 468-file corpus).

5. **Regime quarantine wraps the API.** S9's ITS harness runs on every module's backtest residuals at known regime dates before promotion; the map's as-of quarantine ruler (d32) prevents post-settlement leakage into features. Together: no module ships without (a) leakage-free features and (b) a regime-break screen. This is the CI gate for the intelligence API.

6. **Staged contracts with acceptance gates (the 0118 pattern).** Each module declares typed inputs/outputs/acceptance gate enforced by schema validation — the ResearchPilot pattern with the ledger's fixes (full-text fidelity, citation-verification: every emitted number carries a source pointer, provider fallbacks). This deep analysis applied the same discipline (every claim above carries a `source:line`); the API should enforce it at runtime for module outputs.

7. **Simulation harness for sizing.** S7 (NFL-BBE) gives the API a synthetic live-market environment: every sizing/betting module gets stress-tested on synthetic tapes before touching real data, and the RP(d) sweep yields a per-module edge-half-life (the market sharpness at which the edge vanishes). S6's θ policy and the map's Kelly stack (0791→0813→0834→1748→1463) consume S7's output as their adversarial test bed.

8. **Decision-metric alignment end to end.** 0176 §6(vi) + map 0791: optimize on realized profit/CLV, never on ROI/CRPS/accuracy proxies. The API's module-selection and promotion logic should score on the decision metric (CLV/P&L on walk-forward) with equal-weight baselines kept as the free comparator.

9. **Trust-signal gap is real and unfilled by this chunk.** The map's gap #1 (no social/video quote mining, no QB-receiver public trust dynamics) has no counterpart in c09-d00..d05. The closest in-chunk material: 0202's evidence-grounded reasoner (timestamp/box-grounded answers — the right *retrieval* substrate for press-conference/video quote mining) and 0332's denoiser (the right *timestamping* tool for finding trust-relevant moments in video). INFERENCE: the trust-signal module should be specified as 0202-retrieval + 0332-timestamping over press-conference/interview video, but it is a new build, not an adaptation of anything here.
