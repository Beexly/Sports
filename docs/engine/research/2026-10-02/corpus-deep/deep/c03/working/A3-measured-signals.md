## Ready-vs-directional classification

### READY — measured, replicable from nflverse, can become engine features now

1. **S3 — Rest-differential schedule features (0677).** All inputs (schedule, days-rest bins MNF/Mini/Bye, opening/closing spreads) are computable from nflverse + odds data. Sample is large (5,679 games, 22 seasons). Replication gate already specified (post-2011 bye PD < 1.0 with market pricing ≥0.5 above it; market currently prices +0.97 vs measured +0.31). This is the slice's most directly monetizable coaching/schedule signal.
2. **S4 — Complementary-football drive features (0678).** Prev-drive turnover + turnover×field-position are native nflverse pbp fields; ordinal-drive-EP model refit on 2015–2024 is ~3 days. Gate: GS+SoS+Complem MAE beats SoS-only with non-overlapping SE in ≥4 of 10 seasons.
3. **S1 — Fourth-down τ estimand (1575).** Fully replicable from nflverse; reproduction code public (R). This is not a single number — it is an estimand (τ per coach-team × field region × WP bin) with 200-bootstrap CIs. Caution: the 2014–2022 aggression trend means a 2022-fitted τ̂ systematically underrates 2026 aggression; refit on current seasons before serving as a feature.
4. **S5/S6/S7 — Paganetti situational splits.** Computable directly from nflverse pbp (down, distance, previous-play outcome). League-level rates are stable and engine-usable as priors; team-level splits need rolling multi-season samples (current n=2–16 plays/team are directional only).

## Replication notes — top 5

### R1. 1575 τ estimand — replication bar
- Pull nflverse pbp 2014–2025; build 4th-down state grid (yardline bin × yards-to-go); empirical transitions p̂(s′|σ,a), augment GO transitions with 3rd-down plays (Romer-2006, counters Daly-Grafstein selection bias); value function via Chan–Fernandes–Puterman infinite-horizon approximation; τ-quantile decision maps for τ∈{0.2,…,0.8} with SCAM-style monotonic smoothing; per-team-season-region τ̂ via Hamming-loss inverse problem (Eq. 5.5), 200 game-level bootstraps.
- **Pass gate:** 2024–2025 backtest — team-specific τ̂ rule beats risk-neutral WP-max rule on Hamming accuracy of actual GO/FGA/PUNT calls by ≥3pp in the opponent half (where coach variation is largest).
- **Known trap:** τ-optimal policies plateau outside [0.2,0.8] (underidentified extremes); L≥3 field partitions underidentified with |A|=3 — keep the own-half/opponent-half 2-partition. Refit yearly: stale τ̂ underrates the documented aggression trend.

### R2. 0677 anti-bye — replication bar
- Rebuild Models 2/4 (or logistic ATS equivalents) on nflverse 2015–2024 with the paper's exact category definitions (MNF: ≥1-day diff with disadvantaged team ≤6 days rest; Mini: 9–11 days rest with ≥2-day diff; Bye: did not play prior week), ±1 home/away symmetric; compare to paper's Stan reference (github.com/ThompsonJamesBliss/restadvantageinamerfootball).
- **Pass gate:** post-2011 bye PD estimate within the paper's CI (0.31, CI −1.01–1.64) AND market bye pricing ≥0.5 pts above measured reality → anti-bye fade live. If the market has corrected (pricing ≈ reality), keep the features, drop the fade.
- **Coaching prep vs rest:** the structural break is at the 2011 CBA *practice* elimination; pure-rest categories (mini-bye +0.48, MNF +0.14, both n.s.) show no comparable effect — evidence leans coaching-prep/practice-time, not physical rest. Caveat: 2020 CBA Thursday-practice limits may be eroding the mini-bye further; re-estimate per-CBA-era.

### R3. 0678 complementary features — replication bar
- nflverse pbp 2015–2024; 5-category ordinal drive model (def TD −7 / safety −2 / no score 0 / FG 3 / TD 7); unpenalized team SoS margins; penalized complementary features: prev-drive non-scoring turnover indicator + turnover×starting-position interaction + non-proportional "≥FG" boost; 10-fold CV × replicates; metric = drive-EP MAE + FG-category calibration slope.
- **Pass gate:** GS+SoS+Complem MAE lower than GS+SoS with non-overlapping SE bars in ≥4 of 10 seasons; FG calibration slope ∈ [0.9,1.1]; baseline to beat: nflfastR EP.
- **Trap:** drive-level MAE gains in the paper are shown graphically (Figure 5) without tabulated numbers — the paper's own effect size is not precisely quotable; GSE's replication must tabulate its own. Adjacent drives in the same game can split across CV folds (mild in-sample leakage) — use game-level fold blocking as the stricter variant.

### R4. Paganetti situational splits — replication bar
- Recompute from nflverse pbp 2017–2026: 2nd-&-1 pass rate by season; after-1st&10-run-5+ pass rate by team-season; after-incompletion run rate by team-season; "normal situations only" filters.
- **Pass gate:** 2026 league 2nd-&-1 pass rate (32.7% thru Wk3) vs GSE's recomputation within ±2pp on matched filters; team-level splits stable (|r| rank correlation ≥0.5) across split-half seasons before any team-level feature use.
- **Caution:** the headline 32.7% is 3 games of 2026 — early-season regime; the CAR 87.5% (7/8) / NYJ 0.0% (0/6) extremes are n≤16. These are *tendency priors with explicit small-sample flags*, not features, until rolling rates exist. Also note the map mislabels this "week-2" — the source CSV is through Week 3.

### R5. 1638 NFL port — replication bar (template, not the number)
- **What "aggressive opening tactics" actually is:** the paper's initial-scheme *offensiveness index* — formation aggressiveness at kickoff (defenders×1 + midfielders×2 + forwards×3, range 10–30), inferred per minute from on-pitch player roles coded from match commentary. "Aggressive opening" = high index at t=0. Marginal effect +9.44–16.17pp win probability (BCa CI, evaluated at the mean), home teams, Serie A 2011–2014.
- **Paper's own reproduction bar** (ledger §12): initial-scheme coeff ≈0.30 (OLS), ≈0.54 (logit), all p<0.001; Brant p≈0.76; Model 2 accuracy ≈0.75; model averaging over 393/317/107 specs confirms.
- **NFL port bar:** build per-game coaching-aggressiveness indices from nflverse pbp — early-down PROE (pass rate over expectation), 4th-down go-rate vs WP model, blitz rate — initial (Q1 game plan) vs final (Q4 adjustments), the analog of the paper's t=0/t=90. Fit the triple-outcome panel (OLS on point diff; logit on win; ordered logit on cover/margin buckets) with team + season fixed effects, referee-crew penalty variables, stadium/dome controls; AIC/BIC subset search + Akaike-weight model averaging + BCa bootstrap CIs.
- **Gate:** the aggressiveness index must show a stable positive sign across ALL THREE outcome models with BCa CIs excluding zero on 2020–2024 NFL data. If the sign flips between OLS and logit, the effect is outcome-definition fragile — report as descriptive only. Report the coach-selection endogeneity caveat; prefer within-coach variation (coordinator changes) for causal claims. The 9.44–16.17pp number never crosses from Serie A into the NFL model.
