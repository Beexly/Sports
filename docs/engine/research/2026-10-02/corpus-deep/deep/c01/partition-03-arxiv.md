The genuinely NFL-transferable core is smaller than the map's enthusiasm suggests — roughly 20 papers earn their gates, ~15 more are useful components, and the rest are theory, other sports, or integrity-flagged.

**Reading key:** "Verified vs source" = spot-checked against the paper's own ledger text in the vendor repo. "Verified vs brief" = full brief read, internally consistent, math plausible, no source-level check. INFERENCE tags mark my own compositional reasoning.

## 2. Syntheses

Composed systems from papers that never met each other. INFERENCE throughout — none of these compositions are proposed by the papers.

1. **GSE Tri-Layer Ratings** = 1449 (LS cardinal LSE with N⁺ standard errors, λ₂ connectivity diagnostic, home-covariate gate) + 0425 (OpenSkill Plackett-Luce as the fast weekly update engine, σ as uncertainty feature) + 0495 (hierarchical Bayesian log5 for unit-vs-unit matchups: QB vs defense, OL vs DL, with per-matchup-type learned decay). INFERENCE: each layer answers a question the others can't — LS gives the identifiability theory and honest SEs, OpenSkill gives production runtime, log5 gives the matchup decomposition. The λ₂ diagnostic gates when early-season ratings are trustworthy; the Thm-4.3 home-covariate check is non-negotiable given the NFL schedule.
2. **Minerva-Seal Validation Pipeline** = 2048 (Seal = 1[DSR≥0.95 ∧ PBO≤0.50 ∧ SPA≤0.10 ∧ T≥MinTRL ∧ ρ≥0.60], fail-closed) + 1184 (D/S/I audit so the metric being sealed is worth measuring) + a sports sixth gate the ledger proposes (edge must survive residualization against closing-line movement — statistical robustness ≠ economic edge). Every mined signal (QB behavior, coaching, OL, scheme) needs the Seal before production entry.
3. **Full-Distribution Calibration Stack** = 1074 (ENIR binary calibration, ≥15% ECE reduction gate) + 1642 (SPCI residual-QRF intervals, ≤85% of EnbPI width at ±2pp coverage) + 0675 (Bayesian in-game WP updating with (τ,ω) regime parameters). Point probs → calibrated probs → conditional intervals → in-game updating: one pipeline from pre-game to whistle.
4. **The Robust Payout Machine** = 0435 (pay-out-by-market-class selection doctrine — report correct-pick breakdown by favorite/underdog/pick'em + flat-stake pay-out, select on expected pay-out not accuracy) + 0445 Phase A (market-calibration recipe: fit team strengths to The Odds API consensus via eq.-13 analog, totals market fixes identifiability) + 1214/0626 (distributionally-robust / uncertainty-aware Kelly sizing) + 0445 Phase C (EV-threshold plot as the pick-filter diagnostic; reject profitability claims on <300 games or without the stale-price control). Selection → calibration → sizing → filtering, all dollar-denominated.
5. **The Conditional-Prop Engine** = 0912 (receiver-conditional decomposition P(TD)=ΣₜP(TD|target=t)·P(target=t) — train target-distribution and conditional models, marginalize) + 0858 (beat-writer text embeddings stacked with engine + market probs; gate on reproducing the ≥7pp text-ablation drop) + 1815 (fractional tackles as the reliable IDP/tackle-prop feature: split-half 0.69 vs 0.59) + 1563 (age-conditioned rest effects via X-learner + honest-RF). Props get their own pipeline with prop-specific features, not game-model leftovers.
6. **Disciplined Post/Bet Gate** = 1154 (exact-coverage abstention — calibrate τ̂_c as the empirical c-quantile of engine edge on a rolling window, post only risk < τ̂_c; adaptive c_w per slate quality) + 0445 EV-threshold diagnostic + 0435 confidence-threshold doctrine. This is the operational answer to "how many picks do we post each week": a fixed coverage target with exact calibration, not vibes.

## 3. Challenges

Blunt assessments. The briefs are mostly honest; the failures below are in the papers, the gates, or the NFL transfer.

**Strong rejects (no GSE lane):**
- **0525 Inference-time Nash alignment** — pure LLM inference-time alignment theory (BoN/NMD duality-gap bounds). Zero sports content, zero mapping onto any engine component. The strongest reject in the partition: impressive mathematics, absolutely nothing for GSE. `reader-cleanup/0525_inferencetime_nash_alignment.brief.md`
- **1310 LLM-SoccerArena** — LLM benchmark theater (win-probability elicitation from language models); no edge mechanism, no NFL transfer. Rejected in-file.
- **0475 functional time series / 0485 predictive density (finance) / 1194 seasonal linear** — pure theory papers with no sports application or data.
- **0354 FST.ai taekwondo** — every number explicitly illustrative; a demo, not an evaluation.
- **0254 Pythagorean derivation** — the author's own admission: football seasons are too short for the derivation to apply. Self-rejecting.
- **0404 functional ratings** — zero predictive validation; a framework with no backtest.
- **0344 UTAL-GNN** — unsupervised claim undermined by supervised model selection; the "unsupervised" framing collapses on inspection.
- **1517 Labouchere** — the only correct takeaway is "don't use progression systems." Guardrail, not a paper.
- **0100 Bayesian soccer Poisson** — soccer-only, proprietary data, and the proper scoring rule *favored the baseline* (log-likelihood −163.1 vs −159.6); the £4,486 betting claim rests on an undisclosed strategy. Rejected in-file.

**Overclaimed or non-transferring gates:**
- **0495's betting claims** — brief correctly reports them, but the paper's own 90% CI ([−21%,+48%]) includes negative and +128% ROI is 2 bets. Keep the method and the recency-vs-decision-WPA dissociation; throw away the profitability narrative. Flag: NUTS on ~2,000-play windows per unit is the real cost — budget 2–4 weeks.
- **2048's forward-predictability** — the Seal is an audit grade, not an edge. The paper's own pre-registered test (Spearman 0.013, p=0.40) says scores don't predict forward returns. Anyone wiring the Seal to stake sizing is making a category error.
- **0749 temporal-conformal** — integrity flag: the abstract's near-nominal coverage claim contradicts the paper's own tables (0.86–0.88 actual). Do not trust the abstract; the method needs re-evaluation from the tables.
- **0505 volleyball event graphs** — identical scores across college/pro splits (GCN set accuracy 59.10 twice; Graph Transformer rally 81.15 twice) smell like reporting errors or leakage; no temporal split methodology stated. The temporal-graph encoding is a fine idea; the numbers are uninterpretable.
- **0836 Kelly-VIX** — in-sample (2018–2024) and out-of-sample (2024) windows overlap. Mild leakage; treat results as hypothesis-generating.
- **0858 Exp 2** — random 80/20 split, not temporal; the draw/longshot numbers are optimistic by the brief's own admission. The ≥7pp text-ablation drop (from the temporal experiments) is the number that matters.
- **1214 robust Kelly** — the only numbers are a synthetic horse-race illustration. The convex machinery is real (Sun & Boyd 2018) but GSE has no empirical robust-Kelly result; radii are illustration-only with no selection rule. Build the Π-radius selection rule from GSE calibration residuals *before* claiming any sizing benefit.
- **0304 odds-fusion** — the fused model was slightly *worse* than de-vigged odds on mean probability. The lesson is "don't fuse" — valuable as a negative result, not a build.
- **2082/2092 AI-scientist loops** — the authors explicitly warn: silent misimplementation of ideas, hallucinated ablations, weak novelty operators, and runaway-process safety failures. The overnight-discovery-loop architecture is worth the blueprint; the reviewer-as-judge gate is not production-grade.
- **0435's evidence base** — 2016 lines, single season per league, flat-$100 strawman staking, hindsight "entry timing." The accuracy≠pay-out dissociation replicates across all three leagues and is robust; the specific dollar figures are era artifacts. Adopt the doctrine and re-run it on 2020–2025.

## 4. Buildable systems

Ranked by expected ROI per unit engineering effort. Each entry: computation, inputs, acceptance gate (from the brief), file ref.

1. **Pay-out-by-market-class selection doctrine (0435)** — Computation: 3–4 days; diagnostic harness + pay-out-weighted training objective + confidence-threshold backtest. Inputs: 2020–2025 closing money lines (The Odds API), engine historical probs. Gate: pay-out-optimized variant beats accuracy-optimized variant by ≥$500/season at flat $100 stakes (or ≥2pp ROI) on 2024–2025 holdout, gains concentrated in underdog/pick'em hits. `briefs/c01/reader-04/0435_wages_of_wins_could_an_amateur.brief.md`
2. **Minerva-Seal validation gate (2048)** — Computation: 1–2 weeks, pure statistics. Inputs: per-signal backtest return series, trial counts (log every evaluation including pruned ones), season-phase window Sharpes. Gate: on permuted-label nulls, sports MinervaScore AUROC ≥0.95 separating nulls from historically-profitable signals AND Seal pass rate on nulls ≤5%; sports sixth gate: edge survives residualization against closing-line movement. Seal (≥80, all gates) required for production entry. `briefs/c01/reader-17/2048_minervascore_backtest_robustness_grade.brief.md`
3. **Exact-coverage abstention post-processing (1154)** — Computation: 1–2 days; quantile/binary-search γ on a rolling calibration window, applied on top of existing engine scores. Inputs: engine scores + realized outcomes on trailing window. Gate: realized coverage within ±0.05 of target c across ≥3 consecutive weeks AND selective ROI ≥ fixed-threshold baseline; REJECT the partial/interval machinery. `briefs/c01/reader-21/1154_bounded_abstention_multi_horizon_forecasting.brief.md`
4. **Receiver-conditional TD decomposition (0912)** — Computation: ~1 week. Inputs: nflverse play data, pre-snap/matchup features (target model) + coverage/separation features (conditional TD model). Gate: ≥5% holdout log-loss improvement over the tabular gradient-boosting baseline on 2025 plays (paired bootstrap, p<0.05); adopt decomposition alone if only it wins. `briefs/c01/reader-17/0912_tacticai_ai_assistant_football_tactics.brief.md`
5. **OpenSkill Plackett-Luce team ratings (0425)** — Computation: 1 day prototype, 2–3 days productionize. Inputs: NFL scores 2000–2025 (nflverse). Gate: within 0.002 log-loss of house Elo on the 2020–2024 walk-forward AND full 2000–2025 weekly backtest in <50% of the Elo pipeline's wall-clock; improvement experiment: score-differential-aware updates + snap-share contribution weighting. `briefs/c01/reader-04/0425_openskill_a_faster_asymmetric_multiteam_multiplayer.brief.md`
6. **ENIR calibration layer (1074)** — Computation: 2–3 days; mPAVA + BIC-weighted near-isotonic ensemble as post-hoc calibration on engine raw probs per market, fit weekly on trailing window, O(N log N). Inputs: engine predicted probs + outcomes per market 2020–2025. Gate: ≥15% lower ECE than the best of {IsoRegC, temperature scaling} on time-ordered 2025 holdout with zero AUC degradation (any ΔAUC<0 is a hard fail); replace in-sample BIC weights with out-of-fold log-loss weights. `briefs/c01/reader-19/1074_binary_classifier_calibration_enir.brief.md`
7. **Hierarchical Bayesian log5 unit matchups (0495)** — Computation: 2–4 weeks; NUTS (PyMC) on ~2,000-play trailing windows per unit. Inputs: nflverse 2015–2024 play data; QB vs defensive unit + OL vs DL; scheme-matchup offsets replace handedness. Gate: PBR-style model (unit matchups + recency) shows ≥0.5% relative GMP improvement over baseline AND ≥0.1 added wins/season in the decision simulation; report predictive GMP + simulated added wins for every candidate feature (dual-metric reporting as a standing gate). `briefs/c01/reader-cleanup/0495_the_impacts_of_increasingly_complex_matchup.brief.md`
8. **Market-calibration recipe, Phase A (0445)** — Computation: ~1 week. Inputs: The Odds API kickoff consensus (moneyline/spread/total-implied probs), engine team strengths.
