# No-Claim Rules

## Banned claims
- No win-rate claims
- No ROI claims
- No accuracy claims
- No hit-rate claims
- No “edge” or “guaranteed beat” phrasing
- No bettor outcome claims based on this current backtest state

## Allowed positioning
- Process rigor and decision quality framing
- Transparency in data provenance and uncertainty
- Educational framing on risk, staking discipline, and review cadence
- Waitlist-first invitation language (“audience-limited founder lane,” “review-first”)

## Required disclaimers
Every offer or email surface in this PR1 set must include:
- "No performance guarantee"
- "Backtest truth currently does not show model edge over naive baseline"
- "No automated profit promises"
- "You remain responsible for your own decisions"

## Review checklist
- [ ] Contains explicit backtest truth where relevant
- [ ] Does not include win-rate / ROI / edge wording
- [ ] No pick performance metrics in subject, hero, CTA, or CTA body
- [ ] No implied guarantees in follow-up automation
- [ ] Owner approval required before any external send

## Owner gates
- [ ] No external messaging without explicit approval
- [ ] No pricing/Stripe/live checkout changes in code
- [ ] No sportsbook/affiliate framing
- [ ] No auto-publish or auto-send paths
- [ ] Keep Adult/Wholesome firewall boundary intact
