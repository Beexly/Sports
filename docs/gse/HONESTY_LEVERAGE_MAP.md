# GSE Honesty Leverage Map

**Issued:** 2026-07-30 · **Status:** living · **Rule:** a silent fence is a weakness; a documented fence is a product claim.

This file turns every parked item, rights fence, and founder bottleneck into:
1. a **public-facing claim** users (and hostile experts) can verify,
2. a **pre-built unlock contract** so activation is config/counsel, not a rewrite,
3. a **parallel cleared path** so work continues while the fence holds.

Fences remain absolute. This document does not authorize crossing them.

---

## Operating formula

```
Constraint
  → Document why (hostile-expert readable)
  → Pre-build unlock contract (adapter / brief / checklist)
  → Market the refusal as a verifiable claim
  → Parallel work on cleared path (unlock becomes config, not rewrite)
```

---
