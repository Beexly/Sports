# Disclosure Copy — the canonical "real vs preview" language

> Single source of truth for how every fantasy surface describes what's real vs. preview, so
> the `/launch` page, the tool `note`s, the pricing card, and any social copy all match.
> Doctrine: **we never present illustrative data as live, and we never fabricate ADP.**
> All copy here is trust-gate-safe (no "guaranteed / lock / risk-free / winners" language).

## One-liner (use everywhere)
> Real, cleared data — never fabricated. What's not live yet is clearly labelled "preview."

## Real now (live, cleared, attributed)
- **Draft Assistant** — VOR, tiers, positional scarcity, run alerts, and your-own-ADP overlay.
- **Best Ball** — roster ceiling/spike, QB-stack correlation, bye fragility, and what to draft next.
- **Read-only league sync (Sleeper)** — bring your real roster; no writes, no autonomous moves.
- Data source + freshness are shown on the projections badge: "Live · refreshed Xh ago ·
  Data via nflverse (CC-BY-4.0)."

## Preview / coming (clearly labelled — NOT paywalled as live)
- **Start-Sit, Waivers/FAAB, Trade** need forward weekly projections. We're building our own
  from cleared nflverse data and **will publish it with its own calibration before it goes
  live**. Until then these run on a clearly-labelled illustrative pool.
- Any derived draft rank is labelled **"market/usage rank," never "ADP"** unless a real ADP
  source is present (e.g. the user's own imported CSV).

## Data-source attribution lines
- nflverse-derived projections/metrics: **"Data via nflverse (CC-BY-4.0)."**
- Sleeper facts (when surfaced): **"Player movement data via the Sleeper API."** (Sleeper is
  enrichment only — facts, attributed — never the sole basis of a paid feature; no logos/headshots.)

## Why we say it (the wedge)
A tool on fabricated data isn't worth paying for. Leading with the honest line — what's real,
what's preview, where the data comes from — is the brand. It's the same standard as the picks
product: proof over promises.

## Banned in all fantasy copy (per `trust-gate.mjs`)
"guaranteed," "lock"/"lock of the day," "risk-free," "free money," "winners"/"winning record,"
"sure thing," "AI picks." Sell decision quality + real data, never a certainty claim.
