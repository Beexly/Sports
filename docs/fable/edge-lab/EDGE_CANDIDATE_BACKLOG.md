# Edge Candidate Backlog

Each candidate must define:
- hypothesis
- why incumbents may miss it
- source type
- data required
- legal/TOS risk
- cost to test
- metric affected
- expected improvement
- minimum detectable effect
- sample size needed
- overfit risk
- measurement method
- falsification rule
- decision

Backlog source:
- `MICRO_EDGE_HARVEST_LEDGER.md`

Default expected improvement:
- Unknown until replayed.

Default cost:
- Zero for fixture/local tests.
- Owner decision required for paid feeds.
