# Claim Risk Red Flags

High-risk language must be downgraded unless evidence exists:
- unsupported term: legal cleared
- unsupported term: guaranteed
- unsupported term: lock
- unsupported term: free money
- unsupported term: superior edge
- unsupported term: parity+
- unsupported term: production-ready
- unsupported term: .5+ gain
- unsupported term: green tests
- unsupported term: official NGS
- unsupported term: Ground Truth configured
- unsupported term: AWS deployed

The scanner allows these only when the line marks them historical, unverified, unsupported, blocked, false, or evidence-tied.
