# Demo Data Dictionary

| Field | Meaning |
| --- | --- |
| fixture_id | Stable id for the fixture-only demo. |
| source_id | Source registry id used for legal posture. |
| source_freshness | Fixture text describing freshness posture. |
| market_open_probability | Synthetic market-open probability. |
| current_model_probability | Synthetic current model probability. |
| event_timestamp | Synthetic event time. |
| features | Derived fixture features used by the forensic report. |

The fixture is deliberately small so it can be reviewed in GitHub.
