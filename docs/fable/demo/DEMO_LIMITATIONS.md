# Demo Limitations

This demo does not prove:
- betting edge
- prediction superiority
- live data freshness
- official tracking-data access
- model calibration improvement
- legal clearance beyond source-registry posture
- data rights for any new live source
- production deployment

It proves only that the repo has a reproducible forensic-report shape and a fixture-safe demo command.

The demo uses:
- no network
- no scraping
- no proprietary data
- no keys
- no paid provider call

The demo can be extended only by adding reviewed fixtures, source-rights evidence, and a falsification rule.
