# SageMaker MLOps Ladder

Official references:
- https://docs.aws.amazon.com/sagemaker/latest/dg/model-registry.html
- https://docs.aws.amazon.com/sagemaker/latest/dg/pipelines.html
- https://docs.aws.amazon.com/sagemaker/latest/dg/model-cards.html

Ladder:
1. Local model card docs that mirror SageMaker Model Cards fields.
2. Local replay and calibration reports with sample counts and windows.
3. Owner-approved ML runtime decision.
4. Model artifact policy.
5. Model registry design.
6. Pipeline design.
7. Endpoint or batch inference decision.

Current state:
- Steps 1 and 2 are documentation patterns only.
- No SageMaker resources are configured.
- No endpoint or training job exists.
