# AWS Sports Case Study Contrast

Official AWS examples reviewed:
- NFL Next Gen Stats: https://aws.amazon.com/sports/nfl/
- NFL Big Data Bowl: https://aws.amazon.com/sports/nfl-big-data-bowl/
- F1 Insights: https://aws.amazon.com/sports/f1/
- Bundesliga Match Facts: https://aws.amazon.com/sports/bundesliga/
- NHL EDGE IQ references: https://aws.amazon.com/sports/

Contrast for this repo:
- AWS examples rely on official, licensed, or partner-controlled datasets.
- This repo must continue to treat source rights as the gating layer.
- AWS examples show product patterns, not rights grants for BeeXly/Sports.
- The useful lesson is operational rigor: lineage, monitoring, model documentation, and clear feature explanations.
