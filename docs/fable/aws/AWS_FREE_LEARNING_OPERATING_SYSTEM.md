# AWS Free Learning Operating System

Updated: 2026-07-03

This is a no-cost learning-to-output system for AWS work in GSE/FABLE.

## Weekly Loop

1. Pick one AWS learning area.
2. Write one public-safe learning summary.
3. Map it to one GSE/FABLE system.
4. Improve one guardrail, matrix, or mock plan.
5. Run local validation.
6. Add the result to the learning evidence queue only after public-safe review.

## Learning Tracks

| Track | Repo output | Why it matters |
| --- | --- | --- |
| storage | S3 mock policy and retention plan | avoids unsafe source-data storage |
| compute | local replay versus hosted compute decision | avoids premature paid compute |
| networking | blast-radius and exposure diagrams | avoids accidental public surfaces |
| databases | RDS/Aurora rejection or adoption criteria | avoids unnecessary migration |
| operations/cost | budget, anomaly, and kill-switch templates | avoids runaway spend |
| IAM/security | fake policy review tests | avoids overbroad permissions |
| Amplify | preview-only workflow | avoids production host drift |
| Bedrock/AgentCore | fake-agent permission lab | avoids paid calls and tool overreach |
| SageMaker | local model-card and artifact ladder | avoids hosted ML before proof |
| Clean Rooms | synthetic partner scenario | avoids raw partner-data exchange |

## Public Proof Ladder

| Level | Proof | Repo status |
| --- | --- | --- |
| 0 | learning planned | safe as roadmap |
| 1 | learning summary | safe if no personal data |
| 2 | course or badge name | safe if not overstated |
| 3 | approved screenshot path | safe after redaction |
| 4 | public badge URL | safe after owner approval |

## Output Rule

Learning is useful to GSE/FABLE only when it produces one of:
- a better architecture decision.
- a safer cost/security gate.
- a better partner explanation.
- a no-cost mock plan.
- a clearer public portfolio artifact.
- a better rejection rule.
