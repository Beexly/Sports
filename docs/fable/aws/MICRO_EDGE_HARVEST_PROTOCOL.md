# Micro Edge Harvest Protocol

Purpose:
- Capture small, testable football feature hypotheses without claiming validated performance.

Protocol:
1. Name the feature.
2. List source ids and rights status.
3. Link derivation code.
4. Define expected direction.
5. Run replay or fixture validation.
6. Record sample count and metric.
7. Promote only if the report supports it.

AWS role:
- None by default.
- Future AWS storage or training must pass source rights and cost gates.
