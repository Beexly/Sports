## What Would Make An Incumbent Notice

- a public repo with executable evidence gates.
- fixture demos that clearly say what is and is not proven.
- a service scorecard that rejects expensive AWS paths until local proof exists.
- agent governance that refuses spend, deploy, secrets, and unsafe data access.
- partner-ready Clean Rooms language without exposing partner data.
- a visible learning-to-architecture trail.

## What We Must Not Do

- scrape restricted sources.
- imply official tracking-data equivalence.
- imply live AWS readiness from docs.
- imply partner approval from synthetic demos.
- imply model gain without measured replay evidence.
- spend money before owner approval.
