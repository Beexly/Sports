# Privacy And Aggregation Rules

- Synthetic data only until partner/legal approval.
- No row-level exports.
- Minimum aggregation threshold per partner type.
- Default threshold for user/audience/operator data: 50-100 rows.
- No identity joins.
- No model training unless contract allows it.
- No source data moved to AWS unless registry permits storage.
- Every output must record source tables, aggregation level, and legal marker.
- Any row-level export is blocked.
