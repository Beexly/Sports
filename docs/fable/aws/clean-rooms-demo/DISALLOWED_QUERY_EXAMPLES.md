# Disallowed Query Examples

- Joining on user identity.
- Exporting row-level partner data.
- Reconstructing bettor, athlete, or account behavior.
- Querying below privacy threshold.
- Using partner data for model training without explicit contract.
- Exporting fixture rows below privacy threshold.
- Inferring individual player health from private team records.
- Using partner data to publish unsupported model-edge claims.
