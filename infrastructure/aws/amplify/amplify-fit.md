# Amplify Fit

Official AWS docs say Amplify Hosting supports SSR deployments for Next.js apps. This repo is a Next.js app, so Amplify is a possible preview-hosting candidate.

Fit checks required before live work:
- Build command and output directory.
- Runtime env vars.
- SSR route compatibility.
- Edge API route usage.
- Auth/session behavior.
- Image optimization behavior.
- Release-control decision versus existing hosting.

No live work is performed by this skeleton.
