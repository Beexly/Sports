# Frontier Kernel

GSE is a living, temporal, evidence-governed sports reality and decision-intelligence system.

Five compilers:
1. Reality Compiler: authorized observations -> versioned sports world.
2. Decision Compiler: user intent -> persistent Intelligence Contracts.
3. Capability Compiler: repos/APIs/models/data/docs -> tested capabilities.
4. Discovery Compiler: questions/residuals -> hypotheses, metrics, instruments.
5. Evolution Compiler: product friction -> bounded tested improvements.

SportsIR primitives:
Entity · Observation · Event · Claim · Measurement · State · Relation · Interaction · Intervention · Branch · Outcome · Proof.

Clocks:
occurredAt · publishedAt · observedAt · effectiveAt.

Frontier systems:
- adaptive cognitive sharding
- bitemporal WorldSnapshot and WorldDelta
- branching reality
- active sensing
- Capability Capsules and Capability Foundry
- hypothesis-to-instrument compilation
- multimodal scene hypergraph
- causal pressure field and agent-based Market Twin
- Model Ecology
- personal Decision Twin
- Product Twin
- spatial sports universe
- proof-carrying Reality Receipt
- shared reality/simulation kernel with Dynasty Studio

Implementation law:
- vertical slices, not big-bang rewrites
- one canonical truth path
- recover before recreate
- invariant before spectacle
- replayable object before additional consumers
- real data or honest unavailable state
- exact evidence/model/version/temporal receipt for visible conclusions
