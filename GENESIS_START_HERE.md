## First workstream

`GX-000` builds the missing unifying substrate:

1. **Codebase Twin v0** — a deterministic, queryable map of capabilities, symbols, routes, data paths, models, source gates, feature flags, tests, docs claims and relevant PR assets.
2. **Metacortex Plan Compiler v0** — a shadow-only planner that compiles one typed Intelligence Contract into candidate execution plans, rejects policy-invalid plans, selects the best valid plan, and emits a deterministic Plan Receipt.
3. **Collision and honesty report** — identifies duplicate capabilities, doctrine/code mismatches, unwired foundations and places where new work should extend existing assets rather than recreate them.

It does not execute models, fetch external data, alter scoring, migrate the database, add a public route, or influence production decisions.

## Why this is first

Galaxy already has many strong organs. The new failure risk is uncontrolled multiplication of parallel systems.

The Metacortex gives every later system one common path:

```text
INTENT
  → typed contract
  → capability and codebase graph
  → equivalent candidate plans
  → rights / privacy / trust / temporal constraints
  → information value / robustness / cost / latency / energy
  → shadow execution plan
  → proof-carrying receipt
```

That makes future expansion additive rather than duplicative.
