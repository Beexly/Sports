[ Navigator ]

Four phases.
Every one visible.

No black box, no proprietary hand-waving. Each phase declares its inputs, its outputs, and the gate that controls whether it runs at all. The same pipeline your eyes see is the pipeline the engine runs.

  1. PHASE
    01
    Ingest

    Pull live markets from multiple books.

    The pipeline runs on a 30-minute cadence, faster as kickoff approaches. Every odds row is stamped with bookmaker coverage so the pick card can show how thin or deep the consensus actually is.

    Input
    Live odds across 7 sports
    Output
    Normalized markets, timestamped per fetch
    Gate
    UNGATED — runs always
  2. PHASE
    02
    Score

    Project the edge with explicit uncertainty.

    The engine computes implied probabilities, weighs sharp line movement, evaluates head-to-head context, and looks at venue form. Every contributor is exposed in the factor breakdown so a serious reviewer can see what moved the dial.

    Input
    Normalized markets + canonical team-game logs
    Output
    Confidence range, edge, risk profile
    Gate
    DERIVED_MODEL_HISTORY
  3. PHASE
    03
    Publish

    Ship the pick — with its reasoning attached.

    A pick is only published when the public gate is open. Until calibration completes, confidence is shown as a label (Lean / Strong / Top Pick), never a number. The Ascent surface stays at Collecting until ≥100 canonical outcomes have settled.

    Input
    Engine output + readiness gates
    Output
    Card you see — pick, line, risk, freshness
    Gate
    PUBLIC_PICKS_ENABLED
  4. PHASE
    04
    Calibrate

    Learn from outcomes, not from prior reasoning.

    The model only learns from real settlement results paired with the signal state at prediction time. When a proposed weight change improves out-of-sample calibration, it lands in a versioned model bump — reviewed by a human, then surfaced on every future pick card.

    Input
    Settled outcomes + signal snapshot
    Output
    Calibration proposal, never a silent change
    Gate
    OUTCOME_LEARNING_ENABLED
