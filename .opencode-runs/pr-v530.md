Recovers a stranded local branch: `founder/week3-narrative-live-2026-09-27` (2 commits, 11 files), which has **no `origin` ref at all** and exists on exactly one laptop.

## Why this needed rescuing before merging

`docs/ops/queue-status.md` found that most of the "406 commits behind" backlog is a
false premise — those branches were re-rooted onto a fresh initial commit, so they
share no ancestor with main and every commit reads as "ahead". This one is different:
it shares a real ancestor with main and its content is genuinely unique. Of the
genuinely stranded set, this is the only one that moves `MODEL_VERSION`, so it is
also the only one where losing it would change published behaviour.

## What I verified before recommending it (not just cherry-picking)

- `constants.ts` diff touches **only** `MODEL_VERSION` (`v5.2.7` → `v5.3.0`). No
  confidence weight, no `MIN_PUBLISH_CONFIDENCE`, no env flag, no gate. That is the
  founder's freeze law, satisfied by construction rather than by assertion.
- The supporting doc exists on the branch and is honest:
  `docs/calibration-proposals/2026-09-27-narrative-contract-live-v5.3.0.md`,
  `status: IMPLEMENTED`, with holdout numbers in the doc (n=1942, r=+0.112232).
- The separate `2026-09-13-...-v5.3.0.md` is `status: PROPOSED` and is a *plan*;
  the 2026-09-27 doc is the IMPLEMENTED evidence. They are not the same document and
  the branch is backed by the second.
- `node scripts/guardrails/model-freeze.mjs` exits 0 on main at v5.2.7 and keys on
  an IMPLEMENTED proposal doc, so the v5.3.0 bump satisfies it.
- Branch carries 4 test-file changes alongside the source, so it is not a
  version-string-only bump.

## What this PR is and is not

It publishes the branch so the work stops existing on one machine. It does **not**
assert that v5.3.0 should be live. The "Model freeze" guardrail and full CI must
pass, and the one-line `constants.ts` change is a published-behaviour change
that a human should confirm deliberately.

Held-constant: heuristic confidence weights, `MIN_PUBLISH_CONFIDENCE`, all env
flags, and every feature map (still OFF).
