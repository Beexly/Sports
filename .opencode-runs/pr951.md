## The one code change

`provenance-integrity.test.ts` required a `#symbol` fragment in its regex, so all 22
module-only provenance claims were never collected. It reported 35 violations when
there are 52. A guard that misses 40% of its defect class while reading as a clean
bill of health is worse than no guard. Now fixed, with the count re-derived by a
second method before the constant moved.

## The three findings that matter most

**1. The free odds path cannot structurally produce a price.** `source-router.ts:95`
gives ESPN a `needs[]` array with no `odds` entry — scores, standings, rankings,
player_stats, team_stats. Every free source is facts-only. This is why
`lastSuccessAt` is null in production despite both paid keys being present and 600
credits/day provisioned.

**2. The airwave worker is a printer, not a partial implementation.** Four files,
~200 lines, zero capture/transcribe/extract/persist code — not even stubbed. But
the gap is bigger than a missing producer: ~5,300 lines of downstream control plane
and validators are built and tested, with **no database writer and no durable review
queue anywhere in the repo.** Blocked by two signature decisions and one data
dependency, not by engineering.

**3. The health check cannot report a partial odds failure.** `probeFailed` keys on
*games*, never odds, and only 503s when every sport hard-fails. Separately,
`route.ts:153` reads `if (hasOdds || true /* always attempt signal path */)` — the
`|| true` makes the key check unreachable — and `route.ts:104` passes
`oddsInserted: 0` as a literal on the row `/api/health` reads.

## One correction I owe

I reported six Cursor Cloud Agents as "ACTIVE" and "IDLE". Those states came from
the object `Agent.create()` returned to me, not from the server. Every read path
404s: `GET /v1/agents` returns an empty array, `GET /v1/agents/{id}` 404s on the very
IDs the API issued, `getStatus` does not exist. `send()` is write-only against this
surface, and agents work in ephemeral clones, so that quota is spent and the output
is unrecoverable. I should not have presented those as progress. Full measurement
and the `cursor-agent` name-squat warning are in
`docs/ops/cursor-cloud-agents-reachability.md`.

Also worth flagging for whoever picks up the backlog: the npm package
`cursor-agent@1.0.3` is a name-squat — it installs, reports a version, and ships
`bin: null` with no executable. The real integration is `@cursor/sdk`.
